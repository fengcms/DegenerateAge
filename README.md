# 末法纪元：最后的守护者

原生 macOS 单机斜角 RPG。已完成 P0 工程基础和 P1 手动战斗原型：八向移动、脚底碰撞、绕障寻路、镜头跟随、前后遮挡、腐化野狼巡逻/追击/普攻/死亡刷新、手动斩击与血量反馈。

需求基线：[docs/GDD.md](docs/GDD.md)。经验升级、掉落、装备、自动战斗及实际存档属于 P2；当前退出后不会保留战斗进度。

## 环境

macOS 14+，Swift 6.0+，Apple Command Line Tools 或完整 Xcode。无需第三方依赖、网络服务或正式美术资源。

验证环境：Apple Silicon，macOS 26.6.2，Swift 6.3.3，仅 Command Line Tools。完整 Xcode 工作流和最低 macOS 版本尚未实测。

## 构建和运行

在项目根目录执行：

```sh
swift build
swift run RuleChecks
./scripts/build-app.sh
open build/DegenerateAge.app
```

打包脚本生成本机开发 `.app`，包含 JSON 资源并进行 ad-hoc 签名，尚未配置发布签名与公证。安装完整 Xcode 后可打开 `Package.swift`。

## 操作

- WASD：按屏幕方向移动，组合键八向移动。
- 点击橙色野狼：选中目标，绕障接近并进行一次普攻；黄色边框表示选中。
- 按住 Space：对选中目标持续普攻，距离不足时接近；松开停止持续攻击。
- 移动键：立即取消点击触发的接近动作，保留已选目标。
- Esc：暂停/继续；应用进入后台也暂停，不补算后台时间。
- 死亡后点击“返回营地复活”：恢复满生命/法力，取消行动与目标。
- F3（部分键盘需 Fn）：切换开发调试显示，包括 FPS、节点数、世界坐标、目标 ID/状态、存活怪物数和路径节点数。

出生点位于野狼初始警戒范围外。野狼警戒半径 4 格，追击边界 7 格，死亡后 8 秒刷新。普通攻击间隔 0.8 秒；伤害由规则层独立结算。

## 工程边界

- `GameApp/App`：启动、依赖组装、会话。
- `GameApp/UI`：SwiftUI HUD/暂停/复活，以及 AppKit 键鼠适配。
- `GameApp/Scenes`：SpriteKit 场景、模拟时钟、反馈与镜头。
- `GameApp/Rendering`：等距坐标转换。
- `GameApp/Core`：独立 Codable 模型、导航网格/A*、碰撞与战斗模拟，无图形框架依赖。
- `GameApp/Data`：JSON 配置、加载、启动校验。
- `GameApp/Persistence`：P0 快照结构，P2 补齐字段、迁移与原子写入。
- `Tests`：当前工具链可运行的规则检查。

逻辑坐标按网格计量。64×32 等距投影采用 SpriteKit 向上 Y 轴；屏幕输入逆投影到世界后归一化，八向世界速度恒为 3 格/秒。导航和连续移动均禁止斜切障碍，寻路每 0.4 秒最多重算一次。场景按 60 Hz 固定步长推进，单帧最多处理 0.1 秒，防止后台恢复/卡顿产生瞬移。菱形地图四角显示中性背景。

## 验证

`swift run RuleChecks` 执行六组配置/快照检查和十一组 P1 检查，覆盖八向速度/方向、墙体、禁止斜切、A* 绕障/不可达、伤害、死亡一次结算/冷却/暂停/刷新、死亡复活、时间限幅、追击返回、巡逻，以及绕障击杀。失败返回非零状态。

当前 Command Line Tools 不包含 XCTest / Swift Testing，暂用独立检查程序。安装完整 Xcode 后应迁入标准框架；`swift test` 不是当前验收命令。

手动验收：

1. 启动后确认角色、野狼、障碍和 HUD 可见。
2. 用 WASD 及组合键移动，尝试撞墙、贴墙和通过障碍夹角。
3. 点击野狼，确认黄色选中边框、接近行为；按住空格击杀，查看伤害和击杀计数，等候刷新。
4. 引怪后跑远，确认怪物返回出生区域。
5. 暂停/切到后台，确认 HP、怪物位置和刷新不推进；恢复后再次操作。
6. 故意受击至死亡，确认不能移动/攻击，点击复活后恢复生命和键盘操作。
7. 调整窗口大小，检查 HUD、角色和镜头。
