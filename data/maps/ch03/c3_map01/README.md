# 断流渠岸

两条断渠夹出上下巡回路，倒伏水车形成偏心障碍。

兼任沉井镇与下街水市之间的步行过渡区；北侧通沉井镇，西侧通下街水市。

本轮地图轮廓为 193×108 格，通行掩码新增水渠北缘1、水渠西缘2、断渠残壁；主题地形与原障碍、出口及怪物刷新位一同编译和验收。
