# 聚金地脉

第七章 80 级循环金币图。从无尽回廊北侧入口步行进入，只能由无尽回廊抵达；出口在 `[6,24]`，回廊落点 `[8,24]`。全图危险区，入口到战场约 1,285px（满配约 3.6 秒，仅进图一次）。

96 个固定普通怪席位**全部近战**：6 种复用第六章普通怪（`c6_normal01/02/04/05/07/08`），2 种换成第五章的快速近战（`c5_normal05` 紫鳞潜猎者、`c5_normal08` 折翼掠兽，移速 3.1，会主动贴上来）。**工程 82 起收成单战场 6 营**（3 列 × 2 行，每营 4×4、格间距 2 格），8 个怪种每种每营 2 席，死亡后 15 秒独立重生。6 个营心为 `(35,29)`、`(27,21)`、`(42,22)`、`(34,14)`、`(49,15)`、`(41,7)`，营心行/列步长为等距斜向的 `(7,-7)` 与 `(-8,-8)`（世界列距 448px、行距 256px）。

🔴 **工程 83 换怪的原因**：原 `c6_normal03 失序刻印偶` / `c6_normal06 断誓游魂` 是 `attackRange.kind = ranged`（射程 6 格 = 384px），共 24 席，玩家站进营里会被隔着半个战场点名，战士必须逐个追 —— 与「站桩刷」直接冲突。换怪**只换外观与攻距**：两只新怪的 `goldFieldNormals` 基底逐值沿用被换掉的那两只（`1,781/451/155`、`1,504/379/130`），所以击杀击数、金币/s、`PaceTest` 三护栏全部不变。生成器用 `assert_gold_normals_melee()` 把「不许出现远程」固化在数据侧，`EndgameCycleMapTest` 在产物侧再验一次（配置 + 运行态 `is_ranged`）。

**站桩判据（与旧版相反）**：任意席位到战场中心 `(38,18)` 的世界距离 ≤ **652.7px**（阈值 = `ACTIVE_DISTANCE 760` 留 60px 余量），整片战场世界范围 1280×416px，一屏可见。旧版「堆心两两 ≥858px」保证的是「一次只激活一堆」——那正是玩家必须跑来跑去的根因，已在工程 82 反转。

两种怪为**金脉守卫**（`c6_normal02` / `c6_normal07`，24 席）：血量 ×6、攻击 ×1.5、金币 `1760–2240`（四倍）、装备必掉（`DT_C7_Gold_Guard`）。🔴 守卫是**刻意的净亏配比**（单位时间金币 ≈ ×0.67），定位是「掉落更好、值得打一会儿」，不是「刷钱更快」；按「收益应该更高」去改倍率就把产品定位改掉了。

**超杀保护**：`damageCapPct 0.5` —— 打金图普通怪单次命中扣血 ≤ 目标最大生命的 50%，只截扣血、飘字仍显示真实伤害。作用是掐掉「技能一击秒」（满配裂地斩 1 击 → 2 击），对 `common`/`rare` 档与 Boss 完全无影响。

每次生成按玩家等级（最低 80）投影数值，经验系数 `xpMultiplier 0.1`（等效 `boss_xp(L)/100`，使打金图升级速度与修复前持平或略慢）。地图同屏普通怪预算 32（收拢后第一次真正生效）；远处席位仅保留配置，不常驻实体。

配置由 `tools/build_c7_cycle_maps.py` 生成；布局也由该工具生成，不能只修改生成结果。编辑后同步本段说明并运行 `python3 tools/check_map_catalog.py --update`。
