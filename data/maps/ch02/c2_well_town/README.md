# 沉井镇

沉井镇是第 2 章地图，承担城镇服务与跨图中转。 地形与路线：西进东出的炉塔长街，八名人物围绕集中服务区而非分散四角。

西路经灰烬之地返营地，跨第三章的道路先抵断流渠岸；城镇间免费步行不再直接切图。
