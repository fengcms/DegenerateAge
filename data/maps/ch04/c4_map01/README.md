# 倒根驿路

倒根把旧路劈成三股，可沿根上缺口或根下土路绕行。

兼任下街水市与根驿营地之间的步行过渡区；北侧通下街水市，西侧通根驿营地。

本轮地图轮廓为 211×118 格，通行掩码新增盘根南缘1、盘根东缘2、交错盘根；主题地形与原障碍、出口及怪物刷新位一同编译和验收。

配置源：`map.json`；可通行布局见 `res://data/layouts/c4_map01.json`。
