## 城镇步行过渡

根驿营地向下街水市走需经倒根驿路，向断旗关走需经折旗长堤。车夫仍可按到访与解锁规则直达。

## 地形辨识度

本章采用「盘根与林隙」主题；各图采用独立尺寸组合与不同边缘缺口、内部障碍，怪物和任务点保留原坐标。布局由本章 `地图参考/*.json` 编译，详情见各图 README；目录内旧版 `*-标注.svg` / `*-纯布局.svg` 为历史创意预览，不能替代当前运行掩码。
