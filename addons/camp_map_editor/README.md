# 幸存者营地可视化地图编辑器

这是项目内的 Godot 编辑器插件，不需要另装应用。项目已在 `project.godot` 启用；重新打开 Godot 项目后，在顶部 **2D／3D／脚本** 旁点击 **营地地图**。若正在使用修复前打开的编辑器窗口，请在「项目 → 项目设置 → 插件」将「幸存者营地地图编辑」关闭再启用，或重启 Godot 项目，让编辑器重新加载插件脚本。

当前版本以正式营地为起点，可拖动现有 7 个整体实体与 4 段围栏，可拖动主路及支路的现有控制点。对象整体平移时，美术矩形、脚底层级、视觉轮廓和单个整体碰撞一起移动。顶部按钮提供两种模式、撤销、重做、保存草稿、应用到游戏和重新载入；画布左键拖动、滚轮缩放、中键平移。右侧可点选对象，碰撞轮廓和 NPC 落点可独立显示。

**保存草稿**只写 `data/map_art/camp_editor_draft.json`，游戏不会加载它。**应用到游戏**先校验正式源哈希、对象整体移动、画布边界、NPC／出入口／出生与刷新格、马车落点及连通性，再调用 `tools/build_camp_whitebox.py` 和 `tools/build_camp_style_full_b_v2.py` 同步重建正式布局、道路贴图和实体清单。失败时原正式文件保留；成功后草稿删除。若别的任务在编辑期间修改了正式布局，应用会拒绝，需重新载入。道路模式用青色线显示草稿路径；原道路贴图要点击「应用到游戏」后才会重建。

当前限制：只编辑**既有对象的位置**和**既有道路控制点**；不能新增／删除物件、改变物件尺寸、绘制新地面或编辑碰撞顶点，也不会挪动 NPC 和地图尺寸。这是营地试点，尚未扩展到其他地图。被拖出画布、挡住固定 NPC 或切断通路的改动会被拒绝。进入游戏检验时重新加载营地场景。

编辑器代码分工：`camp_map_document.gd` 管理当前布局、撤销与草稿；`camp_map_canvas.gd` 画矩形画布并处理鼠标；`camp_map_panel.gd` 提供操作面板；`plugin.gd` 接入 Godot 主屏幕。运行游戏不实例化这些编辑器节点。

主屏幕标签回归检查：`/Applications/Godot.app/Contents/MacOS/Godot --headless --editor --path . --script res://tests/camp_map_editor_main_screen_test.gd`。退出码为 0 表示实际编辑器中已创建页面和可见的「营地地图」标签；本测试只读检查编辑器 UI，不修改地图。
