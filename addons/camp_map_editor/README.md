# 幸存者营地可视化地图编辑器

这是项目内的 Godot 编辑器插件，不需要另装应用。项目已在 `project.godot` 启用；重新打开 Godot 项目后，在顶部 **2D／3D／脚本** 旁点击 **营地地图**。若正在使用修复前打开的编辑器窗口，请在「项目 → 项目设置 → 插件」将「幸存者营地地图编辑」关闭再启用，或重启 Godot 项目，让编辑器重新加载插件脚本。

当前版本以正式营地为起点，顶部有四种编辑模式：

- **绘制地面**：右侧选择草簇、碎石、石板或土纹笔刷，在 128×128 画布格上左键点涂或拖涂；选择「擦除覆盖」恢复原来的地纹。四种笔刷从现有营地地面源图裁出，边缘透明渐变，底下仍是原循环地纹。地面笔刷只改外观，不改通行。
- **编辑碰撞**：在画面或右侧列表选择房屋、树、马车、灯、营火或围栏。拖动橙色顶点改变整体碰撞轮廓；Shift 点击边可插入顶点，右键点击顶点可删除，最少保留三点。美术矩形独立保留，编辑碰撞时房屋贴图不会跟着拉伸。应用时重建白盒通行与游戏中的单体碰撞，并校验固定 NPC、出入口、出生点和连通性。
- **移动整体物件**：拖动现有 7 个实体或 4 段围栏，整体移动美术、脚底层级和碰撞。
- **调整道路节点**：拖动主路及支路的现有控制点；正式道路贴图在应用后重建。

四种模式共用撤销、重做、保存草稿、应用到游戏和重新载入。画布滚轮缩放、中键平移；碰撞轮廓和 NPC 落点可独立显示。

**保存草稿**只写 `data/map_art/camp_editor_draft.json`，游戏不会加载它。**应用到游戏**先校验正式源哈希、地面格和碰撞多边形、画布边界、NPC／出入口／出生与刷新格、马车落点及连通性，再调用 `tools/build_camp_whitebox.py` 和 `tools/build_camp_style_full_b_v2.py` 同步重建正式布局、地面覆盖层、道路贴图和实体清单。失败时原正式文件保留；成功后草稿删除。若别的任务在编辑期间修改了正式布局，应用会拒绝，需重新载入。道路模式用青色线显示草稿路径；原道路贴图要点击「应用到游戏」后才会重建。

当前限制：可以编辑既有对象的位置与碰撞，以及 128 像素地面格的装饰笔刷，但不能新增／删除整体物件、替换其美术源图、改变 NPC 或地图尺寸。这是营地试点，尚未扩展到其他地图。碰撞轮廓越界、自交、挡住固定 NPC 或切断通路的改动会被拒绝。进入游戏检验时重新加载营地场景。

编辑器代码分工：`camp_map_document.gd` 管理当前布局、撤销与草稿；`camp_map_canvas.gd` 画矩形画布并处理鼠标；`camp_map_panel.gd` 提供操作面板；`plugin.gd` 接入 Godot 主屏幕。运行游戏不实例化这些编辑器节点。

主屏幕标签回归检查：`/Applications/Godot.app/Contents/MacOS/Godot --headless --editor --path . --script res://tests/camp_map_editor_main_screen_test.gd`。退出码为 0 表示实际编辑器中已创建页面和可见的「营地地图」标签；本测试只读检查编辑器 UI，不修改地图。
