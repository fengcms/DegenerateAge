# 第一章横向地图工程与美术重制计划

日期：2026-10-14。布局版本：`2026-10-14-landscape-v2`。

本计划只推进第一章地图重布局。尺寸、坐标与文件以[统一规格17](17-两章横向16比9地图统一规格与交接.md)为准，怪群与玩法目标见[第一章方案14](14-第一章地图扩大与怪群重设计方案.md)。第二章分别交工程计划15、美术计划16，避免两个AI改动同一套地图数据。

## 1. 第一章制作基准

| 地图 | 逻辑尺寸 | 普通位 | 精英位 | Boss位 |
|---|---|---:|---:|---:|
| 幸存者营地 | 64×36 | 3木桩 | 0 | 0 |
| 试炼野外 | 176×99 | 72 | 3 | 0 |
| 灰烬之地 | 192×108 | 96 | 4 | 0 |
| 腐化源头 | 160×90 | 48 | 4 | 1 |

横向16:9指正交逻辑布局，不是最终游戏投影轮廓。角色、瓦片、攻击范围与移动速度不拉伸。营地功能服务集中；源头Boss场局部可为圆形，不把整图改回方形。

## 2. 工程开发AI任务

### F0：确认工作区与资源接口

核对当前第一章实现与正在进行的美术修改，保留其他AI未提交工作。登记十字路口、任务目标、地图状态、刷怪与资产依赖；只将明确属于本批的文件提交。采用统一布局版本，旧坐标停止作为落图依据。

### F1：野外样板

按176×99编译可走网格、碰撞与相机边界，落地横向商路、北侧岩坡、南草地及4怪区。导航与渲染使用同一数据；玩家、怪物和地图点击移动全部绕障。

设置稳定刷新位、怪群激活和刷新排除区，按14的物种预算拆分；自动巡回可衔接普通怪区，不自行使用出口。先用占位验证主路、旁支、低级接敌和持续战斗，再让美术批量摆放。

### F2：灰烬与源头

灰烬按192×108落实横向长街及6怪区，源头按160×90替换旧洞穴遮罩与地标。不能只改maps尺寸而保留50×50专用CaveLayout、旧walkable_rows或出生点。

源头Boss区不投放普通刷新点，外围精英不闯入观察前室。普通远程攻击能力以当前代码为准，不让美术墙体在没有遮挡判定时被宣称可挡弹。

### F3：营地与交通

按64×36重排服务区与3木桩，所有入口、驿站、休整区、NPC交互位置同步迁移。将camp↔野外↔灰烬↔源头以及camp↔沉井镇成对更新；沉井镇未发布时保留锁定路牌，不开放无效地图。

沿用现有车夫范围、价格、到访和剧情条件；不以重布局为由增加费用或改变任务数量。

### F4：存档迁移与资源整合

保存地图布局版本；旧玩家位置、迷雾、未领取物和刷新位迁移规则按14执行。重点保留Boss剩余刷新、首通、任务奖励与物品实例，失效位置移到合法落点并提示，不重复奖励。

按美术manifest接入地面/建筑/装饰，先检查脚底与占地，再检查遮挡、文字、预警和大视野。已有角色动画和UI并非本批重做范围，接入时不覆盖其他AI工作。

### F5：开发验收

开发阶段做隔离验证与原生窗口试玩：第一章新档完整主线、旧档恢复、道路零金币返程、卡墙/斜穿角、满包战利品、Boss刷新、不同显示倍率与连续挂机。参考图只验证了静态点路径，不代表这些玩法通过。

交付本批提交号、原生截图、可试玩包、已知问题和资源版本。性能与收益调整单独记录，根据已有用户确认推进，避免重复审批相同事项。

## 3. 美术AI任务

### V0：保留可复用资产

盘点现有营地、野外、灰烬、洞穴地砖和装饰，沿用已通过的像素密度、方向和主光。旧人物、图标、怪物动画不横向拉伸，不因关卡变长重新生成人物。

### V1：野外样板

读取新版纯色图、标注图和JSON，制作岩坡/岩脊、旧商路、草地、虫蚀石碑与狼王旁支地标。按工程确认的通道净宽摆放，不先绘成不可拆整图。样板在新手接敌与密集刷怪实景里通过后再推广。

### V2：其余地图模块

灰烬：用长街、分段废屋、输灵管沟表达横向街区，路面与障碍对比清楚。源头：岩洞前庭、北/南侧洞室、封印外环、东侧巨兽场，机械/封印装饰不遮挡危险预警。营地：灯旁服务街、两侧建筑和短训练路，避免功能NPC被门檐遮住。

障碍占地、前景遮挡、纯装饰分层并提供锚点与建议占格。精英/Boss位置由工程实体控制，不烘焙怪物、名字、血条到地图。

### V3：交付与整合修订

manifest记录map_id、布局版本、asset_id、路径、尺寸、脚底锚点、建议占地、图层、源文件和生成记录。交付模块、摆放参考与预览；运行资产由工程接入。导航图、标题、浅线和区域标签不画入正式素材。

资源清单与工程占地不一致时先标记受影响模块，再局部修改，不自行移动出口或强行堵路。按工程反馈完成接缝、透明边、遮挡与预警可读性修订。

## 4. 对接顺序

F0/V0统一契约 → F1/V1野外样板 → F2/V2推广 → F3营地交通 → F4/V3整合迁移 → F5验收。工程可用占位推进，美术可复用现有模块并行制作；样板净宽或关键点位变化必须更新版本并通知另一方。

本轮只交付计划，未执行游戏开发或实机验收。
