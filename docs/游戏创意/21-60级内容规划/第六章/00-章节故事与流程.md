# 第6章《最后的镇脉台》故事与流程

2026-10-15，2026-10-15-content-v1。产品执行稿；数值为待实机校准候选，尚未接入游戏。本文由`制作工具/内容定义.py`与生成器导出，修改事实源后重建，勿只改衍生表。

**章节承诺：让守护不再意味着把一个人留在机器里。** 推荐等级51—60；可从前章末整十级进入，无新增等级硬锁。

## 第一幕：把停机条件写在前面

陆衡和岑素寄来的记录先于主角抵达前哨。独立班组带来的不是一台更大的机器，而是所有人都能看见的调度表。卫澄把停止条件挂在启动条件之上。符素根据岑素的见证信认出旧守护工程的标记：主角属于能够暂存逸散灵能的守护体，原设计应由多段通路共同回注，并非把一个人烧成灯芯。

## 第二幕：谁有资格回来

兵库的守誓审判体还在执行把守护体留在核心的旧命令。程霁没有交出一张更高的官印，而是让主角取得能解除错误资格判定的原始誓条。击败审判体后，程录把第三章警报、第四章证词与第五章相位凭据合并，证明人类的隐瞒和异族的利用共同维持了裂隙。

## 第三幕：每一条旁路都有人

分流环室中，玩家清除侵入旁路的析出体，取回由明确目标保证获得的校验片。林照确认核心通道与撤退路线都能使用。前代残响是可选训练场：它展示当年最后一段错误指令，不掌握主线唯一钥匙。符素选择留在能叫停流量的值守台，不让见证人的记录只停留在纸面。

## 第四幕：守护者不是熔断器

空天之眼占据屏障漏洞，试图诱导主角把所有能量一次回注。主角清除侵入核心；最后回注由 NPC 对话和持久状态表达，按既定分段流程完成。角色吸收过的灵能提供了调谐特征，回注消耗的是核心储能及持续泄漏的流量，不删除玩家经验、装备或星级。林照喊停一次，卫澄真的停止了一段调度，证明人终于能拒绝机器。

## 尾声：最后一页不是终止

核心击杀后世界尚未结算结局，主角回前哨向程录交付。屏障被修复，水、驿信、撤离和营地灯火以短对白逐一回应。程录写下所有协作者；石辕问主角先去哪里。主线完成后等级继续，敌人复刷解释为裂隙留下的残留构型，而非世界从未得救。

## 叙事执行边界

主线线性、一次性；所有关键目标有确定路径。击杀首领只完成目标，领奖才开放下一路。支线不发主线必需钥匙。物理地形以地图JSON为准，文本状态用已领奖标记驱动；不模拟真实水流、根系生长、群众护送或能源管网。
