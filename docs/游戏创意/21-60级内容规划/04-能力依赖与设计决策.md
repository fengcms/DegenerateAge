# 能力依赖与设计决策

2026-10-15，产品侧文件阅读基线。工程、数值和美术工作区同时变化，本文记录设计采用的职责边界，不宣称运行验证。

## 能力盘点

| 能力 | 阅读依据/状态 | 本包采用方式 |
|---|---|---|
| 逐级装备 | equipmentRules.ruleVersion=4，slotOrder十部位；模板requiredLevel，tierBases按套起点；工作区正在接入 | 用21/31/41/51四套起点及各部位真实等级；倍率按套，穿戴/出售筛选按真实等级 |
| 品质/升星 | ItemFactory、Equipment、Upgrade；倍率1/1.2/1.5/1.9/2.4，0—4词条、12星、每星0.1 | 复用；不增加其他成长系统 |
| 可用技能 | HotbarConfig.ACTIVE_SKILLS仅basic_slash、earth_cleave、whirlwind、battle_focus；player.cast_skill逐一过滤 | 全主线以这四项可通关；25破甲/40风暴仅配置存在，列工程扩展，不纳入最低输出假设；50/60不新增技能 |
| 任务 | Quest kill/collect/talk，MAX_ACTIVE=5；谈话支持talkOnAccept；前置按rewarded推导 | 本包全部目标只用这三类；野外对话由该野外NPC自己发布并talkOnAccept完成，跨NPC交付单独turnIn，不把接任务当已找过另一个人 |
| 任务道具 | collect使用击杀来源的确定任务掉落、quest_items状态 | 新道具名由任务定义，不随机进入装备池；接取后指定怪100%给一件至数量足够；放弃重新计数/清任务计数，不能复制装备 |
| 地图/门禁 | MapService、CaveLayout、任务unlocks及当前路由 | 单图加载、静态地形，任务领奖解锁边；不用升降机/多层导航 |
| 刷新预算 | Spawner的普通预算10只限定c2_前缀 | 新章必须推广成地图配置，设计候选普通10、精英2、Boss1同图；不能指望新前缀自动受限 |
| AI与首领招式 | Monster当前基础追击与有限special/bossSkill；本包所述新形状/节奏未逐项实现 | 所有新招式明确作为工程需求；先交预警与固定形状，无强制护送/弹幕系统 |
| 存档/世界状态 | SaveManager与spawn_respawn/visited/unlocks | 只追加内容ID和状态；所有新图未发布时隐藏入口；升级版本须核实最新schema，不能硬写历史版本号 |
| 美术 | 地面64×32图集、角色动画资源库、UI物品图标 | 参考图不直接当运行贴图；按图集/角色家族复用，不给每只怪独立动态材质 |

## 采用的产品决定

D01：四章范围和制作数量按已确认纲领执行，21—30/31—40/41—50/51—60。跨章入口为上一章尾声领奖，不新增等级硬门槛；推荐进入等级为21/31/41/51，经验预算从前一整十级0经验算起。

D02：不新增主线必须的机关目标类型，所有“修复/配水/回流”通过确定收集、击杀与NPC对话的世界状态表达。地图地标可调查但不另加必需计数。清路任务不生成需要AI护送的群众，人员通过完成文本离开。

D03：全新主线仅用已有四技能；新技能可作为后续工程独立增量，未接通时不显示可用按钮。没有传说、没有+12也能按目标配装通关。数值候选须后续实机校准。

D04：第六章不移动旧服务NPC。卫澄等前哨人员实施已学会的流程；陆衡、祁言、岑素等通过有署名的书信参与，主线线索由新记录员程录整理。旧支线交付人永远可达。

D05：地图尺寸均不超过240×135格，25图全由产品提供矢量布局与格坐标。图像不是可直接贴入运行场景的最终美术。静态几何校核不能替代角色半径、等距投影和实际移动验证。

D06：所有门禁只限制出口通往下一地图，返回边保持可用；目标任务只出现在已可达地图，避免“取钥匙的NPC在钥匙门后”。可选首领有独立支线，不发主线钥匙。

D07：普通掉率20%；精英2—3白蓝+1绿金；Boss5—8白蓝+2绿金+5%独立追加传说，保留装备雨。独立额外件不是每个装备槽5%；首通不保证传说。精英随机传说不开额外特例。

D08：经验公式与药品/升星价格保持当前代码；新敌经验按等级曲线推导，任务XP按章预算分配。金币、掉落装备出售和消耗有一套可复算账。持续战斗密度目标必须在有限活动预算下实现，不能靠同时刷数百只。
