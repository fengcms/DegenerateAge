### 4.4 落地注意（务必与既有规范对齐）

1. **尺寸**：运行图 48×48；源稿可 192×192，但**不得进入运行依赖**（[91](91-美术AI制作与接入计划.md) §5）。
2. **品质色不染本体**：品质色（白／蓝／绿／金／紫）由 UI 叠加边框，**不把装备本体永久染成一种品质**；普通布鞋与传说布鞋基础轮廓一致（[91](91-美术AI制作与接入计划.md) §5）。
3. **双槽复用**：护腕／护膝／手镯／戒指各为双槽，**同一型号左右共用同一图标**（[91](91-美术AI制作与接入计划.md) §2）。
4. **星级是 UI 标记**：+12 标记不得遮住数量、评分箭头或拖拽预览（[91](91-美术AI制作与接入计划.md) §5）。
5. **当前状态**：本批 **50 张**图标（第二章 10 ＋ 第三至六章 40）**尚未制作**，数据表暂以第一章基础图标占位；完成前不得在验收中声称「装备美术已交付」。
6. **第二章另有画布契约**：世界地面图按 32×32 独立输出，普通怪 12—20 实色、Boss 可到 32 色（[16](../16-第二章美术AI制作计划.md) §5／§6）；若第二章图标与第三至六章图标同批生成，需保持同一 48×48 与限量色口径，避免两批风格断裂。
