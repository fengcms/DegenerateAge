# 第5章《紫潮边境》故事与流程

2026-10-15，2026-10-15-content-v1。产品执行稿；数值为待实机校准候选，尚未接入游戏。本文由`制作工具/内容定义.py`与生成器导出，修改事实源后重建，勿只改衍生表。

**章节承诺：让撤离名单上的人真正走过关门。** 推荐等级41—50；可从前章末整十级进入，无新增等级硬锁。

## 第一幕：关内也有前线

断旗关墙上仍有完整军旗，内街却挤满没有名字的伤员。韩照最初想让主角先夺回号台，温缄坚持必须先清出营道。两人的争执不是勇敢与怯懦，而是号台和担架都需要同一批人。主角先联系顾烽，确认外线军情，再让测隙师裴炬比对林海的回流图。

## 第二幕：命令的回音

驭潮号将倒下，前哨信号恢复。主角从渡火营道带回通行标片，韩照据此公开安排撤离，不再要求每个人守到最后一刻。营道上的救援通过清路和 NPC 确认表现，不要求脆弱护送对象跟着玩家穿怪群。

## 第三幕：敌人的借口与证人

迟砚来自被统帅征用的异界舟民。他知道相位频率，但要求先让仍有意识的遗民离开裂舟泊位。主角见到异界资源同样枯竭，却也听见迟砚明确承认侵略责任。可选噬骨者占另一泊位，主线所需证词从迟砚处取得，不靠击杀它。

## 第四幕：先交接这道门

逆风军团长以封锁门哨阻断撤离。主角打通关门，孟归确认后卫与前哨完成交接，然后才交出核心通道凭据。执灯者提出用人类土地养活自己的军团。主角拒绝这种把灾难继续转嫁的秩序，击败统帅并夺得通道控制。

## 尾声：最后一班返回

陆辕回来时车厢是空的，因为最后一批伤员已提前转走。穆禾把漏记的孩子从出征册划出，写进到达册。主角带着相位钥前往镇脉台，战争没有一句话结束，但人类终于能选择关上通道。

主线线性、一次性；所有关键目标有确定路径。击杀首领只完成目标，领奖才开放下一路。支线不发主线必需钥匙。物理地形以地图JSON为准，文本状态用已领奖标记驱动；不模拟真实水流、根系生长、群众护送或能源管网。
