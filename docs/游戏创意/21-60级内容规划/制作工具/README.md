# 内容制作与维护工具

本目录维护产品内容源、可重建的章包和设计静态校核。所有文件只服务文档，不被游戏加载，内容总表.json也不是正式data格式。

## 文件职责

- 内容定义.py：手写故事、NPC、地图、敌人、装备名称、任务原话。只在此修改作者内容。
- 生成内容包.py：将源内容与明确的规则生成24章文档、02成长表、03登记、25坐标JSON、50SVG及结构化总表，并检查联合门禁/前置图和静态连通。只覆盖这些衍生产物。
- 生成地图预览.py：读取内容总表，使用Pillow绘制PNG总览及生成HTML索引，不修改已有图片素材。
- 内容总表.json：全部设计对象与关联的交换格式；保留runtime=false，适配正式字段后才可接入。
- 内容校核记录.json：最近一次成功生成的数量、静态校核结论和读取的正式文件SHA256。它不证明游戏运行结果。

## 重建

在仓库根使用独立Python进程运行，避免多次调用已转换的内存对象：

```bash
python3 docs/游戏创意/21-60级内容规划/制作工具/生成内容包.py
# 带Pillow和中文字体的Python；Codex随附Python可用
/Users/fungleo/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 docs/游戏创意/21-60级内容规划/制作工具/生成地图预览.py
```

第一条仅依赖标准库；第二条依赖Pillow，字体优先macOS STHeiti，其次Linux NotoSansCJK。其他机器可换具有相同依赖的Python路径，不把个人缓存路径用于运行游戏。作者不负责通过生成器修改00/01/04/90/91/92这些手写总表与交接，它们需要同步编辑。

生成过程在引用缺失、主线依赖支线、任务目标无来源、任务/门禁互锁、关键点或刷新位不连通时失败，不输出新的通过记录。失败后修内容源再重建，不删除断言或放宽规则凑通过。

地图规范：SVG画面1600×1020，内部逻辑地图1440×810（16:9）；纯布局图仅地图内标出口，标注版含路线与职责点。坐标为格，布局版本与正文一致。地图总览PNG2000×1590，仅文档预览。SVG和PNG不能直接当游戏地面图。

结构检查只核对静态四邻接和一格余量；不包含实际角色半径、等距世界坐标、UI点击、物理、AI、战斗、随机波动或性能。工程验收条件见90，素材验收条件见91。
