# Boss与精英外观、多件掉落及装备雨产品方案

日期：2026-10-12。版本：v1.0，开发交接用产品方案。

> **2026-10-14 装备规则覆写：**本文件的精英/Boss掉落件数、品质权重、5%独立传说追加及未领保护继续有效；“传说专属模板/固定词条/专属池”“逐级装备等级”等段落由[三轴装备模型实施规划](../工程文档/26-装备等级品质星级三轴模型实施规划.md)及产品 05 替代。

用户已认可改进方向。本文件明确首版目标规则，替代创意文档06中这三项的候选参数；它尚未修改正式产品基线与游戏实现。本文数值为本轮执行起点，后续调整须记录版本，开发时不自行改变概率与件数。

## 1. 目标与范围

玩家在敌人未攻击时就能识别普通怪、精英与Boss。每次精英死亡获得多件物品，每次Boss死亡出现清楚可见的装备雨，稳定获得多件装备和至少两件好装备，另有机会得到最高品质。

覆盖第一章裂爪狼王与腐化巨兽，机制支持其他精英与Boss复用。普通怪的外观尺寸、掉落表和刷新时间沿用现有规则。本方案不调整地图尺寸、怪物密度、主动技能或Boss伤害。

交付包含：敌人外观层次、Boss血条、分组掉落、品质分配、传奇属性下限、战利品展示、溢出保护及数据验收口径。无需正式美术素材。

## 3. 品质术语

使用正式产品文档05的枚举与颜色，避免另造一套品质系统。

| 枚举 | 显示名 | 颜色 | 本方案中的角色 |
|---|---|---|---|
| common | 普通 | 白 | 数量感、出售资源 |
| uncommon | 优秀 | 蓝 | 精英基础奖励、过渡装备 |
| rare | 稀有 | 绿 | Boss保底好装备 |
| epic | 史诗 | 黄 | 高品质惊喜 |
| legendary | 传说 | 紫 | 本章最高品质奖励 |

此前创意文档中的“优良”“传奇”分别对应优秀与传说。后续界面统一使用本表名称。

## 4. 敌人视觉规格

所有像素尺寸以当前游戏世界坐标、默认缩放为参考；UI尺寸随既有UI缩放变化。视觉大小与碰撞、攻击距离、仇恨半径分开配置。

| 项目 | 普通怪 | 精英裂爪狼王 | Boss腐化巨兽 |
|---|---|---|---|
| 身体视觉基准 | 沿用半径13 | 基准半径19，约普通1.46倍 | 基准半径36，约普通2.77倍 |
| 轮廓 | 沿用 | 高肩、尖耳、单侧大爪，金色双描边 | 双角、双爪、胸前封印环，多部件轮廓 |
| 地面识别 | 沿用 | 金色菱形精英符号，不闪烁 | 暗红粗环加四个外向刻度，与技能预警区分 |
| 名字 | 沿用 | 常显“精英 · 裂爪狼王” | 常显“Boss · 腐化巨兽” |
| 头顶血条 | 沿用34×4 | 64×6 | 100×8 |
| 受击闪白 | 沿用 | 不覆盖金边与符号 | 不覆盖封印环与Boss标识 |

选中标识继续使用现有青色外环，但应在对应身体轮廓外绘制，不能固定普通怪尺寸。死亡时识别符号与血条一并退出，不残留成可选目标。

占位外观使用多边形、圆环、线段表达，不要求贴图。金边、轮廓与文字是精英识别的常驻信息；Boss的狂暴变色只是阶段反馈，不能承担常态辨识。

### Boss独立血条

进入Boss仇恨战斗或玩家主动命中Boss时显示顶部血条；仅经过远处不显示。顶部居中，默认宽480、高18，避开既有HUD。显示名字、当前HP/最大HP与阶段名；60%和30%位置绘制刻度，不把刻度当作额外护盾。

阶段名固定为“封印束缚”“封印开裂”“腐化狂暴”，对应既有三阶段。随血量更新，未进入阶段不播放额外剧情。

Boss死亡后血条归零，保留0.6秒后淡出。脱离战斗后3秒隐藏；再次交战显示当前实际血量。暂停冻结计时，切图清理。当前首章只有一只地图Boss；若将来同时有多Boss，优先显示玩家当前攻击目标，其他规则另行扩展。

### 死亡表现

精英：0至0.25秒收缩倒下，金色轮廓淡出。Boss：0至0.45秒下沉与封印环破裂，0.45至0.70秒身体淡出。死亡结算在死亡确认帧执行，不等待表现结束；死亡后立即停止攻击和碰撞阻挡。

保留场内剩余敌人的正常战斗，不强制暂停、不锁玩家移动、不执行镜头震动。掉落落点以死亡位置为中心；尸体表现不得遮挡装备。

## 5. 精英掉落：每次3至4件装备

| 分组 | 件数 | 掉落概率 | 每件品质分配 |
|---|---:|---:|---|
| 基础装备 | 2或3，各50% | 100% | 普通70%、优秀30% |
| 好装备 | 固定1 | 100% | 优秀70%、稀有27%、史诗3% |
| 金币 | 一份 | 100% | 沿用48至72，整数等概率 |
| 小型生命药水 | 固定1瓶 | 100% | potion_hp_small |

每次合计3至4件装备、1瓶药水和1份金币，期望装备数3.5。精英不掉传说，不掉Boss专属如意。替换原40%药水条目，不能额外再执行旧表造成重复。

第一章精英所有装备生成等级在3至5之间，整数等概率。基础槽与好装备槽各次抽取独立，不限制重复槽位或重复模板；相同模板仍需唯一实例ID。

精英至少1件优秀以上，30%概率获得稀有或史诗好装备。掉落与精英随机词缀数量无关，词缀不重复加奖。

## 6. Boss掉落：每次7至10件装备，传说独立追加

| 分组 | 件数 | 掉落概率 | 每件品质分配 |
|---|---:|---:|---|
| 基础装备 | 5、6、7、8，各25% | 100% | 普通70%、优秀30% |
| 好装备 | 固定2 | 100% | 稀有75%、史诗25% |
| 传说追加 | 固定1 | 每次击杀独立5% | 传说100%，指定本章传说池 |
| 金币 | 一份 | 100% | 沿用720至880，整数等概率 |
| 大型生命药水 | 固定2瓶 | 100% | potion_hp_large，可生成一个count=2物品包 |
| 如意 | 固定1份 | 30% | rune_iron与rune_jade各50% |

未触发传说时7至10件装备；触发时8至11件。两件好装备均保底稀有以上。基础装备数量和各品质抽取彼此独立；好装备两槽也独立。

概率解释：两件好装备均为稀有56.25%，一稀有一史诗37.5%，两史诗6.25%；至少一件史诗43.75%。传说独立追加，不替换任何保底物品，不对每个装备槽重复做5%判定。

期望每次装备数为6.5+2+0.05=8.55，其中史诗期望0.5件、传说期望0.05件。20次击杀是平均每件传说对应的击杀数量，不是20次必掉。本版不增加保底计数。

第一章Boss装备生成等级9或10，各50%。如意判定只执行一次；不得重复结算怪物模板goldReward。旧Boss装备、药水与如意条目由本表完整替换。

每次重复击杀执行相同掉落规则；首次击杀标记、章节解锁与Q005任务奖励沿用独立结算，不增加隐含的首杀装备倍率。

## 7. 装备池与传说价值

### 普通至史诗

沿用现有非debug、Tier1模板池及等级缩放规则；模板内等概率抽取，品质由本方案指定槽决定。词缀沿用现有生成：普通0条、优秀1条、稀有1至2条、史诗2至3条；稀有和史诗的百分比词缀继续按既有规则执行。

传说专属模板必须排除在普通至史诗随机池之外，不能被抽成白装。不得从debug武器生成任何正式掉落。固定任务奖励仍由任务系统生成，掉落表不额外复制任务奖励。

### 首章传说池

本版指定一件传说武器“镇脉之刃”，候选正式ID为weapon_legendary_vein_guard；只有本章传说追加槽可生成。先实现明确属性价值，不依赖尚不存在的被动执行器。

| 属性 | 执行规格 |
|---|---|
| 槽位与Tier | weapon；Tier1 |
| 基础攻击 | 30，基准等级9；Lv10按既有8%等级缩放得到32 |
| 固定攻击词条 | atk +6，直接写入实例，不再次随机 |
| 固定生命词条 | hp +20，直接写入实例，不再次随机 |
| 品质 | legendary，显示“传说” |
| 生成等级 | 9或10，等概率；穿戴门槛与既有Tier1规则一致 |
| 初始星级 | 0 |
| 基准价格字段 | price=300；出售仍执行现有品质/星级规则 |
| 独特被动 | 本版无；说明不得承诺范围攻击或额外触发效果 |
| 描述 | “封印曾借这柄刃导回灵能。刻纹还亮着，握住它的人却换了一代。” |

该物品使用固定属性路径；现有传奇随机生成跳过词缀的路径不能吞掉上述固定词条。价格只作为经济起点，实际售价依现有结算口径，掉落方案不另发金币补偿。

启动校验必须确认传说池有效且非空、模板存在、非debug、等级与Tier适配、所有品质概率合计100%。配置非法时明确报错，不能静默少发保底好装备或用普通装备替代传说。

## 8. 奖励结算与入包规则

确认死亡后先生成整个掉落批次。批次有唯一ID，各装备有唯一实例ID，随机结果只生成一次。暂停、重载表现、重复死亡信号均不得再次抽取或发奖。

认领在死亡结算帧执行，与动画完成无关。入包顺序：传说→史诗→稀有→优秀→普通；同品质按生成序号。之后处理药水和如意，金币独立入账。只有能够真正入包的物品才标记已领取。

高品质优先只影响背包空间分配，展示仍按照下一节的基础、好装备、传说顺序。背包可立即打开查看已认领物品。关闭自动拾取G不会阻止生成即认领；G仍控制未领取物的顺路拾取。

金币到上限时，先入账可容纳部分，剩余金币作为同批未领取奖励保留；不能重复生成完整金币包。装备不自动出售，不覆盖旧装备，也不自动穿戴。

## 9. 装备雨展示规格

### 时序

时间均从确认死亡的游戏时间t=0计算，暂停与后台冻结。出生动画与结算分开，奖励已结算不代表立即播放拾取飞行。

| 阶段 | 精英 | Boss |
|---|---|---|
| 基础装备、金币、药水出场 | t=0.15起，每份间隔0.05秒 | t=0.45起，每份间隔0.05秒 |
| 好装备出场 | 前组最后一份出场后0.15秒 | 前组最后一份出场后0.20秒，两件间隔0.15秒 |
| 传说出场 | 无 | 最后一件好装备出场后0.25秒 |
| 每份出场落地动画 | 0.25秒 | 0.30秒 |
| 全部落地后的展示停留 | 0.80秒 | 1.50秒 |
| 已认领物品起飞 | 停留结束后每份错峰0.08秒 | 停留结束后每份错峰0.10秒 |
| 每份飞行持续 | 0.70秒 | 0.90秒 |

全部落地时间取最后一份动画完成时刻。起飞顺序为金币/药水/如意、普通、优秀、稀有、史诗、传说；高品质最后离场。金币金额一个表现，药水堆一个表现，装备一件一个表现，不制造与实际件数不符的假装备。

### 散布

精英落点半径为0.7至1.5格；Boss为1.2至2.5格。以死亡位置为中心分环排布，装备中心间距至少0.35格，好装备和传说优先选择玩家容易看到的内侧位置。这里1格指现有逻辑网格，不把屏幕像素当成网格距离。

落点只能在连通可走区域，排除墙体、出口触发和地图外。空间不足时缩小环带并错开标签；必要时把普通物品表现分层，不把实际物品落入不可达地带。当前还没有完整可走网格时至少满足边界内落点，正式障碍加入后复用可走区域校验。

### 颜色、光柱和名称

普通、优秀显示对应品质色轮廓；稀有增加细短光柱；史诗增加宽光柱和双圈底座；传说增加最高光柱和星形底座。高度按稀有36、史诗60、传说90世界像素起步。效果保持可辨形状，不全靠颜色区分。

每份装备以剑、盾、衣甲等占位轮廓表达槽位。稀有以上常显名称与品质，普通/优秀在悬停时显示名称；标签避免覆盖玩家、Boss预警和其他交互提示。史诗和传说出场各播放对应短音效，同批同品质只播一次；普通物品出场不逐件播放高音量提示。

飞行追踪玩家当前位置，不锁定死亡时玩家位置。玩家远离、瞬移、死亡或切图时，已认领表现可立即淡出回收，奖励不受影响。表现节点不在可拾取集合内，不阻挡移动、攻击或任务进度。

## 10. 提示与设置

最后一份出场完成时显示一条批次摘要，如“腐化巨兽掉落：装备9件（稀有1、史诗1）· 金币802 · 大型生命药水×2”。装备总数包含传说追加，括号只列稀有以上；本批如意触发时追加“如意×1”。

有传说时另显示一次“传说 · 镇脉之刃”，持续3秒；不重复弹每件装备拾取Toast。摘要先说明总产出；存在未领取部分时追加“背包不足，3件装备已保留”，不能把总产出误报成全部已入包。

沿用dropFlyAnim设置：关闭时所有实际结算规则相同，仅保留一帧品质提示与批次摘要，省略散落和飞行。未领取物仍须有可见地面标记；关闭动画不能让未领取物不可见。飞行开关不改变掉落数量、概率或自动认领规则。

## 11. 背包满与未领取保护

精英/Boss未领取奖励不沿用普通物品60秒自动销毁。定义为“未领取战利品”，持续到领取或玩家主动丢弃；普通怪和玩家自行扔出的地面物仍沿用现有规则。

首版保护规则如下：

1. 入包失败的批次物品留在死亡区域，表现为可拾取装备，不执行飞行；只发一条批次级背包提示。
2. 记录地图ID、批次ID、实例数据与合法落点。切图或退出后记录保留，重新进入该图时恢复未领取物；已领取物及纯动画不恢复。
3. 自动拾取或点击拾取成功后，移除对应未领取记录并请求保存。拾取失败保持原记录，不重复结算。
4. 如果旧地图布局变化导致落点不可达，恢复到该图驿站附近的合法落点，并提示“未领取战利品已移至驿站附近”。
5. 普通拾取不能再次推进已入包物品的事件。未领取物在实际领取时才发item_picked，避免奖励展示本身触发任务。
6. 本版不设置静默数量上限；主动丢弃未领取战利品需明确二次确认。界面须能查看当前图未领取件数与最近批次位置，避免长时间累积后难找。

这部分是新增的必要支持，不是当前已存在能力。保存结构需版本迁移，旧档默认未领取集合为空。批次结算结果、背包变化与未领取记录应作为一致快照保存；载入后以快照重建，不能根据动画节点重发奖励。该规则保证玩家腾不出空间或立即退出时，好装备不会因展示结束而损失。

## 12. 数据配置要求

数值放在配置中，不硬编码品质概率。建议掉落分组表达kind、countRange、数量分布、chance、qualityWeight、levelRange、templatePool；展示配置按normal/elite/boss分别定义体型、标识、出场与飞行时序。字段名称由开发方案确定，以下语义必须保持。

- countRange按本方案整数等概率抽取；每个分组先判定chance一次，再生成件数；各件再独立抽品质与模板。
- 传说分组固定一件、chance=0.05、指定池；不得先在好装备里抽传说，再追加一次。
- 金币range抽一金额，药水count=2表示两瓶实际数量；显示合并不改变结算数量。
- 保底分组生成失败视为配置/结算错误，不能降低成0件；启动校验需发现空池与无效物品引用。
- 纯表现与未领取实体共享物品显示数据，但领取状态与存档责任明确分开。

本版每个Boss批次最多11件装备、1份金币、1堆药水和1份如意，即最多14份表现；精英最多6份。多批同时存在时可减少低品质光效和标签，不能删减实际奖励或高品质标识。

## 13. 开发顺序与验收清单

推荐按外观→分组掉落与传说属性→批次结算/溢出存档→装备雨→汇总提示推进。未领取保护未完成前，不应作为完整产品包发布。

| 场景 | 验收结果 |
|---|---|
| 普通、精英、Boss同屏静止 | 无需选中或等狂暴即可凭轮廓、标识和血条区分 |
| Boss交战、切阶段、脱战、死亡 | 顶部血条、阶段名、阈值刻度与显隐时序正确 |
| 精英抽取 | 始终3至4件装备，其中1件优秀以上；1药水、1金币；无传说 |
| Boss未触发传说 | 始终7至10件，其中2件稀有以上；2瓶药水、1金币；如意独立30% |
| Boss触发传说 | 比基础结果额外增加1件传说，最多11件；不替换好装备 |
| 品质与模板 | 权重符合本表；不出现debug物品；传说池只生成传说；固定词条保留 |
| 背包只有1个装备空位 | 最高品质优先入包；剩余装备保留；奖励总量不缩水 |
| 金币接近上限 | 只入账剩余容量，超出部分保留，之后拾取不重复发整份金币 |
| 展示中移动、死亡、暂停、切图或退出 | 收益不随动画取消；暂停冻结时序；未领取奖励恢复；无二次发奖 |
| G关闭、飞行动画关闭 | 数量与认领规则相同，未领取物仍可发现与拾取 |
| 连续两次Boss击杀 | 两批独立奖励；首通与任务奖励不重复；旧未领取批次不覆盖 |
| 启动注入空装备池或无效传说ID | 明确校验失败，不能悄悄减少掉落 |

概率验收需使用可控制随机输入验证边界，并独立检查长期分布，统计误差不能被当成实现错误。实际性能在目标分辨率、剩余敌人继续战斗、完整14份表现同时出现时检查；本轮仅提供验收要求，没有执行测试。
