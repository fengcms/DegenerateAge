# 地图尺寸、横向比例与布局提示词评估

日期：2026-10-14。版本：v2.0。旧近方形/竖向尺寸建议已撤销，统一以[创意17](17-两章横向16比9地图统一规格与交接.md)为准。

## 1. 对此前方案的修正

此前主要增加格数，但多张图仍接近方形；旧井甚至是竖向布局。大黑菱形外框又压缩了地图本体的视觉呈现，用户不容易判断真实活动范围。此次将十张地图正交主体重设为16:9，并重新组织路线、井室、街区和侧路，不拉伸旧图。

新版直接显示横向长方形本体；内部可以有异形障碍和局部咬边，但不将绿色主体切成居中的方形孤岛。产品侧提供全部草图与坐标，用户无需绘制。

## 3. 正交布局与游戏画面

16:9是正交逻辑网格比例，不是保证等距投影后的屏幕轮廓16:9。当前x=(col−row)×32、y=−(col+row)×16，矩形网格的投影包围盒宽高约2:1。美术与工程不应通过拉伸瓦片或相机把游戏画面凑回16:9。

纯色参考和导航参考固定1920×1080，导入先按地图指定格数采样，再做游戏等距转换。整张标注图含标题和图例，不用它的外框比例判断地图格数。

## 4. 格数仍不能代替体验长度

当前默认速度256世界像素/秒；沿一个逻辑网格轴移动一格的世界长度约35.78像素、时间约0.14秒。沿100格轴向直走约14秒，不应按每秒4逻辑格估算。

实际路径时间应求每段等距转换后的世界距离之和/实际速度。本版参考路线已提供静态空跑秒数，见创意17和JSON；它不是唯一最短路，也未考虑角色净宽、战斗或骑乘。旧30—60秒估计不能继续作为已完成的验收结果。

## 5. 新提示词约定

```text
制作《末法时代》地图正交顶视布局参考。
地图逻辑尺寸：按本图产品规格填写，宽:高=16:9。
绿色矩形主体必须横向延伸；黑色障碍在内部组织主路、旁路、刷怪区和局部边缘咬口。
不要画外层黑菱形，不把方形活动区放在长方形空画布中央，不对旧图做横向拉伸。
出口、NPC、怪群、精英/Boss位置与布局参考JSON对应。
分清主线通过区和可选挑战，城镇服务集中，Boss场保持开阔。
纯色布局与导航参考地图本体输出1920×1080；图片像素数不是逻辑格数。
标注图可在地图外留标题/图例，标注不能写入导航遮罩。
最终素材仍遵循2:1等距瓦片和统一世界像素密度；该草图本身不画透视。
```

## 6. 后续制作

先按新版野外/断管坡制作样板，对照正常视野、大窗口和自动巡回体验，工程验证碰撞与出生/入口合法性。保持普通小群接敌，怪物集中在有内容的区域，避免扩大后稀释成空地。

本轮输出为产品与参考资产，不是已应用的游戏地图。相关坐标、版本与工程/美术执行依据统一看文档13—17。
