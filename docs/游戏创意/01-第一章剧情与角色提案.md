# 第一章剧情与角色提案：灰烬里的灯

状态：候选故事，未拍板。保留纪元3172、守护者、灵脉过度开发与异界入侵的既有设定。

## 1. 剧情主张

幸存者营地的镇灵灯即将熄灭。居民相信灯能让他们撑过夜晚，长老则知道灯芯与附近旧采灵站相连。主角在废墟醒来，击败异族时能吸收灵能；他可以取回灯芯，但这份能力为何与旧设施产生共鸣，没人能解释。

第一章沿一条证据链推进：腐化野狼身上的紫色纹路 → 裂壳虫腹中的灵能碎片 → 狼王巢边的旧车队遗物 → 灰烬废墟中的镇脉标记 → 巨兽体内的断裂封印。

提案中的镇灵灯是生活与叙事地标。初版可只通过任务描述表达其衰弱与修复，灯光变化、营地状态切换另需支持。它不提供现阶段未定义的防护数值，也不制造现实时间倒计时。

## 2. 情绪与信息递进

| 阶段 | 玩家当下动机 | 得到的信息 | 留下的疑问 |
|---|---|---|---|
| 苏醒 | 拿武器、弄清处境 | 自己能吸收怪物灵能 | 为什么只有自己能做到？ |
| 试炼 | 清理营地外威胁 | 腐化沿旧道路扩散 | 野兽受到谁的驱使？ |
| 碎片 | 为镇灵灯寻找材料 | 灵能与旧时代人造刻纹共鸣 | 异族力量为何进入人类设施？ |
| 狼王 | 找到失联车队线索 | 灰烬废墟连接地下采灵站 | 灾难发生后，设施为何仍运转？ |
| 灰烬 | 确認采灵站位置 | 巨兽胸前有镇脉封印 | 它在扩大裂隙，还是守着什么？ |

首章只确认“旧设施与腐化有关”，不提前揭露幕后主使。主角身份、异族整体目的与终章方案留待后续。

当前已配置的是长老、货郎与车夫功能NPC；姓名、性格、上述对白均为新提案。铁匠在产品规划内，角色文案可先储备。陆衡仅用于第二章设想。

## 4. 现有五连主线文案草案

### Q001 守护者苏醒

任务描述：你在幸存者营地醒来，手掌里残留着紫色的微光。长老把一柄短刃放到你面前。他没有询问你的过去，只请你先去看看营地外的道路。

接取对白：“先拿稳这柄刃。外面的野狼已经失了神智，车队走不过来。你若能回来，我们再说你的事。”

领奖对白：“你的手在发光……别怕。先学会活下来。镇灵灯的事，我还得请你帮忙。”

保持交谈接取即完成、50金币与守护者短刃的现有奖励。药品赠送属于资料描述与配置的差异，不在草案中承诺。

### Q002 初战试炼

任务描述：击败试炼野外的5只腐化野狼，看看它们身上的紫纹是否与营地灯芯的裂纹相同。

领奖对白：“它们曾绕着商路走，如今却沿着商路追人。有人从地下，把这条路重新接通了。”

调查含义通过文案表达；目标仍为击杀5狼，不新增检视尸体步骤。

### Q003 荒野遗物

任务描述：裂壳虫吞食废墟中的灵能碎片。前往试炼野外，重新取得3枚碎片，长老想用它们判断灯芯为何衰弱。

领奖对白：“三枚碎片，全带着同一组刻纹。灯芯还救得回来，可我们得先找到刻纹另一端。”

碎片仍为现有掉落物，接取后拾取才计数；文案不宣称扣除物品或完成真正的灯芯制造。护甲奖励解释为营地为此次调查提供的防护。

### Q004 精英踪迹

任务描述：裂爪狼王盘踞在旧商路附近。它追击的方向通往灰烬之地，长老希望你击败它，查明失联车队是否曾经过那里。

领奖对白：“这柄刃属于守路军。最后一次出车，他们带走了镇脉站的路线。下一段路，在灰里。”

狼王之刃已经是固定任务奖励；其来历为新增文案，不新增任务道具掉落。

### Q005 腐化源头

任务描述：灰烬尽头的旧镇脉站仍向外逸散紫色灵能。击败守在那里的腐化巨兽，切断这次腐化扩散的源头。

领奖对白：“封印上的字，我当年亲手描过。那头巨兽曾替我们守住灵脉。如今灯能再亮一阵了……可其他镇脉站，还在运转。”

保持击杀、500金币、1000经验与chapter2解锁标记。取回灯芯与断开站点目前只能作为收尾叙述；若要玩家实际操作，需独立交互目标。第二章入口文案应说明后续内容状态，避免承诺当前已有新图。

## 5. 呈现规则

每次必要对话建议控制在2至4句，每句聚焦一条信息。任务列表第一句先说明去哪里、打什么、多少只，再放故事。更深的背景可留在装备描述与可选对话中。

自动刷怪期间不强制弹剧情窗口。阶段结束回营地时揭露线索，玩家可以先领取奖励再继续探索。怪物刷新是可重复战斗的玩法约定；故事中的“解除营地威胁”指完成该次主线行动，不宣称地图永久无怪。

反转的重心放在巨兽的守护身份与人类旧设施。第一章保持一个结局，不加入分支选项、好感度或阵营选择。
