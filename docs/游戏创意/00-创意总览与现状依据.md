# 《末法时代》游戏创意总览

日期：2026-10-12。版本：首轮创意提案 v0.1。

本目录供产品讨论与内容选型使用。所有新增故事、人物、任务、区域与怪物均为提案，尚未成为产品基线。现有权威设计仍为 `docs/产品文档/`。本轮只输出文档。

用户称项目为《末法时代》；仓库正式名称为《末法纪元：最后的守护者》。本文沿用用户简称，命名统一留待产品决策。

## 1. 我对产品的判断

最值得放大的主题是：**世界的灵气正在枯竭，主角却靠异族的灵能不断成长。玩家越强，越接近造成灾难的秘密。**

将打怪、装备与探索都变成调查证据：裂壳虫为何吞食灵脉，游魂为何重复人类口令，巨兽身上为何嵌着旧文明的封印。剧情随玩家成长逐步显露，同时保留轻松刷怪、随时退出的节奏。

第一章建议围绕“找回一盏能照亮营地的灯”展开。灯是居民的生活目标，灯芯也是追踪腐化源头的线索。最终打败巨兽，保住营地，并发现人类旧时代的采灵设施仍在运行。第一章完成一个具体救援目标，再打开更大的悬念。

## 3. 内容与能力的现实边界

| 项目 | 当前观察 | 对创意的影响 |
|---|---|---|
| 地图 | 营地40×40、野外60×60、灰烬60×60、源头50×50；推荐等级1/2/6/10 | 优先深化四图；第二章作为储备 |
| 主线 | Q001交谈、Q002杀5狼、Q003收3碎片、Q004杀狼王、Q005杀巨兽 | 保留原目标；新增桥接任务须经基线评审 |
| 收集 | 裂壳虫必掉碎片；只统计接取后的拾取事件；不扣交付物 | 不能写成“拿出背包里已有碎片”或“交付消耗碎片” |
| 支线 | S001杀3虫、S002收1碎片；领奖后无自动重置路径 | 放弃重接不等于无限重复领奖；新任务默认一次性 |
| 多任务 | 同一事件可推进多个匹配任务；进行中最多5个 | 可将主线和支线放在同一路线；避免一次投放过多任务 |
| 灰烬游魂 | 数据是远程；当前通用AI进入射程后直接结算攻击 | “投射物可躲”“主动后撤”需要新增支持 |
| 精英与Boss | 已有配置和生成；通用实体未执行词缀、特殊攻击、Boss阶段 | 不能把减速、践踏、召唤当作当前体验 |
| 地形与刷怪 | 地面为占位网格，刷新位置随机生成 | 地标、固定巢穴、区域怪群属于待支持的关卡设计 |
| 章节解锁 | Q005领奖可写入chapter2；当前四图无进入解锁条件，第二章地图未配置 | 能提前探索源头；解锁标记不代表已有第二章可玩 |
| 技能 | 已有6技能配置；本轮所读玩家脚本主要为普攻路径 | 第一章挑战不依赖主动技能已经可用 |

产品资料内死亡处罚有不同口径（成长章节4.7与4.8），安全区定义也与营地木桩配置存在差异。本轮不基于死亡掉装设计惩罚性剧情，也不擅自统一这些规则。

## 5. 首轮最值得讨论的三项

| 创意 | 玩家能感受到什么 | 推荐程度 |
|---|---|---|
| 营地灯火贯穿第一章 | 刷怪是在解决眼前的生活危机 | 优先：先完成文案，再考虑灯光状态 |
| 灰烬之地补一段主线调查 | 狼王到巨兽之间有因果和准备过程 | 优先：桥接任务需确认是否调整五连结构 |
| 腐化巨兽曾是镇脉守护兽 | 打赢后重新理解“怪物”和灾难 | 优先：以封印外观和任务收尾表达 |

第一轮建议只选择一个核心悬念、一个灰烬目标、一个有记忆点的Boss真相。营地重建、回声收集和动态地图留作后续，不同时扩张多个系统。
