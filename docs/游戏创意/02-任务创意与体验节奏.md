# 任务创意与体验节奏

状态：候选内容。任务奖励数字为讨论起点，未做实机平衡验证。新增任务默认一次性完成。

## 1. 优先补上灰烬之地的目标

现有Q004发生在试炼野外，Q005直接要求击败源头巨兽。灰烬之地虽有远程怪和商店，主线缺少明确调查步骤。

推荐候选任务“灰中余音”：击败灰烬之地的3只灰烬游魂，长老从它们留下的余音中确认镇脉站仍在运行。它让玩家学习先接近远程敌人，再应付附近高防敌人的顺序。

| 字段 | 候选值 |
|---|---|
| 文档编号 | IDEA-Q-ASH01（不是正式数据ID） |
| 地图与目标 | ash_land；kill / ash_wraith / 3 |
| 发布者 | elder，沿用现有任务入口 |
| 前置 | Q004领奖 |
| 奖励建议 | 120金币、180经验；不追加必得装备 |
| 接取描述 | “灰烬游魂仍在重复旧站的口令。击败3只，长老或许能从余音中辨认源头的位置。” |
| 收尾对白 | “它们喊的是‘稳住镇脉’，不是进攻。那地方原来是我们的。” |
| 内容作用 | 提供灰烬目标、战斗准备与巨兽身份伏笔 |

**采用方式需选型：**优先作为Q004与Q005之间的新增主线，Q005的前置相应调整，保留既有五任务ID。若要严格保留五连基线，则作为Q004后开放的可选支线，Q005描述直接交代地点，不能假定玩家做过支线。两种方式不同时采用。

余音是文本中的情节，不承诺现有游魂会掉落新的音频道具。若希望播放死亡口令，另属音效与触发支持。

## 4. 第一章体验节奏建议

这些是设计期望，不是当前试玩测得的通关时间。

| 体验段 | 希望玩家得到什么 | 内容重点 |
|---|---|---|
| 开始约5分钟 | 知道怎样移动、攻击与装备短刃 | Q001；先展示营地灯，再离开营地 |
| 接下来约10分钟 | 完成首次战斗与装备成长 | Q002、Q003；明确碎片来自裂壳虫 |
| 第一场精英挑战 | 感受到装备准备的价值 | Q004；狼王之刃成为明确成长节点 |
| 中段探索与准备 | 理解灰烬为何值得进入 | 灰烬桥接任务；补药、尝试新敌人 |
| 章节高潮 | 挑战巨兽、了解封印真相 | Q005；短收尾对白与下一章线索 |

第一章总时长建议先以45至75分钟作为讨论窗口，需后续试玩确认。现有升级曲线、虫怪刷新、路费和主动技能可用性都会影响实际时长；不据此直接修改任何数值。

## 5. 任务设计的边界要求

任务先说明地图、目标与数量。收集任务写“接取后获得”；若要消耗道具或回溯持有数量，单独提出机制需求。交谈任务目前接取即完成，不能据此设计跨图寻找指定NPC。

任务前置解锁不等于地图封锁。当前玩家可先杀巨兽，尚未接Q005时不会累计任务进度。文案应提示先接任务再挑战；后续再讨论首次击杀记录与任务回溯是否需要协调。

从野外去灰烬再去源头并原路回营地，路费合计320金币（50+100+100+50+20）；每次单独回营地交任务还会增加往返费用。因此将灰烬支线与主线合并出行，领取奖励安排在章节停顿处。新增任务的奖励不应被全部路费抵消，必须与原有刷怪产金一起评估。

避免要求守候刷新若干轮、靠低概率拿主线必需物、死亡才能继续、退出后累计时间。核心线索使用确定目标；稀有装备保留随机打宝的惊喜。
