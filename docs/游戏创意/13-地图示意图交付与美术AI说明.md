# 两章地图示意图交付与美术AI说明

日期：2026-10-14。版本：v2.0。全部十图已替换为`2026-10-14-landscape-v2`横向16:9构图。

用户无需绘制或提供草图，产品侧输出布局与坐标。地图几何以[创意17](17-两章横向16比9地图统一规格与交接.md)为准，故事见11、第一章重设计见14、工程/美术计划见15/16。

## 1. 文件含义

标注示意PNG：区域、地标、路线、NPC与敌人预算，供沟通；纯色布局PNG：绿色可走/黑色障碍/红色出口；导航参考PNG：只有可走与障碍，不含标记；JSON：逻辑格数、障碍、配对出口/入口、驿站、区域物种与预算、地标、参考路径和布局版本。

新版移除大黑菱形外框，地图本体均为1920×1080横向矩形。最终游戏仍按等距转换显示，不按参考图整张做屏幕背景。参考JSON不是现有maps.json的直接替代。

## 3. 给美术AI的统一说明

```text
按landscape-v2标注图与JSON制作地图，不要求用户补画草图。
本体是正交16:9长方形；游戏以等距斜角显示，不能重新按屏幕16:9拉伸。
保留横向段落、关键出入口、循环路线和可选挑战关系，局部障碍可按工程净宽修订。
不恢复旧黑菱形展示框，不沿用旧方形/竖向整图构图，不把旧素材横向拉长。
按地图尺寸制作可复用地面、建筑、障碍和装饰模块；人物、标签与预警单独处理。
NPC/精英/Boss标记代表实体位置，区域小圈代表怪群中心，不是可走范围边界。
标签、浅线、区域圈不画入正式贴图，导航图只保留可走与不可走。
角色与瓦片像素密度统一，攻击预警保持最高辨识度。
```

## 4. 复核边界

已经对新版示意文件进行了静态格网点位连通与参考路径绕障检查。尚未验证角色半径、通道净宽、动态怪群、屏幕射线和实机行走时长，工程须继续完成。JSON路径秒数仅为默认256速度下的参考线长度，非通关时间。

产品侧提供草图不等于导航编译完成。局部通道、落点、保护区与装饰占地变化必须由工程和美术对接并记录版本，不让两个AI各自改动后互相覆盖。
