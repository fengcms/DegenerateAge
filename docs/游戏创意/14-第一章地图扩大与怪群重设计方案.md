# 第一章地图扩大与怪群重设计方案

日期：2026-10-14。版本：v0.2（横向16:9），新版关卡内容提案。

用户明确希望第一章地图更大、怪物更多。本方案重新组织已有四张地图，提供四套布局示意和精确怪物预算。新增地图尺寸、怪群与坐标尚未写入游戏配置；产品侧负责示意图，用户无需绘制草图。

> 最新几何与坐标统一见[创意17](17-两章横向16比9地图统一规格与交接.md)，旧近方形与菱形框示意已替换。怪群预算仍沿用本文件。

## 1. 总体规模

三张战斗地图配置216个普通刷新位、11个精英位、1个Boss位。营地另保留3个教学木桩。刷新位是该图怪物供给预算，不是同时围攻数量；离图不运行AI，活动怪群需控制仇恨与性能。

|---|---|---|---|---|

| 灰烬之地 | 60×60 | 192×108 | 6 / 2 / 0 | 96 / 4 / 0 |
| 腐化源头 | 50×50 | 160×90 | 8 / 4 / 1 | 48 / 4 / 1 |
| **战斗地图合计** | | | **22 / 7 / 1** | **216 / 11 / 1** |

当前值来自本次读取的maps.json，包含近期已增加的灰烬与源头精英。新版重点提高普通怪供给，精英与Boss依然有独立挑战节奏。保持一个章节Boss和现有任务目标ID，不把第一章扩成多Boss长章。

地图格数为逻辑包围盒，主体保持16:9横向长方形，内部障碍和局部边缘缺口形成支路。不要把图片像素当成格数，也不要对现有地图整体放大比例：人物、格子、速度与攻击距离仍按游戏既有单位，增加的是地图范围和内容。

## 2. 交通、剧情与等级

```text
第二章沉井镇（chapter2开放）
          ↕
      幸存者营地 ↔ 试炼野外 ↔ 灰烬之地 ↔ 腐化源头
```

沿用城镇集群：camp为枢纽，其余三图为本集群附属。相邻道路免费步行，到访后车夫提供本集群直达；第一章费用沿用文档10已确认的逐对矩阵，不因地图扩大自动加价。

推荐等级仍为营地1、野外2、灰烬6、源头10。普通怪区域形成渐进等级，任务Q002、Q003、Q004仍在野外，Q005仍在源头。原物品与击杀目标保持，不以扩大地图为由提高任务数量。

玩家可以沿主路继续推进，也可进入旁支刷怪。精英旁支不堵免费返程；Boss场与普通挂机区隔开。灰烬调查任务仍按此前剧情方案单独评审，不把新增主线当成地图扩大的必要条件。

## 3. 幸存者营地：扩大空间，集中服务

64×36的营地采用中央镇灵灯、四组建筑、环形服务街道。长老、货郎、铁匠、仓库在灯周围，车夫与训练区位于南侧，第二章出口在北，野外出口在东。

中央服务区与道路休整点保持安全。训练区3木桩不反击，不增加营地刷怪奖励。营地边缘用树木、岩壁与建筑占地塑造边界，不新增会袭击买药玩家的敌人。

功能NPC之间实际步行目标2—5秒，车夫到主要出口目标3—6秒。通过紧凑服务区达到便利，不用把NPC等比例挪到地图四角。

草图NPC坐标是建议站位；正式实施需根据入口保护、碰撞和当前服务交互范围修正。第二章出口未开放时仍可见路牌并显示条件，不能提前跨章。

## 4. 试炼野外：两个刷怪环路与狼王旁支

176×99，旧商路横贯长轴，中央偏西岩坡和偏东岩脊错位设置。北侧旧商路与南侧回转草地形成两种循环路线。玩家辨认地标后能主动选择刷怪路线，自动战斗也有清楚的区域边界。

| 区域 | 等级建议 | 普通怪 | 区域用途 |
|---|---|---:|---|
| A 营地外路 | 狼L2、虫L3 | 狼12、虫6 | 第一场战斗、Q002；入口附近给观察距离 |
| B 旧商路 | 狼L3、虫L3 | 狼12、虫6 | 初次范围技能练习前的稳定成长 |
| C 虫蚀遗迹 | 狼L4、虫L4 | 狼12、虫6 | Q003碎片来源；虫群有清楚轮廓与地标 |
| D 回转草地 | 狼L4、虫L5 | 狼12、虫6 | 适合开启自动战斗的循环区 |
| **合计** | | **狼48、虫24，共72** | |

每区18普通位，组织为4小群：5、5、4、4只；虫与狼混合，但第一场接敌单独用少量狼。全部刷新位不集中在路口，也不要求玩家同时引到18只。

精英：裂爪狼王1只L4，裂壳虫精英2只L4/L5，分别放在两个旁支。狼王仍是Q004唯一目标，其他精英不替代其进度。三只精英死亡后120秒刷新。

普通位死亡后12—16秒随机刷新，刷怪位在区内固定/小范围变化，不再整图随机重分布。任务碎片沿用现有裂壳虫来源；24只虫能避免原先仅2只导致的目标等待。掉落堆叠和任务物容量需一起核查，不能让更多虫快速填满背包。

## 5. 灰烬之地：街区、废料与六个战斗区

192×108，长街横贯多个街区，民居遗址和偏南废料坑形成主路、北街与南庭院三条连接。驿站和货郎位于西侧前室，玩家补药后可以选择主路推进或环路持续刷怪。

|---|---|---:|---|
| A 焦土前路 | 游魂L6、虫L6 | 游魂10、虫6 | 首批远程敌人，开阔处先观察 |
| B 北街废墟 | 游魂L6、虫L7 | 游魂10、虫6 | 可绕行的远程战斗区域 |
| C 烧毁民居 | 游魂L7、虫L7 | 游魂10、虫6 | 环境故事与混合怪群 |
| D 主路广场 | 游魂L7、虫L8 | 游魂10、虫6 | 主线赶路与可选战斗之间留空档 |
| E 旧庭院 | 游魂L8、虫L8 | 游魂10、虫6 | 自动刷怪回路之一 |
| F 输灵管沟 | 游魂L8、虫L9 | 游魂10、虫6 | 源头前的装备准备区 |
| **合计** | | **游魂60、虫36，共96** | |

每区4群、每群4只。远程不要全部对一个入口形成交叉集火：首轮每群最多1—2只游魂主动开火，剩余分布在回路下一段；治疗恢复与技能可用性按实际战斗校准。

精英：游魂精英2只L8、裂壳虫精英2只L9，分布在街区旁支和管沟后方，死亡后120秒刷新。普通怪14—18秒刷新，错峰恢复。

障碍先作为明确不可走区，不暗中加入持续地面伤害。正式远程投射物尚未接入时，不设计必须靠墙挡弹的通道；游魂射程与碰撞规则按已支持能力执行。

## 6. 腐化源头：可刷外围与独立Boss战场

160×90，从灰烬进入安全前室，沿两侧遗迹探索，再到封印观察点和东侧Boss场。保留洞穴气氛，但用更大的前庭、支路和战场替代紧凑小室。

|---|---:|---|
| A 岩洞前庭 | 裂壳虫8、游魂4 | 短暂准备，入口以外才开始接敌 |
| B 北侧遗迹 | 裂壳虫8、游魂4 | 精英旁支与封印线索 |
| C 南侧虫穴 | 裂壳虫8、游魂4 | 连续刷怪旁环 |
| D 封印外环 | 裂壳虫8、游魂4 | 观察Boss前的缓冲区 |
| **合计** | **裂壳虫32、游魂16，共48** | |

沿用当前本图tierRange=[10,10]，不写L9后又被实现夹成L10。每区3群、每群4只，普通怪16—20秒刷新。精英游魂2只、精英虫2只均L10，120秒刷新。

腐化巨兽仍1只L10、300秒刷新。Boss场中心示意为(136,45)，至少18格直径的可走空间，战场中不设置普通刷新位，外围怪物追击边界不进入场中央。场地位于地图东端，入口有可辨观察点；首版不以地图装饰门增加新的主线解锁条件。

玩家主动进入Boss挑战后按现有战斗规则；普通自动模式是否攻击Boss沿用设置，不能因为怪变多就自行替玩家开启。装备雨与满包保护按文档07，不重设掉落概率。

## 8. 连续战斗与性能预算

这次怪物供给显著增加，必须连同区域刷新与自动寻路实施。当前全图最近/半径选怪如果不支持跨刷怪区巡回，角色仍可能清空附近后等待，不能只改count。

每次主要接敌约3—5只；普通挂机区同时主动追击目标候选上限6—10只，第一张图新手区更低。远处怪群休眠或降低更新频率，不每帧为所有怪算路；显示区也不保证每只立即参与围攻。刷新避开玩家脚下、出口、NPC和休整区。

自动战斗推荐先在当前区挑可达目标，区内清空后巡回到相连普通刷怪区；不跨地图、不进入精英/Boss旁支强制开战。玩家可选择原地附近模式，保持自己指定范围。

新版主参考线静态空跑约：野外26.2秒、灰烬25.5秒、源头17.9秒。完整支路另见创意17。这是默认256速度的路径长度换算，不是实机最短路时间；不再强制源头也达到25—40秒。角色净宽、实际导航和战斗体验在落图后校准。

帧率仍以产品基线为目标，先在野外样板观察常用窗口和大视野。性能不足优先做实体更新节流和区域激活；不把降低视觉数量当作实际奖励削减，不把增加同屏压力当作爽感本身。

## 9. 成长、掉落与难度关联

本次保留普通怪单次XP、金币与装备概率作为第一轮对照，先观察单位时间收益；预计刷怪效率会提高，不能把原有章节时长估计当作仍成立。第一章普通怪总数扩大近十倍不代表每分钟收入也扩大十倍，实际取决于击杀、接近、恢复和供给。

主线击杀5狼、收3碎片与杀1狼王保持原数，任务区更容易找到对应目标。更多怪不意味着任务必须杀50只。Lv5裂地斩、Lv10旋风斩的当前可用能力承接清群；Lv1—4不要先靠十几只围攻逼玩家升级。

精英从7位增至11位会提高多件装备产出频率，需联合评估背包、批量出售Lv15门槛、早期升星资金与药耗。第一章低级角色还不能使用Lv15批量出售，不可假定新手能自动清理所有垃圾装备；保留货郎手动出售和托盘功能，必要时在玩法评审中调整低级装备产出。

收集物沿用既有计数与堆叠能力，不将第二章建议的任务袋视为第一章已实现。增加虫位之前核查满包会不会中断Q003，主线任务提示应明确来源。

## 12. 开发接手与旧存档

先完成野外样板，包括尺寸、导航、怪群与自动巡回，再推广灰烬和源头，最后调整营地服务位置与跨章道路。地图扩大只改maps.json尺寸是不完整交付。

源头现有CaveLayout是50×50专用布局，新160×90必须替换/迁移对应grid_size、walkable_rows、地标、导航和碰撞；不能沿用50格洞穴遮罩。其他地图也应通过布局引用接入导航能力，避免仅源头能绕障。

每个刷新位需要稳定ID和新布局位置。旧档的未领取精英/Boss装备、玩家坐标、迷雾、刷新剩余时间不能静默丢失：合法旧玩家位置可保留，失效时移到本图驿站并提示；旧迷雾保留原坐标区域，新增加区域未探索；未领取奖励落点失效时移到对应驿站；死亡Boss的剩余计时映射到新Boss位，不能因重布局立刻再次产出。

原普通/精英刷新位与新预算需要迁移映射，无法对应的新增位视为新位，不能把旧死亡精英记录套到所有新增精英。主线奖励、Boss首通、到访与金币原样接续。实现细节写入工程方案，不由美术AI猜测。

交付验收应覆盖地图内连通、入口/驿站安全、怪物不生墙内、自动路径不卡障碍、各区怪物预算正确、低级玩家可正常开始、Boss场足够躲避、切图刷新不重复、旧档不掉奖励。草图尚未证明这些行为通过。

本轮只输出产品规划与示意图片，没有修改游戏地图、怪物数量或运行游戏测试。
