## 1. 玩家体验与范围

玩家可通过地图道路出口免费步行前往相邻地图，也可在车夫处一次付费直达已经到访的本章地图。金币不足时始终保留免费返程路线。

覆盖现有四图，不新增地图、不采用无缝加载、不增加途中行车等待。独立地图仍通过短暂加载切换。对地图形状的后续改造可以改变出口坐标，但必须保持相同路线与入口身份。

| 出行方式 | 路线 | 金币 | 抵达位置 | 首次到访要求 |
|---|---|---|---|---|
| 步行 | 当前图相邻道路 | 0 | 目标图对应入口 | 无；只检查剧情开放条件 |
| 车夫 | **本镇集群 ∪ 相邻城镇**（原"本章任一其他驿站"已被 `10` 取代） | 按出发地/目的地一次收费 | 目标图驿站落点 | 目标已到访；营地→野外例外 |

推荐等级只是风险提示，低等级仍可出行。两种方式共用目标地图剧情解锁条件，不允许付钱绕过封锁。现有第一章四图requiresUnlock为空，首版继续允许全部步行探索。

## 2. 免费道路拓扑与入口

```text
幸存者营地 ↔ 试炼野外 ↔ 灰烬之地 ↔ 腐化源头
```

## 3. 出口交互

距离出口中心不超过1.5逻辑格时出现提示：`E 前往灰烬之地 · 免费 · 推荐Lv6`。距离按逻辑网格计算，统一转换后判断，不直接用菱形屏幕距离代替。提示最多显示一个，取距离最近者。

首次按E触发一次切图，不弹确认窗，不要求支付金币。长按E不连续触发；抵达后至少1秒内禁用出口交互，并要求释放E后再次按下。入口落点位于返程交互半径之外，防止直接弹回原图。

面板打开时，E只执行该面板原有操作；不同时触发出口。面板关闭且出口与NPC交互区域意外重叠时优先出口，但地图配置验收应消除重叠。死亡、暂停、后台冻结和切图处理中禁止出行。

玩家可在受攻击或战斗中使用出口，不新增脱战等待。切图提交时停止伤害与交互处理，旧地图怪物不跨图追击；逃生是免费道路的正常用途。刷新状态必须保留，逃离后回来不能重置精英或Boss奖励。

未解锁提示：`道路封锁：请先完成「指定任务」`。具体原因从配置取得，不能只显示“无法前往”。金币不足不会阻止出口，不显示价格或购买入口。

地图点击出口只移动到出口前的合法停靠点，不自动切图。自动战斗、自动拾取、追怪与怪物碰撞均不能使用出口。

例：营地拥有200金币、源头已经到访，选择源头一次扣150，到达后剩50。返回营地费用170，不足时可沿三段道路免费返回。

## 5. 到访与抵达位置

到访在目标地图装配成功、玩家实际落地后记录。步行、教学乘车、新档营地、合法读档均算到访，不要求交谈、击杀、购买或揭示全部迷雾。

首次到访提示一次：`已到访灰烬之地，车夫直达已开放`。未完成场景加载、加载失败或仅看到地图菜单不会记录到访。到访记录与剧情解锁、迷雾、Boss首通分别存储。

| 地图 | 现有车夫位置 | 首版乘车落点 |
|---|---|---|
| camp | (20,24) | (20,26) |
| wild_trial | (30,34) | (30,36) |
| ash_land | (30,34) | (30,36) |
| corruption_source | (25,29) | (25,31) |

落点必须可行走、不与NPC碰撞，且可以直接走向道路或战斗区。步行采用入口落点，乘车采用驿站落点，不再统一出生在地图中心。

出行后保留当前HP/MP、装备、背包和任务状态，不补满、不扣生命、不发经验。入口和驿站不自动变成复活锚点；回城与死亡复活规则独立处理。

## 6. 出行保护与自动战斗

**2026-10-13 试玩修订（覆盖本节原休整区规则）**：仅城镇地图的功能 NPC 周围设一块矩形安全区；营地矩形外和其他现有地图全域都是危险区。道路出入口、野外车夫落点不产生免战区。怪物不在城镇安全区内刷新，安全区内玩家与怪物相互攻击无效；玩家和自动战斗均可穿过安全区，离区后正常寻怪和攻击。

城镇安全区地面使用低饱和浅色矩形边界，不用 Boss 预警色；道路出口与驿站保留各自标记，不附带免战保护。

切图清除锁定目标、追击指令、地图移动目标和待执行攻击，保留自动战斗/拾取开关偏好。若开关开启，抵达后继续自动寻怪或漫游；手动操作结束后仍按原有接管延迟恢复。

`safeZone` 表示地图包含城镇安全区，具体边界由 `safeArea.min/max` 两个逻辑格坐标定义；野外图 `safeZone=false` 且不配置 `safeArea`。

## 7. 切图成功、失败与存档一致性

| 阶段 | 产品要求 |
|---|---|
| 请求 | 校验玩家状态、路线、剧情、到访（车夫）、价格、目标入口与落点；步行还校验当前位置在出口交互范围 |
| 准备 | 锁住重复请求，停止模拟；保存源图状态与原金币、位置；未结算出售托盘先完整退回背包 |
| 加载 | 使用现有整场景重载思路装配目标；不运行目标战斗或发布成功通知 |
| 提交 | 装配和落点校验通过后一次扣车费，确认目标地图/坐标、到访与源图快照；保存一致状态 |
| 完成 | 发布一次map_changed/map_traveled和抵达提示，解除模拟锁，玩家停在休整区 |
| 失败 | 不扣费、不标记到访；恢复源图原位置及状态，提示“前往失败，未收取车费” |

当前travel_to先扣金币、改current_map并发事件，再由界面重载；开发必须调整成功提交边界。不能让自动存档保存“金币已扣但地图未成功加载”的中间状态。

模拟暂停不影响加载和错误恢复UI。目标装配失败后优先恢复源图；源图也无法恢复时展示重试/返回标题选项，保持最后完整存档，不能静默移到营地或覆盖存档。

正在加载时收到退出请求，在保持UI可响应的前提下完成提交或回滚后再退出；强制终止时下一次读取最后完整快照。文件保存失败时提示“出行已完成，存档失败，请重试保存”，保留当前内存状态，不重复收费或再次切图。

## 8. 刷新状态与跨图保留

为避免出口反复重建刷奖励，本版全部怪物点具有稳定ID，按地图保存生存与刷新状态。现有count批量生成需为每个实例生成稳定刷新位ID，不能使用临时节点实例ID代替。

| 类型 | 离图记录 | 返回行为 |
|---|---|---|
| 存活普通怪 | 刷新位与存活标记 | 在合法刷新位置恢复一只，满血；不额外增加数量 |
| 死亡普通怪 | 剩余刷新时间 | 时间未到保持死亡；到期恢复一只 |
| 存活精英/Boss | 稳定刷新位、等级、精英词缀、存活标记 | 回原锚点满血；同一生命周期不重抽词缀、不再次奖励 |
| 死亡精英/Boss | 剩余刷新时间、锚点、死亡标记 | 未到期不生成；Boss恢复墓碑；到期生成一次新生命周期 |

离图后计时在游戏前台正常运行时继续减少，到期只标记待生成，离图不运行AI、掉落或任务。暂停、应用后台和退出期间不减少时间，不累计离线收益。精英/Boss自然到期新生时可重新抽词缀。

例：Boss死亡后剩240秒离图，正常在野外游玩60秒，再返回显示180秒；如果关闭游戏一天再开，仍按保存的180秒继续。满血恢复使玩家不能通过反复逃离累积磨血，离图前死亡奖励则仍只结算一次。

未领取战利品按文档07持久化，出行不丢失；已入包的装备雨动画可清理。尚未实现文档07保护时，交通改造不得宣称已经保护这些物品。普通地面物沿用原有切图清理规则；出口提示页脚可说明“普通地面物切图后消失”，不逐次强制确认。

## 9. 地图标记与道路信息

出口使用双向箭头标记，车夫使用车轮图标，两者必须可区分。当前图大地图从进入起显示道路出口与目的地名称，即使该格迷雾未揭示；只揭示标记，不顺带揭示周围地形和怪物。小地图显示可视范围内出口；锁定道路带锁形符号和条件。

首次任务Q002说明：`沿营地路牌可免费走到试炼野外，也可找车夫乘坐免费教学线路。` 原有“远处必须换车”提示替换为直达规则。

路标最多指示两个相邻目的地。每段道路有连续地面色带与至少一个中途指向标记；狼王挑战放在旁支，不阻断免费返程。步行空跑时间不设硬性等待；现图先测实际路径，异形图定稿后以每段约20至40秒为校准目标，允许沿途战斗延长。

## 10. 任务辖区与旧档迁移

附属地图正式口径改为“当前地图与其相邻步行地图”，不再取carterLinks。任务实际仍按显式mapScope检查；扩大车夫直达范围不得扩大已有任务目标范围。

Q001至Q005、S001、S002继续使用各自现有mapScope，交通不自动接任务、不回溯提前击杀。第二章解锁标记不代表自动到访第二章。

旧档无visitedMaps时，默认标记camp与合法currentMap已到访；不依据奖励、迷雾或解锁推测其他地图到访。不存在的currentMap按存档既有修复规则处理，再标记实际恢复图。

旧档无地图刷新快照时第一次加载按原配置初始化，随后开始记录；不改变firstClear和任务rewarded状态，不补发首杀。合法玩家旧坐标优先保留，若落在障碍或失效区域，修正到最近连通可走格；无法找到时用本图驿站落点并提示。

## 11. 数据配置与校验要求

| 数据 | 首版语义 |
|---|---|
| exits | 出口ID、逻辑坐标、toMap、toEntrance、目标提示；三对道路双向配对 |
| entrances | 每图唯一入口ID、落点逻辑坐标 |
| carterLinks / carterFees | 车夫直达目的地与完整费用表；缺失费用视为配置错误，不默认免费 |
| carterArrival | 每图独立驿站落点 |
| requiresUnlock | 两种出行共用剧情条件；另提供可读失败原因 |
| visitedMaps | 玩家已到访地图集合；新档camp=true |
| travelRestZones | 出口/入口/驿站休整区域与怪物出生排除规则 |
| mapSpawnStates | 各地图稳定刷新位、存活状态、剩余时间、锚点与精英词缀 |

开发可决定具体字段组织，必须保留上述语义并按存档版本迁移。启动校验检查引用存在、ID唯一、坐标有效、路口双向配对、入口与驿站连通、费用非负整数、怪物刷新位唯一及保护区域有效。

用户界面只能发起出口ID或当前车夫目的地请求，不能直接指定任意目标坐标、费用或到访状态。地图服务统一解析并执行。步行校验和车夫校验分别进行，再共享提交、恢复和通知流程。

## 12. 实施顺序与验收

先做稳定刷新位与地图快照，再增加出口与入口；随后加入休整区和自动状态处理；再扩展车夫线路、到访与价格；最后完善地图提示、存档恢复与任务口径。

| 场景 | 必须结果 |
|---|---|
| 新档0金币出发 | 可按三段道路抵达源头并免费原路返回；教学乘车也可用 |
| 首次看车夫菜单 | 灰烬/源头未到访不能乘车，显示步行路线；到访后开放 |
| 营地直达源头 | 已到访且150金币时一次抵达驿站；剩余金币正确，无中转 |
| 双击、长按E、并发请求 | 最多一次切图/扣费；入口无自动返程 |
| 推荐等级不足 | 提示风险但允许出行；剧情锁定仍拒绝两种出行 |
| 自动战斗追到出口 | 不自动跨图；主动出行后不保留旧目标，不自行离开休整区 |
| 入口和驿站停靠 | 不生成怪、不受怪物攻击，也不能在区内攻击外部怪 |
| Boss死亡后反复跨图 | 倒计时保留，不能立即重生或重复领奖；离图正常计时、暂停/退出冻结 |
| 未领取战利品切图 | 精英/Boss物品按07恢复，动画不重复发奖 |
| 目标地图加载失败 | 恢复原位置、金币、刷新状态，不标记到访、不发成功事件 |
