## 1. 产品定位

- **类型**：2D 等距斜角（isometric）、单机、实时战斗、打怪升级（ARPG / Diablo-like 斜角玩法）。
- **平台**：首发 **macOS**（桌面端，键鼠操作）。是否远期扩展 iOS/Windows 待定（GDD 标注若移植 iOS 需重做触控与界面尺度）。
- **商业模式**：✅ **方向已定（买断制优先，可能免费分发；具体定价/分发渠道待定，见 R1）**。GDD 明确"无联网、无账号、无抽卡、无氪金、无 PvP、无交易市场"，即不含任何内购变现机制——产品形态偏向**买断制付费下载**（Mac App Store / 独立站 / Steam 待定）。
- **一句话定位**：在末法时代的人类失地上，扮演一名能吸收异族灵能的守护者，探索斜角地图、实时战斗、打宝成长，逐步解锁地图与技能、击败章节 Boss、最终关闭异界裂隙。

### 1.1 产品边界（明确不做）

下列功能**首版及可预见版本均不包含**，避免范围蔓延：

- 联网 / 多人 / 服务器 / 账号系统
- 交易市场 / 公会 / 抽卡 / 氪金内购 / PvP
- 在线挂机收益 / 离线收益计算
- 复杂制造系统（锻造、合成深度玩法）
- 程序自动替玩家购买物品
- 多结局剧情（GDD 标注多结局属正式剧情版，首版不纳入）

> 游戏内"自动打怪"是**单机玩法的一部分**，但进程退出后不继续运行、不累计离线收益。

## 2. 核心体验目标

产品设计必须让玩家在体验中感知以下 5 点（每条都是验收时的"感受"标准，不仅是功能有无）：

1. **成长感**：几分钟内可观察到等级或装备属性提升，力量变化可感知。
2. **打宝感**：普通怪有小惊喜；精英怪更值得打；Boss 有独特奖励与挑战。
3. **探索感**：进入新地图意味着新敌人、新资源、剧情与阶段目标。
4. **操作自由**：手动操作战斗，或在普通刷怪区开启自动战斗 + 自动拾取。
5. **单机友好**：随时暂停/退出、离线游戏、本地保存，不以多人竞争或付费设计数值。

---

## 3. 核心循环

```
探索地图 → 寻找/击败怪物 → 获得经验与掉落 → 升级、穿戴更好装备
       → 挑战精英/Boss → 解锁下一区域 → 继续成长
```

每个节点必须有明确反馈：命中/受伤动画、浮动伤害值、经验提示、物品掉落、装备对比、升级特效、Boss 奖励及地图解锁提示。

---

## 4. 目标用户与设备

- **用户画像**：喜欢斜角 ARPG、打宝刷怪、单机轻度挂机的玩家；偏好 macOS 生态、对联网竞技无强需求。
- **设备基线**：高分辨率 Mac 屏幕；设计参考视区 **1440×900**，支持窗口化调整大小；UI 可缩放，避免窗口变化导致布局溢出。
- **性能基线**：1440×900 普通战斗场景争取稳定 **60 FPS**；约 30 个同屏敌人 + 常规特效下无明显持续卡顿。

## 6. 功能模块需求清单

> 标注说明：**MVP=开发首版即落地的功能 / 后续=按最小闭环排期在后续迭代落地 / 边界=本版仅留数据结构不实现**。**注意：这些是开发排期标签，不是产品范围裁剪——所有功能（含"后续"）均已在本文完整设计**，见 R2 澄清。每个模块含"功能点 + 落地排期 + 验收要点"。

### 6.1 角色创建与存档槽

- 首次进入创建角色：名称（2–16 字符）、少量预设外观、职业固定"灵刃战士"、初始等级 1、进入幸存者营地。
- 多独立存档槽，首版建议 **3 个**。
- **MVP 归属**：创建 + 多槽位属于 MVP（与存档系统强绑定）。
- 验收：能创建/读取/切换 3 个独立存档，互不影响。

### 6.2 操控（macOS 键鼠）

- `WASD` 屏幕相对八向移动（斜向输入归一化，速度不超标）；鼠标左键选中怪物并手动接近攻击；`Space` 普攻；`1/2/3` 技能栏；`I` 背包装备；`C` 属性；`M` 地图；`F` 自动战斗；`G` 自动拾取；`Esc` 关闭面板/暂停。
- 自动战斗开启时，手动输入令自动行为暂挂，**连续 3 秒无手动输入后恢复**；界面明显显示"自动中/手动接管/暂停中"。关闭自动后不得自动恢复。
- **MVP 归属**：移动 + 手动攻击 + 自动开关属于 MVP；技能栏（2 技能）、背包/属性/地图面板属于 MVP。

### 6.3 角色死亡与暂停

- HP 归 0 → 死亡态、取消目标与行动、停自动 → 玩家选"返回营地复活"，恢复满 HP/MP；**不掉等级、不掉装备、不扣金币**。
- 暂停菜单 / 应用后台 → 停止战斗模拟、敌人 AI、刷新计时、掉落过期计时；恢复后继续；**退出不累计离线经验/金币/掉落**。
- **MVP 归属**：死亡复活 + 暂停/后台属于 MVP。

### 6.4 等级、属性与数值（人物属性定义，2026-10-11 补充；暴击 2026-10-11 确认保留）

- **人物属性（首版核心属性，用户定义 + 暴击确认）**：
  - 血量（HP）：当前生命值；**最大生命值随等级、攻击力、防御力及装备加成变化**（派生公式见下）。HP 归零即死亡。
  - **最大生命值派生公式（主流 ARPG 范式，2026-10-11 AI 提案）**：
    `maxHP = round( (BASE_HP + level×HP_PER_LV + attack×HP_PER_ATK + defense×HP_PER_DEF) × (1 + ΣHPPercent) ) + ΣHPFlat`
    - `BASE_HP=50`、`HP_PER_LV=8`、`HP_PER_ATK=2.0`、`HP_PER_DEF=4.0`（初稿，待调优）。
    - `ΣHPPercent / ΣHPFlat` = 来自装备的百分比/固定加成（见 6.6 高阶装备百分比属性）。
    - 例：L1（攻 12 / 防 5，无装备）：`(50+8+24+20)=102`，与早期"HP≈100"体感一致。
    - 说明：这是 Diablo/MMO 类"主属性派生次生命池"的常见做法——攻击/防御作为成长主属性，间接抬高血量上限，使攻防投入同时提升生存，契合用户"血量随攻防变化"的设计意图。
  - 蓝量（MP）：当前法力值；**使用技能消耗法力值**（闭合 B1）。最大法力值随等级与装备加成变化：
    `maxMP = round( (BASE_MP + level×MP_PER_LV) × (1 + ΣMPPercent) ) + ΣMPFlat`，`BASE_MP=30`、`MP_PER_LV=5`（初稿）。未受攻击时自动恢复、打坐/吃药可加速（详见 6.17）。
  - 攻击力（attack）：对其他玩家或怪物的伤害。
  - 防御力（defense）：对其他玩家或怪物伤害的抵抗能力。
  - 等级（level）：当前等级，初始值 1。
  - 移动速度（movementSpeed）：玩家移动速度，初始值待定。
  - **暴击率（criticalChance）**：造成伤害时触发暴击的概率。✅ 2026-10-11 用户确认保留（此前一度未列入用户定义的 6 项，现已补回）。
  - **暴击伤害倍率（criticalMultiplier）**：触发暴击时伤害乘算系数（如 1.5×）。与暴击率成对保留。
  - 说明：上列为首版人物属性面板（共 12 项）。攻击间隔（攻速）/ 闪避 / 格挡 / 冷却缩减 均 ✅ **已确认纳入首版核心属性**（见 R7，2026-10-11 晚用户补充此前写漏的这四项）。
- 经验公式（沿用 GDD，待调优）：`round(100 × L^1.6)`，多级连升、剩余结转、经验不为负、达到上限停升。
- 伤害公式（沿用 GDD，待调优）：`base = max(1, floor(attacker.attack × skillMultiplier − defender.defense × 0.5))`；每次伤害结算先按 `criticalChance` 判定是否暴击，暴击则 `damage = floor(base × criticalMultiplier)`，否则 `damage = base`；不允许负伤害、HP 不低于 0；对敌我对等结算。
- 升级保留当前 HP/MP 百分比。
- **MVP 归属**：属性、经验、伤害、升级全部属于 MVP。所有数值为**初稿，须经试玩调优**（见第 9 章）。HP/MP 的**脱战恢复与打坐**机制见 6.17。

### 6.5 技能系统

- 首版 6 个技能定义（普通斩击 / 裂地斩 L5 / 旋风斩 L10 / 战意觉醒 L15 / 破甲重击 L25 / 灵刃风暴 L40）。
- MVP 实现：普攻 + 2 主动（裂地斩、旋风斩）；未解锁/冷却/MP 不足/目标无效时不可放并给原因。✅ **技能消耗 MP**（见 6.4/6.17）；技能定义纳入**数据驱动框架**（与装备同源，文本可编辑）。
- 自动战斗技能策略：优先可用范围技（命中≥2），否则单体/普攻；不绕过冷却。
- **MVP 归属**：普攻 + 2 主动属于 MVP；L15+ 技能为后续。

### 6.6 装备与背包（2026-10-11 用户定义，覆盖原 GDD 10 槽）

- **装备分类与槽位**（用户定义，与原 GDD 冲突处以本定义为准）：
  - 防御向：头盔、护甲、鞋子、盾牌、护腕、护膝。
  - 攻击向：武器、手镯、戒指、项链。
  - 槽位数量：护腕、护膝、手镯、戒指 **各 2 个槽位**；头盔、护甲、鞋子、盾牌、武器、项链 **各 1 个槽位**。实际装备位共 **14 位**（1+1+1+1+1+2+2+2+2+1）。
  - 术语修订：原 GDD「服装」→ 本文件「护甲」，原「护肘」→「护腕」。
  - 武器与盾牌可同时装备；每类装备（含双槽类）可分别穿戴；装备即更新派生属性，不改基础值；卸下需背包有空位。
- **装备属性与词条**：
  - 除固定数值加成外，可有**百分比加成**属性：增加血量、增加蓝量、增加攻击力、增加防御力（按比例提升对应属性）。
  - **百分比属性不出现在普通装备上**；装备阶位越高，出现百分比属性的概率越高。
  - 每一件**高阶**装备随机出现不同属性加成，非固定（随机词条）。
  - **装备等级梯度（每 10 级一套）**：装备按等级分段（1–10 / 11–20 / 21–30 …），每分段配一套适配模板；分段越高，基础数值越高、出现百分比属性/随机词条概率越高。每套模板清单由数据配置驱动（见第 14 章）。
  - **装备等级需求（穿戴门槛）**：每件装备有穿戴等级门槛（如 1–10 段需 Lv≥1、11–20 段需 Lv≥11），低于门槛不可穿戴；与「每 10 级一套」梯度配套。
- **装备配置（文本可编辑）**：装备数据以**文本可编辑**格式存储（JSON 或纯文本，依最终引擎而定）；开发期可直接编辑文本文件中的装备属性，**不硬编码在代码里**。
- **可扩展杂项物品（如烟花）**：除装备/药水外，支持「杂项物品」类别，属性可编辑、可后续扩展。例如「烟花」点击后播放动画（useType=playAnimation）。物品类型与效果由数据配置驱动（见第 14 章），方便后续自行添加更多物品。
- **装备经济**：每件装备有其**金币价格**；玩家可出售给 NPC 获取金币。
- **装备升星（核心金币消耗，由铁匠 NPC 执行，见 6.16.2）**：
  - 装备可**升星**以增加属性，最多 **12 星**。
  - 由**铁匠**执行：中心放装备、四周放如意（铁/玉/金/钻石如意 +5%~20%，仅 Boss 掉落）；成功率见 6.16.2 表（0→1 100% 递减至 11→12 5%）；无论成败均扣金币与如意。
  - 升星是金币的**主要消耗途径**，迫使玩家刷怪获取金币（产品设计完整；**开发落地按 R8 建议晚于"出售 NPC"**，由最小闭环排期，见 R2）。
- **品质与实例**：common/uncommon/rare/epic/legendary；**模板 ID 与实例 ID 分离**，同模板可不同词条；生成后实例属性永久保存，不每次重随。
- **背包**：40 格（沿用，待定）；装备不可堆叠、药品/材料堆叠 99；已穿戴不占背包；支持查看/比较/穿戴/卸下/用药/拖到地面丢弃/自动整理（详见 6.15.2）。向货郎**一键出售**见 6.16.1。
- MVP 药品：分级红蓝药水（小/中/大，**每类独立冷却、互不阻塞、无全局公共冷却**，恢复量不超过最大 HP）；药水等级/恢复量/冷却/价格均为文本可配，详见 6.16.1 货郎出售与第 9 章数值表。
- **MVP 归属**：
  - 14 位装备槽穿戴 + 40 格背包 + 品质/词条实例 + 药水 + 自动整理 + 文本可编辑配置：属于 MVP。
  - 百分比属性 / 随机词条：属于 MVP（配置驱动必需）。
  - 装备出售给 NPC、升星：**产品设计均完整**（见 6.16.1 / 6.16.2）；**开发落地顺序**按 R8 建议「出售 NPC 先行、升星靠后」，由最小闭环逐步排期，不在设计阶段裁剪。

### 6.7 怪物、战斗与掉落

- 三类：普通（密集稳定收益）/ 精英（高血量外观标识+特殊攻击+优奖）/ Boss（独立血条+技能预警+阶段行为+首通奖）。
- 怪物状态机：`spawn→idle/patrol→aggro→chase→attack→(return)→dead→respawn`；超出追击边界返回；死亡只结算一次（经验/掉落/任务），不重复。
- **怪物刷新**：地图设**怪物点**，被击杀后按该点配置的**刷新时间**自动重生（每点刷新时间可配）。
- **Boss 墓碑**：Boss 死亡后生成**墓碑**，显示下次刷新**倒计时**；普通怪/精英怪**无墓碑**（击杀后按怪物点刷新时间直接重生）。
- 掉落概率（独立判定通道）：普通怪 金币100%/药15%/装8%；精英 100%/40%/40%；Boss重复 100%/70%/65%；Boss 首杀额外保证 1 件 ≥稀有 装备（标记 `firstClearClaimed`）。
- 品质权重：普通怪 普75/优22/稀3；精英 普40/优45/稀14/史1；Boss 优20/稀60/史19/传1。无对应模板时回退同章史诗并显式记录。
- 地面掉落运行且未暂停 **60 秒（1 分钟）**消失（统一替代原 180s，见 6.17 地面物品时限；适用死亡掉落/打怪掉落/玩家扔地面）；切图清当前地图地面掉落；拾取需距离 ≤1.5 格；背包满则留地提示不覆盖。
- **MVP 归属**：普通怪 + 掉落 + 品质/词条实例 + 地面掉落属于 MVP；精英/Boss 为 P3，但掉落框架 MVP 需预留。

### 6.8 自动战斗与自动拾取（核心功能）

- 原则：自动只调用与玩家相同的移动/寻路/技能/喝药/拾取接口；**默认关闭**，玩家主动开启。
- 状态机：`off/searchTarget/pathToTarget/attackTarget/searchLoot/pathToLoot/pickUp/recover/manualOverride/blocked`。
- 行为：HP≤阈值(初35%)喝药；锚点半径 12 格内搜怪（排除 Boss），优先低代价/弱目标；A* 接近；击杀后拾取；无目标待机避免每帧寻路。
- 设置项：自动战斗 `F`、自动拾取 `G`、是否允许 Boss(默认否)、喝药血量阈值(默认35%)、搜索半径(3–30，默认12)、品质过滤(后续)。
- 硬性异常规则（必须实现）：寻路空/终点占位/连续3次不推进→目标短期黑名单重搜；目标消失/死亡/切图→停旧指令；手动接管→立即取消、3秒后恢复；背包满→停拾取该物不循环；MP不足→回退普攻；药不足→提示、危险血停寻怪；死亡→自动转 off；暂停/后台→停决策；Boss 范围技不可被自动跳过。
- **MVP 归属**：自动战斗 + 自动拾取 + 全部异常规则属于 MVP（GDD 定义 P2 优先级最高）。

### 6.9 地图、坐标、移动、寻路、渲染

- 2D 等距瓦片地图，地表瓦片 **64×32** 逻辑尺寸；地面/装饰/遮挡/碰撞/交互/出生/刷新/导航分层储存。
- 等距坐标转换：`screenX=(col−row)×tileW/2`，`screenY=−(col+row)×tileH/2`；逻辑坐标统一世界/网格，绘制在渲染层转换。
- 八向移动归一化、世界速度一致；脚底碰撞体；**禁止 corner cutting**（斜穿两阻挡格角）。
- 寻路：静态通行网格 + 节流（不得每帧为全部怪算路）；动态障碍需更新图。
- 遮挡：动态高物体按脚底 Y/深度排序；相机平滑跟随，防露边界。
- 地图加载：读静态定义、建实体、定出生/刷新；离开释放旧场景实体与计时器/AI 引用，持久化任务/Boss 信息；入口有解锁条件并提示失败原因。
- **产品范围**：单图与多图切换、地图解锁条件、车夫跨图均在产品层完整设计（见 6.9 / 6.16.3）。**开发落地按 R2 排期**——首版可先单图验证核心循环，多图与车夫在后续最小闭环中接入；加载/释放框架需预留。

### 6.10 UI / UX（详细布局，2026-10-11 用户定义）

1. **左上角 — 玩家状态区**：
   - 头像为一个**圆圈**。
   - 圆圈右侧，从上到下依次为：**任务名称、血槽、蓝槽**。
   - 圆圈**右下角**叠加一个**小圆圈**，内显示玩家**等级数字**。
2. **头像右侧安全区 — 目标状态区**：
   - 该区域与头像及附属元素保持合适间距、不重叠（安全区）。
   - 显示当前**对战怪物或对话 NPC**（统称 NPC）的**头像、名称、血槽、蓝槽**。
   - 当前无对战怪物 / 无对话 NPC 时，此区域为**空**。
3. **右上角 — 小地图区**：
   - 小地图为**圆形**。
   - 圆形**上方**显示当前地图名称。
   - 地图**中间**显示玩家位置的**经纬度坐标**。
   - 小地图圆圈**边框上**放一个**小圆圈（设置图标）**，点击打开设置界面。
   - 点击小地图本体，打开大弹窗显示当前区域**大地图**；在大地图上点击可**移动到点击位置**。
4. **界面下方居中 — 快捷栏（16 格）**：
   - 从左到右共 **16 格**。
   - 其中**左起 12 格**为技能/药品快捷格，快捷键 `1 2 3 4 5 6 7 8 9 0 - =`（共 12 键）。
   - 玩家可**拖放技能图标或背包药品**到这 12 格，设置快捷技能或快捷吃药。
   - 其余格子分别为：**人物属性、背包、技能、坐骑** 的图标（各 1 格，合计 4 格 → 共 16 格）。
   - 这 4 个功能格有**默认快捷键**，玩家可在设置界面为其**自定义快捷键**。
5. **16 格下方 — 经验进度条**：
   - 一条**通栏经验进度条**。
   - 默认**不显示**经验数字；鼠标**悬停**时显示当前经验与升级所需经验数字。
6. **小地图下方 — 任务列表**：
   - 显示当前已接受任务及完成情况。
   - 任务中**需击杀的怪物名**高亮 + 下划线；点击自动**规划路径**前往该怪物位置（**可跨地图**）。

- 高分辨率可缩放；参考 1440×900；美术原创复古像素/斜角 2D，允许占位素材；MVP 换装只改数值不改精灵外观。
- **MVP 归属**：上述 HUD 全部布局（玩家状态区、目标状态区、圆形小地图+设置/大地图、16 格快捷栏、通栏经验条）+ 背包/属性/技能/坐骑面板 + 世界反馈属于 MVP。

### 6.11 音频与可访问性

- 最少音效：命中/受伤/死亡/拾取/升级/装备/Boss 警示。
- 设置：音乐/音效音量分离、关闭屏震/强光闪烁、UI 缩放；声音不成为唯一提示。
- **MVP 归属**：基础音效 + 音量设置属于 MVP（占位音效即可）。

### 6.12 单机存档与数据可靠性

- 存档记录：`schemaVersion / slotId / savedAt`、角色信息/等级/经验/血、技能解锁、背包装备实例、已穿戴实例、金币、当前地图与坐标、任务状态、首杀标记、用户设置与自动开关。
- **重启后自动战斗默认关闭**（即使退出前开启）。
- 保存策略：关键事件即时存（升级/重要物品/穿戴/任务/切图/首杀）；常规每 120 秒自动存；退出存；**原子写入**（临时文件成功后再替换主档）+ 至少 1 份最近有效备份；写入失败提示不静默丢失；不持久化运行时节点对象。
- 旧档迁移：未知/损坏数据明确错误提示并保留备份。
- **MVP 归属**：完整存档/读档/迁移/备份属于 MVP（MVP 定义要求"必须能保存进度"）。

### 6.13 坐骑系统（新增，2026-10-11）

- 坐骑是玩家的**移动工具**，骑乘后可移动到其他位置（提供移动速度加成）。
- 坐骑属性**仅有移动速度**；不同等级坐骑移动速度加成不同，越高越快。
- 玩家需达到 **20 级**才能骑坐骑。
- 获取方式：击败**特定 Boss 有概率获得**坐骑（作为掉落）。
- 坐骑爆出后，玩家拾取放进**背包**（与普通装备一样进背包）。
- 玩家**双击使用**坐骑 → 成为玩家坐骑属性，**不可恢复为普通装备**。
- 使用新坐骑时，**老的坐骑消失**（替换，不共存）。
- **产品范围**：坐骑系统完整设计（见 6.13）。**等级门槛 20 级**为设计事实（需达 20 级方可骑乘）；首版等级上限若为 1–10，则坐骑在达等级门槛后的后续内容中启用，**开发落地按 R2 排期**，不在设计阶段裁剪。

### 6.14 金币经济（新增，2026-10-11）

- 金币是玩家的**货币**。
- **来源**：怪物掉落金币；出售装备给 NPC（每件装备有金币价格）。
- **用途**：
  - 向 **货郎 NPC 购买药水**（分级，见 6.16.1）。
  - **升级装备（升星）**——这是金币的**主要消耗途径**，迫使玩家刷怪获取金币。
- **MVP 归属**：金币作为货币 + 怪物掉落 + 购买药水属 MVP；装备出售与升星属后期（与 6.6 / 6.13 一致，见 R8）。

### 6.16 NPC 系统（2026-10-11 晚补充）

- **安全区（safe zone）**：每个地图都有安全区，聚集功能性 NPC（货郎/铁匠/车夫/任务官）；安全区是玩家的**复活锚点**与**回城落点**。
- **通用交互**：点击 NPC → 弹出对话框（NPC 自我介绍 + 功能菜单）→ 选功能进入对应面板。所有 NPC 的**商品/任务/对话文本均以文本可编辑配置**（用户明确要求，便于后续自行修改）。
- **产品范围**：货郎/铁匠/车夫/任务官/仓库/其他，**全部在产品层完整设计**（功能、面板、交互、文本可编辑配置均定义于此）。**开发落地顺序**由 R2「最小闭环逐步推进」原则排期：先货郎经济闭环 → 任务官/车夫 → 铁匠升星 → 仓库扩容（详见 R2 / 第 13 章），不在设计阶段裁剪任何功能。

#### 6.16.1 货郎（Peddler）
- 安全区常驻，负责交易。
- **出售给玩家**：① 药品（不同等级地图的货郎，出售药品等级不同）；② 随机券（当前地图内随机传送）；③ 回城卷（回安全区起始位置）；④ 复活卷（复活到死亡位置）。
- **收购玩家装备**：玩家可向货郎出售任意装备换取金币。
- **对话框**：自我介绍 + 菜单（购买物品 / 出售物品）。
  - **购买面板**：物品列表，每项含介绍与价格，右侧购买按钮，点击购买。
  - **出售面板**：类背包格子面板；下方为结算金币数与「确认」按钮 + 「一键出售」按钮。
    - 玩家打开背包**双击装备** → 移入面板；或**拖拽**装备到面板。
    - 「一键出售」将背包全部装备批量移入（一格一件）。
    - 属性高于已穿戴的装备**不会被**一键移入面板。
    - 手动将高于自身穿戴的装备拖入面板时，点确认需**弹二次确认对话框**。

#### 6.16.2 铁匠（Blacksmith）
- 安全区常驻，负责装备升星（产品设计完整；**开发落地按 R8 建议晚于"出售 NPC"**，由最小闭环排期，见 R2）。
- **对话框**：自我介绍 + 菜单（升星装备）。
- **升星面板**：十字形 5 格——**中心**放待升星装备，**上下左右**放提升概率物品（最多 4 个）：
  - 铁如意 +5% / 玉如意 +10% / 金如意 +15% / 钻石如意 +20%。
  - 这些如意**仅 Boss 掉落，不可购买**。
- 下方显示升星所需金币 + 升星按钮（点击扣金币与如意）。

#### 6.16.6 仓库（Warehouse）

  - 以「每 10 格为一扩容档」计，`expandCost(k) = round(BASE × R^k)`，其中 `k` = 已购买的扩容档数（从 0 计），`BASE=1000` 金币、`R=1.6`。

### 6.17 生存、恢复与死亡（2026-10-11 晚补充）

- **血量（HP）**：玩家生命值，HP 归零即死亡；**最大生命值派生公式见 6.4**（随等级、攻击力、防御力及装备加成成长）。
- **蓝量（MP）**：所剩法力值；**使用技能消耗法力值**（闭合 B1）；恢复方式同 HP。
- **脱战恢复**：未受攻击时 HP/MP **自动缓慢恢复**；玩家可**打坐**加速恢复。
- **死亡与复活**：HP 归零弹对话框，选择：
  - 「**回安全区复活**」→ 移动到安全区起始位置。
  - 「**原地复活**」→ 消耗**复活卷**，移动到死亡位置。
- **死亡惩罚**：死亡时**随机掉落背包内装备到地面**；原地复活后可再次拾取。
- **地面物品时限**：死亡掉落 / 打怪掉落 / 玩家扔地面 的物品，**均仅保留 1 分钟（60 秒）后自动消失**（统一替代旧 180s 设定；详见 6.7）。
- **MVP 归属**：脱战恢复 + 打坐 + 死亡复活对话框 + 地面物品 1 分钟时限 + 死亡惩罚随机掉装，均属 MVP（核心生存与风险机制）。

## 14. 战斗与技能机制规格（S1–S10，2026-10-11 决策锁定）

> 本章闭合审阅报告 S1–S10。除已拍板项（S1 受击反馈、S2 闪避）外，其余为初稿，须经试玩调优（见第 9 章）。

### 14.1 受击反馈与保护机制（S1，✅ 已决策：硬直 + 无敌帧 + 击退）
- **受击硬直（hit-stun）**：被命中后短暂无法主动行动，初稿 0.2–0.4s，按攻击类型区分（普通怪短、精英/Boss 长）。
- **无敌帧（i-frame）**：受击后获得短暂无敌，初稿 0.5s，防止被多怪围殴连锁控死（核心手感底线）。无敌帧内不叠加新硬直。
- **击退 / 击倒（knockback）**：部分攻击造成位移（击退）或短暂倒地（击倒）；倒地期间不可行动但享有无敌帧。
- 边界：死亡态、无敌帧内、过场/对话中不触发硬直。

### 14.2 命中 / 闪避对抗（S2，✅ 已决策：概率 Miss）
- 采用**概率 Miss** 模型，与自动战斗天然兼容。
- 建议公式（软上限，避免堆到 100% 无敌）：
  `missChance = clamp( defender.dodge / (defender.dodge + DODGE_K), 0, 0.75 )`，`DODGE_K` 初稿 50。
  - 例：闪避 50 → miss 50%；闪避 150 → miss 75%（封顶）。
- 怪物侧引入 `accuracy` 字段（默认 0，即不主动降玩家命中）；玩家攻击怪物默认必中（除非怪物有闪避词缀）。
- 自动战斗与手动战斗使用同一结算。

### 14.3 伤害类型（S3）
- **首版仅物理伤害**（闭合当前设计，简化平衡）。
- 预留"灵能 / 裂隙"元素伤害类型与对应抗性字段（怪物/装备各预留 `resistType`），供后期版本启用，不增加首版复杂度。

### 14.4 控制效果（CC）与精英 / Boss 技能（S4）
- **CC 类型清单**（数据可配）：眩晕（stun，无法行动）、减速（slow，移速/攻速 −X%）、定身（root，不可移动但可攻击）、击退（knockback，见 14.1）、召唤（summon，Boss 召小怪）。
- **精英"特殊攻击"**：从 CC 池随机取 1 项（如寒霜精英=减速、狂暴精英=攻速提升），作为打宝差异点。
- **Boss 技能模板**：技能预警（地面提示圈/读条）→ 阶段行为（血量阈值触发）→ 效果（范围伤害/CC/召唤）。首版每章 Boss 至少 1 个阶段技能。

### 14.5 属性上限（Caps，S5）
- 暴击率 ≤ 75%；暴击伤害倍率 ≤ 5.0×；闪避(miss) ≤ 75%；攻击间隔(攻速) ≥ 0.2s（下限）；冷却缩减 ≤ 50%。格挡首版**不做**（见 S10）。
- 超限部分在属性结算时截断，不报错。

### 14.6 攻速作用域（S6）
- 攻击间隔影响：**普攻施法间隔**与**技能前摇/后摇**；**不影响移动速度**。
- 自动战斗严格遵循攻速与冷却，不绕过。

## 15. 等级与终局模型（G1，2026-10-11 决策锁定）

> 用户决策：**不设满级上限**，等级可无限提升；经验曲线使高等级耗时指数增长，玩家需长期游玩才能升级；通过版本更新补充新地图/新装备/新 Boss，旧档导入继续游玩。

### 15.1 无限等级
- 沿用经验公式 `round(100×L^1.6)`；**无硬上限**。L60→61 需 ≈70k 经验，L100→101 ≈ 200k，天然形成"越升越慢"。
- 等级相关 UI/存档使用 64 位整数，防溢出。

### 15.2 装备分级开放化（S17 延伸）
- 阶位 `Tier = floor((L−1)/10) + 1`，每阶一套适配模板，基础数值随 Tier 递增、百分比/随机词条概率随 Tier 提升。
- 穿戴门槛：Tier T 装备需 `Lv ≥ (T−1)×10 + 1`。

### 15.3 版本化内容 + 旧档导入
- 新地图/装备/Boss 经版本更新发布；存档迁移框架（6.12）支持旧档导入新版本继续（`schemaVersion` 递增，新增字段给默认值）。

### 15.4 满级后目标（替代传统终局）
- 装备词缀深度（刷高阶词条）、Boss 循环（周期性 Boss）、坐骑收集（特定 Boss 掉坐骑）；成就系统见 S40（待 R1 发布策略定）。

## 17. 怪物与关卡规格（S11–S16, B6, G2，2026-10-11 补齐）

### 17.1 怪物模板字段（S11）
定义 `MonsterTemplate`（数据驱动，见第 21 章）：
`id, name, tier, level(基准等级), hpBase(基准等级下的HP), mpBase(默认0), attack, defense, attackInterval(s), attackRange(近战/远程+射程), moveSpeed, accuracy(默认0), dodge(默认0), resistType(预留), xpReward, goldReward, dropTableId, kind(普通/精英/Boss), specialAttack(CC类型), bossSkill(Boss阶段技能模板), spawnWeight(怪物点内密度)`。

**怪物 HP/MP 派生公式（与玩家同源思路，但仅随等级缩放，初稿）**
- **设计要点**：怪物 HP **只随刷新等级线性缩放，不耦合攻击/防御**——因为防御已通过伤害公式 `base = max(1, floor(attacker.attack×coef − defender.defense×0.5))`（见 6.4）独立提供减伤；若 HP 再耦合防御会双重叠算坦度。因此模板只需设定一次 `hpBase`（基准等级下的 HP），引擎按实际刷新等级自动缩放，**无需手工为每个等级算一遍**，实现"加怪物无脑数据化"。
- **怪物最大生命值**：
  `monsterMaxHP = max(1, round( hpBase × (1 + M_HP_PER_LV × (spawnLevel − templateLevel)) ))`
  - `hpBase`：模板 `level` 字段对应等级时的生命值（设计师手填的"基准 HP"）。
  - `templateLevel`：模板 `level` 字段。
  - `spawnLevel`：实际刷新等级（受区域等级梯度 17.5 / 等级差 17.4 影响，可 ≠ templateLevel；低等级区复用高基准怪时自然下降）。
  - `M_HP_PER_LV`：每级生命成长系数，初稿 **0.12**（每高 1 级约 +12%）。
  - 例：裂壳虫 `hpBase=300 @ L3`，若刷在 L7 区域 → `300 × (1 + 0.12×4) = 444`；刷在 L9 → `300 × (1 + 0.12×6) ≈ 516`。
- **怪物最大法力值**（首版默认 0，预留给未来法系/Boss 耗蓝技能）：
  `monsterMaxMP = max(0, round( mpBase × (1 + M_MP_PER_LV × (spawnLevel − templateLevel)) ))`，`M_MP_PER_LV` 初稿 **0.10**；`mpBase` 默认 0（首版怪物仅物理攻击，见 14.3）。
- 以上系数均为初稿，随试玩调优（见第 9 章）；**新增怪物只需填模板字段，HP/MP 由引擎按公式生成**。

## 18. 装备细节补全（S19 / S20 / S22 / S23，2026-10-11 补齐）

### 18.1 「属性更高」判定算法（S19）
- 装备价值评分：`score = w_atk×atk + w_def×def + w_hp×hp + w_mp×mp + Σ(pct×100×对应权重) + starBonus`。
- 权重初稿：攻1.0 / 防1.0 / HP 0.3 / MP 0.3（按数值量纲归一，待调优）。
- 用途：一键出售排除"评分 ≥ 已穿戴同槽位"的装备（6.16.1）；替换提示"新装备评分更高"。

### 18.2 随机词条池与值域（S20，吸收 GDD v0.1 §6.2 保守方案）
- **词条池**：攻击力 / 防御力 / 最大HP / 最大MP / 暴击率 / 暴击伤害 / 攻击间隔(攻速) / 闪避 / 格挡 / 冷却缩减 / 移动速度。
- **各品质随机词条数（吸收 GDD 保守方案）**：普0 / 优1 / 稀1–2 / 史2–3 / 传=独特被动（传说不随机词条，依 GDD 以独特被动效果区分，首章仅预留数据结构）。
- **值域（每条，初稿，随 Tier 缩放）**：固定值词条 = 基础×(0.8~1.2随机)；百分比词条 = 2%~8%（仅稀/史 出现，传说靠独特被动不产随机百分比）。
- 百分比词条仅高阶装备（稀/史）出现，普通/优秀不出现（闭合 6.6）；传说装备通过独特被动而非词条数量堆叠体现强度。

### 18.3 药水数值（S22，与第 16 章 16.1 对齐）
| 药水 | 恢复量(红HP/蓝MP) | 冷却(s) | 价格 | 堆叠 |
|---|---|---|---|---|
| 小红 / 小蓝 | 80 | 8 | 20 | 99 |
| 中红 / 中蓝 | 220 | 12 | 60 | 99 |
| 大红 / 大蓝 | 500 | 20 | 150 | 99 |
- 每类独立冷却、互不阻塞、无全局公共冷却（闭合 6.6 / 第9章）。

### 18.4 升星与品质/词条关系（S23）
- 升星**仅加固定属性**（每星 +基础值×starMult，starMult 初稿 0.1），**不解锁/新增词条**。
- 品质决定词条数量与值域（18.2）；升星在品质基础上叠数值，不改变词条结构。
- 升星后售价按 16.2 公式含 `star×0.08` 加成。

## 19. 任务系统补充（S27，2026-10-11 补齐）

### 19.1 任务生命周期
`locked → available → active → completed → rewarded`；新增 `abandoned`（放弃后可重接，重接后计数清零重做）。

### 19.2 主线 vs 支线
- **主线**：Q001–Q005（第 7 章），线性、推进章节解锁。
- **支线**：任务官发布，以"当前地图及附属地图打怪数量"为主（6.16.4）；可轮换。

### 19.3 「附属地图」定义
某安全区地图 M 的"附属地图" = M 的车夫可达相邻地图集合（见 17.5 拓扑）。任务官"当前地图及附属地图"即 `M ∪ carterLinks(M)`。

### 19.4 放弃 / 重接
- 进行中任务可放弃（已杀/已收集计数清零，怪物点不受影响）；放弃后立即可重接同一任务。
- 同时接取上限 5 个（6.16.4）；主线任务不可放弃（随章节推进锁定）。

## 20. UI/UX 补充（S29–S37, G4, N1，2026-10-11 补齐）

### 20.1 设置面板字段清单（S29）
- **音频**：音乐音量 / 音效音量 / 屏震开关 / 强光闪烁开关。
- **画面**：UI 缩放(80/100/120/150%) / 文字缩放 / 全屏↔窗口 / 分辨率。
- **游戏**：自动战斗默认关 / 自动拾取默认关 / 喝药血量阈值 / 搜索半径 / 品质过滤。
- **控制**：全快捷键可重映射列表 + 冲突提示（见 S46）。
- **数据**：存档管理（手动存/备份/删除）。

### 20.2 主菜单 / 暂停菜单 / 读档界面（S30）
- **主菜单**：新游戏 / 继续(若有存档) / 读取存档 / 设置 / 退出。
- **暂停菜单**（Esc）：继续 / 设置 / 保存 / 返回主菜单（停止模拟，见 6.3）。
- **读档界面**：3 张存档卡，显示 角色名/职业/等级/地图/存档时间；操作 新建 / 读取 / 删除(二次确认)。

### 20.3 战斗信息呈现（S31）
- **伤害飘字**：普通=白色；暴击=黄色加大；格挡=蓝色；治疗=绿色。
- **血条数值**：默认隐藏，悬停 / Boss 血条显示具体数值。
- **目标选中指示**：选中怪物/NPC 脚下高亮圈 + 头顶名称条（见 6.10-2）。

### 20.4 系统提示 Toast（S32）
- 类型：升级 / 任务完成 / 拾取失败(背包满) / 金币不足 / 升星成功失败 / 地图解锁。
- 样式：屏幕中上短暂淡出(2s)，不阻塞操作；重要(解锁)稍长。

### 20.5 加载界面（S33）
- 启动 / 切图显示加载页：进度条 + 随机世界观提示语；不做无缝加载（单机可接受）。

### 20.6 对话系统推进（S34）
- 点击"继续"逐句推进 NPC 自我介绍；末句展开功能菜单（购买/出售/升星/任务等）；首版无分支选项（预留）。

### 20.7 拾取交互澄清（S35）
- **自动拾取(G 开启)**：靠近地面物品 ≤1.5 格自动拾取（自动战斗亦自动拾取）。
- **手动也可**：未开 G 时，玩家走到 ≤1.5 格范围自动入包（简化操作），或点击物品拾取；背包满则留地提示。
- 统一结论：**拾取为"靠近自动"而非"必须点击"**，G 仅控制自动战斗时是否顺路拾取。

### 20.8 鼠标右键功能（S36）
- 右键点地面 = 移动指令；右键点怪物 = 选中并攻击；右键点 NPC = 对话；空闲右键 = 取消当前移动/攻击指令。
- 左键保持"选中怪物 / UI 交互"（6.2）。

### 20.9 显示与缩放（S37）
- 最小分辨率 1280×800；参考 1440×900；支持窗口自由缩放。
- Retina(2x) 渲染清晰；UI 缩放档位 80/100/120/150%（不影响逻辑坐标）。

### 20.10 新手引导（N1）
- 首屏轻提示：移动(WASD)/攻击(Space)/自动(F/G)，由 Q001 长老对话引导；首战(Q002)提示开启自动战斗。不强制教程，提示可关。

## 21. 数据配置文件清单与 Schema（S38，用户强需求，2026-10-11 补齐）

> 本游戏核心原则：**装备/NPC商品/任务/对话/怪物/掉落/地图/坐骑/如意/仓库/杂项物品 全部文本可编辑**。以下为配置文件清单与字段 Schema，开发期可直接改 JSON，不硬编码。

| 配置文件 | 覆盖 | 关键字段 |
|---|---|---|
| `equipments.json` | 装备模板(6.6) | id,name,slot,tier,levelReq,quality,baseAttrs{atk,def,hp,mp},pctAttrs[](可空),affixes[](可空),price,icon,desc |
| `skills.json` | 技能(14.7) | id,name,unlockLevel,kind(attack/buff),coefficient,cooldown,manaCost,shape,range,targetType,desc,icon |
| `monsters.json` | 怪物(17.1) | 见 17.1 字段 |
| `dropTables.json` | 掉落表(B6) | id,entries[{kind(coin/potion/equip),qualityWeight{},chance,itemId/levelRange}] |
| `quests.json` | 任务(19) | id,type(main/side),giver,objective{kind,targetId,count},reward{gold,xp,item},mapScope |
| `shops.json` | 货郎(6.16.1) | npcId,buyItems[{itemId,price,tier}],sellEnabled |
| `upgrade.json` | 升星(6.16.2/16.2) | successRate[13],costParams{UP_BASE,UP_R} |
| `mounts.json` | 坐骑(6.13) | id,name,speedBonus,dropBossId,icon |
| `runes.json` | 如意(6.16.2) | id,name,successBonus,dropBossOnly=true |
| `warehouse.json` | 仓库(6.16.6) | baseSlots,expandBase,expandRate,cap |
| `miscItems.json` | 杂项(6.6/S21) | id,name,useType(playAnimation),animation,desc |
| `potions.json` | 药水(18.3) | id,kind(red/blue),tier,restoreAmount,cooldown,price,stackMax |
| `maps.json` | 地图(17.5) | id,name,size,tierRange,carterLinks[],spawnPoints[{monsterId,respawnTime}],bossSpawn |
| `localization.json` | 文案外置(22.1) | key→text（首版中文，预留多语言） |

- **Schema 约定**：所有数值字段可配；`quality` 枚举 common/uncommon/rare/epic/legendary；`tier` 由等级推导(15.2)；新增物品/怪物只需加 JSON 条目 + 对应图标，无需改代码。
