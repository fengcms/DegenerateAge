# P0 工程初始化验收记录

日期：2026-10-10。

## 交付范围

建立 Swift Package 原生 macOS 应用，SwiftUI 承载 SpriteKit 占位场景。Core、Data、Persistence 为独立编译模块；渲染和 UI 在应用模块内分目录。提供测试营地 JSON、基础模型、配置校验入口、快照编解码检查、应用打包脚本、协作规则和运行说明。初始化 Git，修正 GDD 附录 A 的需求文档路径。

未实现 P1 移动/战斗、P2 自动行为与实际存档写入；最小快照并非正式游戏完整存档协议。

## 实际验证

环境：Apple Silicon，macOS 26.6.2，Swift 6.3.3，Command Line Tools。

| 检查 | 结果 |
|---|---|
| `swift build` | 通过，应用及独立规则检查程序编译成功 |
| `swift run RuleChecks` | 通过，输出 `PASS: 6 rule checks` |
| `./scripts/build-app.sh` | 通过，release 编译、资源复制、ad-hoc 签名成功 |
| `.app` 实际启动 | 通过，内置配置成功加载，显示菱形地图、障碍色块、青色角色与 HUD |
| 原始窗口与系统放大窗口 | 通过，两种尺寸下地图、角色可见，HUD 可读 |
| `git diff --check` | 通过 |

规则检查覆盖六组：正常配置、重复 ID、失效引用和阻挡出生点、尺寸和怪物参数、损坏 JSON、最小快照往返编解码。

## 工具链调整与限制

本机未安装完整 Xcode，`xcodebuild` 不可用；Command Line Tools 不包含 XCTest 和 Swift Testing 模块。当前以独立 RuleChecks 程序完成自动验证，未声称 `swift test` 通过。后续完整 Xcode 环境需验证 IDE 启动并迁入标准测试框架。没有新增第三方依赖。

本轮验证当前机器，不代表全新机器已经实际验证。macOS 14 最低版本尚未实测。后台暂停已接入 scenePhase，但暂停五分钟的正式游戏行为测试须在 P1/P2 有模拟行为后执行。打包产物只供本机开发，尚未配置发布签名、公证和安装器。
