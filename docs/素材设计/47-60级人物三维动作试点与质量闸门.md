# 60 级人物三维动作试点与质量闸门

后续复核发现，本试点的程序化模型没有以既有原画或八向母版为直接建模输入，且人物尺寸、脚底和动作质量均未通过。更完整的原因、量测与修正顺序见 [60 级人物三维试点偏差分析](60级人物三维试点偏差分析-2026-10-25.md)；本文件中的“技术上可行”只表示可以输出帧，不表示造型或动作合格。

本文件记录以游戏现有 `look_06`（51—60 级阶段形象）为对象的一次**未接入游戏的技术试验**。目标是验证「先建立三维角色、制作连续动作，再从固定正交机位烘焙八方向 2D 图集」能否改善目前的走路、攻击和打坐表现。现有角色身份和视觉定稿不作变更。

## 现状与实测证据

- 定稿人物在 [look_06_lv51_final.png](样板/11-51级角色形象/look_06_lv51_final.png)。运行素材登记在 `scripts/systems/character_look.gd` 的 `look_06` 项；每格 64×80，八方向 `s, sw, w, nw, n, ne, e, se`，脚底锚点为 `(32,64)`。
- [图集构建器](../../tools/build_player_stage_looks.gd) 当前将四排走路关键姿势扩成八帧；`look_06` 第四排脚部裁切，所以第 4 姿势复用第 2 姿势。攻击由接触、收势、站姿拼成六帧；打坐由一张坐姿加像素级上下位移拼成四帧。这些是代码证据，解释了动作重复感，但不能仅凭代码量化玩家的主观感受。
- 本次用 Blender 5.2.3 在本机运行 [试验构建脚本](../../tools/player_3d/build_look_06_pilot.py)，生成可编辑的 [三维工程](../../art_source/player/look_06/3d_pilot/look_06_3d_pilot.blend)、八方向站立图、走路/攻击/打坐各八张连续审稿帧。一次完整离线生成约 21 秒（脚本日志计时，仅代表本机此脚本，不是游戏性能测量）。

## 试验结果

| 检查项 | 结果 | 证据 |
|---|---|---|
| 同一模型在八方向保持盔甲、剑、环位置一致 | 技术上可行 | `art_source/player/look_06/3d_pilot/look_06_dir_0.png`—`look_06_dir_7.png` |
| 骨架枢轴产生逐帧连续动作 | 技术上可行 | `walk_preview.gif`、`attack_preview.gif`、`sit_preview.gif` |
| 与定稿人物的造型相似度 | **未通过** | [站立审稿图](../../art_source/player/look_06/3d_pilot/look_06_idle_review.png) 对照 [定稿](样板/11-51级角色形象/look_06_lv51_final.png) |
| 游戏尺寸下的角色辨识度 | **未通过** | [64×80 缩小图](../../art_source/player/look_06/3d_pilot/look_06_native_64x80.png)；脸、破边披风、石甲裂纹与金线层次大幅丢失 |
| 动作自然度 | **未通过** | 走路脚部有滑移和离地；挥剑接触路径与握持不稳定；打坐时剑与地面关系不对 |

原定稿是细节丰富的二维插画。程序化基础几何只重建了黑发、围巾、旧石甲、青石、剑和开口环等**语义元素**，没有还原脸形、服装剪裁、甲片轮廓、破损纹理与材质绘制。三维模型与动作绑定确实让姿势之间的变化更连续，但它不会自动让造型达到原稿质量；模型质量是这条制作路线的前置条件。这是本次实际渲染得出的结论，不是对三维烘焙路线整体可行性的否定。

## 处理决定

此试验不覆盖 `assets/sprites/player/stage_looks/look_06/`，不改 `CharacterLook` 的运行登记，也不更改伤害结算与攻击命中时机。试验工程保存在 `art_source` 供后续动作、相机和八向烘焙复用；当前素材不得标记为正式角色资源。

下一阶段先攻克三维角色造型本身，而非继续批量出帧：

1. 以定稿全身图和八方向母版为同一角色的正面、背面、侧面约束，制作有实际体积的头脸、发簇、甲片、腰摆、披风、剑与旁路环；武器独立于手部，披风使用可控制的局部骨骼或简化动力学，并保留披风破边。
2. 完成统一的材质与手绘纹理后，仅渲染八方向站立和一个走路循环。先在 64×80 原生尺寸与游戏地面上对比，不用高清预览代替验收。
3. 站立轮廓、身份特征和走路脚步通过后，再补攻击与打坐；攻击动作的接触帧需对齐现有战斗结算当帧，若调整逻辑时机须单独评审。
4. 正式烘焙保留固定正交相机、固定光照、统一脚底锚点、八方向顺序和透明背景；打包后检查八向轮廓、方向切换、剑环握持、遮挡、贴图边缘与内存，再接入游戏 A/B 测试。

**进入游戏的闸门**：三维版在 64×80 下仍能认出原人物，八方向武器不换手、不穿模；行走脚部不滑移，攻击的剑与手连续且命中帧明确，打坐坐姿能稳定循环。当前试验未满足这些条件，故不接入游戏。若要保持原稿的精致程度，需要在 Blender 中对模型、纹理和绑定进行专业级细化；仅靠这份程序化模型不足以达到目标。

## 复核方法

在仓库根目录运行 `blender -b -t 4 --python tools/player_3d/build_look_06_pilot.py`。输出全部在 `art_source/player/look_06/3d_pilot/`；打开 `.blend` 可在时间轴查看站立 1—16、行走 21—45、攻击 49—72、打坐 77—108 帧。对照现有运行素材和定稿图，重点看原生尺寸与脚底位置。脚本会覆盖同目录同名试验输出；不会写入正式 `assets/`。
