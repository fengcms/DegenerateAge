# 战斗动作接管与复活表现修正

2026-11-18，外围路线接入前检查隔离表现适配器。

## 现象与根因

旧适配器在宿主复活后仍保持death动作，因为只处理进入死亡，没有处理宿主is_dead恢复false。攻击期间发生实际移动时也保持攻击姿态直到恢复结束，造成滑行观感。两者均属于表现层状态遗漏，不是伤害或移动规则问题。

## 修改与证据

art.gd根据宿主死亡状态退出倒地；正式攻击仍从接触帧开始，接触至少保留0.08秒后，实际位移可切回行走。受击持续0.16秒后恢复，倒地仍0.90秒，未延迟伤害、减少碰撞半径或修改生命。

在真实Player实体上完成点击绕箱、攻击后移动接管、受击恢复、apply_damage致死和_revive复活，CAMP_CONTROLS_OK通过。此功能测试不代表每一帧造型已经精修，也不代表骑乘/打坐外观齐备。影响范围仅tools/camp_combat的表现适配器。
