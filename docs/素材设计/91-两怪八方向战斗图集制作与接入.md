# 两怪八方向战斗图集制作与接入

本阶段补足两类怪物除既有左前以外七方向，每方向待机、行走、攻击、受击、倒地四帧。共14张原创20姿态源页，经离线构建得到70张运行图集，结合原左前包合计80张。全部来自内置image_gen，以项目狼/铜甲虫为身份参考，提示词随源页保存，无左右镜像。

源页实际1295×1214，按四列五行比例定位，单格取323×242，遗漏不足一像素的透明分隔。固定0.32缩放、源锚点(格宽×0.5,格高×0.96)，运行128×96、脚底(64,80)。新方向构建边缘alpha须≤0.05，输出尺寸与锚点固定。修正过铜甲虫左后浅色底，以及铜甲虫左/正前/正后和狼正后的触边问题；原候选保留溯源，build.json只选择合格版。

八向按正式SampleActorArt编号s/sw/w/nw/n/ne/e/se选择。加载期缓存区域，原地待机3fps，步态以实际位移64像素循环；攻击遵循正式即时伤害，从接触阶段开始，受击0.16秒，倒地0.90秒，死亡清理仍由Monster管理。没有修改正式AI、伤害、掉落或存档。

构建、80张清单核对和新素材下真实战斗回归通过；独立方向内容不重复。完整矩阵输出三角色×八向×五状态×四阶段十二张窗口页，人工查看狼、甲虫和主角原尺寸表现：怪物未见矩形底或裁边；不同视角仍有体量和材质细节差异，后续可继续精修，不宣称人工逐像素同构。

同一矩阵发现历史主角左后行走灰底，另立修复，不与本阶段怪物素材混为通过。联系表工具和三轮重开采样继续开发中。

内存：两怪RGBA8理论15360KiB，新增13440KiB；主角7616KiB，角色动作合计22976KiB约22.44MiB。实际场景还含环境、旧正式预载和驱动资源，必须另测。每实例不复制图集；缓存由适配脚本按种类共享，布局释放节点，进程退出释放资源。
