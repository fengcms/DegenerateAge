# 模块化营地正式接入与回归记录

2026-11-19。正式Game场景现在以64×32模块图集拼装营地地面、草地和道路，并使用已确认的新棚屋及树木。保留正式地图坐标、服务身份、原整体碰撞及导航，未把64×16外围演示替换成正式营地。

## 实现与范围

CampModularArt从正式白盒折线编译出的110×110道路/草地掩码建立三张静态网格。土底、草地、道路保持层序，16相位与47邻接规则复用样板，矩形边缘同步裁切顶点与UV。没有整图背景替代地形，也没有逐瓦片Node。每次进图构建一次，离图随地图节点释放；网格和掩码不在每帧重建。两张1024×1536 RGBA8地面图集理论共12MiB，纹理仅在进营地时加载，由当前地图的网格持有并通过资源加载器共享；不使用脚本常量预载让其他地图也驻留这12MiB。

铁匠棚、货郎棚与长老树采用模块精灵，树冠/屋顶使用局部蒙版淡出。仅三个物件进行遮挡更新，各缓存一份掩码图像和玩家引用；位置不变时只推进未结束的过渡，不创建新纹理。物件脚底按世界Y排序，不改变碰撞。仓库、镇灵灯、马车、营火和训练围栏仍是现有独立透明物件，未以不对应功能的素材强行替换。NPC、木桩、后续装备档位的风格全面统一不属于本次已完成范围。

正式营地仍为110×110逻辑网格、3200×1800世界矩形，五NPC、两出口、三木桩。既有白盒、导航掩码、服务点、存档版本和迁移规则未改变。新旧存档沿用原落点校验；不做没有必要的坐标迁移。
