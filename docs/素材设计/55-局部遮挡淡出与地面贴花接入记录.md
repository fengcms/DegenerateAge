# 局部遮挡淡出与地面贴花接入记录

2026-11-17。承接54号实验场，保持16×16格地图与1280×800参考窗口。正式地图、怪物和存档未变更。

## 本轮交付

- 两种原创透明贴花：草根、碎石。内置image_gen生成，源稿和完整提示词保存于 `art_source/environment/camp_modular_v1/`，运行图集为256×64。
- 两份布局各12处贴花，共用一个网格和纹理，固定在道路上方、实体下方，无碰撞。运行时压低亮度和alpha，避免碎石形成亮斑。
- 新增 `SampleOccluder` 与 `reveal.gdshader`，在人物位于树/棚屋后方且头身与上部不透明像素相交时，局部淡出。人物到前方或离开后约0.2秒恢复。仍用原脚底Y排序。
- 树/棚屋alpha图像初始化时各缓存一份；人物位置改变才做至多9点采样，位置不变时只推进尚未结束的淡入淡出。无每帧读图、无屏幕纹理采样、无新增动态光。

## 验证结果与证据

最终执行 `python3 tools/modular_camp/launch.py --verify --capture /tmp/modular-camp-reveal-final`。Godot4.7.2、Compatibility、Apple M1 Max，退出码0，输出MODULAR_CAMP_VERIFY_OK。

保留图集、道路共边、草路互斥、真实长路径、门洞、正面碰撞、绕墙与移动墙失效全部断言。新增：

1. 自动从可通行网格选出会被树或棚屋遮挡的位置，使用现有CaveLayout路径和平滑、真实CharacterBody2D移动到达；到达误差小于8像素。
2. 遮挡位置淡出量大于0.99；前方恢复后小于0.01；远处不误触发。
3. 过程中导航版本、阻挡格和碰撞数量不变，贴花不创建碰撞子节点。
4. 输出实际窗口淡出/恢复截图，并目视确认上部局部透明、下部保持实体。

首轮遮挡截图仅使用手动摆放点，不能证明正常走路可触发，故已替换为可通行点实际到达验证。最终截图不表示角色站到屋顶上：角色仍在地面，屋顶局部透明显示其被遮住的身体；没有增加上楼、室内或屋顶碰撞规则。

## 预算与边界

地面网格由3份增至4份，贴花理论RGBA8增加64KiB。两份alpha缓存按当前树452×230、棚屋392×200估算约0.70MiB；另有材质和驱动开销。当前仅2个遮挡对象，最坏每次人物位置变化18次alpha采样；切布局释放旧对象、材质和图像引用。没有新增帧率/显存实测，不把通过逻辑检查等同于稳定60FPS。

高度蒙版按树上部68%、棚屋上部56%近似，边界有柔化；这是显示策略验证，不是逐像素区分树冠/树干和屋顶/墙体的最终美术分层。人物附近可见柔化窗口，后续需精修轮廓mask以减少人工切割感。墙角其余方向、端帽、自然路缘破口及角色连续动画仍未完成。

下阶段应把树冠、屋檐从这种近似高度范围升级为明确的轮廓蒙版，同时继续补齐模块接头；正式营地迁移需另做全图布局、遮挡与性能验收。
