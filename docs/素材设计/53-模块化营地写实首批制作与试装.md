# 模块化营地写实首批制作与试装

2026-11-17。承接52号结构样板，在相同的两份16×16格布局上替换新风格资产，不使用整张背景。

## 本轮产物

- 两张原创材质母版：低对比土壤与较平整的夯土道路。
- 独立古树、棚屋、短墙透明源稿及运行PNG。墙原先太长，缩至单格后变成细条，已定向重做短高墙段；长墙仅保留源稿。
- 离线构建脚本 `tools/modular_camp/build_assets.gd`：周期共边收口、等距投影、16种相位与47道路形状、透明裁切和缩放。图集1024×1536，共768格，单格64×32。每个地面位置取确定相位，不在加载时生图。
- 复用原两套布局，调整棚屋占地为4×4格，继续以同源占地生成显示位置、通行掩码和碰撞。

## 验证与证据

窗口环境：Godot4.7.2 / Compatibility / Apple M1 Max / 1280×800。新素材及棚屋占地变更后执行 `python3 tools/modular_camp/launch.py --verify --capture /tmp/modular-camp-art-v2`，退出码0，输出MODULAR_CAMP_VERIFY_OK。覆盖道路规范化与共边alpha、两布局通行碰撞一致、实际物理长路径、门洞、正面阻挡、绕墙、移动墙失效。

追加headless验证全部768图集格的中心不透明和角部透明，退出码0且输出成功标记。

最终运行截图：[布局A](样板/模块化营地-写实首批/布局A.png)、[布局B](样板/模块化营地-写实首批/布局B.png)。这些是引擎拼装后的窗口截图，不是AI合成的地图。物件尺度和气氛已经比结构旧素材一致，地面噪点显著收敛（目视判断，非量化质量指标）。

图集理论RGBA8为6MiB，另有物件和引擎开销；未测量显存、P95/P99或宣称达到60FPS。PNG生成耗时不等于游戏加载耗时。启动验证器现在检查成功标记和SCRIPT ERROR，避免退出码0误报通过。

## 尚未通过的完整制作项

草土过渡族、低密度贴花、墙另一轴向/转角/端帽、树冠和屋檐分层还未完成；现有墙重复接头仍有可见竖缝，树与屋的脚底锚点仍需要按精确接地轮廓细化。道路目前是规则软边，缺自然破口。棚屋封闭、无室内，不能把其门作为已实现的可穿门洞。角色仍为静态占位；本轮没有制作连续动画或怪物战斗表现。

本批为新风格模块首批试装，不是完整营地成品。正式地图、任务、怪物与存档均未改动。下一步补墙连接件和草土过渡，再做遮挡分层，不能直接扩产全章节。
