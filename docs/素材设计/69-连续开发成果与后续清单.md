```sh
python3 tools/modular_camp/launch.py
```

| 操作 | 当前效果 |

| 点击 / WASD | 现有导航与真实物理移动 |

1. 精修两方向步幅、脚滑、布料变化与站走过渡；当前是四帧简化试装。
2. 用明确姿态参照制作左向及其余方向；首轮左向仅头部转向明显、身体脚尖不合格，已排除，不能用镜像补剑手。
3. 两怪已有待机，但仍缺行走、攻击、受击、死亡。动作扩展时先明确事件时序，再接正式怪物外观库，不能让图片帧决定伤害结算。
4. 完善物件视觉占地，尤其木桶保守单格占地与树屋轮廓；随后逐步接正式地图并按地图规则更新README/回归。
