# 两类怪物四阶段攻击试装验收

2026-11-18。主角挥剑后继续制作腐化狼短促咬击和铜甲虫合颚。两者由内置image_gen参考各自待机源稿生成；源稿、build.json与完整提示词位于art_source/actors/wolf_attack_trial_v1和beetle_attack_trial_v1。狼首稿各帧边缘alpha最大0.251—0.337，被拒绝；透明提取第二版通过。甲虫首稿最大约0.00392，通过小于0.05的构建门槛。

## 实现与实际效果

每个角色四帧128×96，运行图集128×384，与待机共用(64,80)锚点及0.16倍率，不逐帧移动脚底。阶段0.20/0.12/0.12/0.20秒，总0.64秒。R同时触发单次攻击，播放中重复触发拒绝；结束恢复待机。K保留当前动作暂停，L逐帧，攻击末帧回到待机首帧并保持暂停；J取消并回原图。场景实例重建时释放全部旧状态，没有定时器或补帧队列。

两怪只是展示Sprite，未增加AI、位移、碰撞或伤害。visualContactFrame=2只是制作参考。正式monster.gd与monster_animation_library.gd仍沿既有事件和接触帧规则运行，未登记新外观，也未改变掉落或玩家存档。

## 成本与后续

新增两图集RGBA8理论各192KiB、共384KiB，八个区域引用，没有新增节点、碰撞或寻路更新。两个活动Sprite复用原帧回调，每次最多检查四阶段；暂停或J关闭不运行回调。验收临时八张截图最多31.25MiB，写出清空，普通运行无截图成本。本轮没有重测帧时间，不承诺密集战斗60FPS。

本轮连续完成左后站走、主角挥剑、两怪攻击三个独立成果。后续继续正向视角、其他攻击方向、受击与死亡，最后按正式外观库接入，不把当前单方向展示视为完整动作包。
