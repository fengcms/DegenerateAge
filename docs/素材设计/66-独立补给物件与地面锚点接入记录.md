# 独立补给物件与地面锚点接入记录

2026-11-18继续完善模块化资产包：原木箱是旧占位素材，与新棚屋、墙体材质不一致且在样板中较小。新增原创旧木箱与木桶，保持地图由独立素材拼接。

## 制作与接入

使用内置image_gen生成两物件素材页，完整提示词和裁切/尺寸/源锚点保存在art_source/environment/camp_supplies_v1。仅离线裁切缩放为crate.png 60×51和barrel.png 44×51，不把原图当地图使用，不覆盖正式旧crate素材。

木箱底面接触中心映射到(30,34)，木桶到(22,44)。build_assets.gd把尺寸与锚点写入manifest，main.gd读取后用原尺寸摆放，不再重复硬编码输出高度或使用图片最低边做落点。木桶底座宽44px而导航储物区为64×32一格，保留约10px侧向余量；没有宣称逐像素碰撞。

两套layouts.json分别摆放木桶(2,11)、(12,3)，原木箱位置不变。两类物件通过已有布局事实源生成占地、导航与静态物理体；不增加开箱、掉落或战斗逻辑。

## 验证证据

构建输出CAMP_SUPPLIES_BUILT与完整成功标记。`python3 tools/modular_camp/launch.py --verify --capture /tmp/camp-supplies`在Godot 4.7.2 Compatibility窗口退出0并输出MODULAR_CAMP_VERIFY_OK。

新增专项逐一检查两图尺寸/锚点与manifest一致，再从可通行邻格驱动真实CharacterBody2D向物件移动，要求碰到该格对应的物理体且未进入中心。不能用撞到其他墙代替通过。两布局各两物件全部通过，既有256格导航/碰撞一致性、门洞、绕墙、移墙、四帧行走、停帧、双怪待机和遮挡测试保持。

人工检查/tmp/camp-supplies/supply_crate_0.png和supply_barrel_1.png，尺寸与人物/建筑关系可用，未见背景底框。木箱底面以接触中心排序，木桶较窄，后续仍需更精确的视觉占地审查。

## 成本与后续

两图理论RGBA8合计20,400字节（约19.92KiB），新增木桶每布局一个静态物理体、一个碰撞子节点及一个Sprite2D；B调试另有一个覆盖节点。物件无process回调，纹理按路径共享缓存。加载/切图准备增加一格占地和节点创建，移动期间不重建网格或寻路表。未实测FPS提升，正式地图尚不引用。

后续继续补方向站姿、受控行走姿态与环境可复用物件；不因局部样板通过便宣称正式美术全部完成。
