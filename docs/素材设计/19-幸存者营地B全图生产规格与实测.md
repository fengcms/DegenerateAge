# 幸存者营地 B 全图生产规格与固定窗口实测

本记录对应既定计划的**第二节点**：用精修后同场景 A/B 样板确定全营地素材与装配规格。测试由 [CampStyleBenchmark.tscn](../../tests/CampStyleBenchmark.tscn) 在两个独立进程分别只加载 A 或 B；固定 macOS Retina 屏幕倍率 2.0、1280×800 逻辑视口、2560×1600 截图、同玩家/NPC/镜头、100%/150%/200% 地图倍率。每倍率预热 20 帧、采样 100 个实际绘制帧，独立重复三轮。它冻结世界玩法更新，只比较静态地图，**不代表战斗或满图探索帧率**。

## 实测

| 项目 | A | B | 判断 |
| --- | ---: | ---: | --- |
| 100% 帧间隔中位数（三轮） | 0.63 / 0.66 / 0.69 ms | 0.67 / 0.64 / 0.67 ms | 差异落在本机轮次波动内 |
| 150% 帧间隔中位数 | 0.60 / 0.59 / 0.62 ms | 0.60 / 0.61 / 0.62 ms | 差异很小 |
| 200% 帧间隔中位数 | 0.57 / 0.57 / 0.59 ms | 0.59 / 0.58 / 0.58 ms | 差异很小 |
| 可见绘制调用均值（100% / 150% / 200%） | 21 / 15 / 14 | 21 / 15 / 14 | 相同分层数量，没有因 B 多出绘制节点 |
| 场景首次装配（三轮） | 81.01 / 81.58 / 80.26 ms | 138.27 / 132.01 / 137.56 ms | B 在本机约多 51–57 ms |
| 同进程热装配（三轮） | 77.93 / 79.62 / 81.16 ms | 131.17 / 132.16 / 131.70 ms | B 仍多约 50–54 ms；含正式世界装配，不是单贴图解码 |
| 纹理监视器加载增量 | 17.45 MiB | 38.91 MiB | B 比 A 多 **21.46 MiB**，与新增源像素的 RGBA8 大小一致 |
| 九张运行 PNG 磁盘大小 | 0.97 MiB | 2.65 MiB | B 有额外存储与导入成本 |

固定窗口[原始 JSON 和六张同镜头截图](样板/幸存者营地B生产规格/)可复核清晰度。100% 与 150% 下 B 的石墙、屋瓦和树冠仍比 A 稳定；200% 时 B 的大实体轮廓保留，地面颗粒和道路本来按低频处理，允许比实体柔和。角色和交互文字在三个倍率下都清楚。首次装配数字是**导入已完成后的进程内场景装配**，不等于操作系统冷盘读取或全游戏启动时间；GPU 使用量由 Godot `RENDER_TEXTURE_MEM_USED` 监视器观察，未把 PNG 文件大小冒充显存。

作为正式地图现行基线，固定 1280×800 窗口的 `MapRenderBenchmark` 对未改的正式营地报告中位 **1.029 ms**、P95 **1.113 ms**、约 **169.2** 绘制调用；该基准包含主场景地图 UI，与上述只显示局部样板的 21 调用不是同一负载，不直接相减。全图接入后必须用同一 `MapRenderBenchmark` 复测。

## 采用的全图制作规格

1. **唯一坐标事实源。** 继续使用 `data/map_art/camp_whitebox_v1.json` 的 1672×941 参考画布、3200×1800 世界矩形、110×110 通行网格、7 个实体足迹及 15 个围栏/岩石障碍。绝不移动 NPC、出口或训练场；所有新素材的脚底承重点须落在既有不可走轮廓，屋檐和树冠可外伸但必须独立遮挡。
2. **底层分辨率。** B 地纹以当前 256×256 有效源像素为基本单元，镜像拼成可重复图集，不把整张旧低清原画整体放大。道路与贴地阴影是独立透明层，由现有道路折线生成平滑、低对比边缘；道路属于可踩地面。优先复用地纹，必要时将道路透明层按区域分块，避免另存一张带所有实体的整图。
3. **整体实体。** 铁匠铺、仓库、货郎摊、镇灵灯、长老树、马车各为整体透明精灵，按 B 样板的 **2 倍参考有效像素**制作。所有可绕行实体交付像素互斥的背层与前沿遮挡层，按现有 `foot_y` 排序；围栏和岩带按既有每段多边形作连续整体条段，而非单格瓦片。小型装饰只画成可踩的地面印迹，不新增假的立体障碍。
4. **验收闸口。** 先验证全图每个实体承重区与通行掩码、角色真实绕行、NPC 与出口位置，再运行 100%/150%/200% 和 Retina 截图；同场景比较现行正式地图与 B 全图的装配、纹理监视器、绘制调用、中位/P95/P99 帧间隔。以 60 FPS 的 **16.67 ms 整帧预算**评估完整游戏，不把静态样板的低于 1 ms 当作全游戏性能承诺。若 B 全图的加载或纹理成本超出可接受范围，先收紧远景与道路层的源像素，不缩小焦点实体或破坏碰撞。

复核命令：`DEGENERATEAGE_CAMP_BENCH_STYLE=a python3 tools/run_isolated_tests.py --rendered CampStyleBenchmark` 与 `DEGENERATEAGE_CAMP_BENCH_STYLE=b python3 tools/run_isolated_tests.py --rendered CampStyleBenchmark`；正式现行基线为 `DEGENERATEAGE_RENDER_ONLY_CAMP=1 python3 tools/run_isolated_tests.py --rendered MapRenderBenchmark`。下一节点按此规格制作和接入全营地，并用同一正式基准做前后对照。
