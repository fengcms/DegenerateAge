# 主角左后行走透明背景修复

2026-11-18，真实战斗素材原尺寸对照检查发现左后行走带灰色矩形雾底。其余方向不能据此推断有同样问题。

## 原因与修改

旧源稿hero_walk_nw_trial_v2/candidate.png虽含alpha通道，但保留可见背景；构建仅检查有alpha，透明边缘断言未覆盖nw，因此被正常打包进入hero_walk_nw_v2.png。

使用内置image_gen执行背景移除，提示词保存在alpha_prompt_v3.json，新源稿candidate_alpha_v3.png保留2048×768四列布局、0.14缩放、源锚点(275,710)、运行帧112×128及锚点(56,112)。未覆盖原候选，未用色键破坏盔甲。构建事实源与生成清单同步，并将nw纳入逐帧透明边缘断言。

## 复核

运行modular_camp/launch.py --build-assets成功，主角八方向动作目录检查通过，理论RGBA8仍7616KiB。camp_combat/launch.py --review --capture生成12张实际渲染对照页，hero_phase_0左后行走背景已与页面一致，无原先矩形灰底。源稿透明区存在RGB颜色不等于可见背景，以alpha和实际绘制共同判断。

影响范围为隔离动作样板及真实战斗样板共用的左后行走图集，不改攻击、碰撞或数值。此检查能拦截帧边缘脏像素，内部雾底仍需原尺寸视觉审查。临时对照截图审查后删除，复核命令可重新生成。
