## 0. 一句话结论

「**八向 + 可分层的**人形角色」在开源素材里**基本不存在**；三者（八向 / 分层 / 宽松许可）能同时命中的实测包只有一个，且风格与画质不符。现实里必须在**方向数**与**分层**之间取舍，或自建管线。

## 1. 先明确一件事：等距里的"八向"是什么

等距不能靠旋转复用帧，每个朝向必须单独绘制。这里的"八向"即**网格四正交（N/E/S/W）+ 四对角（NE/SE/SW/NW）**，在 2:1 投影下恰好显示为屏幕八向——与 [01 §4](01-视觉与技术统一规范.md#L67) 的 `s, sw, w, nw, n, ne, e, se` 是同一组。

**关键推论**：市面上绝大多数角色包是**四向**（上/下/左/右），对角四向靠**水平镜像**补。对我们而言，这意味着：

- 镜像补的对角线违反 [01 §4](01-视觉与技术统一规范.md#L67)「武器、盾不允许随意镜像」，且近/远侧遮挡关系是错的 → 「不穿透」方案失效；
- 所以**四向包不等于"打折的八向包"，而是"要我们自己补 4 个斜向"**。这是评估下面所有候选的前提。

## 3. 三条现实路径

| 路径 | 做法 | 代价 | 适用 |
|---|---|---|---|
| **① 四向分层 + 自绘对角四向** | 选 Klimmos（64×80 恰好吻合）/ Mana Seed / LPC，自己补 4 个斜向 | 要补对角帧与遮挡关系；Klimmos 缺 attack | **接入成本最低**，但需美术补帧 |
| **② 真八向分层，接受换风格** | SKYZ0R（CC-BY 4.0），八向 + 400 件可叠装备 | 写实 3D 渲染感、硬边锯齿、148×130 需重排、缺 sit、仅男性；与现有像素素材拼一起会很突兀 | 能立刻拿到"八向 + 换装"能力 |
| **③ 自建 3D → 八向渲染管线** | 用开源 3D 模型 + 脚本批量渲染八向/多帧（可参考 [AUTeddy 的工作流](https://auteddy.itch.io/8-directional-character-mixamo-dummy)） | 需要建模与渲染投入，但**方向数、分层、帧格、锚点全在我们手里** | 长期最可控，与 [11 §3.2 零像素误差对齐](11-角色换装外观方案.md) 的要求最契合 |

**我的建议**：先花很小的成本试**路径 ①**——用 Klimmos 那套 64×80 四向分层包验证整条链路（P0–P4 全部跑通），链路一旦稳定，再决定是补对角帧还是升级到路径 ③。这样**不必现在就把美术方案锁死**，也符合 [11 §5](11-角色换装外观方案.md) 的 P0 先行顺序。

## 4. 核实状态与待办

- **我本人实测**：SKYZ0R（OpenGameArt，CC-BY 4.0 / 八向 / 148×130 / 分层 / 488 帧）；LPC 生成器（许可混合、四向、64×64、署名要求）。
- **代理调研、未逐页实测**：Mana Seed、Klimmos、Mekai、Hormelz、Town Guards、Tiny Swords、Sprout Lands、Ninja Adventure、Zerie、Kenney。
- **购买前必做**：对最终选中的包，按 [12 §4 检查表](12-商业素材采购规格.md#L54) 逐条复核，**尤其确认"是否真八向"**（看同侧持械手在左右两组方向的遮挡是否不同），以及许可原文是否允许商用 + 修改 + 分发。
- 付费包的 EULA 多为自定义条款，**必须读原文**，不能只看商店页摘要。
