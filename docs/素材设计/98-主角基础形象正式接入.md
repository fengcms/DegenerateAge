# 主角基础形象正式接入

2026-11-19。初始形象look_01现使用已验收主角五状态八向素材。正式PlayerCharacter仍通过CharacterLook与SampleActorArt装配，不替换战斗宿主、存档或装备规则。

## 规格与兼容

单帧112×128，脚锚(56,112)，八方向横排，帧纵排。待机1帧，其余行走/攻击/受击/死亡各4帧；攻击从接触帧2开始，死亡表现0.9秒。宿主仍在攻击调用当下结算，不增加前摇。原PlayerCharacter显示比例1.5乘新形象2/3，得到样板的实际1倍尺寸；碰撞半径12不变。移动可在接触反馈0.08秒后取消新挥击恢复。

播放器从各动作定义读取帧数、锚点、显示比例和接触帧，避免把旧六帧死亡/八帧步态硬套到新图集。新造型暂覆盖初始档位；look_02至06、独立人物面板、打坐和骑乘仍沿用已有资产。打坐使用旧(32,64)与1.5倍显示，坐骑使用旧(64,104)；切回步行恢复新脚锚。风格全面统一的休整、坐骑及后续装备素材尚未制作，本次不伪称已完成。

## 构建与验证

build_formal_hero.gd在最小Godot项目执行，输出art_source/actors/hero_formal_v1与assets/sprites/player/guardian_modular_v1。--check逐像素校验；只是无损排列，不缩放、镜像或生成新造型。五图理论RGBA8合计7.44MiB，图集由资源加载器共享，无逐帧I/O。

CharacterLookTest、ArtSampleTest、MountShortcutTest定向通过；DeathChoiceTest、SkillCombatTest通过。正式Game营地窗口装配通过并目视检查主角尺寸。首次尝试新PNG缺少导入描述导致导入失败，经最小项目生成.import后复核；误写不存在的MountTest未算通过，改用现有MountShortcutTest。源PNG与GPU导入纹理的字节格式不同，逐像素验证统一比较源PNG，避免把导入转换误判为重排变形。

共享美术测试只适配初始形象的新规格；保留后续五档原规格、换武器、坐骑、碰撞与伤害检查。原旧脚底像素行断言改为与已确认新源图逐帧像素精确相等，并独立检查新统一脚锚；不是将脚底检查删除或放宽到仅有非透明像素。

复核：`python3 tools/run_isolated_tests.py CharacterLookTest ArtSampleTest MountShortcutTest DeathChoiceTest SkillCombatTest`。全量与导出资源结果随正式营地接入一并记录。

检查发现既有apply_look先显示新档位、后清理旧坐骑键；由带坐骑素材的look_01换到不含坐骑素材的look_02时，可能访问不存在的坐骑定义。现将视觉坐骑键校验移到显示前，不改变GameState骑乘规则。CharacterLookTest新增该跨档位回退用例，与MountShortcutTest定向重跑通过。该修复发生在营地全量快照开始之后，后续报告分别列出全量快照和这两项补测。
