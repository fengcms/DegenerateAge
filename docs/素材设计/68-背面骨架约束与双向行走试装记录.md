# 背面骨架约束与双向行走试装记录

2026-11-18，完成怪物待机与补给物件后，重新处理背面步态阻塞。新的骨架约束候选已接入隔离营地，右上方向由单帧扩展为四帧行走试装；其他方向仍缺失。

## 根因与处理

首轮和一次局部修正都不能可靠交换第1/3帧接触腿，仅靠文字容易重复姿态。build_pose_guide.py新增--direction ne，沿用原等长腿骨和四组接触点，改变相机及人偶排列生成真正的背面参考，不镜像左右肢体。渲染前验证身体前方投影到屏幕右上；默认se仍投向右下。

Blender 5.2.3 LTS分别渲染两个方向并输出POSE_GUIDE_OK。两方向骨架数据frames完全相同，默认se的frames也与原hero_walk_pose_v2数值相同；图像文件校验和不相同，未声称渲染像素逐字节相同。

内置image_gen以背面姿态图与原站姿生成candidate.png，原图/提示词/姿态检查在art_source/actors/hero_walk_ne_pose_v2。固定锚点条带中第1/3帧的腿部交叠与接触姿态有明显区别，允许隔离观察；不能把骨架通过自动等同于生成稿通过，生成稿的布料、步幅和脚滑仍须精修。

另外尝试左向站姿时仅头部转向较明显，躯干和脚尖未可靠转向，已排除，未纳入运行或宣称补齐左向。

## 实现与规格

rearWalkSource记录2048×768四列源稿，统一0.14缩放、源锚点(275,710)，运行图112×512、帧112×128、pivot(56,112)。不逐帧拉伸/贴地/补偿位置。旧右下图与两站姿不覆盖；清单directions为se/ne，SampleWalkSprite按移动意图选方向，但循环仍只累计碰撞后的实际位移，64px一周期。

新增O键实际右上路线，保留P右下、I原地转向、H旧图对照。原静态回退仍适用于未制作方向。审片器新增referencePivot，以实际接触区对齐带透明边的静态站姿，不再错误地按整个帧底对齐；没有调整候选逐帧锚点。

## 验证与修正

构建、审片窗口均通过。`python3 tools/modular_camp/launch.py --verify --capture /tmp/camp-ne-walk`在Godot 4.7.2 Compatibility两布局完整验证退出0，输出MODULAR_CAMP_VERIFY_OK，无SCRIPT ERROR。

新增右上真实移动必须覆盖四帧且纹理来自背面图集；停步恢复背面站姿；原地转向不移动、不开镜像。右上/右下各自持续顶墙，要求真实接近超过10px、播放过行走、连续12物理帧位移<0.01px且有接触，再检查相位清零与对应站姿。两布局均通过。原未制作方向回退、双怪循环、物件碰撞、移墙及遮挡检查保留。

首轮右上顶墙测试选(14,15)，输入沿边界滑动，5秒内没有到稳定角，断言失败；失败后的输入残留也导致紧接着的背面路线检查失败，运行器因SCRIPT ERROR拒绝该次结果。改为与右下共同使用现有右端角附近(14,1)，未增加测试墙、未放宽停稳条件，完整复测通过。

人工检查rear_walk_0_2.png、wall_stop_ne_1.png和四帧条带，未见明显背景底框，转向与停步符合已制作方向。单张截图不能证明完整步态自然，四帧仍是简化试装。

## 成本与后续

新增背面图集理论224KiB，两行走+两站姿合计560KiB。多四个AtlasTexture区域引用，加载期一次建立；每个物理帧增加固定方向判断，不新增节点、碰撞或导航请求。源稿与骨架不复制进运行项目，退出释放缓存；验证背面最多缓存四张截图约15.625MiB，编码后清空。

67号性能数据采于此前dc4202a4，不包含这张新增图集，不能直接冒充本阶段新测量。当前不注册正式八向外观；后续优先细调脚滑/站走过渡，再制作其余方向和攻击、受击、死亡，避免用不合格镜像素材凑齐方向数。
