# 商业素材采购规格（角色换装用）

> ⚠️ **本文已暂时废除（2026-10-15）**
> 角色美术方案已改为「**阶段形象 · 八向单层**」，因此本文 §2 的「**可拆分**（裸装体 / 护甲 / 武器）」与「**像素级同构**（误差 0 像素）」两条门槛**作废**——两套形象永不叠加，不需要对齐。**仍然有效**的是：八向、帧格规则与锚点统一、许可合法性（卖方须为著作权人或持有可转授授权链）、动作覆盖，另加「多套形象须同作者同画风」。
> 当前门槛以 [15-角色形象与素材方案（阶段形象 · 八向单层）](15-角色形象与素材方案（阶段形象·八向单层）.md) §4 为准。本文保留作历史参考。

日期：2026-10-15。状态：**采购前置规格，花钱之前先定**。

用途：把 [11-角色换装外观方案](11-角色换装外观方案.md) 对素材的硬性要求，翻译成一张"买之前逐条勾选"的清单，避免买到不能用的包。依据 [01-视觉与技术统一规范](01-视觉与技术统一规范.md)、[02-分类素材设计规范](02-分类素材设计规范.md)。

## 0. 一句话结论

要买的是「**八向 + 分层（可换装）**」的角色包。**四向包和单层烘焙包直接不用买**——前者会让 448 帧计划作废，后者会让"装备驱动形象"无法实现。

## 1. 为什么必须先定规格

商业像素包的常见形态，与我们的契约冲突如下。**买之前对着这张表看包**：

| 包的实际形态 | 能否用 | 原因 |
|---|---|---|
| **四向**（上/下/左/右） | ❌ **不可用** | 对角线只能靠镜像补，直接违反 [01 §4](01-视觉与技术统一规范.md#L67)「武器、盾不允许随意镜像」；且镜像后的近/远侧遮挡关系是错的，"不穿透"无从谈起 |
| 八向，但武器/护甲**烘焙进身体** | ❌ **不可用** | 无法只换衣服或只换武器，等于回到"MVP 只改数值" |
| 八向 + 单层，但同作者提供**同构变体**（裸装体 / 穿甲体 / 持械体） | ✅ **可用** | 变体之间像素级同构时，等价于分层；按"每个设计各一套"接入 |
| 八向 + **真分层**（身体/衣服/武器分成独立图层或独立文件） | ✅ **最优** | 直接对应 11 号文档的 `body` / `cloth` / `arm` 三层 |
| 俯视（top-down）八向 | ⚠️ 风格不符 | [01 §3](01-视觉与技术统一规范.md#L45) 是 2:1 等距斜角（64×32 地砖、约 30°），俯视角与现有营地/野狼不搭 |
| 单帧尺寸不是 64×80（如 32×32、48×64、128×128） | ✅ 可适配 | 由 P0 工具最近邻重排到 64×80（整数倍优先） |
| 网格/帧数/方向序与我们的契约不同 | ✅ 可适配 | 由 P0 工具重排（列＝方向、行＝姿势帧） |
| 调色板、描边、明暗方向与现有素材不一致 | ⚠️ 可缓解 | 需要程序化限色板 + 人工修，属风格统一成本 |

## 2. 硬性要求（不满足就别买）

1. **八向**，且每个方向都是独立绘制（不是镜像出来的）。判断方法：看包的预览图里，**同一只持械手在左右两组方向的遮挡关系是否不同**——若不同，就是真八向。
2. **可拆分**：至少能拿到 ①**裸装基础体**（对应"只穿裤衩"）②**一套护甲** ③**一把武器**，三者同角色、同作者、同画布、同锚点。
3. **像素级同构**：同一角色的不同变体之间，逐帧的肩、肘、膝、脚底轮廓**重合**（误差 0 像素，即 [11 §3.2](11-角色换装外观方案.md) 的判定标准）。这一条是"不穿透"方案能成立的前提——若变体之间轮廓就对不上，叠加会露出破绽。
4. **帧格规则**：每帧严格等宽等高、锚点统一（脚底），**不是每帧按包围盒裁切贴合的**。包围盒裁切的包，接入时必然错位。
5. **授权**：明确允许**商用 + 修改 + 随游戏分发**，**且卖方须为著作权人或持有可转授的授权链**——付款凭证不等于授权，成品游戏资源的提取/转卖不满足本条；保留购买凭证。按项目既有流程做来源登记（见 §6）。
6. 透明背景 PNG；建议**附带分层源文件**（`.aseprite` / `.psd` / 分图层导出）。
7. **动作覆盖**：至少 `idle` + `walk`；`attack` / `hit` / `death` / `sit` 为加分项，缺的状态可先由现有回退机制顶着（[AGENT.md §3](../../AGENT.md#L41)）。

> 参考量级：按 11 号方案，每个设计需 3 张图集共 **112 帧**（主 8×8、受击/打坐 8×2、行走 8×4）。首批 = 基础体 + 1 护甲 + 1 武器 = **3 个设计 / 336 帧**；若包本身自带完整动作集，直接按包内规格重排即可。

## 3. 可适配项（不要求包原生满足，由我们改造）

这些**不用**作为采购门槛，P0 打包工具会统一重排：

| 项 | 包的原样 | 我们的处理 |
|---|---|---|
| 网格布局 | 任意（可含边距、多块拼版） | 按配置切成固定网格 |
| 方向序 | 任意（如 N/E/S/W 起始） | 重排为 `s, sw, w, nw, n, ne, e, se` |
| 行/列语义 | 可能"行＝方向"（见 [01 §4](01-视觉与技术统一规范.md#L84) 两套约定） | 重排为**列＝方向、行＝姿势帧** |
| 帧数 | 如 idle 2 帧、walk 6 帧 | 按节拍映射到运行时的行序，不做等量强求 |
| 帧尺寸 | 非 64×80 | 最近邻缩放到 64×80，整数倍优先 |
| 命名 | 作者自定 | 重命名为 `<设计ID>_<状态>.png`（[11 §3.8](11-角色换装外观方案.md)） |
| 调色板 | 与现有素材不一致 | 程序化限色 + 人工修（计入风格统一成本） |

**正因为有这些可适配项，采购门槛只看 §2 的 7 条硬性要求。**

## 4. 购买前检查表

- [ ] 是**八向**，且预览图里左右两组方向的持械手遮挡关系不同（非镜像）
- [ ] 能看到**逐方向的动作预览**（不只是单张立绘）
- [ ] 武器、衣服**与身体分开**（或提供同构变体）
- [ ] 有**裸装基础体**（对应"只穿裤衩"）
- [ ] 变体之间**同角色、同作者、同画布尺寸、同锚点**
- [ ] 帧格规则、锚点统一（非包围盒贴合）
- [ ] 授权允许**商用 + 修改 + 随游戏分发**
- [ ] **卖方是著作权人，或能出示可转授的授权链**（不能只凭"我买了我就有权转授"）
- [ ] 附分层源文件或分图层导出
- [ ] 知道自己买到的**单帧尺寸、方向数、各状态帧数**
- [ ] 已确认**画风归属**（见 §5）

### 4.1 已判定案例（2026-10-15）

「征途」8 方向序列帧转卖包（约 20 GB / 48 万张，目录以 `征途NPC`、`征途怪物`、`征途人物素材`、`征途UI.png` 等命名，内部为客户端资源 ID 结构，全包**无任何授权或说明文本**）：**判不可用**——①**来源非法**，卖家非著作权人、无可转授授权链，商用或公开发布即侵权；②**画风不符**，该作为手绘写实国风，与 [01 §1](01-视觉与技术统一规范.md#L3) 的复古像素基线冲突，接入等于全项目换皮。已排除，不入库。

> 形态本身是对的（八向序列帧、人体/武器/头饰分层），错的是**来源**。同类形态的合法包在 itch.io、CraftPix、Unity Asset Store、GameDev Market 上可正常购买，选购仍按 §2 与本节检查表逐条核验。

## 5. 画风一致性风险（需要你拍板）

现有狼、NPC、营地素材出自**内置 image_gen**（见 [可玩样板 README](样板/可玩样板-v1/README.md#L52-L53)），新买的商业包来自另一个作者，**画风很可能打架**。两条路：

| 选项 | 做法 | 代价 |
|---|---|---|
| **A：整套同一作者** | 玩家 + 怪物 + NPC 都买同一作者/同一套系 | 前期采购成本与筛选成本高，但后续不用返工 |
| **B：玩家先行** | 只买玩家八向分层包，怪物/NPC 后续批次再统一替换 | 过渡期画风不统一（玩家精致、NPC 仍为生成图），需要接受 |

建议：无论选哪条，**玩家包与下一批要替换的怪物/NPC 应尽量同源**，否则这批替换会白做一次。

## 6. 落库、登记与适配

- 原始包原样存放：`art_source/vendor/<pack-id>/`，加 `.gdignore` 排除 Godot 资源扫描（沿用 `art_source/` 现有做法）；
- 逐包登记：来源 URL、作者、授权类型、购买日期、订单号、允许的分发范围；
- 重排后的成品输出到 `assets/sprites/player/<角色>/layers/<layer>/...` 与 `assets/ui/portraits/<角色>/...`（[11 §3.8](11-角色换装外观方案.md)）；
- **未经重排的原始包不得直接进 `assets/`**，否则会把作者的网格与方向序带进运行时。
