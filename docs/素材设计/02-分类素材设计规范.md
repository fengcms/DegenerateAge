# 02 分类素材设计规范

本文件造型为美术设定；动作、数量、可用状态和地图功能以当前数据/代码为准。

## 1. 游戏界面

### 1.1 结构与组件

主题为“旧铁框架、暗色内衬、少量镇脉刻纹”。面板中央保持干净，不以羊皮纸噪点或密集花纹承载正文。间距以 4 px 为基本单位，常规内距 12–16 px。

| 区域 | 必须保留的信息 | 素材要求 |
|---|---|---|
| 左上玩家区 | 圆头像、姓名、HP/MP、等级 | 头像框、等级小圆框、槽底/填充/端帽 |
| 目标区 | 怪物/NPC头像、名、血蓝 | 无目标隐藏；精英/Boss身份可附徽记 |
| 右上小地图 | 地图名、坐标、齿轮、地图 | 圆框；设置与点击区域清楚 |
| 小地图下任务列表 | 目标、数量、完成状态、寻路 | 任务图标、状态标识；下划线与文字由代码绘制 |
| 底部快捷栏 | 12可配格＋4固定入口、键位、数量、冷却 | 格底、选择框、禁用层、冷却蒙层，支持绑定耗尽但保留图标 |
| 经验条 | 升级进度、悬停数值 | 横向可伸缩，不把经验数字画入贴图 |
| Boss血条 | 名称、HP数值、阶段信息 | 比普通目标明显，避免抢占预警视线 |
| 自动控制提示 | F/G开关、手动接管、3→2→1恢复 | 开/关/接管图形，必须同时有文字状态 |

图标建议 48×48；按钮点击区建议不小于 32×32，正文参考 16 px、标题 20–24 px、辅助文字 14 px，均为100%基准建议，接入前对照现有布局。快捷栏不是一张固定宽度位图，要用复用格子与容器组装；1280×800 下仍需看清全部16格。

组件状态至少包含 normal / hover / pressed / focus / disabled；选择状态与 hover 分开。不能用“变暗”同时表示锁定、不可用和数量耗尽。可接收拖放用内框提示，拒绝放置用叉号；拖拽幽灵在所有面板之上，Tooltip/Toast 在面板上方，弹窗遮罩不挡自己的交互。

### 1.2 面板与菜单清单

- 人物：角色立绘/静态展示与14槽，12项属性；装备槽底图用类别剪影，成对槽有文字位置标记。
- 背包：格底、金币符号、装备比较双浮层、数量角标、满包提示。
- 商店：与背包并排；出售托盘可投放，售卖成功/拒绝状态明确。
- 仓库：背包与仓库双向拖放；不将存储格画成一次性布局。
- 铁匠/升星：装备位、金币、如意位、成功率和结果状态；成功与失败只影响短时反馈，不遮住实际结果。
- 技能：可拖/未解锁/未接线区分。当前只有基础斩击接通；其他图标储备但加真实不可用提示。
- 坐骑：收藏大图、未拥有来源、20级门槛、骑乘/下骑；未解锁仍允许查看。
- 车夫：当前地点、目的地、费用、已到访/未到访/不可达状态；与免费步行出口图形区分。
- 大地图：已探索/未探索、玩家箭头、怪/Boss、功能NPC、任务点、免费出口、路线与目的地。
- 任务：主支线状态、进度、领取按钮；图标不替代任务名称。
- 设置：音频、显示/界面/文字/地图缩放、控制、游戏、数据等控件；没有接线的开关不能因美术呈现成已生效。
- 主菜单、暂停、3张存档卡、删除确认、加载页：背景、logo、按钮与选中框独立。存档名字/时间不入图，加载提示由代码排版。

最小适配矩阵：1280×800、1440×900、1920×1080、高分辨率2x；UI 80/100/150/200%、文字80/100/150%、地图80/100/150%，外加当前 displayScale 的边界组合。极端缩放需滚动/重排，由后续工程实现，禁止用强制缩小文字掩盖溢出。

## 2. 玩家与 NPC

### 2.1 灵刃战士

年轻守护者，体型中等，重心稳定。短披肩、层叠布革、旧铁护片、单手短刃形成剪影；胸口或护手一处灵能记号即可。颜色为旧布/铁灰，少量暖色与青白能力光。首轮不固定性别选项、不增加角色创建系统。

必须交付世界八向精灵、96×96头像和人物面板展示图（建议256×320透明PNG）。头像与世界精灵保持发型、披肩、主色、武器一致。展示图可细化，但不能另换画风。项目已过 MVP，**穿戴外观层由候选转为必需**：护甲与武器必须驱动世界形象、人物面板形象与头像，其余 12 槽不影响形象；具体分层与首批范围见 [11-角色换装外观方案](11-角色换装外观方案.md)。仍**不制作全组合换装包**，每个被引用的设计各出一套。

### 2.2 功能 NPC

| role | 剪影与道具 | 色彩/动作 |
|---|---|---|
| quest 长老 | 瘦长袍、旧卷册、杖 | 暖灰；翻页/点头 |
| shop 货郎 | 背篓、药瓶、腰包 | 土褐；整理货物 |
| blacksmith 铁匠 | 宽肩围裙、锤、护臂 | 铁灰与炉火；敲击动作仅表现 |
| warehouse 仓管 | 钥匙串、账册、小箱 | 蓝灰；核对账目 |
| carter 车夫 | 短外衣、绳索、路灯/缰绳 | 灰绿；招手/检查车具 |

首批每角色静态八向各1帧、正面/侧前待机4帧和交互4帧，附头像；需要完整转向时再补全八向动画。车夫/货郎跨地图复用，只换少量场景道具，不默认新增人物姓名。功能标记由UI层显示，不永久烘在头顶。

|---|---|---|---|

巨兽核心造型属于本次美术设定；“曾为守护者、胸前封印”等候选故事仅可留源文件可选图层，不列为正式必需。

Boss按现有三阶段分层：常态爪击；低于60%增加践踏，预警0.8秒；低于30%狂暴并召狼。阶段变化优先用核心亮度、裂纹层与姿态，不复制三套全方向角色。践踏表现必须匹配真实圆形世界距离判定：当前代码按屏幕世界欧氏距离计算，不能擅自压成等距椭圆。纯装饰脚底阴影可以是椭圆。

精英词缀用独立叠层：狂暴（短红纹）、寒霜（冰晶）、坚硬（甲片）、迅捷（短残影）、召唤（分叉符）、吸血（细血线）。最多两种词缀同时显示，不能覆盖目标圈/名称。特效是否完整触发需后续事件绑定，图案不能承诺新效果。

## 4. 地图与环境

以模块地砖＋散布装饰＋地标构建，禁止做完整地图一张大背景。可行走区域纹理简洁，障碍的接地轮廓明确；视觉障碍只有配置真实碰撞/寻路后才当成阻挡。现在脚本地面主要是整块菱形和网格，不把拟议地砖系统说成已存在。

| map_id / 当前大小 | 地面与气氛 | 地标/模块 | 色彩递进 |
|---|---|---|---|
| camp / 40×40 | 踩实土路、碎石、少量草 | 木棚、炉火、仓箱、货摊、马车停靠、围栏 | 暖光＋中性灰，安全而简陋 |
| wild_trial / 60×60 | 黄土草地、旧商路、腐化斑 | 枯木、岩石、狼巢、残车 | 灰绿与土黄，少量紫裂纹 |
| ash_land / 60×60 | 黑灰地、烧焦石、余烬 | 断墙、焦木、旧设施碎片 | 低饱和灰黑，点状橙与紫 |
| corruption_source / 50×50 | 破裂岩面、紫晶脉 | 裂隙、祭台/旧设施残构、Boss战场、墓碑 | 冷灰紫，预警橙保持最高辨识度 |

每图建议起步：基础地砖4变体、边缘/过渡8件、道路6件、小装饰8件、中型障碍4件、主题地标1件；是制作预算，不改变地图格数。采用自由绘制过渡贴片起步，不假定已有47片自动地形系统。道路/转角对应2:1网格。

- 树/建筑拆接地基座和高层遮挡；高层未来可透明化，不能永久挡住玩家与掉落。
- 营地的5个NPC位置按JSON保留；地标不占出口、入口、回城点或Boss预警区。
- 出口用道路延伸、路牌、边界缺口；车夫用马车/车轮符号，不能把免费出入口做成收费传送门。
- 支持 mapScale 0.8 与大视口的边缘背景/低对比外圈装饰，地图外围露底不能呈现成可通行区域。
- Boss死亡墓碑需独立32×48或64×64精灵；倒计时实时文字，不入图；普通/精英不用墓碑。
- 迷雾可用程序蒙层，地图轮廓、道路与可探索状态由数据/探索系统生成，美术只交付标记和底图组件。

## 5. 装备与物品

### 5.1 装备

14装备槽为：武器、头盔、护甲、鞋、盾、项链，加双护腕、双护膝、双手镯、双戒指。对应 **10个装备类别底图**，不是14个互不相同的模板图标。成对槽共用类别图标，左右/序号由UI文字区分。

武器统一左下柄→右上刃的斜构图，盾与护甲偏正面3/4展示；首轮48×48图标，主体占约70–85%。边框、品质、升星、锁定与数字是独立叠层，不入物品图。相同模板的随机品质复用主体；传说专属模板单独造型。

| 模板 | 造型要求 |
|---|---|
| weapon_starter | 短直刃、旧缠柄、小镇脉刻线 |
| armor_starter | 布革胸甲、少量旧铁片 |
| weapon_wolfking | 狼牙形护手、爪痕、较长刀身 |
| helmet_cloth / shoes_cloth | 折布帽与绑带布鞋，区别于金属护具 |
| shield_basic | 圆/椭圆木盾、铁钉、断木纹 |
| bracer_basic / knee_basic | 短筒护腕与弧面护膝，轮廓不能相同 |
| bracelet_basic / ring_basic | 厚铜手镯与薄戒指，靠厚度和比例区分 |
| necklace_basic | 明显绳链＋兽骨坠，不画成戒指 |
| weapon_legendary_vein_guard | 镇脉刻纹、封印结构、完整灵能流路，区别狼王之刃 |

### 5.2 药品、如意与杂项

- 红蓝药各3档：小档圆腹短瓶、中档肩瓶、大档宽腹双绑带；瓶型与瓶口同时区分档位，容量不能只靠颜色。红液/蓝液清楚，玻璃高光控制在少量像素。
- 铁/玉/金/钻石如意保留同一弯曲如意头：铁暗灰粗糙、玉青绿半透、金暖金刻纹、钻石冷白棱面。中文名是如意，不画成通用符文石。
- 回城卷：卷轴＋营地屋顶/路标符号；复活卷：卷轴＋灵能回环；随机券：票片＋分岔箭头；烟花：绑线筒；灵能碎片：不对称青白晶片与刻纹。避免三个传送/复活物品轮廓一致。
- 金币：铸纹铜金圆片，单枚和小堆两种世界表现；数值由代码显示。
- 道具均交付UI图标与地面小图，地面图需另绘制，不能依赖48图标缩小后仍可读。

## 6. 战斗、成长与掉落特效

| 事件 | 表现 | 约束 |
|---|---|---|
| 普攻 | 短弧青白刀光，少量命中火星 | 不整屏闪白；方向与命中位置一致 |
| 裂地斩/旋风斩 | 地裂扇面/短环形刀光 | 未来接入项；预览不等于技能可用 |
| 战意/破甲/风暴 | 身体短纹/破裂标记/分段刃流 | 按各技能数据再定范围、时长与段数 |
| 敌方远程 | 灰烬弹、有方向的尾迹 | 与玩家灵能不同形状；只显示真实攻击事件 |
| Boss践踏 | 清楚圆形预警＋边缘推进、落地冲击 | 0.8秒来自数据，爆发不能先于伤害窗口 |
| 升级/经验吸收 | 青白粒子向玩家聚拢、短竖向亮纹 | 与金币/物品飞行区别，不新增经验掉落物逻辑 |
| 喝药/治疗 | 小范围绿光/恢复符号 | 不把治疗色改为红色；红药图标仍红 |
| 升星成功/失败 | 刻纹点亮/短暗裂 | 无持续庆祝，数值结果始终可见 |
| 高品质掉落 | 白蓝基础、绿可读名、黄环、紫徽记与柱 | 品质色遵循现实现；不把普通掉落全做大光柱 |

伤害飘字：普通白、暴击黄且略大、格挡蓝、治疗绿；字体、数字、描边由代码生成。目标选中圈、攻击连线、射程环、移动目的地、自动寻路路线尽量程序绘制，交付样式规范而非固定半径贴图。

掉落需要分开制作“生成散落/短停”“飞向玩家”“满包留地”状态。已入包主路径为短停0.2秒＋飞行1.0秒，不等飞行完成才结算；飞行结束提示。满包物品留地并走未认领逻辑；不能让闪光误示已经拾取。尊重飞行动画关闭设置，首轮不更改现有时序。

建议短特效6–8帧、12–16 FPS，单张图集起步不超过1024×1024；多段风暴按效果拆包。普通战斗不持续全屏光效；减少强闪/屏震模式保留轮廓、预警边界和文字，后续需接线后才能验收该设置。

## 7. 坐骑、界面外素材与音频

腐化之翼是现有唯一坐骑，来源腐化巨兽，20级可骑乘、移动速度+30%。先交付统一风格图标与收藏大图（建议256×192透明），评估现有SVG；世界羽翼/骑乘八向动画作为第二阶段，不擅自添加飞越障碍或新载具机制。收藏态、未达等级与骑乘态有清楚区分。

补充素材：应用图标、游戏logo、鼠标普通/移动/攻击/交互/拒绝状态、空槽、未知图标、存档卡、加载背景、任务/锁定/自动状态图标。光标热点单独记录；每种交互至少有形状区别。商店发布图按最终发布平台要求另开制作单，不预设平台尺寸。

音频是后续配套预算：营地稀疏暖旋律、野外风与草、灰烬低频风声、源头克制异界脉冲；UI点击、拒绝、穿戴、拾取、喝药、升级、爪击、刀击、Boss预警/落地分别建立音色。预警不要混入环境循环。

音效建议WAV 48kHz源文件，音乐/环境建议循环OGG与无损母版；循环接缝无点击，峰值留约3dB余量，实际混音以Music/SFX独立总线验收。当前音量设置尚不能证明已有声源接入；本批不要求台词配音。
