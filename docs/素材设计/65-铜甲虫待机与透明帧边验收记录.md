# 铜甲虫待机与透明帧边验收记录

2026-11-18继续接入第二类怪物待机。仍沿用模块化营地，不修改正式地图、AI、战斗或存档。

## 问题与处理

首轮四帧甲虫有触须变化，但白灰背景并非透明。审片器在帧角alpha断言失败，未放宽断言接入。通过内置image_gen专门去背景得到修正版；源稿、失败稿、首轮与修正提示词均保存在art_source/actors/beetle_idle_trial_v1。

修正版通过透明角检查和棋盘底人工查看，触须、六足、甲壳轮廓可识别。去背景过程仍有轻微材质/姿态漂移；不是严格锁定所有像素的无损操作。只作为隔离待机试装，未达正式动画验收。

## 实现与代价

2×2源格768×512，统一0.16缩放，源锚点(384,410)映射到128×96帧格中的(64,80)。四帧一列128×384，3fps，运行JSON由build.json构建。多足锚点取接触区中心，前足可低于锚点，不能将每帧最低点强制贴齐。

复用SampleIdleSprite与J键，两个怪物分别缓存图集；新增一张图集理论192KiB，两类合计384KiB，不含驱动开销。新增一个O(1)待机回调，没有新节点、碰撞体、寻路或动态材质。关闭待机停止回调；切图释放实例、共享纹理随样板退出释放。没有测量正式密集战斗FPS。

构建增加全部源帧四边逐像素alpha<0.05断言，避免只看一个透明角漏掉截肢或明显背景；低alpha残留与内部区域仍需人工审查。属于扩展覆盖，不放宽既有透明角、移动、碰撞和遮挡检查。

## 复核方式

审片：`python3 tools/motion_review/launch.py --source art_source/actors/beetle_idle_trial_v1 --reference assets/art_pilot/beetle_v2.png --verify --capture /tmp/beetle-idle-review`，修正版退出0并输出MOTION_REVIEW_VERIFY_OK/ART_NOT_APPROVED。

构建：`python3 tools/modular_camp/launch.py --build-assets`。窗口整体验证：`python3 tools/modular_camp/launch.py --verify --capture /tmp/camp-two-idles`。检查两类怪物真实回调覆盖四帧、J关闭后保持原图、固定位置/排序以及导航和碰撞数不变，保留既有测试。截图缓存最多8张约31.25MiB，验证后清空，普通运行无截图开销。

实测结果：构建通过全部八帧边界检查；Godot 4.7.2 Compatibility窗口整体验证退出0并输出MODULAR_CAMP_VERIFY_OK。人工检查了营地内甲虫第3帧截图，未见白色底框；四帧轻微漂移仍按上述限制保留。
