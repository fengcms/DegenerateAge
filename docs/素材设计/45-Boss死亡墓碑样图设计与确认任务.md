# 45-Boss 死亡墓碑：样图设计与确认任务

## 负责 AI

**Codex 桌面端会话「整理游戏技能装备与物品」**（thread `01a135c4-0427-7e53-aaa5-970dc5029f1f`）。
执行者只做本轮：**设计并提交墓碑样图**，不做任何接入。接入在用户确认后另起一轮。

## 一、为什么现在做这件事

Boss 死亡后的墓碑**功能已经全线实现并在跑**，唯独美术还是占位：

- 刷新点带 `tombstone: true` 时进入等待期显示墓碑 —— `scripts/world/spawner.gd:249-264`（`_place_tombstone`）
- 墓碑跨图、读档后按**死亡原位置**重建，位置与倒计时由 `autoload/game_state.gd:798-806` 记录
- 美术**完全没有**：`scripts/entities/boss_tombstone.gd:23-31` 的 `_draw()` 直接画一个 28×30 的灰矩形（`#6e747d`）加两道浅灰线（`#c4c7cc`）当十字，再用等宽字体在正上方居中绘出金色倒计时 `Boss 刷新 MM:SS`（`#f2cc71`）

也就是说：现在玩家看到的墓碑是一个**临时白盒方块**。本轮任务就是给它做出正式外观。

## 二、设计规范（已有约定，必须遵守）

来自 `docs/素材设计/02-分类素材设计规范.md:96`：

> Boss死亡墓碑需独立 32×48 或 64×64 精灵；倒计时实时文字，不入图；普通/精英不用墓碑。

来自 `docs/素材设计/02-分类素材设计规范.md:88` 的 `corruption_source` 地图主题：**冷灰紫**，且**预警橙是保留给攻击预警的最高辨识度颜色，墓碑不得占用**。

补充要求（本文档追加）：

- 墓碑是**地标件＝整体精灵**（`docs/素材设计/24-地图素材丰富化需求分析与制作路径.md:176`），与营地的房屋、树、马车同类处理：直立billboard，**不做 2:1 菱形压扁**，脚底贴地。
- **纯像素风**：结构清晰、边缘干净、**禁止矢量描边、禁止拉伸变形、禁止笔刷涂抹感**。这条是硬要求 —— 之前营地石头出现「形变厉害、像矢量图」时被明确打回，不要重犯。
- **碑面必须留出干净的刻字区**（后续 P2 创意「墓碑写着它过去的名字 / 守护兽旧编号」要用，见 `docs/游戏创意/04-后续章节与创意优先级.md:46-48`）。本轮**不要在图上烘死任何文字**。
- **必须为代码绘制的倒计时留位**：金色文字由 `boss_tombstone.gd` 实时绘制，不随美术走。样图要让人一眼看出「碑体 + 上方或碑面金色倒计时」是一个整体构图。

## 三、比例锚点（用于判断大小是否合理）

| 参照物 | 尺寸 | 来源 |
| --- | --- | --- |
| Boss 本体 `boss_corrupted_beast` | 帧 **192×192**，脚底锚点 `(96,152)`，8 方向×7 帧 | `assets/sprites/monsters/boss_corrupted_beast/animations.json` |
| 玩家角色 | 帧 128×80 | `assets/sprites/player/…look_06_idle_atlas.png` |
| 墓碑规范尺寸 | 32×48 或 64×64 | `docs/素材设计/02-分类素材设计规范.md:96` |

规范给的是 32×48 / 64×64。**请按 64×64 为主方案做**（两个都做我会看不过来）：64×64 在 Boss 的 192 帧旁边是否过小、是否会看不清，用真实缩放对照图说明；如果你判断需要一个更大的方案（如 96×96）才能当「地标」，可以做第二个候选，并在说明里讲清代价。

## 五、硬边界（本轮不要做的事）

- **不改任何 `.gd` 代码**：不接 `boss_tombstone.gd`、不碰 `spawner.gd`
- **不动 `assets/`**：运行素材的裁切、打包、导入留到接入那一轮
- **不动 `data/`**、不改任何既有文档、不改地图
- 样图源稿只写 `art_source/environment/boss_tombstone/`，预览图只写 `docs/素材设计/样板/Boss墓碑样图/`
- 不要顺手做「普通/精英墓碑」「墓碑交互 UI」「其他地标件」

## 六、验收判据

- 1:1 像素下边缘干净，**无半透明糊边、无羽化、无抗锯齿灰边**
- 脚底锚点明确，贴地有接地阴影；与地面接触处不悬空、不切底
- 冷灰紫主色，**不占用预警橙**；金色 `#f2cc71` 只出现在代码绘制的倒计时文字位置
- 与 Boss 同屏时：墓碑**明显小于 Boss**、又**不至于看不见**，两者层次与遮挡关系合理
- 碑面无烘死文字、留有刻字区
- 说明文档能让没看过过程的人独立判断「为什么是这个造型」
