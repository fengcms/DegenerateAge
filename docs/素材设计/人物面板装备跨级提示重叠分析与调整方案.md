# 人物面板装备跨级提示重叠分析与调整方案

2026-11-01。依据玩家提供的554级人物面板截图和当前代码制定；本节点仅提交方案，尚未修改界面。

## 现象与根因

截图中黄色提示覆盖右侧暴击、暴击伤害与攻击间隔等属性，既妨碍阅读，也难以辨认装备落后的具体影响。

`scripts/ui/character_panel.gd`的_build界面构建代码将_stats和_gap_hint两个Label直接添加到同一个stats_card（PanelContainer）。PanelContainer负责给子控件分配内容区域，不按先后垂直排列；缺少VBoxContainer等顺序布局容器导致两段文字占用同一矩形。固定宽度245和11号自动换行字体加剧拥挤，但单纯减小字号或调整坐标无法解决结构问题。此结论由截图和代码结构确认，未重新运行窗口测量。

影响集中于人物面板；目标卡、Boss条、背包装备对比卡是其他布局入口，本次不顺带改变其设计。伤害计算本身不受影响。

## 推荐布局

将提示从右侧战斗属性卡完全移出，放到左侧穿戴装备卡内、人物立绘与两侧装备槽组成的figure下方，利用左侧现有底部留白。左侧equip已有VBoxContainer，可将独立的装备适配卡作为figure后一个子项，由容器自然排布。

示意：

```text
穿戴装备                         战斗属性
[装备列] [人物立绘] [装备列]       生命、法力、攻击……
                                 暴击、攻击间隔……
装备适配                         套装、强化……
参考：当前目标 Lv554
对该目标伤害保留 63.7%
建议各部位装备达到 Lv534及以上
```

示例554按截图展示；正式界面必须显示实际参考等级，不能将人物等级冒充已锁定目标等级。无有效战斗目标时明确写“按人物等级 Lv554参考”。系数从EquipmentGap统一读取，不能用主武器差值另算一个百分比。

卡片沿用PanelChrome的背景、边框、标题和内边距；正文使用现有可读字号（建议13），行间距4～6像素，区域间距8～10像素。标题与说明为常规色，仅伤害保留行用柔和琥珀色，不整块警告红。保留3行简明信息，主武器等级、超额差及20级缓冲规则放进悬停说明，避免小字堆叠。

卡片宽度随左侧装备卡内容区，文字自动换行，高度由内容最小尺寸决定。禁止负偏移、覆盖式锚定或写死高度。空间不足时沿用现有content_scroll滚动，标题栏、关闭按钮不参与滚动。现有展示框258×410和装备槽52×52不缩小。

没有衰减时隐藏整张提示卡，不留空标题或固定占位；属性区不因提示出现/消失改变内部行距。参考目标、穿戴装备、人物等级或规则变化时复用现有刷新入口，不增加逐帧轮询、计时器或背包扫描。

## 实施节点与验收

1. 调整布局与简明文案：新增独立卡片，移除右侧叠放的提示；文本走本地化，保留既有计算与刷新方式。运行人物面板相关测试并提交git commit。
2. 补充针对实际重叠的几何回归：等待容器完成布局后检查提示卡与属性文字全局矩形不相交、提示位于figure下方且未遮挡装备槽；覆盖衰减存在/消失、参考目标切换。运行EquipmentGapUiTest及相关人物面板回归。
3. 用实际渲染窗口复核1280×800及项目支持的小窗口，检查长文本、滚动、套装/强化完整属性和背包同时打开的装备对比卡。最小窗口以FloatingWindow当前约束为准，不能虚构支持尺寸。记录截图结论并提交git commit；临时截图用后清理。

仅增加一个低数量容器组合，随面板生命周期释放；事件更新而非每帧更新，不改存档、战斗数值或出售保护。不以逻辑测试代替最终窗口布局验收。
