# 正后持续推挤的碰撞阻塞记录

2026-11-18，八方向素材联调时发现，隔离营地持续向屏幕正上推挤北边界，无法满足连续12物理帧位移小于0.01px的停步验收。本项未修复，按连续开发约定先隔离阻塞，继续其他方向和动作。

## 证据及影响范围

默认CharacterBody2D模式、半径12、150px/s，从网格(14,14)持续输入(0,-1)，300物理帧后仍有3次接触，位置约(0.378906,-482.3194)，稳定帧计数0，两布局均复现。切换FLOATING模式的排查试验仍失败，位置约(0.072754,-482.5444)、2次接触，且其他方向出现退化，已撤销该模式修改。改从既有木箱下方持续向上推挤，在一套布局沿斜边滑走后再次碰到其他障碍，不能当作稳定停止的替代证据，也已撤销该替代测试。

该现象在加入正后方向测试后暴露，不证明由新图片造成。样板每个阻挡格对应一个独立菱形CollisionPolygon2D，运动由move_and_slide处理。推断多形状边界凹角的接触恢复与沿斜边滑动共同导致细小位移；尚未建立最小复现验证引擎内部根因，因此不作确定归因。没有改变正式player、地图碰撞或导航。

首次新增测试失败后，断言会中止当前协程，未走到清除verification_direction的末尾，导致后续侧向测试被旧输入干扰；启动器仍因SCRIPT ERROR拒绝通过，即使末尾打印成功标记也不接受。另一个独立测试配置问题是侧向终点(10,2)本身为墙格，已把左右试走改到(6,6)与(8,4)共用空地。

## 当前处理

保留原四斜向及正下的顶墙门槛，新增左右侧向同样保持连续12帧、0.01px及真实接触要求。只暂不把新增正后持续顶墙作为已完成项目；正后正常路线四帧、主动停步、站姿保留、原图回退仍必须通过。未加假墙，未移动既有物件，未放宽位移门槛或通过隐藏像素动作掩盖物理位移。

## 后续修复与复核

在隔离项目建立北边界凹角最小复现，记录每帧位置差、碰撞法线、恢复位移和实际前进分量，再比较形状接缝及物理参数。任何修复必须保持既有通行掩码、半径、可达路线、绕墙和门洞行为，不以扩大障碍或取消碰撞掩盖问题。修复后恢复正后持续顶墙测试，并复跑全部八方向及两布局，不把目前七向通过写成八向边界全部通过。
