# 配套站姿与顶墙停帧接入记录

2026-11-17。为主角右下四帧试装补充同方向站姿，修正停步时回到旧原图造成的外观变化，并增加真实顶墙的动作验证。只修改隔离样板，正式外观、战斗和存档不变。

## 变化原因与表现

60号试装在任何零位移情况下都切回原静态主角。该原图与新行走稿的持剑角度、腰摆和站立轮廓不完全相同，停步会暴露差异；仅靠实际位移判朝向，也无法表达已经顶墙但仍朝右下用力的输入。

本轮使用内置image_gen以四帧行走稿为参考生成配套站姿，保留胸前圆环、背带、腰包和低持剑姿势，双脚自然落地。源稿/完整提示词见art_source/actors/hero_walk_pilot_v3/idle_source.png及idle_prompt.json。构建缩放0.069、源锚点(535,1410)，运行帧112×128，与四帧行走共用(56,112)锚点。没有通过改变玩家坐标或拉伸贴图掩盖切换。

SampleWalkSprite分离“朝向”和“是否行走”：移动意图更新朝向，无输入保留；碰撞后的实际位移才推进循环。右下停步或顶墙显示配套站姿，未制作方向以及H关闭时回退原图。沿墙滑动的实际方向不在右下范围时不播放右下行走，因此这仍是单方向试装。

## 验证证据

```sh
python3 tools/modular_camp/launch.py --build-assets
python3 tools/modular_camp/launch.py --verify --capture /tmp/camp-idle-v3
```

Godot4.7.2、Compatibility、Apple M1 Max真实窗口，构建通过，窗口验收退出0并输出MODULAR_CAMP_VERIFY_OK。

- 两布局真实路线覆盖全部四帧，停步后断言切至配套站姿，保留共同锚点。
- 新增顶墙验证：从(14,1)开始持续右下输入，经过真实移动撞到既有地图边界角；要求确实播放过行走且移动超过10px，再连续12个物理帧位移小于0.01px并具有碰撞接触。此时行走关闭、相位为0、配套站姿保留；撤销输入后仍不行走。
- 零位移且仅改变意图时允许切换朝向，不允许开始踏步；反向回退、H开关、原有导航、门洞、绕墙、移动墙失效和树屋遮挡检查全部保留并通过。
- 目视两布局停步截图，站姿的胸饰、腰包、持剑与行走更接近，头身位置没有旧原图切换时同样明显的差异。该项是目视判断，不是像素级无跳动证明。

顶墙使用真实既有碰撞，不新增测试墙，不把“传入零向量”作为唯一物理证据。修改原停步断言是匹配新的明确站姿行为，并新增碰撞覆盖，没有放宽移动、碰撞或导航断言。

## 成本与限制

新增112×128单帧纹理，RGBA8理论56KiB；一份缓存纹理按路径复用，不增加角色显示节点。方向记忆只有一个布尔值，更新仍为常量时间；不新增计时器、信号、寻路或物理对象。切图释放旧角色，关闭样板释放纹理缓存。截图抽样回放沿用既有验收入口，不用于性能测量。

仍是右下单方向、四帧行走加一帧站立。没有呼吸帧、八向、攻击或两类怪物动画；脚锁定、步幅和自然度还需精修。站姿与步态由生成图制作，不能保证所有甲片和脸部细节逐像素一致。当前成果不等于正式人物动画包完成。
