## 1. 统一调用约定

1. **加载锚点**：在 Codex 中把 `style_anchor_A_pixel.jpg` 作为参考图（SD 的 reference / IP-Adapter / img2img 均可），每条 prompt 已注明「match supplied reference image 1」。
2. **生成尺寸**：建议生成 **1024×1024**（或更高）；导出后用**点采样（nearest）**缩放到 **160×160** 作为交付 tile。不要用平滑缩放，否则失去像素块感。
3. **无缝**：**优先在 Codex 中开启无缝/平铺（tile / seamless）模式**。这是解决「拼不上」最可靠的一环——纯靠后处理补缝只能救急。
4. **色板令牌**（统一口径）：深墨 `#171A21`、铁灰 `#353B46`、灰岩 `#687078`、旧布 `#A89978`、骨白 `#E6DDC6`、营火 `#D99A52`；地形以**低对比**呈现。
5. **落位**：生成源稿放 `art_source/environment/map_m1/`，**不要**直接进 `assets/`；正式接入需走 [03-素材清单与制作验收](03-素材清单与制作验收.md) 三关。
6. **交付形态**：地面纹理交付为 **160×160 无缝方纹理（正俯视）**。等距菱形化（`rotate 45 → Y × 0.5 → 裁 64×32`）属**呈现/引擎侧**，不在生成阶段做，提示词也不要写等距角度。
7. **呈现纪律**：任何地面验证图必须同时包含 ① 菱形化 ② 等距铺装 ③ 角色脚下接触影。三项缺一即视为**无效验证**（缺失会直接产出「墙纸感 / 角色挂在墙上」的假结论，见 [27-复核与等距呈现验证](27-M1-1a复核与等距呈现验证.md)）。
8. **混铺纪律**：多张地面变体交替铺装时，**必须用随机（或蓝噪声）散列**。禁止规则排布（4×4 表、Latin square），也禁止按 `(r, c)` 取模的伪散列 —— 实测这两类都会在等距图中显出**明显斜向条纹**（见 [30 号](30-M1第二批复核与四变体判据.md) 4.2）。
9. **语义分层纪律**：草皮（1a/1b）与裸土（1c）、车辙（1d）**不是同一地形的变体**，不得按单格粒度混铺 —— 会形成瓦片形状色块，像拼布被。二者衔接必须走 **L1 过渡边缘**；过渡件到位前，1c/1d 只按区域使用（整片荒地区 / 道路与车辙带）。1d 的车辙为强方向性特征，建议定位为道路专用件（见 [30 号](30-M1第二批复核与四变体判据.md) 4.3 / 4.4）。

## 2. 可复用文本块

同批所有 prompt 共用下面三段，只替换 `[主体]` 段。

### [风格锁定]（STYLE_LOCK）

```text
Match supplied reference image 1 exactly: deliberate chunky pixel clusters with hard square
pixel edges, strict limited palette of about 16 flat colors (deep ink #171A21, iron grey #353B46,
grey rock #687078, worn cloth #A89978, bone white #E6DDC6, muted moss green, campfire orange
#D99A52 accents), upper-left light source, quiet low-contrast terrain so player characters read
clearly on top. No gradient, no blur, no soft shading, no antialiasing, no photographic texture.
```

### [无缝]（SEAMLESS）

```text
Seamless and tileable on all four edges; when wrapped the edges match perfectly. Uniform
micro-detail distribution, no obvious repeating feature, no single feature larger than 25% of the
tile, no directional asymmetry, no dark band or vignette along the edges.
```

### [负面]（NEGATIVE）

```text
No text, no letters, no numbers, no characters, no creatures, no UI, no watermark, no border frame,
not smooth vector, not photorealistic, no large flat empty color patches, no high-contrast lighting.
```

## 3. M1 提示词清单（草地基座）

每条按固定结构拼装：`用途 → 透视尺度 → [风格锁定] → [主体] → [无缝] → [负面]`。生成尺寸 1024×1024，导出点采样到 160×160。

### M1-1a 干草地（建议首个生成）

```text
Game map ground base texture (seamless tile) for a retro pixel-art isometric dark-fantasy RPG.
Flat top-down view, uniform scale, one image pixel will map to one game world pixel.

[风格锁定段粘贴于此]

Subject: a fine ground texture of dry trampled green-and-beige grass with tiny sparse pebbles,
individual grass blades only a few pixels wide, even density over the whole tile.

[无缝段粘贴于此]

[负面段粘贴于此]
```

### M1-1b 湿润深绿草地

```text
[同上 用途/透视/风格锁定]

Subject: a fine ground texture of damp deep-green grass with darker wet patches and a few small
smooth stones, even density over the whole tile.

[无缝段] [负面段]
```

### M1-1c 荒草/枯黄草地

```text
[同上 用途/透视/风格锁定]

Subject: a fine ground texture of sparse dead yellow-brown grass over dark earth, mostly bare soil
with scattered dry tufts, low contrast.

[无缝段] [负面段]
```

### M1-1d 碎石车辙草地

```text
[同上 用途/透视/风格锁定]

Subject: a fine ground texture of packed bare dirt with a shallow wagon-rut track crossing it and
scattered small grey gravel, low contrast.

[无缝段] [负面段]
```

> 变体差异只体现在 `[主体]` 段；其余三段**一字不改**，这是跨素材一致性的保证。

## 4. 生成后验证（你或 Codex 执行）

> 本节命令已于 2026-10-16 按 [27 号复核](27-M1-1a复核与等距呈现验证.md) 替换：旧版「正方形 `tile:` 平铺 + 角色硬贴」会产出「墙纸感 / 角色挂在墙上」的假结论，已作废。

**① 菱形化**（把 160 方纹理投影成 64×32 等距地面块，点采样）：

```bash
magick tile_160.png -filter point -resize 256x256! -background none \
  -filter point -rotate 45 -trim +repage -filter point -resize 64x32! diamond.png
```

**② 等距铺装检查**（不再是正方形平铺）：每行 Y 步进 **16**、奇偶行 X 错 **32**，后画的覆盖先画的（画家序）。建议 384×224 画布、`r=-1..13`、`c=-1..6` 逐块 composite，导出 **3× 点采样放大**后目视，重点看对角边是否露接缝：

```bash
# 逐块 composite（示例：一行一块，实际按 r/c 循环）
magick -size 384x224 xc:"#010000" -alpha set -channel A -evaluate set 0 +channel _ground.png
magick _ground.png diamond.png -geometry +0+0 -composite _ground.png
```

**③ 角色同屏 + 接地影**（影在角色前合成，脚底对齐）：

```bash
magick assets/sprites/player/guardian/guardian_atlas.png -crop 64x80+0+0 +repage _g.png
magick assets/sprites/monsters/wolf_corrupted/wolf_atlas.png -crop 80x80+0+0 +repage _w.png
magick -size 46x18 xc:"#010000" -alpha set -channel A -evaluate set 0 +channel \
  -fill black -draw "ellipse 22,8 20,7 0,360" -blur 0x4 \
  -channel A -evaluate multiply 0.5 +channel _s.png
# 玩家脚底 y≈152、狼脚底 y≈176：先合成 _s.png，再合成角色帧
```

> **ImageMagick 7 注意**：以 `xc:none` 建空白底会把结果图坍成灰度（合成会继承目标色彩空间）。空白透明底请统一用 `xc:"#010000" -alpha set -channel A -evaluate set 0 +channel`。

**④ 若仍有接缝（后处理救急，方向保持、不镜像）**：先做半幅偏移把接缝移到画面中间，再对中间窄带做交叉淡入：

```bash
W=160; B=12
magick tile_160.png -roll +$((W/2))+$((W/2)) rolled.png
# 取窄带与其对侧窄带做羽化混合后回贴（具体幅度按实际接缝微调）
```

> 优先顺序：**Codex 无缝模式 > 提示词约束 > 上述后处理**。项目禁用镜像翻转（会导致草倒长），请勿用镜像平铺。
