# 主角与两类怪物同场景接入记录

2026-11-17，本轮把已认可方向的主角、腐化狼和新铜甲虫放进两套模块化营地，完成实际显示尺寸、地面落点与排序的单帧试装。正式地图、战斗、怪物模板和存档未修改。

## 美术与实现

主角沿用77×96，腐化狼沿用110×57。旧铜甲节肢怪带棕紫光晕，第一次去光晕生成仍未解决；该候选未接入。使用内置image_gen重新生成低矮六足铜甲虫，减少复杂触须，保留磨损铜甲与铜绿。最终源稿与完整提示词存于art_source/actors/camp_pilot_v1，运行图为assets/art_pilot/beetle_v2.png（110×82）。新图保留真实透明度，Godot仅裁留白及缩放，无脚本抠图或重画。

actors.json集中保存图片和锚点。主角暂为底部中心；狼与甲虫按接触区域中心设置，比例分别为(0.5,0.87)、(0.5,0.82)。怪物位置进入两份布局的actors列表，世界Y值参与与主角、墙树的排序；不参与阻挡掩码。N切换名称，名称位于图顶上方22px，不虚构血量。

## 验证证据

运行python3 tools/modular_camp/launch.py --build-assets：输出BEETLE_BUILT: (110, 82)，构建成功。

运行python3 tools/modular_camp/launch.py --verify --capture /tmp/modular-camp-actors：Godot 4.7.2，Compatibility，Apple M1 Max真实窗口，退出0，输出MODULAR_CAMP_VERIFY_OK。目视两布局截图：三种角色可辨，新虫无旧稿大面积光晕，比例可与棚屋门口比较。

新增校验每布局两只展示怪、三个名称节点、110px宽、透明角、纹理复用、落点可达及排序。原有通行掩码、真实物理长路径、门洞、墙体阻挡、绕障与移动墙断言均通过。检查发现原遮挡专项受index==0限制，已改为两布局都执行并通过；56号记录同步纠正。截图属于临时验收产物，不入库。

## 成本、边界及下一步

新增常驻纹理为狼和新虫，RGBA8共61160字节，约59.7KiB；主角原已加载。新增两个Sprite2D与三个名称Label，无怪物每帧回调、寻路、碰撞、掉落或全表查询。纹理按路径缓存直至样板退出，切换布局释放旧节点，复用纹理。新增运行图读取在加载阶段；图像像素检查仅验收执行。未测量整帧P95/P99，不能由这次小样板承诺大地图60FPS。

本轮是同场景静态试装，不是战斗遭遇完成。主角可物理移动但不播放行走帧，怪物保持静态；三者尚无八向、攻击、受击或死亡动画。锚点属于人工初校，正式动画须逐帧验证脚滑和高度一致性。下一制作闸门是单方向真实行走帧，确认姿态与脚底稳定后再扩展方向，沿既有动画资源库接入；不以平移、拉伸单图冒充动作。
