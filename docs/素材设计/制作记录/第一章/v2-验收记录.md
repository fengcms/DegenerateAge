# 第一章横向四图 v2 验收记录

日期：2026-10-14。布局版本：`2026-10-14-landscape-v2`。素材提交 `db2a81d`，运行接入提交 `869b8c1`；此记录及清理另行提交。只涉及第一章地图与测试，没有混入同期装备、任务、掉落和 UI 工作。

## 完成范围

- 营地、野外、灰烬、源头各接入一套完整物件源图及 4 个运行多格主题素材；旧地面 64×32 图集继续复用，灰烬道路另有低亮度变体。小型装饰复用旧资源。
- 四图道路由横向布局参考路线编译，经过运行 `walkable_rows` 过滤；旧“地图中间直线”与旧固定装饰坐标退场。每块大型阻挡由一条实体记录、多段整体图片及一个沿实际格边界合并的 `CollisionPolygon2D` 表达。
- 地面和阻挡顶面保持合批绘制；静态图片只在载图时加载，四图分别有 17、67、81、48 个静态精灵，未在移动中增生。未改变地图尺寸、任务、怪物预算、出行费用、战斗结算或存档版本。

改动前已提交快照的 `ChapterOneArtTest` 仍因“教学木桩血条高度”断言失败；同一失败在本批改动后重现。它属于已有木桩 UI/美术基线问题，本批没有修改怪物绘制、血条或该断言。其余上述检查通过。

`MapRenderBenchmark` 在 1280×800 实际窗口、GL Compatibility 路径完成，每个场景 140 个实绘帧。首次改动前基线：野外普通场景约 137 draw calls，中位 1.357 ms；源头约 1997 draw calls，中位 7.616 ms。接入后样本：野外约 143 draw calls，中位 1.38–1.43 ms；源头约 1993–1996 draw calls，中位 8.12–8.16 ms。野外 P95 在重复采样中波动较大（同一接入代码出现 9.55–33.18 ms），基线采样也有 24.36 ms 峰值；这组短时冻结场景测试不能证明完整战斗始终 60 FPS，也没有显示稳定的 draw-call 激增。三图自动战斗短测通过，无静态节点持续增长。
