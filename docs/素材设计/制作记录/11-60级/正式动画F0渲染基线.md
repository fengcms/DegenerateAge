# F0 正式怪物动画渲染基线（尚未接入新动画）

在已提交快照 `68f7a91e` 上执行 `python3 tools/run_isolated_tests.py --committed-tree --rendered MapRenderBenchmark`。Godot 为本机 `/Applications/Godot.app` 的 4.7.2 稳定版；测试在隔离项目与真实窗口渲染，每个场景采样 140 帧。该快照已有第一章正式图和第二至六章临时静态图，但第二至六章正式动画仍为 0/79。本记录为之后 F1 三样本的同场景对照，**不是新增动画性能已经通过的结论**。

| 场景 | 帧时间中位数 | P95 | P99 | 绘制调用均值 |
|---|---:|---:|---:|---:|
| `c2_lower_works normal` | 1.220 ms | 1.698 ms | 2.586 ms | 178.0 |
| `wild_trial normal` | 1.107 ms | 2.108 ms | 2.768 ms | 155.0 |
| `corruption_source normal` | 8.518 ms | 14.143 ms | 16.010 ms | 2011.0 |

`MapRenderBenchmark` 主要定位绘制负担，不包含完整的长时间密集战斗、首次纹理解码与跨图内存释放；不能据此断言稳定 60 FPS。三只样本接入后须在相同设备、渲染后端、地图、分辨率及镜头条件下重测，并增加冷加载、纹理内存峰值、战斗 P95/P99 和离图释放记录。若工作区并行修改地图或地面，必须再用固定提交快照建立基线，不能把不同版本的数字直接相减。
