# F1 汲灵幼虫方向稿试作与复核（未通过）

本记录是[正式动画方案](../../40-11至60级怪物正式动画制作方案.md)的第一只样本预检。目标只是在制作分层动作前，确认逐方向生成能否形成稳定八向结构；没有改动运行图、外观档案或正式动画进度。

## 实测现象

- 以现有 `concept.png` 为造型参考，使用内置 `image_gen` 逐张制作北、 西、 南三个透明候选。北向先生成斜向背面，再按“头在画面上方、尾在下方、口器全隐”编辑一次；保留的源稿分别是 `rear_candidate_v3.png`、`west_candidate_v1.png` 和 `south_candidate_v1.png`。三张均为 1536×1024 RGBA，保留在 `art_source/chapters/ch02/monsters/c2_spirit_larva/`。输入均为现有概念图，北向修正还引用上一张背面草稿；提示词明确单体、六足、象牙分节、铜阀、紫光、透明背景和方向。工具产物只作方向候选，不是可编辑层或正式帧。
- [原生尺寸并排预览](c2_spirit_larva_direction_pilot.png)从左至右为 `s / w / n / 原有 se`。按透明边裁切后统一缩至不超过 70×58，再放进 80×80 框，仅用于同屏比较。以 alpha 大于 20% 的主体估计，可见范围依次约 36×40、53×36、33×41、41×30 像素；背向已经不再露出口器，西向也有独立侧面轮廓。
- 三个候选与原有 `se` 的体量和透视仍不一致：南/北像近顶视长虫，原稿东南向是低矮斜视；南/北的纵向主体约 40—41 像素，而东南向为 30 像素。铜阀的前后顺序、头尾宽度及近远侧腿也不能直接从四张扁平图拆成同一套关节。其余四个方向尚未制作，五状态动作与接触姿也为零。

## 判断与下一步

逐方向单张生成比此前“一次生成整张八向图集”更容易得到真正背面，但**仍未通过 F1 的八方向结构、统一锚点与可编辑分层门槛**。不能将三张 PNG 镜像、缩放、平移或补重复帧后登记为正式动画，也不能把 `formal_animation` 从 `pending` 提升。

下一步先把幼虫的头、分节腹囊、两只铜阀和三对足做成独立透明层，建立固定 80×80 画布、脚底 y=64 与前后遮挡顺序；先手工修正 `s / w / n / se` 四个关键方向的体量和转身连续性，再补斜向与动作关键帧。只有四方向结构能在原生尺寸保持同一只怪物，才继续烘焙五状态。若分层调整后仍像纸片或轮廓跳变，则该形体改用逐方向逐动作关键帧，不套运动母版；不启动其他 78 只的批量复制。

## 补充：八方向候选完整排版

随后继续按同样的单方向方式生成 `sw/nw/ne/e` 四张透明候选（均保留在同一源稿目录），与前述 `s/w/n` 和原有 `se` 排成[八方向原生尺寸对照](c2_spirit_larva_8dir_candidate.png)，顺序为 `s/sw/w/nw/n/ne/e/se`。这完成的是**八张候选静态视角**，不是可编辑的八向结构板。并排后可复核三个新问题：

- `w` 与 `sw` 的头身朝向几乎相同，转向时方向反馈不足；`nw` 仍露出较明显的铜色口器，与背斜向应隐藏正面构件的要求冲突。
- `e` 的近侧明显画出了四条大腿/爪，而原设计为三对足；各向铜阀前后位置和腹节数量也不稳定，无法直接把候选图按同一骨架切层。
- 把大图统一裁切、缩至 80×80 并排后，上述问题仍可见；仅调整整体缩放和脚底坐标不能修复内部结构。候选 PNG 原始尺寸为 1536×1024，预览仅供检查，不作为游戏资源。

因此 F1 的**方向结构门槛仍未通过**，更不能开始 `idle/walk/attack/hit/death` 的批量烘焙。后续路线必须是手工重画/分层校正这些视角，再用[41 号源稿契约](../../41-怪物分层动画源稿与烘焙契约.md)制作真实关键姿势；若没有能够完成同一体量、同一关节的源稿，不应把 79 只怪物都按这批平面候选复制。当前临时图继续用于游戏，`formal_animation` 仍是 79/79 `pending`。

## F1 暂停依据与恢复条件

本轮从首个工程准备提交（2026-10-17 13:42）到八向候选复核提交（16:42）跨越约 3 小时；这是 Git 提交时间的**墙钟区间**，包含工具开发、等待图像生成和其他工作，不能当作幼虫单只的纯绘制工时，更不能据此估算 79 只的交付日程。幼虫当前仅完成八张未通过的静态候选：可编辑分层源稿 0、合格动作帧 0、游戏正式接入 0。与 F1 要求的八向、五状态、实窗战斗和性能复核相比，样本尚不能用于推算批量产能。

失败点发生在**结构稿**，不是图集烘焙或运行时加载：原生尺寸对照中仍可见方向重复、背斜向口器、侧向腿数与腹节变化。继续让生成工具独立画各方向，或让烘焙器运动这八张扁平图，都不会自动修正同一角色的空间结构。根据[40 号方案](../../40-11至60级怪物正式动画制作方案.md)“样本失败时暂停批量复制”的门槛，F2—F5 暂不启动。

推荐恢复路线是先由具备像素角色动画能力的美术人员（或等效的逐帧人工绘制流程）完成幼虫 `s/w/n/se` 四个关键方向的统一结构：固定三对足、腹节和两只铜阀，明确每向前后遮挡与脚底锚点；复核通过后补四个斜向，再画 `idle/walk/attack/hit/death` 的真实关键姿势。可沿用已完成的[分层源稿契约](../../41-怪物分层动画源稿与烘焙契约.md)、离线烘焙器与按地图加载链路，不必重做工程准备。若分层关节始终显得像纸片，应改为逐方向逐动作手绘关键帧；这会增加单只成本，须在三只样本实测后重新排期。若短期没有这类绘制产能，则维持已接入的 79 只简化版，正式状态保持待制作，不能通过降低验收标准把静态图登记为完成。

恢复 F1 的第一个可审查交付是：幼虫四个关键方向的分层源稿、80×80 原生尺寸并排图、逐层遮挡说明，以及与原有 `se` 同屏的转身复核；通过后才推进八向动作和第二、第三只样本。
