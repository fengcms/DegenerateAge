# 第二至六章临时怪物外观接入验收

本记录验收用户于 2026-10-17 选择的“先接入简化版，后续补动画”方案。它只改变外观层的交付口径；原计划要求的八方向、五状态、首领独立技能动作仍保留为后续工作，不因本次接入而视为通过。

## 交付与规格

- 第二至六章 **79/79** 个稳定怪物 ID 均有独立透明单体造型、三格运行图和外观档案，分章为 **16 / 15 / 15 / 18 / 15**。每只的 `appearanceId` 指向自身档案，`SimplifiedMonsterLibrary` 显式预载运行图；原有怪物身份、数值、碰撞、掉落、任务及存档字段未变。
- 图集横排原姿、受击闪白、死亡褪色三格。普通/精英/首领每格为 **80×80 / 112×112 / 192×192**，脚底锚点为 **(40,64) / (56,88) / (96,152)**。现有怪物状态机切换受击和死亡帧；攻击、移动时使用单一东南向原姿。章节 Boss 的已有逻辑预警不依赖本图集。
- 五章[第二章](ch02_monsters_runtime_preview.png)、[第三章](ch03_monsters_runtime_preview.png)、[第四章](ch04_monsters_runtime_preview.png)、[第五章](ch05_monsters_runtime_preview.png)、[第六章](ch06_monsters_runtime_preview.png)原尺寸深浅底拼版已逐张查看，普通/精英/首领体量和主要轮廓可辨。拼版只检验静态图尺寸与透明边，不替代实窗密集战斗人工体验。
- 79 张运行 PNG 共 **3,849,273 字节**，按 RGBA 未压缩像素估算为 **12.91 MiB**；Godot 导入副本、显存分配与其他场景资源不在此数内。原始概念大图仍在 `art_source`，未被运行档案引用。

## 检查结果

- `python3 tools/build_chapter_art_manifest.py --check`：150 个稳定 ID 通过，包含 79 张临时图的三格尺寸、RGBA、数据引用和预载检查；`python3 tools/check_monster_catalog.py`：87 个怪物模板，目录一致。
- `ChapterMonsterSimplifiedArtTest`：在 Godot 中逐个实例化 79 只第二至六章怪物，核对贴图共享入口、三格、尺寸和脚底锚点，全部通过。
- `ChapterTwoEncountersTest`、`ChapterThreeCombatTest`、`ChapterFourCombatTest`、`ChapterFiveCombatTest`、`ChapterSixCombatTest`、`MonsterAppearanceReuseTest`、`SmokeTest`：定向回归通过。
- `MapRenderBenchmark` 以实窗模式通过；其场景帧时包含既有地形与 UI，**不能**据此单独断言本批怪物使任一地图稳定达到 60 FPS。
- 全量 `--all` **未全绿**：`ArtSampleTest`、`QualityFrameTest` 和部分营地样板测试有失败；在临时怪物接入前的 `dc5c30cb` 快照中复跑，`ArtSampleTest`、`QualityFrameTest`、`CampFullArtAcceptanceTest` 同样失败。`MapRenderBenchmark` 必须单独以 `--rendered` 运行，不能把 headless 的失败当作渲染故障。同期新增的存档导入测试也在当前共享工作区失败，未纳入本次美术改动；不修改或放宽其断言。

## 尚未完成的正式动画

79 只怪物仍缺真实八向转身、待机/步行/攻击/受击/死亡逐方向帧和首领独立技能动作。清单标为 `reviewed/temporary_static`，并用 `temporary_sprite` 指向运行文件；不得改记为 `integrated` 的正式动画。后续按[动画样本技术验收](动画样本技术验收.md)先做普通、精英、Boss 三种分层动作样本，逐 ID 切换为 `animation_pack`。临时图可作为造型及接入回退，不复用其单帧来冒充正式动作。
