## HUD 项目的处理边界

09 清单将 HUD 任务追踪器列为「完全原生」，与当前工程不符：[`Hud.tscn`](../../scenes/ui/Hud.tscn) 已对 `QuestTracker` 指定 `sb_panel` 半透明样式；经验条也由 [`HotbarVisual.style_experience()`](../../scripts/ui/hotbar_visual.gd) 在运行时覆盖。它们属于此前单独确认的 HUD 视觉系统，**没有改成带标题的浮窗外框**，以免破坏玩家确认过的透明 HUD 和快捷栏布局。

## 验证与限制

- `PanelChromeLayoutTest`：四个常驻浮窗标题几何一致，圆钮不压线。
- `FloatingWindowInputTest`：重叠命中、上沿拖动及按钮独立点击通过。
- `PanelChromeCoverageTest`：17 个功能面板均在实际场景树中接入共用外框；没有遗留的原生 `ConfirmationDialog`。
- `DeathChoiceTest`、`FlowFeedbackTest`、`MenuFlowTest`、`SettingsTest`、`MapCanvasCacheTest`、`EquipmentAxesTest`、`InventoryUpgradeBadgeTest` 与 `SmokeTest` 已通过隔离运行。`SmokeTest` 中自动战斗目标锁定断言曾间歇性失败，原始基线也有通过记录；复跑通过，未改动战斗代码。
- 自动测试只验证结构和交互，**不能代替玩家在实际渲染窗口中确认 80%～200% 倍率下的文字间距、边缘高光和长文案换行**。这部分仍需视觉验收。
