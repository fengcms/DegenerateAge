## 0. 本轮范围

你已确认：**「种类更多」两层都要（变体更多 + 材质更多），但先做 A 层 = 变体更多**。

- 本轮**只做 A 层**：把**同一材质**的地面变体从 4 块扩到 **9 块**，铺装不再单调。
- 范式**回到 32 号**：生成器直接画整菱形砖；后处理只做 硬阈 → trim → 点采样 64×32 → 菱形掩码 + 填底。**禁止** `rotate 45` / `Y×0.5` / 方纹理投影。
- (B) 层（新增材质族：泥地、砾石、石板、沙地、夯土、焦土、湿岩、水面浅滩）**下一批**再做；族间边色不一致的问题由 L1 过渡边缘解决，与 B 层同批推进。
- 本轮**先做 wild 草土族**作为试点（铺装面积最大、单调感最重）；跑通后再按同一模板复制到 ash / cave。

## 1. 关键规格：图集几何

| 项 | 规格 | 理由 |
|---|---|---|
| 图集排版 | **strict 3 columns × 3 rows = 9 块** | 一次生成拿满 9 变体，省你的生图成本 |
| 画布 | **1536×1536**（每格正方形 512×512） | 与已成功的 2×2（1536×1024）同量级，不触发生成器尺寸上限 |
| 格内菱形 | **每格一块 FLAT 2:1 菱形地面，水平居中、占满格宽、约占格高一半，上下留清晰空白** | 方形格里放 2:1 菱形，必然上下留缝——**这正好防止邻格相接** |
| 底 | 真透明（alpha=0） | 打包脚本靠 alpha 硬阈裁边 |

> ⚠️ **不要把 2×2 的旧措辞照抄**。旧措辞里「diamond spanning the full cell width and full cell height, points at exact midpoint of each edge」在**方形格**里会推出 **1:1 菱形**（错误）。本单已按方形格改写为「占满格宽、约半格高」。验收时若测得某格宽高比 ≈ 1.0，即判定为误读，整张退回。

**退回方案（仅当 3×3 排版失败）**：改出 **2 张 2×2 图集**（`wild_tiles_a.png` / `wild_tiles_b.png`，各 1536×1024），合计 8 变体，打包为 `tile_0..7`。2×2 排版已被证明可靠，代价是多一次生成。

## 2. 可复用英文文本块

同批共用的四段，只有 `[主体]` 段换族。四段**一字不改**——这是跨素材一致性的保证。原 [25 号](25-地图素材提示词包-M1地面基座.md) 的 `[风格锁定]` 段色板与主光**继续沿用**（该段仍有效）；`[无缝]` 段整段**弃用**（那是方纹理口径的产物）。

### [风格锁定]（沿用 25 号 §2，原文照抄）

```text
Match supplied reference image 1 exactly: deliberate chunky pixel clusters with hard square
pixel edges, strict limited palette of about 16 flat colors (deep ink #171A21, iron grey #353B46,
grey rock #687078, worn cloth #A89978, bone white #E6DDC6, muted moss green, campfire orange
#D99A52 accents), upper-left light source, quiet low-contrast terrain so player characters read
clearly on top. No gradient, no blur, no soft shading, no antialiasing, no photographic texture.
```

### [等距菱形排版]（LAYOUT · 本轮新增，替代 `[无缝]`）

```text
Create ONE atlas: strict 3 columns by 3 rows, nine SEPARATE FLAT 2:1 diamond isometric ground
tiles on a truly transparent background. Every cell is an equal square. Inside each cell place
exactly ONE diamond ground tile, centred horizontally, spanning the full cell width, about half
the cell height, with clear empty transparent gap above and below it. No tile may touch, overlap
or bleed into a neighbouring cell. Each diamond is a flat ground patch only. Do not draw grid
lines, borders, labels, numbers or letters between cells.
```

### [像素密度与边缘纪律]（DENSITY · 本轮新增）

```text
LOW resolution pixel clusters appropriate for final 64x32 tiles enlarged with nearest neighbour:
chunky readable clusters, hard square pixel edges, no antialiased or painterly blur.
Screen-upper-left light, muted low-contrast palette so player characters read clearly on top.
Match the soil/ground edge tone consistently across all nine diamonds so any two tiles can sit
side by side without a bright seam. Ground features must not cross the tile boundary: no large
rock, no tall grass tuft, no slab sticking out of a diamond. No cube sides, no drop shadow,
no outline drawn around the diamond.
```

### [负面]（NEGATIVE · 本轮改写）

```text
No text, no letters, no numbers, no watermark, no border frame, no grid. Not smooth vector, not
photorealistic, no high-contrast lighting, no vignette. No creatures, no characters, no UI, no
items. No objects with height: no trees, bushes, walls, buildings, carts, fences, ruins, rocks
standing out of the ground. No water, no sand, no cobblestone, no road markings.
```

## 3. `[主体]` 段 · wild 草土族（九变体）

```text
Subject: nine variations of ONE single ground material — dry trampled grey-green grass over dark
earth with a few tiny pebbles. All nine tiles must obviously be the SAME material, sharing one
palette and one soil edge tone; they differ ONLY along three narrow axes: (1) grass density, from
sparse clumps with visible bare soil to dense even cover; (2) dryness, from fresh green to pale
dry yellow-green; (3) amount of small grey pebbles, from none to a light scatter.
Spread across the nine cells in roughly this order: sparse / dry / much visible soil / no pebbles;
sparse / dry / some soil / few pebbles; medium / neutral grey-green / some soil / few pebbles;
medium / neutral / little soil / moderate pebbles; dense / neutral / little soil / no pebbles;
medium / fresh green / little soil / no pebbles; dense / fresh green / little soil / few pebbles;
medium / damp dark green / little soil / no pebbles; sparse / dry / much visible soil / moderate
pebbles. Ground tiles only: flat, no height, no objects.
```

拼装顺序固定为：`用途 → [风格锁定] → [等距菱形排版] → [主体] → [像素密度与边缘纪律] → [负面]`，开头一句为：

```text
Use case: stylized-concept. Asset type: production terrain atlas for a 2D isometric pixel-art
dark-fantasy RPG. Match supplied reference image 1 for palette, pixel chunkiness and lighting.
```

## 4. `[主体]` 段 · ash 灰烬族与 cave 洞穴族（同批下发）

结构完全相同，只换 `[主体]` 段，**同样 9 块同为一种材质**。

### 4.1 ash 灰烬族

```text
Subject: nine variations of ONE single ground material — ash-grey scorched soil, fine coal dust
over packed grey earth with a few tiny cooled cinder specks. All nine tiles must obviously be the
SAME material, sharing one palette and one soil edge tone; they differ ONLY along three narrow
axes: (1) dust density, from thin pale ash to a thick settled layer; (2) darkness, from mid grey to
near-charcoal; (3) amount of tiny cooled cinder specks, from none to a light scatter.
Spread across the nine cells in roughly this order: thin ash / mid grey / no specks; thin ash /
mid grey / few specks; medium / mid grey / few specks; medium / darker grey / moderate specks;
thick settled ash / darker grey / no specks; medium / near-charcoal / no specks; thick settled ash /
near-charcoal / few specks; medium / dark with faint damp sheen / no specks; thin ash / mid grey /
moderate specks. Ground tiles only: flat, no height, no objects, no glowing embers brighter than
the ground tone.
```

### 4.2 cave 洞穴族

```text
Subject: nine variations of ONE single ground material — damp pale limestone cave floor with fine
mineral staining over packed grey rock dust. All nine tiles must obviously be the SAME material,
sharing one palette and one edge tone; they differ ONLY along three narrow axes: (1) staining
density, from almost clean pale stone to heavily stained; (2) dampness, from dry matte to a faint
cool sheen; (3) amount of tiny rubble specks, from none to a light scatter.
Spread across the nine cells in roughly this order: clean pale / dry / no specks; clean pale /
dry / few specks; light staining / dry / few specks; light staining / slightly damp / moderate
specks; medium staining / slightly damp / no specks; medium staining / damp sheen / no specks;
heavy staining / damp sheen / few specks; medium / damp with darker grey patches / no specks;
light staining / dry / moderate specks. Ground tiles only: flat, no height, no objects, no glowing
crystals and no violet veins rising above the ground surface.
```

> 注意：ash 现役 4 块里 **`tile_3` 是道路砖**（被 `road_soft.png` 复用）。扩到 9 块时**9 块全部是地面变体，道路仍由既有道路/过渡砖机制供给**，不占变体名额。这一条在改造 ash 时单独处理。

## 5. 硬约束（违反即整张退回，不进打包）

1. **同族九块必须是同一材质**：语义跨度大的东西（裸土、车辙、水、沙、石板）一律不得进入本族——[30 号 §4.3](30-M1第二批复核与四变体判据.md) 已实测：语义跨度大的变体按单格混铺会让地图变成拼布被。
2. **九块必须在同一语义窄带内**，任意两块都可互换用在任意格子上。
3. **无立体物**：地面砖只画平的东西，树/墙/车/石都不许出现（那是 L4/L5）。
4. **禁止镜像翻转 / 旋转**（会导致草倒长；项目明令）。
5. 生成源稿放 `art_source/environment/ground_tiles_v1/`，**不要**直接进 `assets/`。

## 6. 生成后验收（我方执行，用 magick）

对源图逐格裁 512×512，量 alpha 包围盒：

```bash
magick art_source/environment/ground_tiles_v1/wild_tiles_3x3.png \
  -alpha extract -threshold 50% -format "%@" info:
```

判据（**全部满足才通过**）：

| 检查 | 判据 |
|---|---|
| 格数以内容独立 | 9 个互不相交的内容包围盒 |
| 2:1 形态 | 每格 bbox 宽高比 ∈ [1.70, 2.10]；**出现 ≈1.0 即退回** |
| 占格宽度 | 每格 bbox 宽 ≥ 410px（≥0.8 格宽） |
| 尺度统一 | 九格 bbox 面积极差 ≤ 15% |
| 不跨界 | 相邻格 bbox 间距 > 0，无粘连 |
| 材质同一 | 九格主色/亮度聚类同组（目视 + 均值比对），无一块跳画风 |

不合格 → 我按「排版 / 密度 / 色板」三项反馈给对应文本块，只改那一处重出，不动其余参数。
