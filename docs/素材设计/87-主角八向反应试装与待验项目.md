# 主角八向反应试装与待验项目

本阶段补齐 sw、nw、s、n、e、w 六方向受击与倒地，共十二张运行图集。内置 image_gen 以项目已有方向站姿生成原创八姿态源页；西南、正右的初稿背景不合格，构建采用透明修正版。提示词、修正记录、采样参数均留在 art_source，源页不进入运行依赖。

每帧 112×128，脚底 (56,112)，四帧；受击 0.52 秒，倒地 0.90 秒。正前页按 sourceIndices 重排姿态，其他页按前四受击、后四倒地。复用现有方向缓存和反应优先级，不新增更新节点、计时器或寻路。切图释放节点，纹理由样板路径缓存共享。F/C 按当前八向朝向播放，V 重置；尚未连接正式伤害和死亡结算。

构建透明边缘检查与动作清单通过。主角动作 RGBA8 理论成本 7616 KiB，两怪 1920 KiB，合计 9536 KiB，不含环境、原图、驱动或导入开销。相对上一阶段增加 2688 KiB。
