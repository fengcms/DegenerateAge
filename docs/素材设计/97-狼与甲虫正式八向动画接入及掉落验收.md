# 狼与甲虫正式八向动画接入及掉落验收

2026-11-18。将已确认风格的腐化野狼、裂壳虫从隔离样板推进到正式外观档案和地图级动画缓存。主角与模块化地图仍保留隔离试装，未以外围小场景替换正式营地。

## 接入链与素材规格

保持具体怪物ID和appearanceId为wolf_corrupted、shellback_bug，仅将对应外观档案renderer切换为animation_pack，assetKey分别为wolf_corrupted_modular_v1、shellback_bug_modular_v1，头顶血条Y=-78。

八个方向顺序s/sw/w/nw/n/ne/e/se，五状态idle/walk/attack/hit/death各四帧。单帧128×96、脚底锚点(64,80)，正式图集横四帧纵八方向，尺寸512×768。待机3fps、行走6fps，攻击接触帧2，倒地时长0.90秒；攻击/受击推进沿用正式MonsterActorArt接口。伤害仍在原事件发生时立即结算，不因动画准备帧延后。

build_formal_monsters.gd只对已验收80张方向图集的像素做重排，--check逐像素验证全部方向/状态；没有缩放、镜像或重新生成造型。源包分别位于art_source/actors/*_combat_pack_v1，提示来源沿用各方向源稿记录。统一构建器build_monster_animation_assets.mjs新增这两种受限源路径，生成运行目录与MonsterAnimationLibrary，不手改生成库。

正式MonsterAppearance→MonsterAnimationCache→MonsterActorArt完成装配、地图预取和共享，切图由原世界释放缓存。实战与外围样板也保留这个装配结果，不再先创建正式怪物再替换成独立方向适配器。两类怪物的独立方向图仍用于原尺寸审查与源包重建，正式世界不引用那些试作图。

## 玩法与体宽边界

未修改怪物生命、攻击、冷却、经验、掉落表、稳定身份和任务引用。碰撞半径实测仍为13。既有MonsterAppearance按画面可见宽度计算分离距离，因此换图后的分离半径为狼61.5、甲虫52像素；这会影响怪物视觉间距，不应笼统宣称所有站位完全不变。头顶位置按新帧尺寸调整，正式点击与伤害回归保留。

每张图集理论RGBA8为1.5MiB，十张合计15MiB；新源包和运行PNG各约3.3MiB压缩文件。资源按地图所需外观预取，不全局预载六包。正式动画注册表由4包增至6包；旧四包像素和元数据不变，旧两怪sample_atlas文件保留用于历史引用，不是当前外观入口。

## 功能验证

- 构建器6包只读校验通过；新两包重排逐像素校验通过；87种怪物目录检查无问题。
- --formal-monsters要求宿主直接持有正式MonsterActorArt，检查地图预取、8向×5状态×4帧、接触帧、脚底与死亡时长，再完成真实追击、互击、死亡、经验、金币和拾取。窗口及无窗口均通过。
- 使用正式怪物的64×16外围路线完成六个指定刷新点击杀，三段生命103/77/52、10次拾取、1次实际返营；不是靠旧组重生怪凑击杀数。
- --capacity占满40格后实际击杀两怪，实测保留1件非金币普通掉落、金币14正常入账；等待5秒后奖励仍在，移走测试填充物后由正式自动拾取收取1件，实例/数量核对一致。未直接调用拾取函数或代怪物伪造奖励。

满包测试初版误将coin的item_picked事件计为背包物品，并误认为普通怪掉落都应有持久记录，均属测试对现有契约理解错误。现已区分金币和背包物；普通掉落仅要求同场保留，只有原本persistent的精英/Boss掉落才要求持久登记，不改变现有跨图规则。该样本没有覆盖精英/Boss满包持久掉落，不冒充这部分验证。
