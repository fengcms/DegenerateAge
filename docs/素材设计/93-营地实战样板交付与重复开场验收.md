# 营地实战样板交付与重复开场验收

2026-11-18。本阶段完成可操作的小场景：模块拼装营地、主角、腐化野狼、裂壳虫，复用正式追击、攻击、反击、死亡、经验、掉落和拾取。不是整张背景图，也不把16×16试验场直接覆盖正式营地。

## 运行与实现边界

在仓库根目录运行 `python3 tools/camp_combat/launch.py`。WASD移动，点击怪物追击，点击空地移动，F自动战斗，G自动拾取，R重新开始。三级演示角色由正式800经验成长建立。随机项目身份和临时user目录隔离真实存档，退出清理。

三种角色均八方向五状态；两怪七个新增方向独立源稿，旧左前复用。主角待机单帧，其余四帧；怪物每状态四帧。运行纹理按种类缓存，不在每个实例重新裁切。攻击接口对应即时伤害，显示从接触帧进入恢复，不为了播放准备帧延迟伤害；死亡结算仍立即发生，0.90秒倒地后由正式死亡流程清理。

源码入口为tools/camp_combat/main.gd、art.gd、ground.gd；细节与前两阶段见90、91号文档。主角左后行走灰底问题见92号文档。原尺寸审查工具review.gd读取同一图集入口，12张阶段页通过窗口绘制，临时截图阅后删除。
