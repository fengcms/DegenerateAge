# 统一面板 UI · 视觉样稿 v1

依据 [统一面板 UI 设计规划](../../04-统一面板UI设计规划.md) 制作。用户修订后的 SVG 是本轮游戏界面的视觉基准；同名 PNG 是同步更新的 1280×800 渲染预览。所有面板、角饰、格子、图标示意与文字均为 **SVG 内可编辑对象**。样稿中的数字、物品和状态用于展示排版，游戏继续读取实际数据与本地化文本。

| 样稿 | 重点审阅 |
|---|---|
| [背包与人物浮窗.svg](01-背包与人物浮窗.svg) · [预览](01-背包与人物浮窗.png) | 两个独立窗口的框体、标题栏、物品格、角色与装备/属性列；点击置顶和拖动区域的视觉区分 |
| [设置与选项卡.svg](02-设置与选项卡.svg) · [预览](02-设置与选项卡.png) | 五个现有页签、当前页标识、「控制」列表、滚动条与键盘焦点 |
| [NPC 对话与服务.svg](03-NPC对话与服务.svg) · [预览](03-NPC对话与服务.png) | 铁匠当前「自我介绍 → 升星入口」两阶段的容器与按钮；未定义逐句对白和分支功能 |
| [组件细节.svg](04-组件细节.svg) · [预览](04-组件细节.png) | 框角、按钮、页签状态、文字层级的放大对照 |
| [技能与坐骑浮窗.svg](05-技能与坐骑浮窗.svg) · [预览](05-技能与坐骑浮窗.png) | 同一框体下的技能行卡、可用/未解锁状态、坐骑收藏与预览布局 |

本稿选择轻薄旧铁双框、暗蓝黑内衬与局部旧金刻纹，延续已确认的头像、小地图和快捷栏；没有给每个面板加厚重图案。标题约 20 px、页签与分区约 16 px、正文 15–16 px、说明约 13–14 px。框体与控件状态共用一套样式，但背包/人物/技能/坐骑维持可同时打开的浮窗，设置和 NPC 会话维持各自的关闭式流程。页签只用于已有的真实分类，人物、背包和坐骑不为了对称增加空页。

游戏内已使用统一的可伸缩面板外框与标题、按钮、页签规则，覆盖背包、人物、技能、坐骑、设置、任务、商店、车夫和铁匠面板。背包格、人物属性、技能行、坐骑预览与铁匠两阶段对话也按样稿的内容层级调整。浮窗拖动、背包拖放、设置改键和 NPC 操作继续读取原有逻辑。后续视觉微调仍可直接编辑 SVG；`.gdignore` 让这些审阅稿不作为运行资源导入。

预览图由 Chrome 以 1280×800 视口渲染同名 SVG 取得；修改 SVG 后可用浏览器重新截图。游戏内框体由 `scripts/ui/panel_chrome.gd` 按实际尺寸绘制，不会把整张预览图当作游戏贴图。
