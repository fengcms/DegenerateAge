## 造型基准与制作方法

用 `art_source/playable_sample/guardian_source_atlas.png` 作为角色身份参考，通过内置 imagegen 生成一张独立全身像：乱黑短发、炭灰衣裤、灰银护肩与护臂、旧布披肩、皮革束带、带小面积青色细节的钢刃，光从画面左上来。原稿实际为 1024×1536；导出时置于透明 1024×1600 画布中央，以最近邻缩至 256×400，再清理与主体不连通的低透明杂点。保留原稿，是为了后续调整尺寸、透明边缘和 UI 缩放，而不是让游戏加载大图。

```bash
magick art_source/player/look_01/guardian_panel_master_candidate.png \
  -background none -gravity center -extent 1024x1600 \
  -filter point -resize 256x400 guardian_panel_candidate.png
```

导出后须再做一次不连通杂点清理；以本目录候选图为本轮审稿基准，不把上面的基础导出命令单独当成完整复建流程。生成图的来源为项目既有角色源稿与本轮 AI 再创作；没有使用第三方新增素材。正式游戏只依赖 `assets/ui/` 下的运行图，不依赖 `docs/` 或高分辨率母版。

## 本轮自检与待审问题

- 实测运行候选为 256×400、带透明通道；左上角透明，主体在 50% alpha 阈值下约占 248×378，位于 `(4,12)`，与面板内宽 256 像素相符。
- 深色面板预览与白底检查均已查看；白底发现的散落透明杂点已从候选运行图清除，主体轮廓、披肩和剑刃未裁断。
- 对比现有八向站姿，头发、披肩、胸带、护甲和持剑侧一致；面板画法有更丰富的像素簇，需审稿确认这种清晰度和人物占框比例是否正合预期。
- 目前只完成 A 节点候选；六状态逐帧动画、骑乘形象、代码接入和实机 100%–200% 验收仍在后续节点。用户审定造型后，再以此为基准批量生产，不提前扩散未审定的人物形象。
