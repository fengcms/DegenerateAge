# 快捷栏与经验条设计审阅

以 [用户设计的效果.svg](用户设计的效果.svg) 为视觉准稿。用户将底座去掉，并明确经验条只与 16 格快捷栏整体同宽，不按屏幕宽度拉伸。[居中排版建议.svg](居中排版建议.svg) 仅把原稿中的约 720×75 px 图形整体移到 1280×160 透明画布的底部中央，没有修改格子、图标或经验条的造型。原稿保留，方便继续编辑。

正式接入时，快捷栏与经验条应由同一个底部居中容器约束宽度，并随 UI 缩放一起变化。16 格分为 12 个可配置操作格和 4 个固定功能入口（人物、背包、技能、坐骑）。经验填充按实时进度裁切；图中约 46% 只用来预览。默认不显示经验数值，悬停时显示。

**所有 16 格的键位角标都必须是运行时文本，不使用 SVG 内烘好的字形。**前 12 格读取 `hotbar_1` 至 `hotbar_12`；后 4 格依次读取 `panel_character`、`panel_inventory`、`panel_skill`、`panel_mount`。初始显示与读档后从 `SettingsRuntime.key_for(action)` 获取物理键码，使用 `OS.get_keycode_string()` 生成名称；收到 `EventBus.settings_changed` 后立即刷新。角标为较长键名预留可伸缩宽度，完整键名同时保留在悬停说明中。冷却、数量、禁用与拖放状态也由代码叠加，不能烘在底图里。

审阅建议：当前键位角标只有约 12×10 px，1280×800、100% UI 缩放下可能偏小。若实机仍难辨识，可增至约 14–16 px 宽、12–14 px 高，并让两位及以上键名向格内横向扩展；无需加回整块底座。
