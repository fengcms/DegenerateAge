## 用途与限制

- 仅用于**方向决策**与 **M1 验证**，不接入游戏、不改数据与代码。
- 含图像生成工具渲染痕迹，不得作为正式素材；正式素材须按 [03-素材清单与制作验收](../../../docs/素材设计/03-素材清单与制作验收.md) 重新制作并过文件/视觉/接入三关。
- 验证结论与下一步见 24 号文档第十节。
