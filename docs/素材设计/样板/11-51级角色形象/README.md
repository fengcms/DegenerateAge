五张面板候选为真实透明 RGBA、256×400，按最近邻从修正版全身稿导出；不是世界 64×80 首帧放大。五张八向源稿每张保留八个屏幕方向，但列宽与角色脚底仍需离线整修后才能成为运行素材。`look_02` 的 `walk_8dir_4pose_master.png` 有四种行走关键姿态，`attack_contact_8dir_master.png` 是一张攻击接触姿态，均尚未打包或接入。

创作提示词要点：同一黑发年轻守护者与旧沙色围巾；按章节依次加入井镇旧铁/暖灯、渠铜测量布/圆盾、林海短绿披肩/红色邮签、边境深铁重甲/撤离军旗、镇脉灰白旧石/暖金旁路。画布透明、复古像素簇、左上主光、完整全身；武器握柄—护手—刃身同轴，避免错手、断刃、斜接；禁止现代机械、全身紫化、神环和大面积发光。八向源稿额外要求 `s, sw, w, nw, n, ne, e, se` 顺序、足底同线与各列留白。
