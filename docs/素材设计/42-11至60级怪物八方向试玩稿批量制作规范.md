# 11—60 级怪物八方向试玩稿批量制作规范

2026-10-17 用户已在游戏中目视验收「汲灵幼虫」的八方向单帧试玩稿，明确接受这一质量作为其余怪物的开发基准。本规范接替[40 号正式五状态动画方案](40-11至60级怪物正式动画制作方案.md)的**当前制作批次**；五状态逐帧动画保留为远期升级项，不再阻止八方向试玩稿接入。启动时 1/79 只为八方向试玩稿，其余 78 只使用单方向三格临时图。

## 每只怪物的交付

- 沿现有 `concept.png` 和已审查的身份元素，逐方向生成 `s/sw/w/nw/n/ne/e/se` 的真实视角。允许使用已有东南向运行图作为其中一向；不能用纯水平镜像替代全部反侧方向。AI 图须透明背景、单体、无文字、无地面与投影底图。
- 八方向均在普通 80×80、精英 112×112、首领 192×192 的固定格中展示，同 ID 保持统一脚底锚点（64/88/152）和近似体量。原生尺寸并排图须能辨认同一怪物、正侧背方向及标志性装备/肢体；允许汲灵幼虫级别的小结构差异，不要求可编辑分层或五状态动作。
- 运行图集采用 3 列 × 8 行：原姿、受击闪白、死亡褪色；方向行顺序固定 `s/sw/w/nw/n/ne/e/se`。移动按速度转向，攻击朝目标转向，受击/死亡保留该朝向。攻击伤害、刷新、碰撞、掉落、任务和存档身份不随美术改变。
- 外观登记为 `directional_preview`，资产清单登记试玩接入；独立的 `formal_animation` 继续保持 `pending`，不把静态朝向称为逐帧动画。保留 `simplified_atlas.png` 用于可回退构建，运行时不再为已升级 ID 全局预载旧图。
- 原生尺寸对照、源图路径、最终图集、构建命令、特殊问题与实际试玩地图写入每 ID 的制作记录。首领须额外检查技能预警及头顶 UI 遮挡，但本批不新增独立技能姿势。

## 批次与提交

按第二至六章地图顺序推进：先章内普通怪，再精英，最后首领。每 1—3 只为一个美术小节点；源图、图集、外观档案、清单和预览同批提交。通用构建器、装配器和数据校验单独提交，避免每新增一只复制一套运行脚本。每批运行外观装配、章节战斗、资源引用和导出/导入检查；实窗抽样查看深浅地形、移动、攻击、受击、死亡。遇到形体方向严重不一致时只重做该 ID，不拖累已通过的怪物，也不填充镜像占位。

本批完成定义：79/79 个稳定怪物 ID 都有八方向试玩图集和运行档案，能在各自地图正常转向与保持反馈；另以五状态逐帧动画数量单独统计。资源加载遵守根目录 `AGENT.md` 的地图级需求与释放约束，不因批量 PNG 把 79 套大图全部预载。
