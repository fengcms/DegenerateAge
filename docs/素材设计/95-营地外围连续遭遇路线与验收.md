# 营地外围连续遭遇路线与验收

2026-11-18。把两怪小场景扩展为营地出发、三处窄口、三组遭遇和返营的连续路线。保持原有灰褐写实风格，复用独立地块/道路/草层/建筑/墙/树/箱桶，不使用整图背景。

## 实现与范围

入口为 `python3 tools/camp_combat/launch.py --route`。64×16格，地块64×32等距投影，镜头跟随角色；窗口仍1280×800，不等于地图尺寸。route_layout.json为物件/道路事实源，碰撞与CaveLayout由同一占地编译；原16×16样板入口保留。SampleRoadRules邻接查询改为读取行列大小，地面仍三层FlatTileMesh。

route_map.json仅在隔离进程内追加camp_route_trial，不覆盖正式地图、NPC、任务或存档。营地安全矩形[0,0]～[10,15]，窄口x=12/28/45、y=6～9，遭遇节点(21,8)/(37,8)/(55,8)。六个点各一只狼或甲虫，60秒刷新，普通怪预算10；实际激活/退场遵循正式距离阈值。route_spawner.gd只在正式Spawner生成成功后换外观、接统计信号，不复制刷新、死亡、经验或掉落逻辑。

角色沿用三级成长；顶部导航按钮调用正式request_map_move，不传送。点击敌人按距离选择最近目标，避免先遍历到的怪抢选；点击无目标时调用正式移动。F自动战斗、G拾取、X休整、R重开。休整调用既有每三秒恢复规则，暂用待机外观，HUD显示休整状态；移动或受击仍由正式规则中断。

## 接入问题与修正

此前地面门面只注册map_ground组，却未命名Ground。怪物和自动战斗按组可找到，但正式玩家点击寻路通过map_world/Ground查找，开阔地击杀验证漏掉此问题。本次明确节点名称，controls.gd用正式Player绕(4,3)箱子从(3,3)走到(5,3)，要求多路点和实际到达，未减小半径或放宽碰撞。动作接管与复活表现修复见94号文档。

## 首次卡顿定位边界

在原两怪同场三轮soak中增加大于25ms帧的帧号、动作、伤害/击杀/拾取数量及引擎监视器读数。新样本三轮峰值79.744/28.777/36.274ms，P95为14.886/14.326/14.357ms，P99为16.579/14.975/14.812ms。首轮前13个采样内多次慢帧时damage=0，纹理120658569字节；已有伤害与掉落后为120745949字节。三轮结束节点329，纹理一致。

这说明本次开场慢帧在首次伤害之前就出现，不能直接归因于攻击/掉落；此前283.822ms没有稳定复现，不能把一次峰值下降当作修复。TIME_PROCESS=300.168ms等监视器值在前多个采样重复，它不是同一帧的纯脚本耗时；仅凭这些值不能进一步断言GPU上传、编译或操作系统调度是根因。保留定位入口和未解决项，没有为降低数字修改战斗规则。

## 成本与生命周期

1024地块为三层网格；36段墙及建筑占地、边界用于静态碰撞，无逐地块活动逻辑。8个大物件遮挡按实际位置更新，HUD5Hz，最多10普通怪由原预算快照管理。动作包按角色种类缓存，实例切AtlasTexture引用；场景退出释放实体、信号和遮挡，进程退出释放共享资源。压力测试帧样本仅验收开启，约120秒×120Hz，不用于正式运行。

## 验收记录

初次无窗口路线累计2/4/6击杀，结束12次拾取、9次生成、1次返营；经验升级正常恢复生命，不由样板额外加血。每个窄口必须实际抵达，玩家死亡或超时拒绝通过。初版只计阶段击杀数量，不能排除旧组重生怪混入；最终验收已加强为按monster_id与ordinal逐个确认六个指定点死亡，使用正式手动追击接口完成。自动战斗另由高密度持续验收覆盖。

窗口复核发现返营消息与HUD往返计数可能错开一个5Hz刷新周期，现已让消息/阶段改变立即刷新HUD，并显示自动战斗开关。运行态地图尺寸与实际地面尺寸必须一致。

高密度测试独立注入12个固定点、10活动上限，额外30000经验通过正式成长建立测试角色；不改变普通路线难度和怪物模板。持续120秒覆盖正式倒计时刷新，随后返回营地并重新开场检查节点回到初始值。首轮高密度运行逻辑完成24次击杀，但持续绘制断言失败，因此未认定性能通过；前台窗口复测通过，要求实际绘制帧覆盖至少90%的采样，不调用force_draw。

## 后续接入条件

正式营地仍需逐项迁移NPC、任务、出口、完整外观状态与存档。当前不因局部路线通过就覆盖正式地图。需要继续定位首轮尖峰、扩展更长挂机与满背包累积测试，并精修帧间造型；本次两分钟压力样本不等于长期稳定性证明。

- `python3 tools/modular_camp/launch.py --verify`：原两套16×16样板回归。
- `python3 tools/run_isolated_tests.py SpawnerBudgetTest CaveConnectivityTest`：正式刷新预算及连通性定向回归。
