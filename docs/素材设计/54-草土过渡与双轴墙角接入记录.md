# 草土过渡与双轴墙角接入记录

2026-11-17。继续53号模块化营地试装；只修改隔离实验场，正式地图与存档不变。

## 已完成

1. 使用内置image_gen生成独立草地材质母版、另一轴向短墙和一种L墙角；保存完整提示词与生成来源，未输入第三方游戏资产。
2. 构建第二张1024×1536草土覆盖图集，16相位×47种连接形状，另保留一行备用土底。仍使用64×32瓦片、周期共边约束和既有FlatTileMesh。
3. 实验场按土底、草土覆盖、道路三层各一个网格合批；grass和roads独立数据且互斥。草土渐变宽度增加，内凹角半径同步调整，防止宽边造成接缝。
4. 两种布局均增加双轴短墙加L角组合，独立贴图按脚底排序，占地继续生成通行掩码和碰撞。未镜像墙贴图。
5. 增加树前/树后定点遮挡截图及z顺序断言，检查人物与树的实际前后关系。

## 验证

最终命令：`python3 tools/modular_camp/launch.py --verify --capture /tmp/modular-camp-grass-v3`。Godot4.7.2 / Compatibility / Apple M1 Max，1280×800窗口，退出码0，输出MODULAR_CAMP_VERIFY_OK。

覆盖：两张图集共1536格中心与透明角、256邻域规范化得到47连接形状、草土与道路两套边宽的共边alpha连续、草路格互斥、两布局通行/物理碰撞一致、长路径、墙段门洞、正面阻挡、绕墙、移动墙后的掩码与导航更新。树前后定点检查在物理和显示帧更新后执行，不是行走动画验收。

过程中修正了新增图集检查的显式Image类型声明；新增遮挡测试曾在物理帧信号发出、角色排序尚未更新时提前断言，现等待显示处理帧完成后检查。原通过条件未放宽。启动器增加导入脚本错误检查与超时日志输出，避免无信息等待。

## 成本、限制与下一步

两张图集未压缩RGBA8理论12MiB，比首批增加6MiB；地面网格由2份变为3份。物件按纹理路径共享；纹理加载只在初始化，切换布局重建小样板网格与物件，帧循环不重建地面。未进行显存与P95/P99实测，不承诺60FPS或性能改善。

只完成一种墙角方向，其他角向和端帽未完成；草边仍缺自然破口和跨格贴花。当前树是整体排序，不是独立树冠淡出；屋檐仍未分层。人物依然静态占位，未完成新动画、两类怪物战斗或正式营地迁移。

下一步优先精修墙接头与脚底锚点，补充低密度草根/碎石贴花，再处理树冠/屋檐遮挡层；不能靠增加整图背景掩盖模块接缝。
