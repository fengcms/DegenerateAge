## 三、「挂在墙上」的根因判定

### 3.1 你看到的这张图是怎么来的

`preview_scale.png` 由 25 号 §4② 的命令生成：

```bash
magick tile_160.png -write mpr:t +delete -size 1200x340 tile:mpr:t _base.png
magick _base.png _g.png -geometry +160+240 -composite _w.png -geometry +380+230 -composite preview_scale.png
```

这条命令做了三件事：把 160 方纹理**按正方形网格平铺成 1200×340 的墙**、把角色帧**直接贴上去**、**不做任何投影**。

后果：地面没有任何透视压缩，正好是一个「正对镜头的方形纹理墙面」；角色贴着这张墙，脚下没有接触阴影 → 大脑判定为「角色被挂在一张墙纸上」。**这与纹理画得怎么样无关——换任何一张再好的草地纹理，用这条命令呈现出来都是墙纸。**

### 3.2 缺的那一步：透视压扁（这是等距地面的物理定义）

在 2:1 等距视角里，**地面平面相对屏幕是纵向压缩 50% 的**。所以一张正俯视的无缝纹理要变成「地面」，必须做一次仿射变换：

```text
rotate 45°  →  Y 轴 × 0.5  →  取中心 64×32
```

等价于把「正方形的顶视纹理」投影到「斜俯视的地面平面」。**M1 地面纹理的正确交付形态就是一张 160×160 的无缝方纹理，菱形化是后处理/引擎的事** —— 这一点在 25 号里没有写清楚，24 号 §四的「交付形态：可循环平铺纹理 **或** 64×32 等距瓦片图集」也没给出选择依据，是本次翻车的文档缺口。

### 3.3 次要放大器：接地投影缺失

角色帧直接 `-composite` 贴图，脚下无接触阴影 → 空间归属丢失。即使地面对了，无影的角色仍会「飘」。这是我方呈现口径的第二个缺口。

### 3.4 需要纠正的一处误判（26 号简报）

26 号把「墙纸感突出」记在了**纹理侧**（"米黄色草簇较多且重复规律明显…墙纸感突出"），并据此把「减少/打散米黄草簇」列为第一优先修复项。**方向错了**：本张图墙纸感的主要来源是呈现（3.1/3.2），草簇重复只是次要项。若按 26 号的判断走，会在纹理上反复重生成而问题依旧。

## 四、等距呈现验证（我方复现，同一张纹理，不改素材）

用**同一张** `M1-1a_dry_grass_160.png`，只改呈现方式，重做一版验证：

```bash
# 1) 方纹理 -> 2:1 菱形（点采样，严格像素）
magick M1-1a_dry_grass_160.png -filter point -resize 256x256! -background none \
  -filter point -rotate 45 -trim +repage -filter point -resize 64x32! diamond.png
# 2) 满幅等距铺装（每行 Y+16，奇偶行 X 错半格 32）
#    384x224 画布，r=-1..13、c=-1..6 逐块 composite（后画的覆盖先画的，即正确的画家序）
# 3) 角色帧 + 脚下椭圆接触影（blur 0x4，alpha 0.5）后再合成角色
```

**结果**：墙纸感消失，地面读作一块**可站立的平面**，角色踩在自己影子上 → 与你反馈中的「站在地上、有立体角度感」完全对应。

产出：

| 文件 | 内容 |
|---|---|
| [`_verify/preview_iso.png`](../../art_source/environment/map_m1/_verify/preview_iso.png) | 384×224 等距呈现验证图（1×） |
| [`_verify/preview_iso_3x.png`](../../art_source/environment/map_m1/_verify/preview_iso_3x.png) | 同上 3× 点采样放大，便于目视 |
| [`_verify/preview_compare.png`](../../art_source/environment/map_m1/_verify/preview_compare.png) | 上：旧「方砖平铺」呈现（你看到的）；下：等距呈现 —— 同素材、同角色，可直接对照 |

**结论：同一张 M1-1a，不重生成即可达到「站在地上」。** 因此按 25 号 §5 的迭代约定，M1-1a 不进入「回炉重出」，而是进入「呈现口径修正 + 变体扩展」。

## 五、菱形凹缝线强度 A/B（避免引入棋盘格）

菱形化后是否需要在每格四边画一条暗线来暗示接缝？实测两种强度：

| 方案 | 表现 | 建议 |
|---|---|---|
| A 不画凹缝线 | 纹理本身已读作地面，无可见网格，画面干净 | **推荐默认** |
| B 每边 1px、alpha 0.30 黑线 | 出现清晰菱形棋盘格，人工感强，在大面积地图上会很明显 | 不采用 |

产出：[`_verify/preview_iso_ab.png`](../../art_source/environment/map_m1/_verify/preview_iso_ab.png)（左 A 右 B）。
若你希望保留一点接缝暗示，上限建议压到 **alpha ≤ 0.12**，且只在「相邻变体交界」处使用，不做全图统一网格。

## 六、素材侧仍待修的两项（实测，附数据）

### 6.1 无缝性：未通过

对 160×160 交付纹理实测四边均值差（`-compose difference` 后取 `%[fx:mean*255]`）：

| 对比 | 均值差 / 255 | 占幅 |
|---|---|---|
| 左边 vs 右边 | 7.02 | ≈ 2.8% |
| 上边 vs 下边 | 14.43 | ≈ 5.7% |

上下边差约为左右边差的 2 倍，属真实接缝，与 26 号自述一致。菱形化后接缝被旋转分散到四条对角边上，观感上不明显（这也是本张图菱形化后看不出接缝的原因），但**不能因此免修** —— 大面积连续地面仍会积累离散感。

修法优先级（沿用 25 号 §4）：**请求生成器走真 wrap/tile 模式 > 提示词约束 > 半幅偏移 + 窄带羽化的方向保持后处理**。禁用镜像平铺。

### 6.2 重复感：部分残留

米黄草簇在单张 160 范围内有固定周期；菱形化把它旋转打散后明显好转，但大面积铺开仍可辨认。建议按 24 号 §十.3 执行：**打散大块低对比色块、单个可重复特征不超过单块 25%**。

### 6.3 根本解不是重做一张，而是扩变体

墙纸感的彻底消除靠**变体交替**：M1-1a 只是「干草地」单张，实际地面应由 M1-1a/b/c/d 等多张交错使用（对应 24 号 §十.3 与 §五「丰富度靠层数 × 变体数」）。**建议下一轮一次性出 M1-1b/c/d 三张，而不是把预算继续花在重出 M1-1a 上。**

## 七、对 25 号文档的落地修正

### 7.1 §1 增补：交付形态与呈现口径（新增条目）

> **交付形态**：M1 地面纹理交付为 **160×160 无缝方纹理**（正俯视）。等距菱形化（`rotate 45 → Y×0.5 → 裁 64×32`）属**呈现/引擎侧**，不在生成阶段做。
> **呈现纪律**：任何地面验证图必须包含 ① 菱形化 ② 等距铺装 ③ 角色脚下接触影，三项缺一即视为无效验证。

### 7.2 §4 验证命令替换（原文 ① ② 作废）

```bash
# ① 菱形化（点采样，严格像素）
magick tile_160.png -filter point -resize 256x256! -background none \
  -filter point -rotate 45 -trim +repage -filter point -resize 64x32! diamond.png

# ② 3×3 等距铺装检查（不再是正方形 tile: 铺装）
#    Y 步进 16，奇偶行 X 错 32；384x224 画布，r=-1..13、c=-1..6 逐块 composite
#    导出 3× 点采样放大后目视，重点看对角边是否露接缝

# ③ 角色同屏 + 接地影
magick assets/sprites/player/guardian/guardian_atlas.png -crop 64x80+0+0 +repage _g.png
magick assets/sprites/monsters/wolf_corrupted/wolf_atlas.png -crop 80x80+0+0 +repage _w.png
magick -size 46x18 xc:"#010000" -alpha set -channel A -evaluate set 0 +channel \
  -fill black -draw "ellipse 22,8 20,7 0,360" -blur 0x4 \
  -channel A -evaluate multiply 0.5 +channel _s.png
#     _s.png 在角色前合成，脚底对齐（玩家 脚底 y≈152、狼 脚底 y≈176）
```

> ImageMagick 7 注意：以 `xc:none` 建空白底会把结果图坍成灰度（合成会继承目标色彩空间）。空白透明底请用 `xc:"#010000" -alpha set -channel A -evaluate set 0 +channel`。

### 7.3 §2 可选增补（暂不启用）

只有当 M1 多张变体大面积铺开、且仍显「平板」时，才在 `[主体]` 段追加：`subtle terrain micro-relief, faint shadow pooling in recesses, gentle ground undulation`。**本轮不改提示词、不改密度(160)、不改色板、不改方向 A。**
