# 模块化营地结构样板实施记录

2026-11-17。实现51号方案的第一步“结构样板”，暂未完成新风格资产生产和正式营地迁移。

## 已完成

- 使用同一组7张既有素材，按数据拼出两套16×16格场景；运行依赖中没有整图营地PNG。
- 新增八邻接道路规范化与47种透明连接形状，覆盖转角、端头、交叉连接；修正共边渐变半径，使相邻覆盖砖的alpha在边界一致。
- 基础地面和道路各一份FlatTileMesh；独立物件按脚底世界Y排序。未修改正式ground.gd及旧道路规则。
- 物件占地是通行掩码和物理碰撞共同输入；复用原Iso与CaveLayout。点击寻路和WASD实际移动；支持切布局、显示碰撞、移动一段墙并清空旧导航路线。
- 独立临时工程运行，不加载游戏单例，不修改正式地图、怪物、任务或存档。

## 验证证据

Godot4.7.2，Apple M1 Max，Compatibility，1280×800窗口。执行 `python3 tools/modular_camp/launch.py --verify --capture /tmp/modular-camp-review`，退出码0，输出 `MODULAR_CAMP_VERIFY_OK`。

自动检查全部256邻域规范化得到47形状；固定随机道路排列共边alpha连续；两布局各256格的通行/碰撞一致；真实物理移动到远端、穿过墙段门洞、正面运动会被墙阻挡、寻路可绕墙到达；移动墙释放旧格、阻挡新格并清空路线。

首次新增正面碰撞测试误用了局部transform，已纠正为CharacterBody2D要求的global_transform，再运行全部检查通过。没有放宽断言。

## 质量边界和后续

本轮只通过结构验证。旧地面重复明显、偏黄，墙贴图轮廓尚未与单格占地精修对齐；棚屋仍是一个外部阻挡物，没有独立屋檐和可进入室内。角色是静态贴图随物理体移动，不称作动画。对角连接有程序遮罩，但自然破口与新材质尚未制作。没有新增帧率或内存实测。

下一阶段按已确认写实风格制作土/草材质母版与道路、草土过渡族，先替换这两种布局的地面，不重新生成整图；再替换有精确占地和锚点的墙段、树及棚屋。真实造型遮挡、纹理拼缝、共边色差和密集战斗需另行验收。仅在新资产通过后迁移正式营地。
