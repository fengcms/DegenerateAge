## 2. 项目事实与依据

- 类型：Godot 4 工程，单机实时战斗、键鼠操作、2D 等距斜角 ARPG；首发 macOS。
- 世界观：纪元 3172，灵脉过度开发、屏障损坏、紫色异界裂隙、文明退守营地；玩家吸收异族灵能成长。
- 产品美术基线：复古像素、斜角 2D。首版职业为灵刃战士，MVP 换装只影响数值，不要求世界精灵逐件换装。
- 当前第一章配置：幸存者营地、试炼野外、灰烬之地、腐化源头；6 个怪物模板（含教学木桩）、12 个装备模板、6 个技能模板、6 种药品、4 种如意、5 种杂项/任务物、1 种坐骑。
- 当前表现：人物、怪物、地面与掉落主要通过脚本绘图；装备/技能配置中已有 PNG 路径，但不能据此认定图像已存在或已被 UI 加载。坐骑已有 `corrupted_wing.svg`，需在后续制作时评估复用。
- 坐标基线：`scripts/systems/iso.gd` 使用 64×32 菱形瓦片；地图整体沿负 Y 展开。
- 高分辨率：参考视区 1440×900，工程视口基值 1280×800；运行时显示、UI、文字、地图缩放分离，现有 UI 上限已扩至 200%。
- 品质色以 `scripts/systems/item_util.gd` 为准：普通白、优秀蓝、稀有绿、史诗黄、传说紫，不能套用其他游戏的常见顺序。

## 3. 冲突处理与范围

产品文档定义玩法；数据和代码用于确认当前落地状态。旧创意提案不自动覆盖产品基线，旧工程文字不自动覆盖当前代码。遇到差异，记录差异并将美术表现与待开发功能分开：

| 差异 | 本规范处理 |
|---|---|
| 旧表中营地不刷怪，当前配置含教学木桩 | 制作不反击的教学木桩，不表现成营地敌袭 |
| 产品中装备约 20 个，当前只有 12 个模板 | 本批制作 12 个，其他留扩展名额 |
| 产品 UI 缩放旧档位到 150%，当前代码到 200% | 验收到 200%，布局重排属于后续接入工作 |
| 城镇集群出行是最新产品方向，当前工作区仍在改出口与拓扑 | 做免费出口与车夫两套符号；最终可达/锁定状态从接入时数据读取 |
| 技能和杂项有模板但部分效果未接线 | 可以储备图标；不能表现为已可施放或已可使用 |
| “灰烬里的灯”、NPC 新姓名与巨兽守护身份来自候选故事 | 仅作为可选氛围草案，不画成确定剧情事实 |

本批不新增职业、章节、装备模板、收费系统或复杂过场。美术文件不能改变碰撞、攻击距离、拾取时间、地图出口位置与技能伤害时机。

## 4. 视觉目标

**破败但仍有温度的人类营地，逐步走向失控的异界腐化。**

画面读图顺序：危险预警 → 玩家/当前目标 → 可拾取奖励与路径 → 环境装饰。成长主要通过装备图标、品质边框、升级反馈与战利品表现建立。长时间自动战斗时应看得清敌人、拾取与自动控制状态，避免持续强闪和大面积光效。

第一轮先用一个代表角色、一只狼、一组地砖、三个物品图标和 HUD 局部完成风格验证，再批量扩展，防止批量素材各自形成不同画风。
