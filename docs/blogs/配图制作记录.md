# 《末法纪元·游戏开发》配图制作记录

日期：2026-11-10。正式文章配图共 240 张：80 张封面、160 张正文机制图。模板候选 A/B/C 为历史选型材料，不计入正式配图数量。

## 已确认风格

用户确认 C「场景与图解」。参考文件为 `assets/cover-templates/2026-11-10/C-场景与图解.png`。深蓝灰、米白、琥珀色贯穿全套；封面以游戏主题物件或场景过渡到工程线稿，内文采用浅色背景保证技术标签可读。

封面固定品牌“末法纪元 · 游戏开发”、篇号、短标题、ARPG 开发实录副标题和 FungLeo 署名。第 01 篇直接采用用户确认的 C 样稿，其标题为“从全栈到游戏开发”，副标题沿用样稿“一个人的单机 ARPG 开发实录”；其余各篇使用对应短标题。版式统一到同一视觉规范，不承诺 AI 图像中每个文字坐标像素完全相同。

C 样稿参考了本项目 `assets/maps/camp_final_v1/guardian_lamp.png`，其余封面以 C 为风格参考重新生成主题画面。未套用 PHP 系列的 FengCMS 标识，也未把 Godot 默认工程图标冒认为游戏官方 Logo。

## 生成方式与来源

- 封面：内置 image_gen 生成；第 01 篇复用已确认样稿，第 02—80 篇独立生成。完整提示词、输出来源和修订链存放于 `editorial/cover_generation_records.json`。
- 正文图：根据原文机制和配图意图编排结构，以 `editorial/render_diagrams.py` 绘制 PNG。规格、节点、注释及原始完整提示词存放于 `editorial/diagram_specs.json`；不是 AI 自动生成并未经校验的公式/数值图。
- 图片为本次博客整理制作的主题插画与机制示意，没有采用外部图库下载图。此记录说明制作来源，不额外声明对第三方字体或参考素材拥有排他权利。
- 正文图字体使用本机 STHeiti Medium，输出为栅格图，字体文件未复制到仓库。
- 封面约 16:9；正文图为 1500×1000（3:2）。实际尺寸、文件哈希见 `editorial/validation_result.json`。

图片不是游戏运行截图；图中人物、美术、UI、数值条均为说明性表达，不能作为当前游戏美术完成度、测量结果或平台界面证据。数学图中的系数明确标为示例。

## 制作复核

封面逐张检查主题、标题、篇号、署名、可读性和 C 风格一致性。正文 160 图通过八张缩略联系表检查整体排版，并放大检查任务契约、墙角反例、几何迁移、变化分级、相机追赶等代表图。脚本对所有文本盒执行边界断言，240 张 PNG 均通过解码。

第 36 篇“护盾分配”按伤害、预期耗蓝、实际可用法力、剩余生命扣减表达，避免把状态快照误当成护盾算法。第 53 篇“失败与清理”分为成功提交与失败保留两条路径，避免将失败画成成功链上的下一步。部分封面初稿误加入简介或使用长标题，已通过图像编辑移除多余文字、恢复指定短标题；修订前来源保留在制作记录，文章只引用最终图。

## 后续维护

修改图解文案时先编辑 `assets/game/editorial/diagram_specs.json`，再从项目根目录运行：

```sh
uv run --with pillow python docs/blogs/assets/game/editorial/render_diagrams.py
```

重新绘制后必须目检并再次运行发布校验。封面保留完整提示词便于迭代，但 AI 重生成不保证像素一致。不要覆盖原稿基线 `baseline.json`；正文修改后应同步变更记录和最终哈希。
