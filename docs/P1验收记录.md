# P1 地图、移动与手动战斗验收记录

日期：2026-10-10。环境：Apple Silicon，macOS 26.6.2，Swift 6.3.3，Command Line Tools。

## 实现

- 扩大测试营地至 32×32，配置三只同类腐化野狼及墙体/障碍夹角。
- AppKit 适配 WASD、Space、Esc、F3 和鼠标输入；失去焦点时清空按键，暂停恢复/复活后恢复游戏焦点。
- 屏幕输入逆投影为世界方向再归一化，脚底碰撞半径 0.18 格，移动小步检测、贴墙滑动、地图边界阻挡。
- 自定义 A* 服务于玩家接近和怪物追击，禁止斜切，并以 0.4 秒节流重算。自定义实现便于在无图形依赖的规则程序中直接验证；未新增导航框架依赖。
- 怪物待机/巡逻/追击/普攻/返回/死亡/刷新。超过出生点追击边界返回，到达后恢复生命；刷新生成新实例 ID。
- 玩家点击选怪、接近并一次斩击，按住 Space 按冷却持续攻击；目标死亡取消行动。
- 玩家和怪物共用伤害公式；玩家 5% 暴击使用可注入种子。死亡事件及击杀计数每个实例只结算一次。
- 镜头平滑跟随并限制在地图包围边界内，演员与障碍按脚底深度排序；HUD、血条、浮动伤害、受击闪烁、暂停和复活面板。
- 固定模拟步长及卡顿限幅；暂停/后台停止模拟和刷新，恢复不补算时间。
- 调试开关显示 FPS、节点数、位置、目标/AI 状态、路径数量和失败提示。

主要文件：`Core/Navigation/NavigationGrid.swift`、`Core/Combat/CombatSimulation.swift`、`UI/GameViewport.swift`、`Scenes/PrototypeScene.swift`、`App/GameSession.swift`、`UI/GameRootView.swift`、配置模型/校验/JSON 和 `Tests/CombatChecks.swift`。

## 限制与后续

- 美术为色块，尚无完整八方向精灵动画和音效。攻击/受伤反馈使用浮动数字和短暂闪烁。
- P1 的死亡奖励仅验证击杀事件及计数；经验、掉落和任务订阅在 P2/P3 接入同一事件边界。
- 当前地图四角保留背景；镜头限制针对地图包围矩形。后续正式地图可通过外围地表填充消除菱形边缘空白。
- 标准 XCTest / Swift Testing、macOS 14、完整 Xcode、30 敌人负载与长时间稳定性尚未验证。暂停五分钟的规则冻结通过模拟检查，未进行五分钟真实后台计时测试。
- 当前 P0 最小存档结构不接收战斗进度，退出后不会保存本轮战斗。

P1 核心通过标准已验证：可以绕过障碍击败怪物，不能穿墙/斜切，死亡只结算一次。下一轮 P2 建议先实现经验成长和基础掉落，再接背包、装备与实际存档。
