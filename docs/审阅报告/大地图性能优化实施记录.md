# 大地图性能优化实施记录

日期：2026-10-14。各阶段独立提交；不纳入工作区已有装备、美术和本地化修改。

## 阶段 0：隔离 CPU 基准

新增 MapPerformanceTest，通过 `python3 tools/run_isolated_tests.py MapPerformanceTest` 运行；随机项目名隔离 user://，保护真实存档。测量无固定时间断言，只断言行为。

Godot 4.7.2，headless，c2_lower_works 单次基线：

| 指标 | 基线 |
|---|---:|
| 场景同步装配 | 110.757 ms |
| 首次巡游点构建（624 点） | 616.847 ms |
| 地图坐标投影 10000 次 | 88.077 ms |
| 刷新器检查 200 次（131 点） | 130.206 ms |

这不是帧率或 GPU 测量，也未计入第一次实际绘制。单次耗时会波动；后续在相同入口对照。

## 阶段 1：小地图投影缓存与绘制分层

MapCanvas 的静态地形保留在父节点，玩家/任务/NPC 标记放入独立绘制子节点。移动仅重绘标记；地图、尺寸、探索、布局与样式变化更新底图。探索按已揭示的 4×4 区块迭代，仍逐格验证可行走掩码，避免暴露洞壁。投影中心、尺度和世界边界按地图/尺寸缓存。

验证：MapCanvasCacheTest、MapPerformanceTest、SmokeTest 通过。缓存测试覆盖移动不重建底图、缩放、两种地图模式的投影往返、探索字典替换、隐藏更新与重开。SmokeTest 初次运行有两条自动战斗断言失败；优化前地图代码对照通过，当前代码单独复跑通过，未据此修改战斗行为。

同入口单次测量：投影 10000 次为 5.072 ms（基线 88.077 ms，约减少 94%）；巡游 664.160 ms、刷新器 103.505 ms，后两项本阶段未优化。

## 阶段 2：刷新器每轮预算复用

批量装配和每帧刷新各统计一次普通怪，成功生成/距离退场在同一轮更新局部预算。保留独立 `_spawn()` 调用的计数兜底；未增加重试延迟，避免改变生成响应和墓碑到期行为。

验证：SpawnerBudgetTest、ChapterTwoEncountersTest、BossReviewTest、MapPerformanceTest 通过。专用测试验证初始化与满额刷新只统计一次、同轮不超过 10 只、死亡补位与持久倒计时、外部释放、退场再返回，以及精英不占普通预算。

200 次刷新检查为 51.919 ms（基线 130.206 ms，约减少 60%）；这是相同地图入口的单次 CPU 对照，并非 FPS 增幅。

## 阶段 3：连通性筛选与导航缓存失效

CaveLayout 懒构建连通区域编号，巡游、搜怪及拾取的可达性筛选不再生成完整平滑路线；真正移动时仍保留原有带碰撞间隙的路线与禁止穿墙兜底。区分巡游未初始化与合法空列表。安全锁变化递增导航版本，巡游、CaveNavigator 与地图底图缓存随之更新。

目标切换还清除上一巡游/目标的移动方向并重置重算计时，防止继承旧方向。原 AutoControlAcceptance 的 20 物理帧接近断言在优化前代码也失败；定位为保留旧方向后，通过修正运行代码恢复原测试，不降低断言要求。

测试运行器改为限制最大渲染帧率并要求明确的成功完成标记，修复异步测试提前退出被误判通过的问题。代码、数据与测试在开始时复制为快照，避免并行美术脚本修改造成已导入的类缓存失效；资源仍复用工作区素材。

验证：CaveConnectivityTest、CaveNavigationTest、CaveAutoBattleTest、ChapterTwoRoutesTest、MapCanvasCacheTest、AutoControlAcceptance、AutoExplorationSurvival、MapPerformanceTest、SmokeTest 通过。覆盖角落不可达、区域与 AStar 对照、安全锁开关后的路线缓存、624 个候选点零次完整寻路、合法空巡游只构建一次。

首次巡游构建含连通标记为 20.046 ms（基线 616.847 ms，约减少 97%）。仍可能超过单帧 16.67 ms；后续将连通数据准备移至地图装配阶段，避免首次自动巡游时集中准备。

## 阶段 4：加载准备与碰撞资源复用

默认落点直接读取布局掩码寻找最近格，不建立阻挡字典或 AStar；按地图、尺寸与布局路径缓存结果，数据重载清空缓存。Ground 在地图装配时准备连通数据。洞壁碰撞节点共享不可变菱形 Shape，保留原有碰撞轮廓与数量。

CaveLayoutTest 原本写死旧版 50×50 地图及旧坐标，已改为读取当前地图尺寸、入口、Boss 点与真实边界格，保留完整八向通行、实体碰撞和实际绕墙移动断言。测试运行器遇到脚本异常立即停止该场景，避免断言中断后持续空转。

验证：MapLoadingCacheTest、CaveLayoutTest、SpawnerBudgetTest、MapCanvasCacheTest、ChapterTwoRoutesTest、CaveAutoBattleTest、MapPerformanceTest 通过。落点与完整 CaveLayout 最近格结果对照一致；缓存重载、尺寸改变以及 522 个共享 Shape 均验证通过。

首次巡游构建为 1.723 ms；默认落点缓存 1000 次查询为 3.712 ms。场景同步装配为 122.962 ms，较初始基线 110.757 ms 增加约 12 ms，代价是将约 20 ms 的连通准备从游玩阶段移至加载阶段。工作区同期有美术修改，装配总耗时不宜完全归因于本阶段。
