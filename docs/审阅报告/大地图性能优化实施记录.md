# 大地图性能优化实施记录

日期：2026-10-14。各阶段独立提交；不纳入工作区已有装备、美术和本地化修改。

## 阶段 0：隔离 CPU 基准

新增 MapPerformanceTest，通过 `python3 tools/run_isolated_tests.py MapPerformanceTest` 运行；随机项目名隔离 user://，保护真实存档。测量无固定时间断言，只断言行为。

Godot 4.7.2，headless，c2_lower_works 单次基线：

| 指标 | 基线 |
|---|---:|
| 场景同步装配 | 110.757 ms |
| 首次巡游点构建（624 点） | 616.847 ms |
| 地图坐标投影 10000 次 | 88.077 ms |
| 刷新器检查 200 次（131 点） | 130.206 ms |

这不是帧率或 GPU 测量，也未计入第一次实际绘制。单次耗时会波动；后续在相同入口对照。

## 阶段 1：小地图投影缓存与绘制分层

MapCanvas 的静态地形保留在父节点，玩家/任务/NPC 标记放入独立绘制子节点。移动仅重绘标记；地图、尺寸、探索、布局与样式变化更新底图。探索按已揭示的 4×4 区块迭代，仍逐格验证可行走掩码，避免暴露洞壁。投影中心、尺度和世界边界按地图/尺寸缓存。

验证：MapCanvasCacheTest、MapPerformanceTest、SmokeTest 通过。缓存测试覆盖移动不重建底图、缩放、两种地图模式的投影往返、探索字典替换、隐藏更新与重开。SmokeTest 初次运行有两条自动战斗断言失败；优化前地图代码对照通过，当前代码单独复跑通过，未据此修改战斗行为。

同入口单次测量：投影 10000 次为 5.072 ms（基线 88.077 ms，约减少 94%）；巡游 664.160 ms、刷新器 103.505 ms，后两项本阶段未优化。
