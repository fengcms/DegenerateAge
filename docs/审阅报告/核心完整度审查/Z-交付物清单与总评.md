## 4. 跨域共性问题（收敛根因）

以下问题在多个域被独立发现，属同一根因，建议合并处理：

1. **「未领取战利品」无件数上限**（C P2-5、D P2-1）：`GameState.unclaimed_loot` 只 append、无上限、`persistent=true` 不淡出，长挂机/背包长期满时节点数、每帧重绘与存档体积**单调增长**（增长结论为推断，机制为代码证据）。建议设上限与超限策略。
2. **`DataLoader.get_entry` 线性查找**（D P2-2/P2-3/P3）：迷雾揭示（`Fog.reveal` 每次换格对内层 289 格重复解析地图尺寸）、快捷栏每帧遍历背包并线性查表，根因统一指向按 id 线性扫描数组。建议改为索引查表 + 循环外提取 `dims`。
3. **装备战斗词条「显示与结算」口径不一致**（A P2-1、E P2-2）：暴击/暴伤/攻速/闪避/移速/CDR 被汇总并在人物面板展示，但战斗结算只读基础值；当前因配置未开放这些词条而不触发（推断），属「执行链未完成」。建议结算处统一为「基础 + `equip_bonus()`」或暂缓面板展示。
4. **本地化缺 key 的可检测性不足**（F P2-2、H P2-3）：`tr_key` 缺 key 且带参时触发格式化错误而非安全回退；全仓未见消费 `missing_keys()`；无自动化断言。建议修正回退分支 + 补冒烟断言。
5. **启动校验缺口**（B P2）：`skills/quests/potions/miscItems/upgrade` 五表零结构化校验，任务跨表引用不校验，坏配置要到玩到该任务才暴露。建议补类型/范围/引用校验。
6. **系统层反向依赖场景节点路径**（B P2）：`settings_runtime`/`travel_item`/`auto_battle`/`monster` 硬编码 `"Game/Entities/Player/Camera2D"`、`"Ground"` 等深路径，违反 AGENT.md §9。建议收敛为服务/信号获取。
7. **测试与发布治理**（H P2）：61 个测试场景仅 22 个纳入默认回归；导出预设 `all_resources` 把测试场景打进正式包；文档「21/21」实为默认子集口径。建议区分默认/全量入口与导出排除规则。

1. **P2 治理批次一（稳定性）**：未领取战利品上限 + `DataLoader.get_entry` 索引化（收敛共性问题 1、2）。

3. **P2 治理批次三（可靠性）**：启动校验补 5 表 + 任务引用（5）、系统层去节点路径依赖（6）、发布包排除测试场景（7 之导出治理）。
