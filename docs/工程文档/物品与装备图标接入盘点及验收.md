# 物品与装备图标接入盘点及验收

## 现象与实测证据

`docs/素材/icons/items/` 有 16 张 48×48 正式物品图：六药水、四如意、四杂项、一灵能碎片、一金币。接入前，`assets/sprites/items/` 只有小红药和灵能碎片两张早期样板 UI 图，其他 14 张没有运行副本；`SampleArt.ICONS` 也只登记了这两种物品。`HotbarVisual` 的自动红蓝药读取 SVG 占位图，`GroundItem._draw()` 对未登记物品绘制圆形或菱形。故设计稿虽已交付，玩家尚未在这些入口看到它们。

`data/equipments.json` 的现行 60 个装备模板均有可加载的 `icon` 路径，已由 `SampleArt.icon_for()` 进入装备、背包和仓库界面。素材目录另有“狼王之刃”“镇脉之刃”两张旧专名图；现行装备规则已将其归并为同档正式型号，数据表没有两个独立 ID（见 `docs/游戏创意/21-一至二十级装备两档同名简化方案.md`）。给现行型号任意换成旧专名图会改变同一型号的外观语义，因此本次保留为美术储备，不重建已废止的独立型号。

`docs/素材/icons/mounts/` 还交付了一张“腐化之翼”图；接入前 `data/mounts.json` 指向 SVG 占位图。第二章“驮炉兽”没有对应的已设计图标。

## 根因、影响范围与处理

物品图标交付目录与运行资源目录分离，运行时预载表未同步维护；金币与坐骑另有独立显示路径。本次将 16 张正式物品图和一张坐骑图的 48 像素版本复制到 `assets/sprites/`，保留原 ID，并生成 Godot `.import` 元数据。更新 `SampleArt`、快捷栏、技能页自动药入口、地面掉落和坐骑收藏预览；所有缺图的后续章节任务物品继续沿用原文字/几何回退。`GroundItem` 只查询预载图标表，不在重绘路径执行资源加载。没有修改物品效果、装备数值、掉落概率或存档结构。

17 张 RGBA 48×48 图若按未压缩像素估算合计约 153 KiB；这只是图像像素下界估算，不代表实际显存测量。96/256 像素审阅版本没有进入运行目录。

## 复核方法与结果

- `python3 tools/run_isolated_tests.py IconIntegrationTest PotionAccessibilityTest HotbarUiTest SmokeTest`：通过。覆盖现行装备路径、16 张物品图标、自动红蓝药、药水区分标记、快捷栏拖放及游戏冒烟。
- `python3 tools/run_isolated_tests.py MountShortcutTest IconIntegrationTest SmokeTest`：通过。覆盖“腐化之翼”地面与收藏预览同图、最近邻显示及坐骑原有逻辑。
- 逐文件 SHA-256 对比：16 张物品图及一张坐骑图的运行副本均与交付源稿一致；Godot 导入后的图标集成测试确认 48×48 纹理尺寸。
- 旧 `ArtSampleTest` 另有“戒指图标尚未制作”和守护者脚底锚点断言失败；前者是先前装备图标接入后未更新的测试预期，后者不属于物品图标路径。本次验收未将该场景计为通过。Godot 资源导入曾发生一次引擎线程崩溃，原样重试后上述定向测试均通过。

本次盘点后，已有正式设计稿但未绑定现行装备或物品模板的只有两张已废止专名图。尚无设计稿的任务袋物品和“驮炉兽”不计入本次待接入数。
