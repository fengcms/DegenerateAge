# 倍速相机稳定跟随修复与验收记录

对应[原因分析](百首禁域倍速视野剧烈跳动原因分析.md)，记录2026-11-01分节点修复。相机视觉采用真实时间，玩法时间倍率、伤害、移动和奖励规则不变。

## 节点一：稳定跟随骨架

Player相机接入StableFollowCamera，关闭原生线性平滑。相机仍由玩家节点持有和释放，但使用top_level避免父节点运动直接带走镜头；每渲染帧以Time.get_ticks_usec真实时间推进指数跟随，alpha=1-exp(-8×dt)，真实dt上限0.1秒，长暂停/卡顿后不突然追赶。每帧O(1)，不创建节点、资源、Tween或计时器，无全局信号及存档字段。

地图装配完成后显式snap_to_target，清除旧位置和时钟。StableCameraTest覆盖0/1/2/4/8/16倍率相同真实时间的逐帧轨迹一致、单调收敛、父变换隔离及0～30秒的大步长；测试、CaveAutoBattleTest及AutoExplorationSurvival全部通过。后续节点补齐边界、异常恢复、缩放/旅行和窗口压力验收。

## 节点二：边界、异常与明确复位

内部跟随位置和目标均按当前viewport/zoom约束至现有矩形camera limit；地图小于视口时按中心显示，不产生反向clamp。有限值检查在写入节点变换前执行，损坏内部状态恢复到玩家的合法镜头目标；非法时间步长不传播NaN。每帧仍为固定数量向量/指数计算，边界变化无需全图扫描。

StableFollowCamera.snap是明确传送/装配/缩放统一入口，普通Camera2D保留reset_smoothing语义；未入树相机跳过复位。随机传送券落位后、SettingsRuntime应用倍率后、Game出生/切图后均清理旧内部位置和时钟。真正暂停依旧冻结镜头，零时间倍率不依赖除法，原地复活不产生位置跳转；返回城镇/读档通过已有世界重建装配。

测试中有意移动玩家后立即截图/点选的夹具改为调用新复位入口；固定全图截图关闭相机脚本process，避免跟随覆盖测试取景。原有点击、NPC、穿行与范围断言未放宽。冻结地图渲染基准在修改玩家位置后显式复位，保持原确定性相机路线。

验证通过：StableCameraTest（加入三档zoom、非有限内部状态、异常dt、视口大于地图）、CameraLifecycleTest（正式百首禁域装配、明确位移、缩放、零倍率、暂停恢复及释放）、RandomTicketTest、SettingsTest、SmokeTest、AutoSearchRangeTest、CampLiveIntegrationTest、CampFullArtAcceptanceTest。最初新增测试有一处Variant类型推导报错，已显式声明Vector2并复跑通过，未放宽断言。
