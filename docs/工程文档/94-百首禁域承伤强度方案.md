### 1.1 为什么不掉血

`Combat.resolve` 的破防判据是 `攻 − 防×0.5 > 0`：

```
13,087（Boss 实攻）− 20,928（你 def 的 50%）= −7,841  ⇒  raw ≤ 0
⇒ 走 monster.gd::_min_hit_on_player() = clampi(maxHP × 0.25%, 10, 60) = 60
```

**每击固定 60 点 = 你血量的 0.0147%。** 一只打 14.7 秒只挨约 **4.5 击**（`interval 1.8s × 0.55 出手率`）⇒ 一只总共掉 **270 血**，占血量 **0.07%**。血条上根本看不出变化。

### 1.2 🔴 破防阈值附近有个反常陷阱：配 2.40 反而更轻

破防阈值 = `防×0.5 ÷ Boss 基础攻` = **2.3987 倍**。但**恰好配 2.40 时**：

```
8,725 × 2.40 = 20,940 − 20,928 = 12  ⇒  每击 12 点（比保底 60 还低！）
```

原因是**保底只在 `raw ≤ 0` 时生效**：一旦 `raw > 0` 就按实际结算，而它可能小于保底 60。

| 倍率 | 实攻 | 每击 |
|---|---|---|
| 1.50（现状） | 13,087 | 60（保底） |
| **2.40（"阈值"）** | 20,940 | **12** ← 比现状更轻 |
| 2.41（刚过 60） | 21,027 | 99 |
| 3.00 | 26,175 | 5,246 |

**结论：不能按"阈值倍数"配**，必须配到"比保底明显疼"的位置。阈值只是破防的下限。

## 3. 三档备选

### 方案 A · 2.8（温和：掉血但几乎无压力）

- 每击 **3,502**（0.86% 血），比保底高 58 倍
- 单只掉 **3.9%**（1.8s 怪）/ 4.6% / 5.0%
- 60 秒连刷掉 15.7% ⇒ 不喝药约 **6.4 分钟**见底
- 被 3 只围 3,210/s < 只备大红 4,083/s ⇒ **站着不动也不会死**

### 方案 B · 3.0（推荐：看得见掉血，必须喝药，但挂机安全）

- 每击 **5,246**（1.28% 血），比保底高 **87 倍**
- 单只掉 **5.8%**（1.8s 怪）/ 6.9% / 7.4%
- 60 秒连刷掉 **23.6%** ⇒ 不喝药约 **4.2 分钟**见底，**血条肉眼可见地一格一格掉**
- 被 3 只围 4,809/s：只备大红（4,083/s）**会缓慢掉血 ⇒ 需要走位**；三档药（8,676/s）能兜住
- **自动战斗（阈值 35%）能兜住最坏情况**：腐化巨兽 3 只围 6,183/s < 8,676/s，余量 40%

### 方案 C · 3.2（明显：每一只都在掉，压力持续）

- 每击 **6,992**（1.71% 血）
- 单只掉 **7.7%** / 9.2% / 9.9%
- 60 秒连刷掉 31.4% ⇒ 不喝药 **3.2 分钟**见底
- 被 3 只围：腐化巨兽 **8,240/s ≈ 三档药 8,676/s，余量只剩 5%** ⇒ 暴击叠加 / 技能连招时**挂机会死**

> **推荐 B（3.0）**，理由三条：
> ① 你原话是「不要太狠」——A 的单只 3.9% 大概率还是"感觉不明显"（血条 40 万，掉 1.6 万）；
> ② 3.0 是**唯一同时满足**「单只明显掉血」+「被 3 只围需要走位」+「自动战斗挂机不会死」的档位；
> ③ C 虽然更爽，但把挂机刷图这条主玩法弄成"要盯着"，和百首禁域的定位相冲（它是 100 席连刷场，不是硬仗）。
