# 满星紫装第五词条开发与验收记录

日期：2026-10-30。设计依据：《满星紫装重铸解锁第五词条分析与实施方案》。

## 实现结果

12星紫装成功重铸后解锁5条，组成4固定＋1百分比；首次最多锁3、之后最多锁4。失败不解锁不扣资源，低星重铸和升12星不自动解锁，保星新实例回到12星四条。原单条数值、基础费用与掉落规则不变。

规则由ReforgeAffixes集中定义；基础词条数仍由品质配置决定，扩展形态由实例reforgeAffixTier=1表示。GameState在候选副本上重掷并取优，通过后同批提交标记和词条。ItemFactory普通入口与保星取优不会提前置标记；装备属性/评分原有数组遍历自然覆盖5条。schema升至16，旧11—15保持快照，新增形态严格校验。

已完成节点：

- 2ac0514b：规则、生成与配置校验；60模板多种子及原随机快照通过。
- cb9a2424：重铸原子解锁、锁数、存档16和保星兼容；业务与JSON回归通过。
- e7fb77bc：面板预告、锁数、解锁反馈与通用属性说明；实际渲染通过。
- 本验收节点：补充失败分支、真实升星/穿戴、数值采样和文档。

## 逻辑、兼容与窗口证据

FullStarReforgeTest遍历60模板、每模板32次重掷，验证5条唯一stat、4固定＋1百分比和四锁原值；业务覆盖真实升星11→12仍4条、金币/如意不足/精炼失效不扣资源、首次禁止全锁4条、三锁首次解锁保留原值、17次如意取优保持5条、后续不增加到6条、穿戴同步更新、保星新产物不继承。

存档覆盖背包/仓库JSON往返、旧schema15满星装备原样读取；拒绝无标记5条、错品质/低星、未知tier、重复stat、6条、2百分比、标记1却4条。共用校验用于所有现有持久装备容器。既有技能存档和Smoke只将版本契约15准确更新为16，没有放宽断言。

隔离回归通过：FullStarReforgeTest、FullStarReforgeBalanceTest、ReforgeTest、ReforgeLockTest、ReforgeScoreTest、ReforgeSessionTest、RuneRerollTest、EquipmentFusionTransactionTest、SkillRankSaveTest、DynamicEquipTest、SmokeTest。FullStarReforgeTest已登记默认回归（共98项），数值采样测试保留显式运行。同步测试使用360帧退出上限并仍要求完整成功标记；Smoke保留运行器原14400帧及240秒上限。初次采样测试完成标记附有后缀，运行器按失败处理；已独立打印成功标记，复跑通过。

实际Godot 4.7.2、OpenGL Compatibility、Apple M1 Max窗口检查：1280×800默认、960×720默认、1280×800 UI/文字150%。第五行和锁4显示正常，顶部解锁状态、下部费用/操作按钮可通过已有滚动访问。截图在/tmp生成并查看，不将临时截图入库。未进行移动、寻路、Boss阶段或完整挂机实测。
