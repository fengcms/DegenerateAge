# 诊断探针隔离运行说明

2026-11-02。重铸取证探针只能在随机项目名对应的默认user目录运行，不能直接用正式工程F6运行或只依赖HOME变量。

```bash
python3 tools/run_isolated_probe.py ReforgeCrashProbe --save-file /absolute/path/save-copy.json
python3 tools/run_isolated_probe.py NoopProbe --save-file /absolute/path/save-copy.json --headless --probe-args --panel
python3 tools/verify_115_negative.py
```

第一个命令启动实际窗口（默认1280×1200）；第二个是逻辑对照，不证明GPU或窗口绘制正确。支持ReforgeCrashProbe、ReloadCrashProbe、FullPathProbe、SplitProbe、NoopProbe。分步参数通过--probe-args传入，源存档仅复制，不改源文件。

启动器冻结代码、数据与探针，素材只读复用；先导入资源，再由实际Godot报告隔离user目录，然后只将显式输入副本复制为临时slot_1。结束或Python异常时删除本次随机目录。SIGKILL或系统断电可能留下随机临时目录，不能自动删除其他会话的目录。

探针正文检查项目名、实际user目录末级和自定义目录开关；SaveManager在探针的autoload初始化阶段也检查启动路径，拒绝正式身份时不创建saves、不迁移偏好、不连接自动存。正常游戏不受影响。不要为方便绕过这两道守卫。

CrashTrace关键事件保留即时落盘；普通怪死亡合并为心跳计数。需要逐事件取证时，在启动环境设置DEGENERATEAGE_TRACE_VERBOSE=1。当前及上一份日志保留于隔离user目录；启动器退出清理前输出进程日志，若需要留存原始文件应在调查工具中显式导出，而不能把正式user目录作为输出位置。

负向验证脚本的变异只发生在临时快照，不再写工作区源码，也不会读取并回灌/tmp中的历史备份。
