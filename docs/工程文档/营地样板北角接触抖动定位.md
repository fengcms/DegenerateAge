# 营地样板北角接触抖动定位

## 现象与证据

样板以半径12的 CharacterBody2D 接触逐格菱形边界。旧测试无法在北角达到连续12物理帧小于0.01像素；西南角撤销输入还曾出现0.167741像素恢复位移，误触发行走。后者不是每次复现，不能用单次通过声称消失。

临时隔离探针使用同样18×18外围菱形、半径12、速度150、300步接近、3步释放，在 Godot 4.7.2 headless 固定60物理步运行。北向默认 Grounded/safe_margin=0.08 的末20步峰值0.751337像素；仅缩小到0.001仍为0.855856。Floating/0.08为0.145075；Floating/0.01为0.018497；Floating/0.001为0.000863，连续286步小于0.01，释放峰值0.000400。西南在后者配置连续269步稳定，释放峰值0.000792。

## 原因与调整

最小复现确认问题来自俯视菱形交角的物理移动和接触恢复，而非动画计时。默认平台地板分类与较大接触余量共同放大抖动；底层求解器的精确机制未追踪，不作进一步断言。样板采用 Floating 与0.001安全余量，保留12像素碰撞半径、原有几何、150速度和真实位移驱动。没有合并碰撞或放宽0.01/12帧标准。

八向墙停测试恢复北向，从(14,14)接近北角。此变化仅在 tools/modular_camp，不修改正式角色物理设置。完整两布局无窗口验收通过，八向接触及释放、物件碰撞、绕障与动态墙均未出现脚本错误；窗口与性能需另行确认，不能用 headless 证明帧率。

## 复核

运行 python3 tools/modular_camp/launch.py --verify，要求无 SCRIPT ERROR 且成功标记存在；覆盖八向持续接触、释放、绕障路线、物件真实碰撞与动态墙重建。再做窗口截图与持续实际移动，尤其检查细小间隙、角部停步、按键释放和新障碍附近。新增配置只改变常量，无新节点、逐帧遍历或缓存。
