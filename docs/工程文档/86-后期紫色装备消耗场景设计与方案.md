## 1. 结论摘要

后期紫装（`legendary`）**不是"消耗途径不够多"，而是现有四条出口在循环图里各有硬性上限**，其中「四紫升档」在等级跟随的地图里实际是**死功能**。

| 出口 | 单次消耗 | 后期实际可用性 |
|---|---|---|
| 四金合紫 | 4 件金装 | 不消耗紫装 |
| 四紫定向 | 4 件同档紫 | 可用，但产物 0★ + 词条随机，刷到目标部位后需求归零 |
| 四紫升档 | 2–4 件同档紫（期望 4） | **不可用**：产物档位 = 材料档 +1，永远高于玩家当前掉落档，穿不上 |
| 保星升级 | 1 件高档 0★ + 1 件低档 12★ | 可用，但要求先有 12★ 底件，频次天然低 |
| 出售换金币 | 无限 | 可用，但回收价约模板价 60%，玩家心理上"亏"，选择囤积 |

**推荐 P1：传说熔解 → 精粹 → 传说共鸣**（任意档、任意部位、可批量，给确定性永久收益）。
**P2：精粹兑换**（指定部位券 / 如意），承接共鸣满级后的余量。
**P3：同部位洗练**（紫装当重铸券），给"同档同部位"的垃圾件一个更轻的出口。

### 3.2 每小时产出

两张图各 20 只 Boss、`respawnTime = 600`。按"30 秒清一只、击杀后立即接下一只"的流水线估算：

| 地图 | 只/小时 | 紫装/小时 |
|---|---|---|
| 无尽回廊 | ≈120 | **≈6 件** |
| 百首禁域 | ≈120 | **≈12 件** |

这是用户"背包里大量紫装"的直接来源，与手感一致。

### 3.3 存量阈值

背包 40 格（可扩到 200）+ 仓库 200 格。按每小时 12 件计，**不停手刷 2 小时就能填满 24 格**，扣掉药水/如意/卷轴常驻占用后，实际 1.5–2 小时满一次包。

## 4. 为什么现有出口吃不下（四条结构性缺口）

### 4.1 缺口一：四紫升档产物永远"高一档"，穿不上

规则：产物档位 = 材料档位 + 1（[05 §5.13](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/docs/产品文档/05-装备与背包系统.md#L137)）。而循环图掉落 `levelFromBoss: true`，档位 = **玩家当前等级所在十级档**。

```text
玩家 L100 → 掉落档 91–100 → 升档产物 101–110 → 需求等级 ≥101 → 穿不上
玩家升到 L101 → 掉落档变 101–110 → 升档产物 111–120 → 又穿不上
```

**结论：只要玩家还在升级，四紫升档在循环图里永远差一档，产出即废件。** 它不是"消耗慢"，而是"没有有效产出"。

### 4.2 缺口二：四紫定向只解决"部位"，不解决"词条"

四紫定向 = 4 件同档紫 → 1 件指定部位的同档 0★ 紫，词条重新随机。玩家一旦拿到"目标部位 + 可接受词条"的那一件，**后续所有同档紫装对他就只剩"再赌一次词条"的价值**，而赌一次的胜率远低于直接穿身上的那件，理性玩家会停手 → 囤积。

### 4.3 缺口三：保星的门槛把它锁成了低频操作

保星要求"1 件低档 12★ + 1 件任意更高档同类型 0★ + 128,747 起金币"。12★ 底件本身要先烧掉 12 次升星（成功率从 90% 掉到 5%），这是**件/周级**的操作，无法承担"每小时 12 件"的消耗。

### 4.4 缺口四：所有出口都要求"同档 + 凑够件数 + 不收藏"

- 四紫定向要 4 件同档；
- 四紫升档要 2–4 件同档；
- 保星要同类型、跨档；
- 收藏件一律不可投入。

**没有一个出口能做到"任意档位、任意部位、任意星级、可以批量"，而产出的紫装恰好是"任意档位、任意部位、任意星级"。** 供给与需求的口径对不齐，是溢出的根本原因。

## 5. 设计目标与红线

### 5.1 目标

1. **不挑档位、不挑部位、可批量**——一件紫装进去，不需要先凑同档同部位；
2. **给确定性收益**——不要再用"随机紫装"换"随机紫装"，那只是把 4 件垃圾变 1 件垃圾；
3. **不新增金币产出**（遵守 13 §6.1 的 D-4 硬约束）；
4. **不替代升星 / 重铸的金币出口**（D-17 / D-24 是刻意的金币回收阀）；
5. **复用现有 UI 与系统**，不新开 NPC、不新开地图。

### 5.2 红线

- 收藏件、穿戴中的件、任务件**不可投入**；
- 不做"全自动熔解"——必须玩家在清单里确认（与批量出售同口径）；
- 不放松存档校验，不新增会导致旧档判坏的字段；
- 不改变"紫装可出售"的既有出口，熔解必须是**并列选项**而非替代。

## 6. 方案 A（推荐）：传说熔解 → 精粹 → 传说共鸣

### 6.1 机制

```text
任意紫装（背包内、未收藏、未穿戴）
        │  熔解（批量清单确认）
        ▼
   传说精粹（可堆叠道具，1 件紫装 = 1 颗；12★ = 3 颗）
        │  投入
        ▼
   传说共鸣（永久进度条，每级消耗固定精粹）
        │
        ▼
   永久收益（见 6.3 两个变体）+ 满级后精粹转兑换
```

**为什么它能吃下溢出**：熔解不挑档位、不挑部位、不挑词条，且可以一次勾选几十件，唯一限制是玩家是否愿意放弃"卖金币"。它把"装备"转成"进度"，天然没有上限（在共鸣满级前）。

### 6.2 数值

| 项 | 建议值 | 理由 |
|---|---|---|
| 熔解产出 | 1 件 = 1 精粹；12★ 额外 +2（共 3 颗） | 12★ 是 128,747 金币级的投入，不能与 0★ 同价 |
| 共鸣每级消耗 | 2 颗 | 100 级 = 200 件紫装 |
| 共鸣上限 | 100 级 | 按 12 件/小时 ≈ 17 小时满级，是一个"赛季级"目标 |
| 精粹堆叠 | 99（`misc` 默认上限，见 [item_util.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/systems/item_util.gd#L40-L43)） | 200 颗约占 3 格，可接受 |

> 200 件是刻意选的：既能让玩家在几十小时内看到明确进度，又不会一周就喂满导致系统作废。

### 6.3 共鸣的收益：两个变体（需拍板）

**A1 数值版（改动最小）**

- 每级全属性 +0.1%，100 级 = **+10%**。
- 与全紫套装的 +20%、全 12★ 的 +20% 加法叠加，终局上限从 +40% 抬到 +50%。
- 风险：会轻微破坏 13 §2.3 的"击杀次数恒定"不变量（玩家实际变强 10%）。属于终局奖励，可接受，但**必须重跑 `PaceTest` 的三条护栏**。

**A2 解锁版（更有目标感，改动较大）**

- 每 25 级解锁 1 条"传说词条"进入重铸池（暴击 / 吸血 / 穿透 / 技能冷却），100 级解锁 4 条。
- 不膨胀已有数值，只提供横向 build 空间；但需要新词条类型 + 重铸池过滤，约等于一次小版本。

**建议先做 A1**（一周内可落地），把 A2 作为后续赛季内容。

### 6.4 UI 与代码落点

| 环节 | 落点 | 说明 |
|---|---|---|
| 熔解入口 | 背包面板操作行，「出售」旁新增「熔解传说」 | 与批量出售并列，复用同一行的按钮样式 |
| 批量清单 | 新建 `EquipmentMeltPreview`，结构照抄 [`equipment_sale_preview.gd`](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/ui/equipment_sale_preview.gd) | 只列 `legendary` × 未收藏 × 未穿戴；显示"将获得 N 精粹" |
| 规则层 | 新建 `scripts/systems/legendary_melt.gd` | 纯函数：`can_melt()` / `essence_of()` / `preview()` / `apply()`；二次校验照抄 [GameState 的出售校验](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/autoload/game_state.gd#L705) |
| 精粹 | `data/miscItems.json` 新增可堆叠道具 | 走现有 Inventory 堆叠，**旧档零迁移**（没有该道具就是 0 件） |
| 共鸣 | 铁匠面板新增第 5 项服务「传说共鸣」 | 一个进度条 + 一个"投入精粹"按钮，复用铁匠面板的浮窗托管 |
| 存档 | 精粹是背包道具，**本身无需新字段**；共鸣等级需要新增 `legendaryResonance` | 按 `favorite` / `durability` 的既有先例做成**可选字段、缺省 0**，旧档读入不报错，不提升 schema 版本 |

> 关键取舍：精粹走道具、共鸣等级走可选字段，两者都不触发旧档迁移。代价是存档里多一个数字，收益是"重启/读档后进度不丢"。

### 6.5 消耗能力测算

| 来源 | 件/小时 | 熔解后可投入 | 共鸣满级耗时 |
|---|---|---|---|
| 无尽回廊 | 6 | 6 颗 | ≈33 小时 |
| 百首禁域 | 12 | 12 颗 | ≈17 小时 |

即使玩家只用一半（其余照旧出售/合成），也能在 1–2 周内看到满级，之后精粹转入次级兑换（见 6.6），不会二次溢出。

### 6.6 满级后的次级出口（P2）

- **指定部位券**：3 颗精粹 + 四紫升档，可指定产物部位（把"随机部位"变成可控，直接补上四紫升档"穿不上"之外的另一个痛点）；
- **如意兑换**：10 颗精粹 = 1 颗随机如意（覆盖升星材料）；
- 两者都**不产金币**，不破坏 D-4。

## 7. 方案 B：同部位洗练（紫装当重铸券）

| 项 | 设计 |
|---|---|
| 触发 | 重铸面板选中目标件后，可勾选"消耗 1 件同档同部位紫装" |
| 效果 | 本次重铸**免费锁 1 条词条**（等价于省掉 50% 加价） |
| 消耗 | 1 件紫装 + 正常重铸金币 |
| 优点 | 无新道具、无新面板、无存档改动；对"同部位垃圾紫"极友好 |
| 缺点 | 受"同档同部位"限制，低档/异部位仍无出口；消耗速率受重铸金币上限约束（约 4–6 件/小时） |

**定位**：不是主力，而是方案 A 的"轻量替代"——不想熔解的玩家可以用紫装换一次免费锁词条。

## 8. 方案 C：传说献祭（局内 Buff，不推荐本期做）

进循环图前投入 N 件紫装，换本轮"掉落品质权重偏移 / Boss 额外刷新 / 移速"。优点是有即时爽感；缺点是**新面板 + 新平衡轴 + 正反馈循环**（掉落品质提升会加速紫装产出），风险最高。列为后续赛季方案，不进本期。

## 9. 不采纳的方向

| 方向 | 不采纳理由 |
|---|---|
| 紫装换追猎令牌 / 随身道具 | 绕过装备系统直接买 Boss，经济上等价于"用装备买击杀"，容易套利 |
| 跨档万能材料（低档紫直接当高档料） | 会废掉四紫升档的逐档爬升设计，且 2 件低档 = 1 件高档的折算无法自洽 |
| 自动熔解 / 拾取即熔 | 与收藏、出售的选择权冲突；玩家会误熔掉想要的件 |
| 提高传说掉率 | 反向加剧溢出，且破坏 D-16 的"捡→卖→金币"节奏 |
| 单纯扩大背包/仓库 | 只是把溢出推迟，玩家实际体验是"更大的垃圾场" |

## 11. 验收与埋点

1. **总量守恒**：熔解前后，背包紫装件数 = 勾选件数；精粹增量 = Σ`essence_of()`；不产生/销毁其他物品。
2. **不可投入件**：收藏、穿戴中、任务件、非 `legendary` 一律不在清单内；手工注入也必须被规则层拒绝。
3. **无套利**：熔解再兑换（如意/部位券）的期望价值 **不得高于**同件紫装的出售价 + 一次四紫定向的边际价值。
4. **旧档零迁移**：旧存档读入后无 `精粹` 时显示 0，不报错、不判坏档。
5. **节奏**：`PaceTest` 三条护栏必须重跑；新增"每小时紫装产出 vs 可消耗量"埋点，目标：**存量稳定在 15 件以内**。
