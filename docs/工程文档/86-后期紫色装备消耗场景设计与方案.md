## 1. 结论摘要

后期紫装（`legendary`）不是「出口数量不够」，而是**现有出口在循环图里各有硬上限**：

| 出口 | 单次消耗 | 后期实际可用性 |
|---|---|---|
| 四金合紫 | 4 件金装 | 不消耗紫装 |
| 四紫定向 | 4 件同档紫 | 可用，但产物 0★ + 词条随机，拿到目标部位后需求骤降 |
| 四紫升档 | 2–4 件同档紫（期望 4） | 产物档位 = 材料档 +1，**需求等级高于玩家当前等级**；要等升一级才穿上，届时新掉落又是同档，价值被抹平 |
| 保星升级 | 1 件高档 0★ + 1 件低档 12★ | 要求先有 12★ 底件，件/周级频次 |
| 出售换金币 | 无限 | 回收价约模板价 60%，玩家觉得亏，选择囤积 |

**推荐主方案（v2）：重铸精炼**——重铸时投入 1–4 件紫装，抬高本次重掷词条的数值下限；不新增道具、不新增面板、不新增存档字段。消耗速率与重铸频率天然挂钩：后期重铸约 5–9 次/小时，每次投 4 件即可吃掉 20–35 件/小时，覆盖 6–12 件/小时的产出。

**配套调整**：铁匠合成的「指定产物部位」改为**金币收费**（紫装仍按原规则消耗），避免精炼与部位锁定抢同一份资源。

## 4. 为什么现有出口吃不下（四条结构性缺口）

### 4.1 缺口一：四紫升档的产物要"等升级"，且升级后被新掉落抹平

产物档位 = 材料档 + 1（[05 §5.13](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/docs/产品文档/05-装备与背包系统.md#L137)），而循环图掉落 `levelFromBoss: true`，档位 = 玩家当前等级所在十级档：

```text
玩家 L100 → 掉落档 91–100 → 升档产物 101–110 → 需求等级 ≥101 → 暂时穿不上
玩家升到 L101 → 掉落档变 101–110 → 此前那件只等于"新掉落的同档件"，且是 0★ 随机词条
```

所以它不是"永远没用"，而是**价值期货化**：要先攒经验、且兑现时已被新掉落抹平。理性玩家不会把它当主要出口。

### 4.2 缺口二：四紫定向只解决"部位"，不解决"词条"

4 件同档紫 → 1 件指定部位的同档 0★ 紫，词条重新随机。玩家拿到"目标部位 + 可接受词条"后，后续同档紫装只剩"再赌一次词条"的价值，而赌一次的期望低于身上那件 → 停手 → 囤积。

### 4.3 缺口三：保星是件/周级操作，撑不起件/小时级的产出

保星要求"低档 12★ + 任意更高档同类型 0★ + 128,747 起金币"。12★ 底件本身要烧 12 次升星（成功率 90%→5%），频次天然低。

### 4.4 缺口四：所有出口都要求"同档 + 凑够件数 + 不收藏"

- 四紫定向要 4 件同档；
- 四紫升档要 2–4 件同档；
- 保星要同类型、跨档；
- 收藏件一律不可投入。

**没有一个出口能承接"任意星级、件数零散、且高频产出"的紫装。** 供给与需求的口径对不齐，是溢出的根本原因。

## 5. 设计目标与红线

### 5.1 目标

1. **不挑部位、件数零散也能投**——不需要先凑 4 件同档；
2. **给确定性收益**——投入后本次重铸的词条下限实打实抬高，不是"再随机一次"；
3. **不新增金币产出**（13 §6.1 / D-4）；
4. **不替代重铸的金币费用与锁词条加价**（D-17 / D-24 是刻意的金币回收阀）；
5. **改动尽量小**：复用重铸面板，不新增道具、面板、存档字段。

### 5.2 红线

- 收藏件、穿戴中的件、任务件**不可投入**；
- 材料在**确认重铸时**才扣除；预览、取消、关面板都不扣；
- 不放松存档校验；
- 熔炼/精炼不改变装备的实例 id、品质、星级、基底、需求等级。

## 6. 主方案：重铸精炼（紫装作为"精炼材料"）

### 6.1 玩家看到的操作

```text
铁匠 → 重铸 → 选中目标紫装
        ├─ 词条区：可锁 0..3 条（金币加价，原规则不变）
        ├─ 新增「精炼材料」区：可拖入 0–4 件紫装
        └─ 「重铸」按钮：显示费用 + 本次词条下限
```

### 6.2 机制

投入 `n` 件有效紫装后，本次**未锁定**词条的数值下限抬高：

```text
floor_ratio = min(0.60, 0.15 × n_effective)
value = randf_range(lo + (hi − lo) × floor_ratio, hi)
```

| 有效件数 | 词条数值下限 | 效果 |
|---|---|---|
| 0 | 0%（现状） | 均匀随机 |
| 1 | 15% 分位 | 明显减少"极低值" |
| 2 | 30% 分位 | |
| 3 | 45% 分位 | |
| 4（上限） | **60% 分位** | 四条传说词条全部落在上半区 |

- **上限 60%**：保留"极品词条仍需运气"的稀缺性，不做成"必满值"；
- **锁定词条不享受提升**：锁 3 条 + 精炼 4 件若同时生效，等于"三条不动、最后一条必高"，重铸会退化成按按钮。锁定的词条按原规则原样保留；
- **词条类型池不变**：只抬数值，不改类型权重，避免与重铸的概率设计冲突；
- **金币费用不变**：仍按 `Reforge.cost(level, locked_count)`，精炼不额外收费也不打折。

### 6.3 材料折算（任意档位都能投）

| 材料 | 有效件数 |
|---|---|
| 同档紫装（0–11★） | 1 |
| 高 1 档及以上紫装 | 2（鼓励把高档料留给四紫/保星，而不是喂重铸） |
| 低 1 档紫装 | 0.5（2 件算 1） |
| 低 2 档及以下 | 0.25（4 件算 1） |
| 12★ 紫装（任意档） | 额外 +1 |

> 折算的意义：**任何档位的紫装都能投**，低档料按折价进炉，高档料不被"省事"吃掉。这与「四紫随机放入只取最低合格档」的既有设计同口径。

### 6.4 为什么这套能真正吃掉溢出

| 变量 | 数值 | 说明 |
|---|---|---|
| 后期重铸频率 | 5–9 次/小时 | 13 §6.2 实测 |
| 单次可投材料 | 最多 4 有效件 | 上限固定，玩家没有理由不投满（纯增益） |
| 消耗速率 | **20–36 件/小时** | 覆盖 6–12 件/小时的产出，且有余量消化存量 |
| 存量收敛 | 数小时内见底 | 背包从"垃圾场"回到"缓冲区" |

关键性质：**精炼是纯增益且不花钱**，理性玩家每次都会投满，所以消耗速率会稳定贴近"重铸次数 × 4"，而重铸次数又被金币费用（D-17）锁住——两个既有阀门自然咬合，不需要新的平衡轴。

### 6.5 与既有系统的关系

| 系统 | 影响 | 处理 |
|---|---|---|
| 锁词条（D-24） | 锁定词条不享受精炼 | 写明；`reroll_affixes` 的锁定条目直接跳过下限抬升 |
| 升星 | 精炼不改星级 | 12★ 可作材料，但只加"有效件数"，不消耗星级以外的收益 |
| 四紫合成 | 材料池与精炼池互斥 | 已收藏/穿戴件两边都不可投；同一件不会在一次操作里被两边吃掉 |
| 出售 | 紫装仍可卖 | 精炼是并列选项，不强制 |
| 存档 | **零新字段** | 材料只是"本次面板内选择"，重铸后即消耗，不落档 |

## 10. 验收与埋点

1. **守恒**：重铸前后，投入材料件数 = 扣除件数；目标件实例 id / 品质 / 星级 / 需求等级不变；不产生/销毁其他物品。
2. **不可投入件**：收藏、穿戴中、任务件、非 `legendary` 不在可选范围；手工注入必须被规则层拒绝。
3. **默认零回退**：`floor_ratio = 0` 时，`reroll_affixes` 的随机调用序列与现状**逐位一致**（对照工程 75/81 的既有断言语义）。
4. **下限可测**：固定 `seed` 下，投 4 件的每条词条都 ≥ 该词条区间 60% 分位。
5. **锁定隔离**：锁定的词条数值完全不变，且不参与下限抬升。
6. **节奏**：`PaceTest` 三条护栏重跑；新增埋点「紫装产出 / 精炼消耗 / 出售 / 合成」四类占比，目标：背包紫装存量稳定 ≤ 15 件。

## 附录 A：熔解 → 精粹 → 共鸣（v1 方案，已降级）

### A.1 概念说明

「共鸣」不是角色等级，也不是装备等级，而是**一个独立进度条的名字**：

```text
熔解 1 件紫装 → 1 颗传说精粹
投入 2 颗精粹 → 共鸣 +1 级
共鸣 100 级 = 全属性 +0.1% × 100 = +10%
```

它与角色 9999 级上限无关；100 是共鸣自己的上限，对应约 200 件紫装。若担心"上限太低"的观感，可以把共鸣做成 999 级、每级 +0.01%，总量仍是 +10%，只是进度条更长。

### A.2 为什么降级

| 维度 | 熔解/共鸣 | 重铸精炼 |
|---|---|---|
| 新道具 | 需要（精粹） | 不需要 |
| 新存档字段 | 需要（共鸣等级） | 不需要 |
| 新面板 | 需要（熔解清单 + 共鸣面板） | 不需要（重铸面板加一区） |
