### 1.1 为什么不破防

`Combat.resolve` 的破防判据是 `攻 − 防×0.5 > 0`：

```
Boss 攻 7,867 − 你防御 37,734 × 0.5 (18,867) = −11,000  ⇒ raw ≤ 0
⇒ 走 monster.gd::_min_hit_on_player() = clampi(maxHP × 0.25%, 10, 60) = 60
```

**每击固定 60 点 = 你血量的 0.016%。** 148 秒内挨约 118 击，共 **7,080 血 = 血量的 1.9%**。
站着不动、不喝药、不看屏幕都能过 —— 这就是「一点难度都没有」的全部原因。

> 🔴 **破防需要 2.40 倍攻击**（18,867 ÷ 7,867）。工程 91 §Q3 当时判断「配 `atkMultiplier` 也没用，
> 翻倍也破不了防」是对的，但结论下成了「那就不配」，等于把这张图做成了血包。本轮修正：
> **不是不配，而是必须配到 2.40 倍以上才有效。**

### 1.2 药水天花板（135 级口径）

## 3. 三档备选（待拍板 Q1）

### 方案 A · 3.0（宽松：只喝大红也能稳过）

- 每击 **4,735**（1.25% 血），裸站 100 秒死
- 20 秒窗口：掉 75,760 vs 喝回 75,632 ⇒ **几乎打平，血线稳在中高位**
- 观感：会掉血、需要喝，但**永远不危险**；比现状好很多，但谈不上「爽」

### 方案 B · 3.3（推荐：「血线一路掉到底，全程按着药」）

- 每击 **7,095**（1.88% 血），裸站 **67 秒死**（击杀要 148 秒 ⇒ 不喝必死）
- 20 秒窗口：掉 113,520 vs 喝回 75,632 ⇒ **净亏 37,888**
- 148 秒内累计亏 28 万血 ⇒ **血线从 100% 一路滑到约 26%**
- 只备大红就够，但**每 20 秒必须按一次、一次都不能漏**（余量只有 1.6%）
- **正好对上你的原话**：「要破防，我要不停的吃药，才能打死，才爽」

### 方案 C · 3.6（硬核：必须三档药轮换）

- 每击 **9,455**（2.50% 血），裸站 50 秒死
- **只喝大红必死**（亏 24%）；必须小红 + 中红 + 大红轮着按（余量 24%）
- 观感：血线在中段剧烈拉扯，操作强度最高
- 风险：要求玩家管理三种药水，和「按一个键狂喝」的直觉不符

> **推荐 B（3.3）。** A 的压迫感不够，C 的操作门槛（三档药轮换）容易变成负担。
> B 的手感最贴你的原话：**疼、但只用一种药就能打，代价是全程不许停**。

## 4. 必出紫（Q2）

现状 `DT_C7_Solo_Boss` 传说组：`chance 0.05`、`countRange [10,10]`。

**改动**：`chance 0.05 → 1.0`，件数保持 10 件。

`Loot.roll` 判定是 `if r.randf() >= chance: continue`，`randf()` 返回 `[0,1)` ⇒ `chance = 1.0` **恒命中**。

结果：每次击杀固定掉 **10 件 141—150 级传说（紫）**
（你 135 级 ⇒ `levelOffset 10` ⇒ 145 ⇒ `T(145) = 141` ⇒ 141—150 套，是**下下套**期货，一件穿不上）。
另加 50—80 件普通/优秀 + 20 件稀有/史诗（视觉爽感 + 自动出售收益，保留）。

### 4.1 必须同步的三处（不写就会踩）

1. **`tests/solo_boss_field_test.gd::_test_count_multiplier`** ——
   现在有一条「本图每组 `chance` 必须与回廊一致（放大件数、不改概率）」，改后必然变红。
   **不能直接删**，要改成：传说组单独断 `chance == 1.0`（并写明 D-30 拍板理由），
   普通组 / 稀有组的 `chance` 仍须与 `DT_C7_Arena_Boss` 一致；**件数十倍**那条三组全保留（1×10 = 10）。
2. **`data/dropTables.json` 的 `desc`** —— 现在写「chance 不变，只放大 countRange」，必须改。
3. **产品 13 §13.3 / 工程 91 §10** —— ⚠ 5% → 100% 是 **20 倍概率**，不要再写「十倍爆率」，
   口径改成「**件数十倍，且紫装必出**」。

### 4.2 连带影响

- **紫装献祭（D-27）**：一次 10 件 141—150 紫，经验可观，但半小时一只 ⇒ 不影响节奏。
- **自动出售**：普通/稀有件会被 `SellGearPolicy` 判低价值卖掉，紫装留包（既有口径）。
- **地面节点**：一次 80—110 件，远低于 `unclaimedLootCap 600`；`preserveUnclaimedLoot` 已在位。

## 5. 🔴 风险

| 编号 | 风险 | 说明与对策 |
|---|---|---|
| 🔴 R1 | **倍率是绝对值，跨等级体验会漂移** | 破防线：100 级 ≈ 2.24 倍、135 级 ≈ 2.40 倍。按 3.3 配，100 级每击约 3.3% 血、135 级 1.88% 血 ⇒ **低等级反而更疼**。这是「防御涨得比 Boss 攻击快」的必然结果，可接受（低等级玩家本来就该更吃紧） |
| 🔴 R2 | **只备一种药在 B 档就是极限** | 只备大红余量 1.6%。这是药水曲线决定的硬事实，不是调参失误 |
| 🔴 R3 | **自动战斗会死** | 自动喝药阈值默认 35%、`pick_index` 挑「够用的最小档」，实际供给远低于 8,036/s。这张图本就该手动 |
| 🔴 R4 | **死亡掉一件背包装备** | `death_penalty.gd` 随机掉背包里一件 `equip`。满地紫装时掉一件紫的概率不低（可原地捡回，成本低但非零） |
| 🔴 R5 | **技能系数会再放大** | `bossSkill` 的 A/B 招系数 1.15 / 1.3 在普攻之外另算，实际峰值比表中高约 2%—5% |
| 🔴 R6 | **生成器会静默冲掉改动** | `map.json` 是 `tools/build_c7_cycle_maps.py` 的产物，只改 JSON 不改脚本，下次重跑生成器就把 `atkMultiplier` 抹掉，且**测试全绿**（测试读的是 JSON）。见改动清单第 4 项 |
| 🔴 R7 | **探针不是权威** | 数字来自 `tools/boss_ttk_probe`（读真实存档 + 复用生产派生链路），权威仍是 `monster.gd` / `game_state.gd` / `balance.gd`。改公式必须同步探针 |
