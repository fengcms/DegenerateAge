# 装备图标与保星材料区回归修复记录

2026-11-02，先处理玩家报告的两个UI回归，再进行高倍速性能分析。使用隔离项目、用户目录与固定夹具，未访问玩家真实存档。

## 原因与修复

图标回归来自aaf5d36a的共用SampleArt.decorate：透明裁边后又按格宽放大。48像素原图失去透明边距，背包、穿戴和材料格共用此入口，导致装备填满格子。本次恢复原始纹理及34逻辑像素上限，移除不再需要的裁边缓存，不改PNG或地面掉落表现缓存。

保星材料格节点仍存在，滚动区却被裁成0高。1280×800实际窗口冷开保星，100%缩放实测scroll高度0、材料格78；125%时偶尔正常，200%再次为0。面板只在_resize中手动fit_content一次，没有把scroll注入FloatingWindow，后续文字排版变化无法校正。

接入set_content_scroll，由统一按帧调度持续收敛；说明、结果和反馈纳入滚动区，确认按钮固定在外，避免大缩放固定文案挤空材料。另修正FloatingWindow固定/停靠布局：以目标分区尺寸适配内容，而非被旧最小尺寸夹大的Container.size，保证缩放后能收缩。影响全部共用浮窗分区逻辑，不改交易、拖放、自动穿回或奖励流程。
