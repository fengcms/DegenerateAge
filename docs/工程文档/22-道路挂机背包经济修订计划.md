# 22 · 道路、挂机与背包经济修订计划

## 目标与规则

1. 免费道路出口支持 E 与鼠标左击；近处直接调用同一通行校验，远处先步行接近，到范围后再校验并切图。点击未解锁出口给原因；点击地面仍是移动。
2. 手动操作结束后的自动战斗恢复等待由 3 秒缩至 1.5 秒，状态文字显示到 0.1 秒，持续输入会重置等待。
3. F 与 G 同时开启时，地面可拾取物优先于怪物。当前掉落不可收取（背包无空间、未出现或已认领）时继续打怪；到达拾取距离后由 `GroundItem` 的唯一收取入口处理。不能因不可拾取的物品卡住。
4. 背包初始 40 格，金币扩容每次 +10 格，最多 200 格；价格复用仓库公式（首档 1000，倍率 1.6），但背包与仓库次数独立。扩容后的 UI、HUD、仓库存取与读写档均使用实际背包长度；旧档迁移为 0 次扩容。
5. Lv15 解锁背包「一键卖出低级装备」与货郎「一键移入」；背包按钮直接结算，货郎按钮只移入待确认托盘。两者读取同一筛选：装备实例等级 `< N` 且品质 `≤ X`，初始 N=5、X=普通，Lv1 即可调整；不按当前穿戴评分动态筛选。手动出售保持原能力。批量交易不触碰穿戴、仓库或非装备物品，整批售价会超过金币上限时拒绝本次出售，不扣物。

## 开发节点与验收

| 节点 | 实施内容 | 验收 |
|---|---|---|
| A | 道路点击与手动恢复间隔 | 近远点击、锁路反馈、E 不回归；持续手动操作后 1.5 秒恢复 |
| B | 拾取优先于寻怪 | 同画面有怪和地面物时先走向地面物；背包满则继续打怪；G 关不拾取 |
| C | 背包金币扩容及存档迁移 | 金币不足/上限失败不扣费；扩容后界面格数更新，旧档可读，新档重载保留全部物品 |
| D | 低级装备筛选与双入口批量出售 | Lv1 可设置、Lv15 解锁；阈值边界与成色排序正确；背包直售、货郎暂存；旧档默认阈值 |

每个节点单独提交 Conventional Commit。自动测试在独立用户数据目录运行；保留工作区内无关的美术和反馈文件改动。
