## 3. 各子步骤方案

### M5-1 性能达标

- **目标**：1440×900、`gl_compatibility` 后端，普通战斗稳定 60 FPS；约 30 同屏敌人无明显卡顿。
- **交付**：新建 `tests/PerfProbe.tscn` —— 在指定地图一次性生成 N 只怪（20 / 30 / 40 阶梯）、开启自动战斗与自动拾取、持续 60s，采样 `Performance.get_monitor(FPS / 帧时间)` 与进程内存，输出 `/tmp/degenerateage_perf_report.md` + 采样 JSON。
- **判据**：30 同屏时 1% Low ≥ 55 FPS、平均 ≥ 58 FPS、无 >100ms 卡顿帧（沿用 SoakTest 的 gap 判据）。
- **优化手段（按需，命中哪项做哪项）**：
  1. 掉落飞行动画 / 飘字节点池化（复用而非 `new`）；
  2. `Monster` / `GroundItem` 的 `_process` / `_physics_process` 降频或按可见性禁用（离屏怪不必逐帧决策）；
  3. 阴影 / 高亮圈（`_draw`）合批或缓存；
  4. 等距深度排序（`y_sort`）在大批量下改稳定排序 / 分层。
- **红线**：**不改战斗 / 经济 / 掉落公式**（性能优化只动"表现与调度"，不动数值）。

### M5-2 内存与事件卫生

- **目标**：开背包 / 切图（含多次往返）/ 连续击杀 200+，进程内存不持续单调增长、不重复注册信号。
- **交付**：`PerfProbe` 内建内存采样；新增「生命周期审计」用例：记录 `ObjectDB` 中各类型节点数、`get_signal_connection_list` 计数，在「开合面板 ×50 / 切图 ×20 / 击杀 ×200」前后比对，允许一次性缓存增长但要求**同态收敛**（不随操作次数线性增长）。
- **重点排查**：`EventBus` 信号连接是否在实体释放时正确断开；`GroundItem` / `DamageNumber` 回收是否泄漏（拖拽幽灵 0.25s 宽限已防）；面板 `set_panel_open` 登记 / 注销是否成对。
- **判据**：同态内存差 < 5%；无节点 / 连接数净增长。

### M5-3 中文与主题（⚠ 口径需重定）

- **背景冲突**：工程文档 02 §8 原写交付物为「`assets/fonts/` + 默认主题」，但项目**已改为不引入字体文件**——用 `SystemFont`（Menlo 系 + CJK 回退链，见工程文档 14 §7.2）。两者口径不一致，**须拍板**（见 §4 决策 D1）。
- **方案 A（推荐）｜沿用 SystemFont**：零体积、macOS 自带 PingFang SC 保证中文。**关键动作 = 导出包复验**：导出 `.app` 后逐界面检查中文无方框（重点：HUD、任务、tooltip、自绘 4 处）。
- **方案 B｜内置字体**：随包携带一份子集化 CJK 字体（体积数百 KB~数 MB，需确认授权），彻底摆脱系统依赖，代价是体积与授权成本。
- **判据**：导出包全部界面中文正常显示（截图留证）。

### M5-4 本地化骨架

- **目标（产品 11.1 / 10.1）**：全部 UI / 提示文案外置到 `localization.json`；预留多语言（首版仅中文）。
- **交付**：新建 `autoload/localization.gd`（`Localization`，Autoload）——`tr_key(key, [args])` 读 `localization.json`，缺 key 回退原文并 `push_warning`（便于发现遗漏）；`localization.json` 从 31 条扩展为**分类命名空间**（`ui.* / toast.* / error.* / loading.tip.* / quest.*`）。
- **迁移分级（避免范围蔓延，见 §4 决策 D2）**：
  - **P0 界面骨架**：HUD、主菜单 / 暂停、四面板、设置、存档面板、Toast、错误提示（**必做**）；
  - **P1 交互文案**：按钮、二次确认、tooltip 模板、数值格式串（**建议做**）；
  - **P2 数据文案**：物品名 / 描述 / 任务文本 —— **本就在 `data/*.json`**，不改（`localization.json` 只管"代码里的字符串"）。
- **判据**：P0（+ P1）范围 `grep` 硬编码中文为零残留；切换语言 key 前缀能整体替换。

  3. **色盲模式 S44 + 独立字号缩放 S45**（11.6）：**待拍板是否纳入 MVP**（见 §4 决策 D5）。

### M5-6 错误与崩溃反馈

- **目标（产品 10.3）**：存档损坏 / 数据非法**均有可见提示、不静默**。
- **交付**：
  1. 启动数据校验失败 → **界面可见横幅**（当前仅 `push_warning`），列出问题项，可继续但标注"配置异常"；
  2. 存档加载失败（T16 已覆盖备份恢复）→ 明确 Toast / 对话框文案，指向 `.corrupt` 保留现场；
  3. 写盘失败 → 已有"成功静默、失败必提示"，补统一文案走 `Localization`。
- **判据**：构造损坏存档 / 非法数据两类故障，均出现可见提示且不崩溃。

- **进度**：✅ **M5-9a 已完成（2026-10-13）** —— 策略改为 `disabled`（**运行时**由 `SettingsRuntime.apply_display_strategy()` 应用，不入 `project.godot`，原因见工程 17 §4/§5）；实测 `1280×800 → 1920×1200`：玩家像素高 **24 → 24（不变）**、可见世界 **1280×800 → 1920×1200（+50%）**；旧策略对照 **24 → 36（1.5×）且视野不变**。三层验证全绿（导入 / 冒烟 / 启动回归 + `SettingsTest`）。⚠ 新增的 `tests/DisplayProbe.tscn` 属开发期工具，随批次 ③ 清理。
