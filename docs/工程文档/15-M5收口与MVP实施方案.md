## 0. 目标：达到 MVP 标准

产品文档 01 §1.5 **MVP 定义**：*能持续游玩并验证核心循环（打怪 → 掉落 → 成长 → 挑战更强敌人 → 解锁）的版本，**必须能保存进度**；不要求精美素材。*

据此，M5 出口 = 工程文档 02 §8 的四条硬指标：

| # | 出口条件 | 判据 |
|---|---|---|
| E1 | **场景回归全绿** | T01–**T17** 逐条通过并记录证据 |
| E2 | **性能达标** | 1440×900 普通战斗稳定 60 FPS；约 30 同屏敌人无明显卡顿 |
| E3 | **中文显示正常** | 全部界面在**导出包**内不出现方框 / 缺字 |
| E4 | **打包可用** | macOS 导出包能独立运行、能存档 |

> ⚠「不进 M5 的东西」：平台成就（11.2）、手柄（11.3，首版仅键鼠）、Demo 分发（11.4）、崩溃上报服务（11.5，仅本地日志）、多语言成品翻译（仅做骨架，见 M5-4）。

## 3. 各子步骤方案

### M5-1 性能达标

- **目标**：1440×900、`gl_compatibility` 后端，普通战斗稳定 60 FPS；约 30 同屏敌人无明显卡顿。
- **交付**：新建 `tests/PerfProbe.tscn` —— 在指定地图一次性生成 N 只怪（20 / 30 / 40 阶梯）、开启自动战斗与自动拾取、持续 60s，采样 `Performance.get_monitor(FPS / 帧时间)` 与进程内存，输出 `/tmp/degenerateage_perf_report.md` + 采样 JSON。
- **判据**：30 同屏时 1% Low ≥ 55 FPS、平均 ≥ 58 FPS、无 >100ms 卡顿帧（沿用 SoakTest 的 gap 判据）。
- **优化手段（按需，命中哪项做哪项）**：
  1. 掉落飞行动画 / 飘字节点池化（复用而非 `new`）；
  2. `Monster` / `GroundItem` 的 `_process` / `_physics_process` 降频或按可见性禁用（离屏怪不必逐帧决策）；
  3. 阴影 / 高亮圈（`_draw`）合批或缓存；
  4. 等距深度排序（`y_sort`）在大批量下改稳定排序 / 分层。
- **红线**：**不改战斗 / 经济 / 掉落公式**（性能优化只动"表现与调度"，不动数值）。

### M5-2 内存与事件卫生

- **目标**：开背包 / 切图（含多次往返）/ 连续击杀 200+，进程内存不持续单调增长、不重复注册信号。
- **交付**：`PerfProbe` 内建内存采样；新增「生命周期审计」用例：记录 `ObjectDB` 中各类型节点数、`get_signal_connection_list` 计数，在「开合面板 ×50 / 切图 ×20 / 击杀 ×200」前后比对，允许一次性缓存增长但要求**同态收敛**（不随操作次数线性增长）。
- **重点排查**：`EventBus` 信号连接是否在实体释放时正确断开；`GroundItem` / `DamageNumber` 回收是否泄漏（拖拽幽灵 0.25s 宽限已防）；面板 `set_panel_open` 登记 / 注销是否成对。
- **判据**：同态内存差 < 5%；无节点 / 连接数净增长。

### M5-3 中文与主题（⚠ 口径需重定）

- **背景冲突**：工程文档 02 §8 原写交付物为「`assets/fonts/` + 默认主题」，但项目**已改为不引入字体文件**——用 `SystemFont`（Menlo 系 + CJK 回退链，见工程文档 14 §7.2）。两者口径不一致，**须拍板**（见 §4 决策 D1）。
- **方案 A（推荐）｜沿用 SystemFont**：零体积、macOS 自带 PingFang SC 保证中文。**关键动作 = 导出包复验**：导出 `.app` 后逐界面检查中文无方框（重点：HUD、任务、tooltip、自绘 4 处）。
- **方案 B｜内置字体**：随包携带一份子集化 CJK 字体（体积数百 KB~数 MB，需确认授权），彻底摆脱系统依赖，代价是体积与授权成本。
- **判据**：导出包全部界面中文正常显示（截图留证）。

### M5-4 本地化骨架

- **目标（产品 11.1 / 10.1）**：全部 UI / 提示文案外置到 `localization.json`；预留多语言（首版仅中文）。
- **交付**：新建 `autoload/localization.gd`（`Localization`，Autoload）——`tr_key(key, [args])` 读 `localization.json`，缺 key 回退原文并 `push_warning`（便于发现遗漏）；`localization.json` 从 31 条扩展为**分类命名空间**（`ui.* / toast.* / error.* / loading.tip.* / quest.*`）。
- **迁移分级（避免范围蔓延，见 §4 决策 D2）**：
  - **P0 界面骨架**：HUD、主菜单 / 暂停、四面板、设置、存档面板、Toast、错误提示（**必做**）；
  - **P1 交互文案**：按钮、二次确认、tooltip 模板、数值格式串（**建议做**）；
  - **P2 数据文案**：物品名 / 描述 / 任务文本 —— **本就在 `data/*.json`**，不改（`localization.json` 只管"代码里的字符串"）。
- **判据**：P0（+ P1）范围 `grep` 硬编码中文为零残留；切换语言 key 前缀能整体替换。

### M5-5 UI 细节补齐（对照产品 09 逐条勾）

- **待补（现状核查 §1 标 ❌ / ⚠ 的）**：
  1. **加载界面**（9.7）：启动 / 切图显示加载页 = 进度条 + 随机世界观提示语（提示语已在 `localization.json` 的 `loading.tip.*`）；单机可接受非无缝。
  2. **新手引导首屏轻提示**（9.12）：移动(WASD) / 攻击(Space) / 自动(F/G) 轻提示，由 Q001 对话引导、可关。
  3. **色盲模式 S44 + 独立字号缩放 S45**（11.6）：**待拍板是否纳入 MVP**（见 §4 决策 D5）。
- **已完成（仅校验回归，不重做）**：飘字 9.5 / Toast 9.6 / 对话推进 9.8 / 拾取澄清 9.9 / 右键 9.10 / 缩放 9.11 / 目标锁定 9.13。

### M5-6 错误与崩溃反馈

- **目标（产品 10.3）**：存档损坏 / 数据非法**均有可见提示、不静默**。
- **交付**：
  1. 启动数据校验失败 → **界面可见横幅**（当前仅 `push_warning`），列出问题项，可继续但标注"配置异常"；
  2. 存档加载失败（T16 已覆盖备份恢复）→ 明确 Toast / 对话框文案，指向 `.corrupt` 保留现场；
  3. 写盘失败 → 已有"成功静默、失败必提示"，补统一文案走 `Localization`。
- **判据**：构造损坏存档 / 非法数据两类故障，均出现可见提示且不崩溃。

### M5-9 高分辨率显示适配（09-A，批次 ②B）

- **依据**：创意 `09`（v1.0，§9 三判断已确认）+ 工程 `16` D1/D2；**完整方案见 `docs/工程文档/17-高分辨率显示适配实施方案（09-A）.md`**（本文不重复细节，避免双份事实源）。
- **内容**：① 渲染策略 `canvas_items` → `disabled`（窗口变大＝**视野变大、元素不变大**）；② 新增「**地图显示大小**」＝相机 `zoom`；③ 界面 / 地图 / 文字**三轴解耦**，界面档位扩到 200%；④ 世界文字（头顶名 / 飘字）**反向补偿**保持可读；⑤ 逐面板复验 + 点击坐标一致。
- **批次出口**：拖大窗口视野明显增加且元素不变大；4K/5K 默认清晰可读、**不重复密度补偿**。
- **顺序**：**必须先于 M5-8**（打包会定死显示配置，带病打包不可逆）。

### M5-7 全量回归

- **目标**：T01–**T17** 逐条通过并记录证据。
- **交付**：`docs/工程文档/` 内新增回归记录（或在本文 §9 追加），每条附证据（冒烟用例 / 截图 / 无头输出）。
- **说明**：T01–T17 现均已在各阶段 ✅（工程文档 02 §9），M5-7 的价值是**在打包前于当前代码基上全量复跑并留证**。

### M5-8 macOS 打包

- **交付**：
  1. 新建 `export_presets.cfg`（macOS 预设：Universal 或 arm64，参考 1280×800 / 1440×900 窗口，图标占位）；
  2. 导出 `.app`（或 `.zip`），**验证：独立运行、中文正常、能新建 / 存档 / 读档、无 GL 后端问题**；
  3. 记录导出命令与产物路径到工程文档 01（换机复现）与本文件 §9。
- **已知点**：无 Apple 开发者签名时，macOS Gatekeeper 会拦截 → MVP 阶段**不做签名 / 公证**，文档说明"右键 → 打开"绕过（见 §4 决策 D3）。

### 批次 ①「度量与卫生」（2026-10-12 完成）

**交付**：`tests/PerfProbe.tscn` + `tests/perf_probe.gd`（开发期工具，M5 打包前移除）

- **M5-2**：`--audit` 依次压测「面板开合 ×50 / 切图往返 ×20 / 击杀 ×200」，比对节点 / 对象 / 孤儿 / **EventBus 信号连接数** / 关键分组节点数。

**M5-1 结果（开窗 · 1440×900 · 本机 120Hz 显示器）**

| 同屏 | 垂直同步 | 平均 FPS | 最小 FPS | 1% Low | p99 帧(ms) | 长帧 | 卡顿 |
|---|---|---|---|---|---|---|---|
| 20 | 开 | 121.5 | 22.4¹ | 110.0 | 44.6 | 1 | 0 |
| 30 | 开 | 119.9 | 104.0 | 120.0 | 9.6 | 0 | 0 |
| 40 | 开 | 119.9 | 108.9 | 120.0 | 9.2 | 0 | 0 |
| **30** | **关** | **535.2** | 69.4 | **480.0** | 14.4 | 0 | 0 |

¹ 首档启动瞬态（世界初始化）；其余档无掉帧。
**结论：M5-1 达标且余量极大**（30 同屏关垂直同步 ≈ 535 FPS，约为 60 FPS 目标的 9 倍）→ **无需性能优化（R2 未触发）**，判据（30 同屏 1% Low ≥ 55 / 均 ≥ 58 / 无 >100ms 卡顿）全部满足。

**M5-2 结果（无头审计）**

| 阶段 | 节点 | 对象 | 孤儿 | EventBus 信号连接 | enemies | ground_items | npcs | map_world |
|---|---|---|---|---|---|---|---|---|
| 基线 | 837 | 3948 | 0 | 88 | 3 | 0 | 5 | 1 |
| 面板×50 | 837 | 3957 | 0 | 88 | 3 | 0 | 5 | 1 |
| 切图×40 | 836 | 3972 | 0 | 88 | 3 | 0 | 5 | 1 |
| 击杀×200 | 839 | 3993 | 0 | 88 | 3 | 0 | 5 | 1 |

**结论：健康** —— 孤儿恒 0；EventBus 信号连接恒 88（**无重复注册**）；切图 / 面板 / 击杀后节点与分组全部回到基线（**无泄漏**）。

**过程中排查并澄清的一处"疑似泄漏"**：`HUD.ToastBox` 在 200 连杀后瞬时堆积 ~270 个 Toast Label 未回收——**初判为泄漏，实测为瞬态**：每个 Toast 有 `1.4s 停留 + 0.6s 淡出 → queue_free` 的自毁补间，稳定窗口 ≥ 落地 + 2.0s 后全部归零（7.5s 采样：节点 835 vs 基线 837，`ToastBox` 子节点 0）。
👉 结论：**非泄漏**；审计的稳定窗口设为 **5.0s**。附注：**连杀时 Toast 无上限合并**，属观感问题，归入 **M5-5**（09 §9.6）打磨，不属 M5-2 泄漏。
