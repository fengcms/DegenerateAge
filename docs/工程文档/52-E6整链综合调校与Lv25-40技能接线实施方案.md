## 0. 一句话

工程 30 看板上**唯一还挂着「待开始」**的是 E6 整链综合调校；审阅报告里**唯一玩家可感知的成长断层**是 R4（25/40 级拿不到新技能）。
只读探针实测后，两者的性质完全不同：**E6 是「结构已经通了，但没有任何测试能证明它一直通」**，**R4 是「加 id 也没用，三项战斗能力根本没实现」**。

## 3. 判断：什么健康、什么真缺

| 结论 | 依据 | 处置 |
|---|---|---|
| **结构不用改** | 50/50 通、结局达成、26 图可达、无分叉 | 只需**固化成测试** |
| **等级轨迹不是缺陷** | 任务经验占 ~1/3，其余靠刷怪；越级打怪有 ×1.5 经验加成（`LevelGap` 上限），能自洽追赶 | 不调数值，但要**把「一章 500–700 只」写进文档让人确认** |
| **E6 的真缺口是「没有证据」** | 章内 5 个测试全绿，跨章无任何测试 | 新增 `CampaignChainTest` |
| **R4 是真缺陷，且比看上去贵** | F-6：三项能力零实现 | 补引擎能力，不能只加 id |
| **4h 挂机无载体** | F-4：`SoakTest` 已不存在 | 见 Q-3 |

> ⚠️ 2.2 / 2.3 的「−18 级」**不是要修的东西**。前 60 级本来就是「任务给方向、刷怪给等级」，产品从未承诺纯任务满级。真正需要产品点头的是 **2.3 的「一章 500–700 只」是否就是设计想要的节奏** —— 一章约 1.5–2 小时（按每只 10–15 秒）。若产品认为偏多，改的是怪物经验或任务经验，**属数值变更，必须单独拍板**。

## 4. 落地方案

### 4.1 E6-1　`CampaignChainTest`（新场景，5 组）

放 `tests/campaign_chain_test.gd` + `.tscn`，进默认隔离集（**45 → 46**）。

| # | 断言 | 判据（有牙） |
|---|---|---|
| 1 | 主线链完整 | 从 `Q001` 沿 `prev` 走出的链 = 67 个，且 `C3..C6` 段 = **50**；出现分叉或断层即红 |
| 2 | 逐节点可接可取 | 50 个逐个 `accept(giver)` → 补 `quest_items` → `deliver(turnIn)`，任一失败即红并报 **qid + 原因**（不接受「整体 ok」） |
| 3 | 结局达成 | `GameState.unlocks["campaign_complete"] == true` |
| 4 | 无残留 | 50 个状态全部 `rewarded`；不得有任何主线停在 available/active/completed |
| 5 | 无支线也行 | 全程不动任何 `type=side` 的状态；断言支线仍是 `locked`/`available` 原状 |

**不断言等级数值**（实测 42，但会随经验/怪物调整漂移）。只断言「每个节点接取时没有撞上 `requiresLevel`」—— 把「等级不够」变成失败文案的一部分。

### 4.2 E6-2　整链实测留证（新报告）

`docs/审阅报告/E6-整链实测-2026-10-19.md`：把 §2 三张表 + §3 判断固化，作为「逐项留证」的交付物。含结论：结构 ✅、节奏待产品确认、4h 挂机载体缺失。

### 4.3 E6-3　长时回归（**取决于 Q-3**）

- 方案 A（推荐）：不重建，引用工程 09 的历史 600s 结论 + M10-9 的战斗不变量，在报告里标注「4h 挂机为历史结论，未随 M10 复跑」。
- 方案 B：重建 `SoakTest` 30 分钟版（采样 5s、内存/节点数/帧时间三线），进隔离集**但不进默认集**（跑太久）。

### 4.4 R4　Lv25/40 技能接线（四项，缺一不可）

| 子项 | 改动 | 说明 |
|---|---|---|
| R4-a `defensePierce` | `cast_skill` 结算时 `_target_defense(enemy) * (1 - pierce)` | 纯本击，无状态 |
| R4-b `hits` | 多段循环，每段独立 `Combat.resolve`；`_attack_cd` 只设一次 | 纯本击，无状态 |
| R4-c `debuff.armorBreak` | `Monster` 加 `armor_break_left: float`，`_physics_process` 递减；`get_defense()` 在 >0 时 ×0.7 | **唯一需要怪物侧状态**的一项，风险最高 |
| R4-d 接线 | `ACTIVE_SKILLS` +2；`AutoBattle.choose_skill` 补两条评分；技能面板/快捷栏可拖入 | 只接线，不改数值 |

**R4-c 的语义要先定**：JSON 写的是 `debuff: {type: armorBreak, duration: 5.0}`，没写减益幅度。方案建议 **×0.7（−30%，与 `defensePierce: 0.3` 同数）**，否则要回创意章包补字段。
