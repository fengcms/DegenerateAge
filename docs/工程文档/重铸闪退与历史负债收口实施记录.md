# 重铸闪退与历史负债收口实施记录

2026-11-02，依据《重铸闪退修复独立复核与历史负债清理建议》实施。保留原防自激能力，按节点收口，不改重铸数值、交易或存档结构。

## 节点一：统一布局调度与正式回归

新增FrameLayoutScheduler，每宿主一个RefCounted实例，弱引用宿主；仅脏时订阅一次process_frame，不常驻逐帧运行。每帧至多执行一次，执行期间的请求保留dirty到下一帧；同步入口也受同帧预算限制，宿主释放或排队销毁后回调安全放弃。FloatingWindow所有公开布局操作共用调度，三个旧面板不再直接排deferred闭环；人物面板通过公开request_layout请求，不调用私有动作。

fit_content不再用缓存最小尺寸减去刚写入的滚动最小尺寸迭代推算边距；改用实际已排版外框与滚动区尺寸差，单次只设置一次目标尺寸，初次布局由后续容器信号校正。这消除了本轮阈值测试中的跨帧尺寸振荡，而非仅限制自激速度。

新增FrameLayoutSchedulerTest验证100次同帧请求合并、动作内末次更新、暂停、同步入口预算及宿主销毁；ReforgeLayoutStabilityTest真实面板151候选、四紫装、四钻石如意，在800/940/960/1200高度逐轮完成17次取优，检查钻石消耗、连续12帧稳定、外框边界与结果可滚动阅读。无头及实际窗口通过，已查看960/1200截图。

已有13项定向通过：PanelChromeLayoutTest、FloatingWindowInputTest、ShopBuyLayoutTest、PortableShopLayoutTest、EquipmentGapUiTest、BossTokenTest、PortableCarterTest、TownCarterArrivalTest、ReforgeSessionTest、ReforgeTest、ReforgeLockTest、ReforgeScoreTest、FullStarReforgeTest。没有放宽旧断言；新增共享调度也覆盖交易并开、拖动与人物卡片布局。尚待后续节点全量回归。

### 节点一补验：首轮响应

扩大到SettingsTest后发现3倍界面倍率下车夫面板一帧内未收敛。调度器现保留首轮同帧deferred合并，只有本帧已执行时的新请求通过process_frame跨帧，既保留旧打开响应也防同帧循环。SettingsTest、FrameLayoutSchedulerTest、ReforgeLayoutStabilityTest全部通过；未放宽车夫可见边界断言。

## 节点二：队列配置与结论纠正

移除16MB覆盖，使用目标Godot默认32MB，不再宣称默认4MB。修正Main/SettingsRuntime的NaN根因断言与两个探针的“内嵌/墓碑为必要条件”注释；NaN有限性代码继续保留。前两轮历史报告顶部标明已被第三轮替代，第三轮顶部标记后续调度与默认值修订。SettingsTest、FrameLayoutSchedulerTest、ReforgeLayoutStabilityTest在新默认配置下通过。

## 节点三：历史测试债务

数字快捷键测试只补成功标记，原五项按键与隐藏隔离断言不变。工具目录锚点更新为明确5件，原4件夹具保留为合铸前状态；新增合铸后只补超级令牌、旧工具退休、满背包走仓库、重复补领和读档自愈覆盖。NaN测试完成后按结果退出，不再等待运行器帧数上限。ToolReclaimTest、SuperPortablePanelTest、NanGuardTest、PortableBlacksmithTest全部通过，没有改生产补领规则或放宽原断言。

## 节点四：诊断日志与探针隔离

CrashTrace在每次写入前检查文件大小，长单条截断；新写入的当前/上一份日志各受2MiB阈值约束。轮转/打开/写入错误检查结果，失败只停止诊断并保留当前证据，不以WRITE兜底覆盖旧日志。已有历史超大日志保留为上一份，不为凑大小截掉证据。普通怪死亡聚合到节流心跳，Boss及重铸关键事件仍立即flush；DEGENERATEAGE_TRACE_VERBOSE=1可启用逐事件取证。心跳不再因关键事件累计条数提前停止，计数键上限32、无新增定时器或autoload。

新增isolated_project供诊断与负向注入复用。run_isolated_probe必须显式提供只读存档副本，复制到随机项目的默认user目录再启动；正文身份守卫与SaveManager启动前检查共同阻止正式项目运行五种取证场景，包括主场景UID解析。未在正式路径读写测试数据。verify_115_negative只修改一次性快照，删除了改写工作区/恢复历史备份的做法。

CrashTraceTest、DiagnosticProbeGuardTest、SpawnerBudgetTest、SaveTransferTest、ReforgeTest全部通过。NaN三项独立负向均命中指定断言，基线与还原复测通过。集成验证用程序生成的独立存档副本运行NoopProbe成功、源文件哈希不变；非隔离身份拒绝启动且没有创建saves目录。新测试纳入默认集。
