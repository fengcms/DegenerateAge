# 怪物头顶名字标签（分档配色）

## 1. 需求

玩家反馈：地图中的怪物头顶**只有血条、没有名字**，无法一眼分辨正在打的是谁。要求给所有怪物头顶增加名字标签，并按档次配色：

| 档次 | `kind` | 名字颜色 |
|---|---|---|
| 小怪（普通） | `normal` | 白色 |
| 精英 | `elite` | 黄色（金） |
| BOSS | `boss` | 红色 |

## 2. 现状链路（证据）

名字与血条都画在怪物自身节点的 `_draw()` 里（[monster.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/entities/monster.gd#L975-L1009)），没有独立 Label 节点。绘制分三条支路：

| 支路 | 触发条件 | 名字 | 血条 |
|---|---|---|---|
| 贴图怪 · 正式动画包 | `sample_art is MonsterActorArt`（[monster_actor_art.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/entities/monster_actor_art.gd)） | 有：`_draw_sprite_identity()` 画精英金 / Boss 淡粉 | 有 |
| 贴图怪 · 其余图集 | `sample_art` 为 `SampleActorArt` / `dummy_art` 为 `Sprite2D` | **无**（`_draw_sprite_identity()` 不被调用） | 有 |
| 程序占位怪 | 无贴图 | 精英 / Boss 有（`_draw_elite` / `_draw_boss`），普通**无** | 有 |

- 第二条「其余图集」覆盖 `sample_atlas`（第一章普通怪：腐化野狼 / 裂壳虫 / 灰烬游魂）、`static_atlas`（教学木桩等）、`directional_preview`（第二至六章试玩稿，见 [README](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/data/monster_appearances/README.md)）。也就是说：**除第一章精英/Boss 外，所有怪物目前头顶都没有名字**。
- 判定档次的口径是怪物模板的 `kind` 字段，由 [monster.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/entities/monster.gd#L474-L475) 的 `_kind()` 统一读出，绘制/半径/血条尺寸都走它——名字配色复用同一口径即可。
- 绘制锚点由 [monster.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/entities/monster.gd#L1108-L1116) 的 `_head_hp_y()` 提供：外观档案 `headHpY` → 正式动画包脚底锚点 → 贴图默认 `-46` → 程序占位 `-radius*2.4`。

**根因**：名字绘制被拆在三处（`_draw_elite` / `_draw_boss` / `_draw_sprite_identity`），且只在「程序占位」与「正式动画包」两条支路里生效，图集类怪物的分支从未画名字；普通档本身也被设计为无名（见 `docs/游戏创意/06`、`07`：普通怪仅「简短头顶血条」，精英才「常显名字」）。因此本次需求同时包含**补齐缺失支路**与**改变普通怪原设计**两件事。

## 3. 方案

**统一入口 + 单一配色表**，不新增节点、不动存档与玩法字段：

1. 新增 [monster.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/entities/monster.gd) 常量：`COLOR_NAME_NORMAL`（白）、`COLOR_NAME_BOSS`（高亮红 `#ff5252`）、`COLOR_NAME_OUTLINE`（`Color(0,0,0,0.85)`）、`NAME_OUTLINE_SIZE = 2`；精英沿用既有金边色 `COLOR_ELITE_EDGE`，**不另造一个同值常量**，避免两处同色后续漂移。
2. 新增 `_head_name_style()`：按 `_kind()` 返回 `{color, size, width}`（普通白 12px/180 / 精英金 13px/220 / Boss 红 15px/300），字色、字号与血条档位一一对应。
3. 新增 `_draw_head_name()`：所有档次常显名字，位置为**血条正上方**（基线 `_head_hp_y() - 8.0`），先 `draw_string_outline` 再 `draw_string`，保证在草地 / 灰烬 / 洞壁等不同底色上都能读。锚点复用 `_head_hp_y()`，因此外观档案 `headHpY`、正式动画包脚底锚点自动生效，不需要新增档案字段、不需要改任何 JSON。
4. 删除 `_draw_elite` / `_draw_boss` / `_draw_sprite_identity` 里各自的名字绘制，改为在两条支路统一调用 `_draw_head_name()`，消除三份重复样式。

**为什么用 `_draw()` 而不是新建 Label 节点**：怪物同时活动数量受刷新预算约束（第二章普通怪预算 10，另有召唤物），逐只挂 Label 会增加节点树与布局更新成本；自绘文字复用现有单次 `_draw()`，符合 AGENT.md §6「避免为每个实体创建独立节点」。代价是名字的描边必须自行绘制，做法与 `player.gd` 自绘名字同类。

**描边口径**：`Color(0,0,0,0.85)` + `outline_size = 2`，与项目既有「压在场景/图标上的自绘文字」约定一致（`item_slot.gd`、`hud.gd` 世界飘字、`hotbar_slot.gd` 冷却秒数）。

## 4. 影响面

| 项 | 影响 |
|---|---|
| 玩法 / 数值 / 存档 | 无。只改 `_draw()` 表现层，不碰伤害、掉落、AI、`display_name` 生成逻辑 |
| 外观档案 / JSON | 无改动。名字位置由 `headHpY` / 脚底锚点派生 |
| 第一章精英/Boss | 名字从「金 / 淡粉」改为「金 / 红」，位置由 `-6` 微调到 `-8`（更贴近血条，留出描边空间） |
| 第一章普通怪、第二至六章全部怪物 | 由「无名」变为「常显名」，颜色按档位 |
| 死亡表现 | 名字随节点 `modulate` 一并淡出（`_die()` 的 0.35s tween），与血条行为一致 |
| 每帧成本 | 每只怪多一次 `draw_string_outline` + `draw_string`；受活动怪数量约束，不新增节点、不新增纹理。密集战斗下的实际影响需实机观察帧时间 |

## 5. 验收口径

- `mon._kind()` 为 `normal` / `elite` / `boss` 时，`mon._head_name_style()["color"]` 分别为白 / 金 / 红。
- 三条支路（程序占位、正式动画包、图集类）都调用 `_draw_head_name()`，不再出现「某支路无名」。
- 名字基线位于血条上方且随 `_head_hp_y()` 变化。
- 既有契约不回归：`_head_hp_size()`（34×4 / 64×6 / 100×8）、`_head_hp_y()` 取值、档次半径全部保持不变。

测试：在 [smoke_test.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/tests/smoke_test.gd#L4027-L4052) 的 `_test_boss_health_bar()`（已遍历三档）补名字配色、名字非空、描边口径三类断言；再跑定向 `SmokeTest` + `ChapterOneArtTest` + 默认隔离回归 32 项。

## 6. 待实机确认项

1. 白 / 黄 / 红三色在实际地图底色上的可辨识度（尤其灰烬之地的白字、腐化源头的红字）。
2. 第一章普通怪（`wolf_corrupted` 等 `sample_atlas`）沿用既有血条高度 `-46`，名字落在怪物头部区域上方，需目视确认是否遮挡形象。
3. 密集战斗（第二章满刷新预算 + 召唤物）下名字数量增加是否影响帧时间。
4. 名字与 Boss 践踏/技能预警文字、玩家头顶名字是否发生视觉冲突。
