# 营地动态样板性能基线

## 范围与方法

2026-11-18，Apple M1 Max，Godot4.7.2，GL Compatibility，1280×800。隔离样板每布局预热3秒，正常窗口采样30秒；主角在起点与(13,13)往返，两怪每秒尝试播放攻击。每轮确认真实累计移动大于100像素、实际绘制帧数不少于采样数90%、节点不增长；再切图6次校验释放。此测试不截图、不调用force_draw、不使用headless，禁止与其他渲染测试并行。

当前结果是新增内容的基线，不是与旧美术的性能提升对照；没有测冷启动、满怪预算、密集特效、真实掉落或长期挂机，不能据此宣称全游戏稳定60FPS。

## 最终实测

| 指标 | 布局0 | 布局1 |
|---|---:|---:|
| 正常绘制/样本数 | 3577/3577 | 3585/3585 |
| 真实移动距离（像素） | 4469.79 | 4472.49 |
| 帧间隔中位数（ms） | 8.764 | 8.440 |
| 帧间隔P95（ms） | 14.262 | 14.164 |
| 帧间隔P99（ms） | 14.814 | 14.734 |
| 最大帧间隔（ms） | 34.151 | 20.694 |
| 绘制调用中位/峰值 | 91/92 | 92/92 |
| 节点数 | 313 | 313 |
| 引擎纹理内存（字节） | 40509935 | 40509935 |
| 静态内存（字节） | 116662499 | 116668035 |

六次切图后节点始终313，静态内存在116661311～116662535字节间，后四次按布局重复，没有持续增长证据。纹理约38.63MiB，包含场景资源，不能等同于9.31MiB角色动作RGBA8理论量。

首轮同场采样曾出现95.449ms峰值，复核仍有34.151ms峰值；不能把一次下降当优化成果，也不能忽略尖峰。P95/P99在16.67ms以内只说明这两个短样本的主体帧间隔，并非每帧达标。

Performance.TIME_PROCESS/TIME_PHYSICS_PROCESS是引擎更新的监视器值，可能跨采样帧重复，不是逐帧纯脚本/GPU耗时。工具保留这些读数用于定位，不将其与帧间隔直接相加或当独立脚本预算；实际整帧口径使用单调时钟相邻process_frame间隔。没有提供GPU计时结论。

## 复核与后续

运行 `python3 tools/modular_camp/launch.py --benchmark`。要求两条CAMP_BENCHMARK、六条CAMP_RELEASE及MODULAR_CAMP_BENCHMARK_OK，无SCRIPT ERROR。窗口未持续绘制、没有真实移动、节点增长均失败。普通验收与采样参数互斥，避免截图I/O污染结果。

后续正式接入必须重测当前地图规模、满刷新预算、战斗与掉落、冷/热切图和持续游玩，并追踪尖峰；当前结果只支持局部动态样板阶段交付。
