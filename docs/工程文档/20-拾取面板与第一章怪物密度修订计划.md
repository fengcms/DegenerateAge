# 拾取、并存窗口与第一章怪物密度修订计划

> 2026-10-13 试玩反馈；本计划覆盖产品 03 §3.14、07 §7.6、09 §9.2/9.9。旧「怪物掉落始终生成即入包」与「四面板互斥」规格在本轮失效。

## 1. 目标与边界

1. G 关闭：怪物掉落全部留地，靠近不收取，玩家点击才收取；F 自动战斗继续打怪但不自动拾取。G 开启：维持近距离自动收取与自动战斗顺路寻物，成功收取后可播放飞行动画。固定击杀经验与模板金币不是地面掉落，照常结算。
2. 货郎打开时联动背包；关闭货郎时只关闭商店、退回未售托盘物，背包仍打开并恢复普通布局。
3. 背包、人物、技能、坐骑允许并存。标题栏拖动、可见区域钳制、点击置前、各自独立关闭；Esc 关闭最上层。设置 / 主菜单 / 存读档 / NPC 交易保持模态，不允许被浮窗遮挡或误操作。
4. 人物面板列出当前地图可见且存活的怪物，名称高亮并可点击。点击后锁定目标，关闭这四个浮窗并复用现有超距接近与普通攻击路径；死亡、切图后列表失效项即时移除。
5. 灰烬之地为 6 普通 + 2 精英；腐化源头为 8 普通 + 4 精英 + 1 Boss。新增精英模板复用现有词缀、掉落、等级与刷新规则；怪物点仍受地图尺寸和安全区校验。

## 2. 实施顺序与验收

| 节点 | 修改范围 | 准出条件 |
|---|---|---|
| A 拾取语义 | `GroundItem`、怪物掉落、自动战斗与相关测试 | G 关击杀 / 靠近不入包，点击收取；G 开自动收取；背包满、精英 Boss 未领取持久化不回退 |
| B 商店退出 | 商店 / 背包会话 | 关闭商店后背包仍在、托盘已返还，背包恢复普通布局 |
| C 浮动窗口 | 四面板、统一拖动与层级工具 | 四窗可同时显示，拖动不越界，前后层级正确，Esc 只关最上层，交易会话仍可并排拖物 |
| D 怪物索引 | 人物面板、目标 / 移动接口 | 当前可见怪物名可辨、点击后接近并攻击指定怪，死亡与切图不留失效按钮 |
| E 怪物密度 | `maps.json`、`monsters.json`、数据校验 | 灰烬 2 精英，源头 4 精英 + 8 普通；等级、掉表、刷新与首章 Boss 验收通过 |

每个节点完成后运行对应回归并单独提交；全部节点再运行 `SmokeTest`、`ChapterOneAcceptance`、`ReviewRegressionTest` 与 Godot 导入校验。原生窗口复验重点：高倍率下拖动边界、多个窗口的点击层级、地面物品点击命中。

## 3. 兼容与风险

- 存档 schema 不变：G/F 为运行态开关，未领取战利品结构沿用；旧档仍可读取。普通地面掉落仍受 60 秒寿命限制，精英 / Boss 未领取掉落沿用跨图 / 跨档保护。
- G 关闭后自动挂机不再带来掉落物品收益，这是玩家明确要求的行为；HUD 的 G 状态必须与实际拾取一致。
- 浮窗只放开背包、人物、技能、坐骑；其他已有面板的互斥规则不能被统一修改破坏。拖动窗口时不得触发地图移动、物品拖放或快捷栏点击。
- 测试在独立项目名和用户数据目录运行，不触碰玩家存档及显示偏好；仓库中的美术草稿改动不参与本轮提交。
