# 城镇步行过渡与中段地图差异化实施方案

本方案处理三个体验问题：相邻城镇步行距离过短、21—60 级地图辨识度不足、车夫抵达城镇时落在远离车夫的位置。车夫仍是已到访地图的快捷出行方式；本次延长的是免费步行路线。

## 现象与证据

- `camp → c2_well_town → c3_map00 → c4_map00 → c5_map00 → c6_map00` 在 `data/maps/chNN/*/map.json` 中均存在城镇直连出口，跨章时不经过野外。`MapService.request_walk()` 只按出口与目标入口切图，因此目前确实可以连续穿越城镇。
- 第三至第六章的首张野外图都采用「城镇右侧出口 → 野外左侧入口」模式，野外图面积在 176×99 至 240×135 格之间重复排列；例如 `c4_map01`、`c5_map01`、`c6_map01` 均为 208×117 格。布局参考每图约四片封闭障碍，虽然坐标不同，但路线与外轮廓的节奏接近。第二章的五张野外图已有不同尺寸，优先保留其既有美术与任务布点。
- `MapService.carter_arrival()` 直接读取地图的 `carterArrival`。第三至第六章城镇均写成 `[10,27]`，车夫在 `[42,35]`，相距约 33 格；沉井镇为 `[69,36]` 对 `[69,33]`，营地为 `[42,30]` 对 `[46,33]`。

## 目标与边界

1. 相邻城镇的**最短免费步行路径**必须经过恰好一张既有野外地图。按路线顺序分别借用灰烬之地、断流渠岸、倒根驿路、折旗长堤、埋光外廊。保持原地图 ID、怪物、任务与城镇门禁；章节未解锁时不能借中转图进入下一城。
2. 第三至第六章采用章节主题的地形轮廓与路线变化：水渠为分叉/闸口，根驿为林地/环道，战地为长堤/壕沟，镇脉为廊室/分流。调整应从原始布局参考生成运行掩码，并校验所有出口、入口、NPC、刷新点、Boss 与地标可达；不为了差异化无限放大地图面积或增加活动怪物预算。
3. 车夫抵达**城镇**时，落点距目标城镇的车夫 1—3 个逻辑格，通行且不与 NPC 重叠。随身车夫与当地车夫共用该规则；步行入口、回城卷及复活保持各自既有落点语义。

## 实施节点

### 节点一：车夫抵达位置

校准六座城镇的 `carterArrival`，运行时统一检查城市车夫旁落点的可走性和距离，数据测试覆盖所有城镇。每图 README 同步参数。提交后可独立回退。

### 节点二：免费步行过渡路线

重接五组双向出口与入口，继续使用原出口 ID 以减少 UI 与存档引用变化，但目标图和标识改为中转地图。中转图新增通向相邻城镇的双向入口/出口；跨章方向的出口保留 `chapterN` 锁，返回方向无锁。同步原始参考、运行布局具名点、地图说明与章节说明。更新章节路线测试并增加全图图论测试：相邻城镇无直接步行边、经指定一图可双向到达、未解锁不能越章。

### 节点三：21—60 级地图差异化

以现有怪物刷新类型和场景任务为约束，针对第三至第六章野外图分别增加不同的地形特征和通路轮廓；至少让同章各图的尺寸或形状、主路线方向、障碍分布不雷同。优先通过地形参考多边形改变可走掩码；不能把出口、刷新点或剧情目标封在孤岛。每章独立生成、校验和提交，并记录运行资源体量变化。

### 节点四：集成回归

运行地图目录检查、数据引用校验、章节路线/任务/战斗测试、全图跨章导航和地图性能基准。检查旧存档仍能用稳定地图 ID 读入；已在城镇内的玩家不强制重定位。记录真实测试结果与无法在无头模式验证的主观美术效果。

## 数据与性能约束

本轮复用五张已有野外图，不新增怪物模板、刷新预算或活动节点。布局掩码只在切图加载时解析；寻路连通缓存沿既有 `CaveLayout` 生命周期释放。新增路线至多为每张中转图增加一个出口标记。若扩大地图，需分别记录原始与新增格数、加载耗时、静态网格与寻路开销；任何新形状都不能导致首次寻路遍历不必要的全图面积。

## 验收口径

- 五组城镇免费步行需经且只经指定野外中转图；车夫可按原解锁/到访/报价规则直达相邻城镇。
- 中转图的新增出口可以鼠标点击或按键触发，来回落点均在同一可走连通区，任务跨图导航能穿过中转图。
- 每座城镇的车夫抵达点与目标车夫相邻且无碰撞；随身车夫与 NPC 车夫结果一致。
- 21—60 级每章地图的地形轮廓和行走路线有明确区别，所有剧情目标和怪物刷新点可达；运行成本无明显倒退。
