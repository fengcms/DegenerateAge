# 第二章成长与经济校准记录

日期：2026-10-14。此记录区分配置计算与实机结果；尚无完整章节实机时长样本。

## 已入表的产出

- 装备采用现行等级、品质、星级三轴。十种基础型号覆盖十个部位；工坊下层、余烬炉房和井心机室使用对应的十种改装型号。四件任务固定奖不进入随机池。
- 铁臂统领、炉渣吞噬者、百臂主机各有独立传说型号，Boss 追加槽概率为 5%。该概率是每次结算该槽的概率，不是整场装备总传说率。
- 普通怪金币每只 20—36；中红药 14%、中蓝药 12%、随机装备槽 18%。精英有三至四件装备和药品；Boss 有七至十件基础装备、独立传说槽和大红/大蓝各两瓶。
- 百臂主机额外有 3% 驮炉兽收藏掉落；拾取后不能重复获得。

## 经验账本

现行公式为升下一级需 `round(100 × 当前等级^1.6)`。从刚到 Lv11 升至 Lv20，合计约 **69,524 XP**；从刚到 Lv10 升至 Lv20 则约 **73,505 XP**。十二条主线固定奖励共 **14,400 XP**，六条支线共 **5,300 XP**。每只普通怪 40 XP、精英 150 XP、Boss 900 XP。若从 Lv11 起，完成所有任务并各首杀三 Boss 后，仍约需 **47,124 XP**；这些额外经验来自刷怪，不应把任务闭环误认为保证达到 Lv20。

这一差额约等于 1,179 只普通怪，或约 785 只按 60 XP 折算的混合击杀。它只是静态预算，不含等级压制、死亡、走路、排队刷新和过量击杀。当前不承诺 3—5 小时通关，也不将 Lv20 写成必达条件。
