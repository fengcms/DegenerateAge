# 第二章正式资源接入记录

日期：2026-10-14。工程已提供 `data/chapter2_art_manifest.json` 与运行时装配入口：资源完整时以正式八方向动画替换怪物占位表现；任何状态缺失、路径错误、尺寸不符时回退到现有玩法占位，并按角色记录一次警告。碰撞半径、技能判定、掉落与任务 ID 均不从图集推断。

每个 `actors.<monster_id>` 需要：

```json
{
  "frame_size": [112, 112],
  "foot_anchor": [56, 88],
  "directions": 8,
  "states": {
    "idle": {"path": "res://assets/sprites/monsters/<id>/idle_atlas.png", "frames": 7, "fps": 8},
    "walk": {"path": "res://assets/sprites/monsters/<id>/walk_atlas.png", "frames": 7, "fps": 10},
    "attack": {"path": "res://assets/sprites/monsters/<id>/attack_atlas.png", "frames": 7, "fps": 12, "contact": 3},
    "hit": {"path": "res://assets/sprites/monsters/<id>/hit_atlas.png", "frames": 7, "fps": 24},
    "death": {"path": "res://assets/sprites/monsters/<id>/death_atlas.png", "frames": 7, "fps": 10}
  }
}
```

路径只是字段示例，实际路径由美术交付后填写，不按命名惯例自动猜测。图集时间帧在横向、八方向在纵向，像素尺寸必须等于 `frame_size × (frames, 8)`。附加的 Boss 招式动画可后续登记；这五个基本状态先作为正式接入最低门槛。

运行 `python3 tools/check_chapter_two_art.py` 可逐项列缺失。目前 **0/16** 个第二章怪物达到正式资源门槛；工作区中另一个 AI 正在试作断管坡地砖与汲灵幼虫部分帧，尚未进入本次工程提交，也未计为已接入。六图和所有怪物在占位模式下可玩；E6 正式美术准出需等待完整资源，再逐图检查脚底锚点、遮挡、动画暂停和高分辨率显示。
