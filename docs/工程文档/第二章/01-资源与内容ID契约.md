## 地图接口

参考布局来自 `docs/游戏创意/地图示意图/*-布局参考.json`，第一章修订来自 `docs/游戏创意/第一章地图重设计示意图/*-布局参考.json`。运行时 `maps.json` 只存玩法字段和每图布局资源路径；网格、遮罩、出口、落点使用同一版本。布局生成器应验证尺寸、入口与固定目标的可达性，拒绝旧布局版本混入。

## 美术 manifest 接口

正式角色动画按“状态独立资源、方向在行、帧在列”。每项资源至少记录 `actor_id`、`state`、`path`、`frame_size`、`directions`、`frames`、`fps`、`foot_anchor`；Boss 另登记命中帧/预警效果 ID。工程通过 manifest 找素材，缺失时使用明确的占位图并记录警告，不按文件名猜测状态。现有样板图集“方向在列、姿势在行”，只作过渡输入，不能用同一裁切规则读取正式图集。

正式批量制作前，先用一只普通怪和一只 Boss 验证走、攻、受击、死亡及脚底锚点。美术交付不修改 `maps.json`、怪物数值或任务状态；工程修改地标/入口坐标后须更新布局版本并通知美术。
