## 0. 30 秒上手（新机器最短路径）

```bash
# 1) 装 Godot 4.7.2 + Git（推送时按仓库权限配置 GitHub 凭据）
# 2) 拉代码
git clone https://github.com/fengcms/DegenerateAge.git
cd DegenerateAge
# 3) 首次必须注册全局类（新机器没有 .godot/ 缓存）
GODOT=/Applications/Godot.app/Contents/MacOS/Godot      # macOS；其它平台换成自己的 Godot 可执行文件
"$GODOT" --headless --path . --import
# 4) 验证环境（应输出「配置校验通过 ✅」且无 SCRIPT ERROR）
"$GODOT" --headless --path . --quit
# 5) 用 Godot 打开本目录（选 project.godot），按 F5 运行
```

- 主分支 `master`（**现行开发分支**）；`bak` 是旧 Swift/SpriteKit 归档，**不要在其上开发**。
- 详细环境安装 / 换机清单见 **`docs/工程文档/01-脚手架搭建与换机复现指南.md`**（§0 一页速览 / §2 环境 / §9 换机清单）。
- **`.godot/`、`.workbuddy/`、`bak/`、`docs/history/`、`.vscode/` 已在 `.gitignore` 中**，不会随 clone 过来 —— 每台新机器都要跑一次 `--import`。

## 1. 项目是什么

**《末法纪元：最后的守护者》**——2D 等距（isometric）单机实时战斗、打怪升级 ARPG（Diablo-like），首发 macOS。

| 项 | 值 |
|---|---|
| 引擎 | **Godot 4.7 stable**（`config/features = "4.7", "GL Compatibility"`） |
| 语言 | **GDScript**（必要时可切 C#） |
| 分辨率 | 1280×800，`canvas_items` 拉伸 + `expand` 宽高比 |
| 主场景 | `res://scenes/Main.tscn`（UI 层 + 世界层）；世界场景是 `scenes/Game.tscn` |
| Autoload | `EventBus` / `GameState` / `DataLoader` / `SaveManager` / `QuestService`（M2） / `MapService`（M3-1） |
| 设计事实源 | **`docs/产品文档/`**（总纲 + 12 章 + 术语表）—— 一切设计以它为准 |
| 工程实现 | `docs/工程文档/`（本目录，01~15；**08 为滚动交接文档**） |

**商业模式**：买断制优先；**无联网 / 无账号 / 无抽卡 / 无氪金 / 无 PvP / 无交易市场**。
**开发排期原则**：先做最小闭环（货郎经济 → 任务 → 多图 → 坐骑/升星），但**产品设计是完整的**，讨论产品时不要因"排期"裁剪功能描述。

**工具用法**（细节见 09 文档）：
```bash

"$GODOT" --headless --path . res://tests/SoakTest.tscn                          # 正式压测（600s）
```

## 7. 已踩过的坑（**先读这一节，能省半天**）

| # | 坑 | 结论 |
|---|---|---|
| 1 | **Godot 拖放** | 只能用 `Control` 虚方法 `_get_drag_data` / `_can_drop_data` / `_drop_data`；**代码构建的 UI 无法给 `Button` 实例挂虚方法** → 必须抽独立控件（本项目是 `scripts/ui/item_slot.gd`）。 |
| 2 | **`set_drag_preview` 挂载点不可控** | 引擎会把预览塞进任意祖先节点（实测 `Main/UI/InventoryPanel/@PanelContainer@195`），同 canvas 同 z → 被面板挡住。解法：**自绘跟随元素** `scripts/ui/drag_ghost.gd` 挂到 `UI/DragLayer`。 |
| 3 | **`z_index` 只在同一 `CanvasLayer` 内有效** | 本项目 UI 全在 `CanvasLayer(layer=1)`。层级秩序：**面板 `0` ＜ HUD `ToastBox` `2048` ＜ 拖拽幽灵 `DragLayer` `4096`**。 |
| 4 | **JSON 往返会改变字典键顺序** | 断言"实例逐字段一致"必须做**键集 + 逐键深比较**；直接 `str(dict)` 比较会**假失败**。 |
| 5 | **无头模式不锁帧** | 等待必须用 `await create_timer(秒)`，别用帧数或 `process` 累计。 |
| 6 | **截图工具要加载 `Main.tscn`** | 加载 `Game.tscn` 会**没有 HUD**（UI 在 Main 层）。 |
| 7 | **`var x := <Variant 来源>` 在"警告视为错误"下直接编译失败** | `SaveManager._read_file()` 这类返回 `Variant` 的函数，接收变量必须显式写 `var x: Variant = ...`。 |
| 8 | **`max_hp()` 由攻击派生**（4.3：攻×2 + 防×4） | 调试时直接改 `player.attack` 会连带改 HP 上限与占比 → 会误触发 3.14「危险血量保护」。测试时**必须同步补满 HP**（`AutoBattleProbe` 里踩过）。 |
| 9 | **`String.join` 需要 `PackedStringArray`** | 普通 `Array` 会报类型错误。 |
| 10 | **掉落物被瞬间吸走 → 挂机丢件** | 根因：近战射程 64px < 自动拾取半径 96px，掉落物约 1 帧即被吸走；而「落地保护期」方案又与自动战斗「击杀后不逗留」互斥（保护期内玩家已走远 → 掉落物等 60s 消失 → **丢件**）。**正解（工程文档 10）**：`GroundItem` 改为**生成即认领**（当帧入包、不可逆）+ `remove_from_group("ground_items")`（顺路拾取自动看不见它）+ 停驻 0.2s + 追踪抛物线 1.0s。字段 `pickup_delay` → `hold_time`（0.2），新增 `auto_claim` / `stagger_delay`。 |
| 11 | **编辑事故** | 避免同一条消息里对**同一文件**做 `old_string` 重叠的批量 Edit —— 曾导致整章静默丢失。 |
| 12 | **中文字体** | 用 **`SystemFont` 回退链**（`assets/themes/default_theme.tres`：PingFang SC → 微软雅黑 → Noto Sans CJK …），**不需要内置字体文件**，跨平台自动选系统字体。 |
| 13 | **改完脚本必须先跑一次实跑自检，再上长测** | 若被指定的场景脚本**解析失败**，Godot 会**静默回退加载 `run/main_scene`（Main.tscn）**——即"测试脚本没生效，真游戏跑起来了"，还会因 `SaveManager` 的续档 + 定时存**写玩家真实存档**。本次实测踩到：一次编辑把 `return` 与下一行粘连 → 解析失败 → 回退跑主场景 2 分钟 → 自动存写进 1 号槽。**防护**：`--check-only --script …` 先查解析（它仍会报 autoload 不可见的预期错误，但 `Parse Error` 一定先出现），再跑 3~5 秒极短实跑确认流程走通。 |
| 14 | **测试工具会写坏玩家存档（已修复）** | 启动续档后 `SaveManager.active_slot` 指向**玩家真实槽位**；测试工具 `GameState.reset_to_defaults()` + 大量击杀升级 → 关键事件自动存 → **把玩家档覆盖成测试态**（实测 `SmokeTest` 日志出现 `已保存到槽 1`）。**修复**：`SaveManager._autosave_allowed()` 增加**测试场景闸门**——`current_scene` 在 `res://tests/` 下时拒绝自动存 / 退出存；`autosave_in_tests` 可显式放开（`SoakTest` 已放开，因其自行快照 / 还原存档目录）。**写新测试工具时不要绕过它。** 详见工程文档 06 §10。 |
| 15 | **自动搜怪旧锚点限制已废弃** | M4-9 后以 `Game.visible_enemies()` 作为候选；`searchRadius` 仅为旧档兼容字段。更新回归时别再断言 `_anchor`，不要恢复固定半径。 |
| 16 | **恢复数值要累积小数并扣除脱战等待时间** | HP/MP 按最大值每秒百分比恢复；`_tick_regen(delta)` 必须只使用超过 5 秒脱战等待的那部分时间，不能让一个跨过门槛的大帧提前恢复。打坐、暂停、受击起身见 M4-9 专项测试。 |

## 12. 常见任务 SOP（照做即可）

| 想做的事 | 步骤 |
|---|---|
| **新增一件装备 / 一只怪 / 一个任务** | 只改 `data/*.json`（`equipments.json` / `monsters.json` / `quests.json` 等）→ 跑三层验证。**不改代码**（铁律 1） |
| **新增一张地图** | ① `data/maps.json` 加条目（`size` / `tierRange` / `safeZone` / `recommendedLevel` / `carterLinks` / `carterFees` / `spawnPoints` / `bossSpawn` / `npcs`）；② 在相邻图 `carterLinks` + `carterFees` 里**互指**；③ `--quit` 看 `配置校验通过 ✅`（`DataLoader` 会校验拓扑连通与引用合法性） |
| **新增一个 NPC** | `maps.json` 对应图 `npcs` 加 `{role, ...}`（`role=shop` 需 `shopId`；`quest` / `carter` 用 `npcName`）→ 启动引用校验自动覆盖 |
| **加一个 NPC 面板** | 复制 `scenes/ui/CarterPanel.tscn` + `scripts/ui/carter_panel.gd`，改标题与列表项；`EventBus` 加请求信号；`game.gd::_try_interact()` 加 `role` 分支；`Main.tscn` 挂实例 |
| **改数值** | 🔴 **先出书面方案 + 拿用户明确确认**（铁律，见 §3.1 / §4）；改完复跑 `tools/balance_check.py` 并补冒烟锁值断言 |
| **改设计** | 先改 `docs/产品文档/`（单一事实源），再同步 `data/*.json` 与代码 |
| **加测试** | 断言写进 `tests/smoke_test.gd`；需要看图就照抄一个 `*Shot.tscn`；**新测试工具务必确认没有绕过 `SaveManager` 的测试场景闸门**（坑 14） |
| **每次收尾** | 运行对应专项与冒烟验证 → 更新产品/工程文档的实际状态 → `type(scope): 中文描述` 提交；推送以当前任务要求为准 |
