## 1. 项目是什么

**《末法纪元：最后的守护者》**——2D 等距（isometric）单机实时战斗、打怪升级 ARPG（Diablo-like），首发 macOS。

| 项 | 值 |
|---|---|
| 引擎 | **Godot 4.7 stable**（`config/features = "4.7", "GL Compatibility"`） |
| 语言 | **GDScript**（必要时可切 C#） |
| 分辨率 | 1280×800，`canvas_items` 拉伸 + `expand` 宽高比 |
| 主场景 | `res://scenes/Main.tscn`（UI 层 + 世界层）；世界场景是 `scenes/Game.tscn` |
| Autoload | `EventBus` / `GameState` / `DataLoader` / `SaveManager` |
| 设计事实源 | **`docs/产品文档/`**（总纲 + 12 章 + 术语表）—— 一切设计以它为准 |
| 工程实现 | `docs/工程文档/`（本目录，01~08） |

**商业模式**：买断制优先；**无联网 / 无账号 / 无抽卡 / 无氪金 / 无 PvP / 无交易市场**。
**开发排期原则**：先做最小闭环（货郎经济 → 任务 → 多图 → 坐骑/升星），但**产品设计是完整的**，讨论产品时不要因"排期"裁剪功能描述。

## 6. 项目铁律（违反会被打回）

1. **数据驱动**：新增装备 / 怪物 / 任务 / 地图 = **只加 `data/*.json` 条目 + 图标，不改代码**。
   （C3 修精英掉落就是加一张表，不是加 `if kind == "elite"` 分支。）
2. **单一事实源**：改设计先改 `docs/产品文档/`，再同步 `data/*.json` 与代码。
3. **三层验证，每步必跑**：
   ```bash
   GODOT=/Applications/Godot.app/Contents/MacOS/Godot
   "$GODOT" --headless --path . --import                    # A0 新增 class_name 后必跑
   "$GODOT" --headless --path . res://tests/SmokeTest.tscn  # A 冒烟：退出码 0
   "$GODOT" --headless --path . --quit                      # B 启动回归：0 SCRIPT ERROR + 「配置校验通过 ✅」
   "$GODOT" --headless --path . --check-only --script res://<某脚本>.gd   # 单文件语法快速检查
   ```
4. **提交规范**：中文约定式提交（`feat(m1): …` / `fix(m1): …` / `chore(m1): …`），**每个阶段完成后自动 commit + `git push origin master`**。
5. **文档分工**：`docs/产品文档/` = 需求基线（设计事实源）；`docs/工程文档/` = 实现文档（01 换机 / 02 计划 / 03~07 各专项方案）。
6. **非静默失败**：任何失败都要有可见提示（`EventBus.toast_requested.emit(msg, "danger")`），不允许静默吞错。

## 7. 已踩过的坑（**先读这一节，能省半天**）

| # | 坑 | 结论 |
|---|---|---|
| 1 | **Godot 拖放** | 只能用 `Control` 虚方法 `_get_drag_data` / `_can_drop_data` / `_drop_data`；**代码构建的 UI 无法给 `Button` 实例挂虚方法** → 必须抽独立控件（本项目是 `scripts/ui/item_slot.gd`）。 |
| 2 | **`set_drag_preview` 挂载点不可控** | 引擎会把预览塞进任意祖先节点（实测 `Main/UI/InventoryPanel/@PanelContainer@195`），同 canvas 同 z → 被面板挡住。解法：**自绘跟随元素** `scripts/ui/drag_ghost.gd` 挂到 `UI/DragLayer`。 |
| 3 | **`z_index` 只在同一 `CanvasLayer` 内有效** | 本项目 UI 全在 `CanvasLayer(layer=1)`。层级秩序：**面板 `0` ＜ HUD `ToastBox` `2048` ＜ 拖拽幽灵 `DragLayer` `4096`**。 |
| 4 | **JSON 往返会改变字典键顺序** | 断言"实例逐字段一致"必须做**键集 + 逐键深比较**；直接 `str(dict)` 比较会**假失败**。 |
| 5 | **无头模式不锁帧** | 等待必须用 `await create_timer(秒)`，别用帧数或 `process` 累计。 |
| 6 | **截图工具要加载 `Main.tscn`** | 加载 `Game.tscn` 会**没有 HUD**（UI 在 Main 层）。 |
| 7 | **`var x := <Variant 来源>` 在"警告视为错误"下直接编译失败** | `SaveManager._read_file()` 这类返回 `Variant` 的函数，接收变量必须显式写 `var x: Variant = ...`。 |
| 8 | **`max_hp()` 由攻击派生**（4.3：攻×2 + 防×4） | 调试时直接改 `player.attack` 会连带改 HP 上限与占比 → 会误触发 3.14「危险血量保护」。测试时**必须同步补满 HP**（`AutoBattleProbe` 里踩过）。 |
| 9 | **`String.join` 需要 `PackedStringArray`** | 普通 `Array` 会报类型错误。 |
| 10 | **掉落物被瞬间吸走** | 近战射程 64px < 自动拾取半径 96px，掉落物存活约 1 帧。解法：`ground_item.gd` 加 `PICKUP_DELAY := 1.2`（落地保护期，仅拦自动拾取，点击不受限）+ 落地弧线 + 高亮圈。 |
| 11 | **编辑事故** | 避免同一条消息里对**同一文件**做 `old_string` 重叠的批量 Edit —— 曾导致整章静默丢失。 |
| 12 | **中文字体** | 用 **`SystemFont` 回退链**（`assets/themes/default_theme.tres`：PingFang SC → 微软雅黑 → Noto Sans CJK …），**不需要内置字体文件**，跨平台自动选系统字体。 |
