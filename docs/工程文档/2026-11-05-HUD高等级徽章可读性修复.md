# HUD 高等级徽章可读性修复

头像下方等级徽章原为固定35像素圆形，文字区宽29像素，四位数字可能侵入金色边缘；文字没有描边。当前角色等级上限9999，必须完整容纳四位等级。

## 修改

- 等级数字保持13号字，增加3像素深棕色描边，提升浅色数字与金边、场景背景之间的对比。
- 徽章按当前字体实际字宽加左右各10像素留白，最小宽度35像素。长数字变成金边胶囊，右缘固定，向头像一侧延展，避开右侧状态图标。
- 仅在文字或主题最小尺寸变化时重新测量；底牌样式缓存，不新增逐帧测量、纹理解码或存档字段。

## 验证

隔离窗口探针按真实升级事件依次显示1、99、999、1000、9999及再次回到1，测得徽章宽度依次为35、36、44、52、52、35像素；完整数字均可容纳，右缘不动，且不遮挡状态图标。额外检查75%、100%、150%的HUD缩放，均通过布局断言。实际查看9999级的100%和150%窗口截图，数字完整并具备深色描边；临时探针和截图验证后删除。

现有隔离回归 HudLiveTooltipTest、HudBuffTest 均通过，`git diff --check` 通过。本轮修改仅涉及等级徽章绘制及其文字布局，没有改动等级数值与升级逻辑。
