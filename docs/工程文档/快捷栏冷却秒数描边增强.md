# 快捷栏冷却秒数描边增强

## 1. 现象

快捷栏上的技能 / 药品进入冷却后，格子上会显示剩余秒数（如 `3s`）。该文字为纯琥珀色，直接压在技能图标之上；在图标本身是亮色（浅色底、白色高光）时，文字与底图对比不足，玩家难以快速读出剩余时间。

## 2. 现状证据

冷却秒数的绘制位置：[hotbar_slot.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/ui/hotbar_slot.gd#L33-L44) `_ready()` 中的 `_cooldown` Label：

- 设了 `font_size = 12` 与 `font_color = Color("ffcb71")`；
- **没有**设置 `font_outline_color` 与 `outline_size`，即无描边。

同一套 UI 中，压在图标 / 底图上的其他小字都已带深色描边，冷却秒数是唯一漏掉的一处：

| 位置 | 文字处理 |
|---|---|
| 快捷格数量角标 [hotbar_slot.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/ui/hotbar_slot.gd#L27) | `outline_size = 2`（默认黑色描边） |
| 快捷格键位角标 [hotbar_visual.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/ui/hotbar_visual.gd#L49-L50) | `font_outline_color = Color("080d10e6")`、`outline_size = 2` |
| 背包格数量 [item_slot.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/ui/item_slot.gd#L113-L114) | `font_outline_color = Color(0, 0, 0, 0.85)`、`outline_size = 2` |
| 世界飘字 [hud.gd](file:///Users/fungleo/Sites/GameProjects/DegenerateAge/scripts/ui/hud.gd#L200-L201) | `font_outline_color = Color(0, 0, 0, 0.85)`、`outline_size = 4` |

## 3. 改动

只补冷却秒数的描边，不动字色、字号、对齐、位置，也不改冷却计时逻辑：

```gdscript
_cooldown.add_theme_color_override("font_outline_color", Color(0, 0, 0, 0.85))
_cooldown.add_theme_constant_override("outline_size", 2)
```

取值口径跟随「压在图标上的数字」这一既有约定（`item_slot.gd` / `hud.gd`）：`Color(0, 0, 0, 0.85)` + `outline_size = 2`，与同格数量角标、键位角标保持统一，不在快捷栏内再造一套描边样式。

描边由字体渲染通道完成，不新增节点、纹理或材质；`_cooldown.text` 仍是原有的逐帧文本刷新，绘制成本可忽略。

- 同格左下角的药水颜色标记（`_potion_marker` 的 `R` / `B`）本次未加描边：本次需求只针对冷却秒数。若同样觉得可辨识度不足，可复用同一口径补上。
- `hotbar_slot.gd` 其余历史函数的中文函数说明仍缺失；本轮只补了文件级说明和被改动处，其余留作独立的注释补齐任务，避免在本功能提交里做大面积注释重写。
