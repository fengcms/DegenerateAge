## 0. 一句话

地面是 64×32 的等距投影，**地面上的正圆在屏幕上必须是 2:1 椭圆**。
本轮新增 `Iso` 地面原语与 `GroundFx` 绘制门面，把 20 个画在地面的元素全部改为椭圆，
其中 **10 个参与伤害判定的形状做到「画与判同源」**（等面积 √2 补偿，危险面积不变）。

---

## 1. 落地结构

### 1.1 `Iso`（几何唯一来源）

| 成员 | 语义 |
|---|---|
| `GROUND_SQUASH` = `HALF_H / HALF_W` = **0.5** | 地面纵向压缩比。**唯一来源**，禁止再写字面量 0.45 / 0.5 |
| `to_ground(p)` / `from_ground(p)` | 屏幕 ↔ 地面坐标（纵向 ×2 / ×0.5），线性、可逆 |
| `ground_dir(dir)` | 屏幕方向 → 地面单位方向。只改纵向比例，**屏幕上的指向不变** |
| `ground_distance(a, b)` | 两个屏幕点之间的地面真实距离 |
| `ground_ellipse(center, r, n)` | 地面正圆 → 屏幕椭圆点集（`r` 是**横向**半径，纵向自动减半） |
| `ground_arc(center, r, a0, a1, n)` | 地面圆弧点集（未闭合） |
| `ground_contains` / `ground_ring_contains` | 与绘制同源的包含判定 |
| `ground_diamond(center, half_w)` | 2:1 菱形（地面正方形投影），替代手写四顶点等距 |

### 1.2 `GroundFx`（绘制门面，`class_name` 静态类，不挂节点）

| 方法 | 用途 | 注意 |
|---|---|---|
| `fill(canvas, center, r, color)` | 地面圆填充 | 内部 `draw_set_transform(center, 0, (1, 0.5))` + 一次 `draw_circle`，代价最低 |
| `outline(canvas, center, r, color, w, seg)` | 地面圆描边 | **必须用折线**：`draw_arc` 的 `width` 会被压成「横向 2px、纵向 1px」 |
| `band(canvas, center, inner, outer, color, seg)` | 地面环带填充 | 拆成 N 个凸四边形逐片填充。**不要**拼「外圈正向 + 内圈逆向」的自交多边形 |
| `sector` / `sector_outline` | 地面扇形（填充 / 描边） | `dir` 取**屏幕方向**，内部转地面后在平面里旋转 |
| `band_quad(canvas, from, to, half_w, color)` | `line` 预警矩形带 | 四点在地面空间构造再投影 → 屏幕上得到**平行四边形**，不是矩形 |

> 参数约定：所有 `radius` / `inner` / `outer` / `half_width` 都是**地面半径**，
> 也就是椭圆在屏幕上的**横向**半径；所有 `center` / `dir` 都是**屏幕（世界）坐标**。

## 2. 判定口径（A′：同源 + √2 等面积补偿）

### 2.1 三方案对比（以屏幕半径 r = 128 的跺地圈为例）

| 方案 | 视觉 | 判定 | 纵向命中半径 | 最坏「看着在外却挨打」 | 危险面积 |
|---|---|---|---|---|---|
| C 现状 | 圆 128 | 圆 128 | 128 | 0 | 100% |
| B 只改画 | 椭圆 128×64 | 圆 128 | 128 | **+100%** | 100% |
| A 同源不补偿 | 椭圆 128×64 | 同椭圆 | 64 | 0 | **50%**（Boss 明显变弱） |
| **A′ 采用** | 椭圆 181×90.5 | 同椭圆 | 90.5 | 0 | **100%（面积不变）** |

采用 A′ 的理由：**「看见就是打到」是底线**（B 不可接受），而 A 会让所有纵向威胁腰斩、
污染战斗手感基线。A′ 面积守恒 ⇒ 击杀数、承伤期望不变，只是躲闪方向从「绕圈」变成「上下走位」，
而上下走位在等距视角里视觉位移只有实际的一半，本来就该是主要躲法。

### 2.2 实现要点

```gdscript
# boss_action.gd
const COMPENSATE := 1.4142135623730951   # 屏幕半径 r → 地面半径 r·√2

func geometry() -> Dictionary:           # 返回**地面空间**
    var tc := float(Iso.TILE_W) * COMPENSATE
    ...
    "fan": return {"kind": "fan", "space": "ground",
        "center": Iso.to_ground(_origin),
        "dir": Iso.ground_dir(_facing.rotated(...)),   # 地面方向
        "radius": radius_t * tc, "arc": deg_to_rad(arc_deg)}

func hits(point: Vector2) -> bool:       # point 是**世界坐标**
    var g := Iso.to_ground(point)        # ← 漏掉这一步就是「画椭圆、判屏幕圆」
    ...
```

- **中心点**：`Iso.to_ground(原屏幕中心)` —— 屏幕上落点位置与改动前完全一致（`offset` 仍按屏幕格算）。
- **长度量**（半径 / 半宽 / 长度）：一律 × `COMPENSATE`。
- **方向**：`Iso.ground_dir(屏幕方向)`；绘制时 `Iso.from_ground(地面方向)` 还原，中心线指向设计意图。
- 环击 `band` 直接吃 `geometry()` 的 `inner` / `radius`（都是地面半径），与判定同一份数据。

### 2.3 唯一例外：玩家技能范围提示

`skill_range_fx` 椭圆化但**不做补偿**。它与 `player.gd` 的施法门控 / 命中筛选（屏幕度量）共用
同一个 `range × TILE_W`，画小只会「以为打不到、其实打到了」—— 与 Boss 预警的方向相反，可容忍。
代码注释里已写明这是**刻意不一致**，不要为了「看着一致」补成 √2。

## 6. 红线

1. **禁止在 `_draw()` 里裸调 `draw_circle` / `draw_arc` 表示地面圆** —— 一律走 `GroundFx`。
2. **禁止删掉 `hits()` 里的 `Iso.to_ground(point)`** —— 那是「画椭圆、判屏幕圆」的假修。
3. **禁止调大 `COMPENSATE` 来「让 Boss 更难」** —— 它只负责等面积守恒；难度请改 `data/monsters` 的
   `radius` / `coeff`，否则数值平衡会在无人察觉的情况下漂移。
4. **UI 的圆不要动** ——「统一」的边界是世界空间的地面，不是整个游戏。
