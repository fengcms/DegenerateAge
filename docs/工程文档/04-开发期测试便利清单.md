## 2. 测试武器与正式掉落池的隔离（关键）

**问题**：`Loot._pick_equip_template()` 会从 `equipments.json` **全表随机**抽模板（tier 匹配优先）。
若直接往表里加一把 999 攻武器，怪物掉落会随机掉出这把神兵 → 污染经济与成长曲线。

**措施**：模板标 `"debug": true`；`Loot._pick_equip_template()` **跳过带该标记的模板**：

```gdscript
for e in t:
    if bool(e.get("debug", false)):
        continue        # 开发期模板不参与掉落抽取
```

回归断言见 `tests/smoke_test.gd::_test_debug_seed()`：固定种子抽取 500 次野生掉落，命中数必须为 **0**。

> 该过滤逻辑本身是**通用防护**（M5 不必移除），移除测试武器条目后自然不再命中。

## 5. 已知副作用（不修，记录备查）

- **穿装后当前 HP 不补满**：测试武器把攻击拉到 999 → `max_hp()` 按 4.3 公式派生为 2100，
  而当前 HP 保持 102（M1-7 既定规则：上限变化时保持当前绝对值，仅在上限下降时收敛）。
  血条会显得很短，但战斗不受影响（HP 充足）。若需调整测试体感，改 `equipments.json` 的 `atk` 一个数字即可。
- **测试武器可被出售**：`price: 1` → 售价 12 金币（无实际影响）。
- ~~**营地内存在精英 / Boss 测试点（M2 起，仅 debug 构建）**~~：**✅ 已于 M3 批次 1（2026-10-12）消除** —— `TEST_ELITES` 已删除，精英 / Boss 随 `maps.json` 的 `spawnPoints` / `bossSpawn` 落到各自地图，营地只保留 3 只教学木桩（`ai:false`）。历史记录：该测试点曾把裂爪狼王（L4）与腐化巨兽（L10）放进 `camp`，Boss 设 `ai:false` 不主动追击，但玩家主动靠近仍会挨打（L10 攻击 22）。
- 🔴 **长跑 / 测试工具与「实时游戏会话」互抢存档目录（2026-10-12 实测）**：`SoakTest` 会**快照整个 `saves/` 目录 → 跑完原样还原**（保护玩家存档）。但若此时**用户正开着编辑器并在编辑器内运行游戏**（`--embedded --scene res://scenes/Main.tscn`），实时游戏自身的**自动存**会与还原步骤互相覆盖：实测还原写回旧快照后，实时游戏在 2 秒内自动存又写回更新的内存态。**结果是"谁最后写谁赢"**——本次恰好实时游戏更新（未丢档），但顺序反过来就会瞬时回退玩家进度。**防护惯例**：① 跑长跑 / 任何测试工具期间**先关掉游戏会话**（编辑器内运行也算）；② 测试前后各取一次 `md5(slot_1.json)` 必须一致，不一致先排查是否有实时会话在写；③ 需要长时间挂着试玩时，别在同一工程上跑 `SoakTest`。
