## 4. 地图与交通要点

- c3_map00 为安全枢纽：普通/精英/Boss 均为 0，八个服务点集中在中街。
- 网格与掩码：全图正交逻辑格、横向 16:9；`obstacles` 为不可走多边形；沿用既有 CaveLayout/导航/地面图集入口编译同一掩码，**不把 SVG 当碰撞**。
- 门禁（[02-地图与布局](../游戏创意/21-60级内容规划/第三章/02-地图与布局.md) 出口表）：

| 出口 | 去向 | 条件 | 目标到达点 |
|---|---|---|---|
| c3_map00 P2 | c3_map01 | 本地开放 | c3_map01 [8,54] |
| c3_map00 P3 | c4_map00 | 第四章批次接入 | 随 c4_map00 落地时登记 [4,27] |
| c3_map01 P2 | c3_map02 | `c3_access_02` | c3_map02 [8,59] |
| c3_map02 P2 | c3_map03 | `c3_access_03` | c3_map03 [9,63] |
| c3_map03 P2 | c3_map04 | `c3_access_04` | c3_map04 [7,50] |
| c3_map03 P3 | c3_map05 | `c3_access_05` | c3_map05 [8,59] |

- 返回边一律不锁；正向只在对应任务 `rewarded` 后解除。
- **唯一旧图改动**：沉井镇新增至 c3_map00 的双向步行边与相邻 `hubLinks`，候选落点 [80,27] 须与当前沉井镇实图掩码/NPC 核查（见 [90 §3](../游戏创意/21-60级内容规划/90-工程开发AI交接计划.md)）。
- 车夫只连本集群附属图与相邻枢纽，不跳过主线首次探索；免费步行永远可完成主线。

| 场景 | 预期 |
|---|---|
| C2Q12 已领奖旧档接 C3 | 显示相邻枢纽；未访问野外不能车夫跳关 |

| 新招式多段与死亡 | 单段不重复命中；死亡/切图释放预警与动作状态 |
