# Boss技能表现美化开发与验收记录

本记录说明2026-10-31接入的程序化Boss技能表现、兼容边界与实际窗口测量。对应[美化方案](../素材设计/Boss技能表现美化方案.md)。本次完成代码接入、专项逻辑回归和窗口样板验收；完整地图30分钟战斗、亮色地图/最大倍率的交互验收尚未执行，不将专项数据视为整场战斗60 FPS承诺。

## 1. 实现结果与原问题

原预警主要依靠单色几何，命中后缺少主题反馈。现在17个Boss均登记独立主题，覆盖裂纹、工业棱纹、符印、砂纹、骨纹、林风、孢子、根须、潮汐和眼纹等组合。统一暖色危险边界、逐渐增强的填色与主题进度纹样，命中瞬间短闪后消散；阶段转换出现不造成伤害的小符印，巨兽普通攻击增加短爪弧。

- `data/bossVisuals.json`仅登记颜色、纹样与密度，不复制伤害、半径和时间。DataLoader统一加载和校验；第七章复用原Boss ID自动取得相同主题。
- `BossAction.visual_impact`在既有结算入口发出锁定几何，表现不能反向触发伤害。第一章践踏仍走原到期结算，第二章抽出同源几何供绘制与原语义判定共用。
- `BossSkillVisual`负责圈、胶囊线、扇、环及命中残纹。线的完整圆头现在覆盖原有胶囊判定；所有地面几何保持2:1等距投影，环击不填中心安全区。
- 每个Boss增加一个无物理处理的`BossSkillCanvas`，绝对z=-3501，位于地形之上、实体之下；预警不再随Boss实体深度覆盖玩家。普通怪不创建该节点。
- 时间由原物理帧推进，继承暂停和Engine时间缩放。死亡、脱战归位、退出节点时清空残留；数据重载更新主题并清除旧残纹。不添加存档字段。

## 2. 成本、所有权与释放

17个主题在数据加载期读取，宿主初始化/重载时取得小字典副本；热路径不读文件或解析JSON。每Boss最多3段命中记录，每段0.56秒，100Boss上限300段，逐物理帧推进，退出立即回收。全局命中详细装饰最多24份，屏外命中不占装饰额度；同渲染帧预警详细纹样最多8份，屏外跳过次要纹样。超过预算仍画完整危险边界、渐强填色和主要命中轮廓，不删除战斗事件。

初版窗口测量暴露了18技能装饰叠加成本：314→586次绘制调用，绘制脚本中位1.655→2.092ms。移除重复透明形状、收紧纹样预算后，最终复核为275次及1.108ms。

环带复用`FlatTileMesh`将48个不相交四边形合成一次网格绘制；网格键为内外半径，颜色和中心不入键，不填安全中心。进程级不可变缓存最多32项，超限清空重建；网格与地图、数据颜色无关，无需随切图失效。首次遇到新半径最多构建192顶点/288索引，后续共用；Canvas绘制命令持有的旧网格由引擎随命令释放。无粒子节点、动态灯光、全屏后处理或新纹理资源。

## 3. 真实窗口对照

设备Apple M1 Max，Godot 4.7.2，GL Compatibility/OpenGL 4.1 Metal；窗口1280×800，关闭垂直同步，限制120 FPS。`BossVisualBenchmark`使用固定圈/环/扇/线几何与数量，旧版分支复现原绘制，新版调用正式入口。每组预热20帧、采120帧；最终复核将环带旧基线的颜色、外边宽度和内圈32段精确恢复为改造前代码；不含AI、移动、装备结算、地图和掉落。整帧栏是连续frame_post_draw墙钟间隔，包含调度及帧率限制；绘制脚本耗时不是GPU耗时。

## 4. 验证与复现

通过：`BossSkillVisualTest`、`BossActionTest`、`BossReviewTest`、`ChapterTwoEncountersTest`、`SmokeTest`。新用例覆盖锁定几何与伤害事件次数、单Boss残留上限、全局装饰预算、宿主释放回收、17Boss映射、非法样式拒绝、环带网格复用与安全中心、缓存上限。第二章四种形态以独立旧公式逐点对照（每形态660点），没有放宽原断言。新测试加入默认集，103项仍为常用子集，不表示全量回归已执行。

窗口通过：`BossVisualSamples`（践踏、双线、环击完整动效）、`BossVisualGallery`（17主题各预警/命中共34张）、`BossVisualBenchmark`。截图仅写`/tmp`，动效预览放工作区外的Codex可视化目录，不混入运行资源。主题画廊自动取景，避免偏移圈与长线在截图中被裁切；正式游戏不改变相机。

```bash
python3 tools/run_isolated_tests.py BossSkillVisualTest BossActionTest BossReviewTest ChapterTwoEncountersTest SmokeTest
python3 tools/run_isolated_tests.py --rendered BossVisualSamples BossVisualGallery BossVisualBenchmark
```

复核重点：原预警首帧边界、双线分段与间隔、环击安全中心、第二章多爆圈只结算一次、死亡/归位清除、玩家站在Boss前后均不被地面层覆盖。自动测试提供逻辑与绘制证据，不能替代完整战斗手感验收。
