# 06 经济与 NPC 系统

本章定义金币经济模型、安全区与 NPC 通用交互，以及五类功能性 NPC（货郎 / 铁匠 / 车夫 / 任务官 / 仓库）。

## 6.1 金币经济总览

- **金币是玩家的货币**。
- **来源**：怪物掉落金币；出售装备给 NPC（每件装备有金币价格）。
- **用途**：向货郎购买药水（分级）；装备升星（主要消耗途径）。
- 经济闭环：`刷怪掉金 + 卖装 → 买药 / 升星 → 更强 → 刷更高级怪`。

## 6.2 数值与经济模型（初始参数）

**金币产出 / 消耗量级（目标比例）**：

| 项 | 量级 | 说明 |
|---|---|---|
| 普通怪金币 | `level×3`（±20%） | 约 300–500 只 / 小时 |
| 精英金币 | `level×15` | — |
| Boss 金币 | `level×80` | — |
| 小时净产出（仅刷怪） | ≈ `level×1000` | 粗估，待埋点 |
| 药价（小 / 中 / 大） | 20 / 60 / 150 | 文本可配 |
| 升星成本 | 随星递增（见 6.2 公式） | 主要消耗 |
| 仓库 / 背包扩容 | 前 16 档几何递增 BASE=1000, R=1.6；200→400 格平价尾段 | 见 6.8 |

**关键公式（初始参数）**：

```
升星金币成本：upgradeCost(star) = round( UP_BASE × UP_R^star )
             UP_BASE=500, UP_R=1.5（0→1 低费，随星陡增）

装备售价：   sellPrice = round( baseValue × tierValueMult × qualityMult × (1 + star×0.08) )
             qualityMult：普1 / 优1.5 / 稀3 / 史6 / 传12
             tierValueMult：Lv1=1 / Lv10=2 / Lv20=3.5（首版配置，可试玩调优）

非装备售价： sellPrice = round( baseValue × 0.6 ) × count
             （药水 / 杂项 / 如意统一六折回收；整叠一次卖完，count 为叠内数量）
             回收比例低于买价 ⇒ 不存在「买入再卖出」的无损套利

金币上限：   999,999,999（达上限后不再拾取金币并提示）
             **出售永不受上限限制**（2026-10-20 修订，D-22）：金币已满时仍可正常卖出，
             只是入账额按「上限 − 当前余额」截断，差额以「金币已达上限，超出部分未计入」提示；
             绝不因钱包装不下而把物品退回。
```

- 目标：刷约 30 分钟可完成前 **3 星**左右（M1 校准实测：L2–5 阶段一轮「6 狼＋2 虫＋1 精英」≈108 金 + 装备卖价 ≈48 金，约 **100 金/分钟**；早期升星成本低，故远快于原「1 星」估计）。
- 所有数值为起始参数，试玩调优后定稿。

### 循环图金币产出口径（2026-10-20 定案）

| 循环图 | 单只金币 | 说明 |
|---|---|---|
| 聚金地脉 `c7_gold_field`（普通怪） | **440–560（均值 500）** | 第六章普通怪 `44–56` 的 ×10；15 秒重生，6 堆 × 16 席、同屏上限 32 |
| 无尽回廊 `c7_arena`（Boss） | 3,000–3,400（不缩放） | 叠加装备回收后单只期望约 1.16 万金 |
| 百首禁域 `c7_boss_field`（Boss） | 3,000–3,400（不缩放） | 装备条目期望翻倍，单只期望约 2.0 万金 |

- **与 Boss 路线的对照**：打 Boss 的「掉落件数」体面，但单位时间金币低；聚金地脉单只看似廉价，却因击杀密度高而成为金币主产出。按单位时间算，满堆打金图约 **1,375 金币/s**（含装备回收），约为循环 Boss 路线（约 **386 金币/s**）的 **3.6 倍**，确认打金图的定位。
- **药水消耗是金币回收的一环**：怪物 → 玩家的不破防伤害下限改为按最大生命比例（`clampi(maxHP × 0.25%, 10, 60)`，见《03 核心循环与战斗系统》§3.2），使高等级自动喝药必然触发，让「刷钱 → 买药」的回流真实发生，避免药水经济空转。

## 6.3 安全区与 NPC 通用交互

- **安全区（safe zone）**：只有城镇地图配置局部矩形安全区，覆盖功能性 NPC（货郎 / 铁匠 / 车夫 / 任务官 / 仓库）及城镇回城落点。营地矩形外仍可战斗；其他现有地图全图为危险区，野外车夫、道路出入口不产生免战圈。玩家可自由穿过安全区；怪物不在区内刷新，也不会主动走入追击。区内玩家攻击与怪物攻击均不造成伤害。
- **通用交互**：点击 NPC → 弹出对话框（NPC 自我介绍 + 功能菜单）→ 选功能进入对应面板。所有 NPC 的**商品 / 任务 / 对话文本均以文本可编辑配置**。
- **键盘入口（等价交互）**：靠近 NPC（≤ **2 格**）后按 **`E`** 即可对话 / 开店；鼠标左键点 NPC、右键点 NPC 为等价入口。远处点击会先步行靠近，手动移动可取消待执行交互（M4-2）。
- 与功能 NPC 对话期间，已开启的自动战斗保留开关状态但暂停寻怪、移动、攻击和自动拾取；关闭该 NPC 面板后立即重新决策。普通背包、人物、技能、坐骑等非 NPC 面板仍允许挂机。对话中可按 F 或点头像旁自动战斗图标主动开关自动战斗。

## 6.4 货郎（Peddler）

安全区常驻，负责交易。

- **出售给玩家**：① 药品（不同等级地图的货郎，出售药品等级不同）；② 随机券（当前地图内随机传送）；③ 回城卷（回当前地图所属城镇的安全落点）；④ 复活卷（复活到死亡位置）。
- **卷轴使用口径**：回城卷按当前地图的 `hubId` 返回本区域安全城镇：第一章野外回幸存者营地，第二章野外回沉井镇；已在所属城镇、死亡、城镇不存在／未解锁或世界不可用时不消耗。背包双击与快捷栏共用入口。随机券同样可经这两种入口传送到当前地图内可通行且从当前位置可到达的位置。二者均在校验成功后才消耗 1 张。复活卷仅在死亡选择界面消耗，成功后原地复活，不可拖入快捷栏；烟花仍未接通。
- **收购玩家物品（2026-10-17 修订）**：玩家可向货郎出售**装备、药水、杂项材料与如意**换取金币。任务物品（任务袋物品）与无价物品不收。非装备按 §6.2 的六折回收，**整叠一次卖完**；装备售价公式与回收比例不变。
  - 修订理由：药品与材料只进不出会让背包格子持续被低价值物品占用，玩家缺一条把「用不完的战利品」换回金币的通道。
  - 六折而非原价：药水买价即 `potions.price`，原价回收等于「金币 ⇄ 药水」无损兑换，会稀释金币掉落的意义。
- **对话框**：自我介绍 + 菜单（购买物品 / 出售物品）。
  - **购买面板**：物品列表，每项含介绍与价格，右侧购买按钮。
  - **出售面板（出售托盘）**：与**背包面板并列**显示（左背包、右货郎），两窗按实际宽度紧挨摆放，仅留小间隙；把背包里的**物品**（装备 / 药水 / 杂项 / 如意）**拖拽到出售托盘**（一格一件，堆叠品整叠占一格；先暂存、未结算）。整个托盘网格含格间空隙均可投放，空隙归最近格；玩家放到哪一格，物品就留在该格，不自动压缩排序。占用格拒绝新投放并提示。
    - 点托盘中的物品可取回背包；货郎「挑选装备」从 Lv1 即可使用，与背包「出售装备」共用预设和本次逐件勾选清单。确认只把所选背包装备整批移入托盘空格（一格一件，已有格位不变），**不立即结算金币**；空格不足时整批拒绝，不只移入前几件。背包内直接出售仍须 Lv15，以引导前期玩家找 NPC 交易（产品方案 14）。
    - **「一键移入药品」（2026-10-20 由「一键移入材料」收窄）**：只把背包中的**药水**批量移入空格（排除任务物品）。卷轴（杂项）与如意**不再自动移入** —— 卷轴随时可能要用、如意是升星材料，误卖代价远高于药水，需要时单独拖入即可。两键语义互斥 —— 「挑选装备」只列装备，「一键移入药品」只搬药水，避免把保命药当成低价值装备整批卖掉。
    - 托盘 tooltip：整叠物品显示「单价 X 金币 × N 件」与总价；如意额外提示「升星材料，出售后不可撤回」，托盘含如意时结算区出现升星材料告警（与「优于已穿戴」告警分行显示）。
    - 预设会保护**评分高于已穿戴同槽装备**的装备和已收藏装备；默认替换槽为空时不计入该评分保护。未收藏的高价值装备可手动勾选并额外确认。手动拖入仍可用，但收藏装备须先解锁；
    - 托盘下方为结算金币数与「确认出售」按钮，点确认才真正结算为金币；出现不可售物时托盘不清空。**金币容量不足不再是拒绝理由**（D-22）：照常结算，入账截断到上限，并在汇总提示后补一句「金币已达上限，超出部分未计入」；
    - 关闭面板（`E` / `Esc` / `×`）时，托盘内未确认的装备**自动退回背包**（不静默丢失）；
    - 手动将高于自身穿戴的装备拖入托盘时，点确认需**弹二次确认对话框**。
  - **首版实现说明**（M1）：并列双面板 + 拖拽出售 + 托盘暂存 + 确认结算已实现（工程文档 05）。
    手拖升级件时的**二次确认对话框**、以及对话框式的 NPC 自我介绍 + 功能菜单，随 M4 面板完善一并补齐（首版以托盘结算区的警示行 + 提示文案代替弹窗）。

## 6.5 铁匠（Blacksmith）

安全区常驻，提供升星、重铸、四金合紫、四紫定向和保星升级。对话框先自我介绍，再选择服务。升星仍采用十字 5 格面板；四个如意格可选填，下方显示基础 / 加成 / 最终成功率、所需金币和升星按钮。点击后按所选如意扣除库存；无论成功失败均消耗金币和已选如意。

合成消耗四件装备、不另收金币，结果品质为紫色传说；四金取最低档随机类型，四紫要求同档并可指定类型。保星升级消耗两件紫装（12 星旧件 + 任意更高档 0 星新件）和**按跨档数计价**的金币：跨 1 档为 0→12 全部一次成功的金币和，当前为 128,747；每多跨 1 档再加 1 份基准价（跨 2 档 257,494、跨 3 档 386,241）。产物确定为高档 12 星，词条重新随机，**不再按概率升 12 次**。材料与产物的精确约束见 05 §5.13。

服务菜单按**强化**（升星、重铸）与**合成**（四金合紫、四紫定向）两组排列，每组带一句材料口径说明；保星升级有跨档扣费规则，独占一整行并单列说明；「离开」与「继续」固定在面板底部操作行，不再混进服务按钮。

进入三种合成服务时同时打开背包和合成工作台。玩家拖入材料格、撤下或随机放入都只修改预选；随机放入只在四件合成中可用，默认保护带星与收藏装备。关闭工作台后背包保持打开，背包关闭则结束整个合成会话；NPC 会话期间自动战斗按既有规则暂停。

合成会话中**可以同时打开人物面板**（按 C 不再关掉工作台）：保星**第一格**接收从身上直接拖来的 12 星旧件，确认后该穿戴槽清空、产物进背包；第二格与四金 / 四紫仍只收背包件，货郎出售托盘**不接受**身上装备。人物面板是普通浮窗，与工作台重叠时由玩家自己拖开标题栏摆放（不自动重排布局）。

## 6.6 车夫（Carter）

安全区常驻，负责地图切换。对话框：自我介绍 + 地图菜单；点击扣金币切换地图。

**可达范围（城镇集群模型）**：地图分**枢纽城镇**与**附属地图**两级；**集群** = 一座城镇 + 从它辐射出的全部附属地图。车夫可选目的地 = **本集群全部地图 ∪ 相邻城镇 − 当前地图**：

| 关系 | 可否一次付费直达 |
|---|---|
| 本镇 ⇄ 本镇各附属（含附属之间互达） | ✅ |
| 本镇 ⇄ 相邻城镇 | ✅ |
| 前往**其他城镇的附属地图** | ❌ 须先到该城镇再**换乘**（2 跳） |

- 「**需中转增加趣味**」保留，但**中转层级由「图」上移为「镇」**（原"每图仅连相邻 1–2 图"的口径已废止，拓扑见 7.8）。
- **同一集群内每张地图的车夫菜单相同**（= 集群 − 当前地图），只是按当前位置标注。
- **到访门控**：目标地图需**已到访**才开放付费直达（教学线路除外）；首次抵达须走**免费步行道路**（见 7.8）。

## 6.7 任务官（Quest Officer）

安全区常驻，负责发布 / 检查任务（详见《08 任务系统》）。主要任务为**打怪数量**（当前地图及附属地图）；满足数量后奖励金币 + 经验。玩家**最多同时接 5 个任务**。

## 6.8 仓库（Warehouse）

安全区常驻，负责背包物品**存储**。

- **存储格**：初始 **40 格**；玩家可**存入 / 取出 / 查看背包中的任何物品**（装备、药品、如意、杂项、任务物品；金币作为独立货币不占背包格）。支持双击 / 拖拽，堆叠物品整堆转移，不会无提示地部分移动。
- 仓库面板有独立「整理」按钮，规则与背包整理相同；只调整仓库内部格位，不影响背包。存取与整理后的物品及容量均需入档。
- **扩容**：玩家可用**金币购买更多存储格**；扩容价格**分段**（前段几何增长、尾段平价）：
  ```
  前 16 档（40→200 格）：expandCost(k) = round( BASE × R^k )，BASE=1000, R=1.6
  第1档(40→50)=1000；第2档(50→60)=1600；第3档=2560；第4档=4096……第16档(190→200)=1,152,922
  尾段（200→400 格）：以几何段末档为锚点平价，每档同价 1,152,922
  扩容上限为 400 格（配置项 cap，前段分界由 geoCap=200 决定）
  ```
  首版 0→200 格累计约 307 万金，买满 400 格累计约 2613 万金；任一档均远低于金币上限，不会出现买不到的档位。
- 仓库内物品**不占背包空间**，且**不计入死亡掉落**（死亡惩罚仅作用于背包内物品）。
- 仓库容量与扩容价格配置同样**文本可编辑**。
