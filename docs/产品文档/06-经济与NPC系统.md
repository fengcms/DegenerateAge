# 06 经济与 NPC 系统

本章定义金币经济模型、安全区与 NPC 通用交互，以及五类功能性 NPC（货郎 / 铁匠 / 车夫 / 任务官 / 仓库）。

## 6.1 金币经济总览

- **金币是玩家的货币**。
- **来源**：怪物掉落金币；出售装备给 NPC（每件装备有金币价格）。
- **用途**：向货郎购买药水（分级）；装备升星（主要消耗途径）。
- 经济闭环：`刷怪掉金 + 卖装 → 买药 / 升星 → 更强 → 刷更高级怪`。

## 6.2 数值与经济模型（初始参数）

**金币产出 / 消耗量级（目标比例）**：

| 项 | 量级 | 说明 |
|---|---|---|
| 普通怪金币 | `level×3`（±20%） | 约 300–500 只 / 小时 |
| 精英金币 | `level×15` | — |
| Boss 金币 | `level×80` | — |
| 小时净产出（仅刷怪） | ≈ `level×1000` | 粗估，待埋点 |
| 药价（小 / 中 / 大） | 20 / 60 / 150 | 文本可配 |
| 升星成本 | 随星递增（见 6.2 公式） | 主要消耗 |
| 仓库扩容 | 几何递增 BASE=1000, R=1.6 | 见 6.8 |

**关键公式（初始参数）**：

```
升星金币成本：upgradeCost(star) = round( UP_BASE × UP_R^star )
             UP_BASE=500, UP_R=1.5（0→1 低费，随星陡增）

装备售价：   sellPrice = round( baseValue × tierValueMult × qualityMult × (1 + star×0.08) )
             qualityMult：普1 / 优1.5 / 稀3 / 史6 / 传12
             tierValueMult：Lv1=1 / Lv10=2 / Lv20=3.5（首版配置，可试玩调优）

金币上限：   999,999,999（达上限后不再拾取金币并提示）
```

- 目标：刷约 30 分钟可完成前 **3 星**左右（M1 校准实测：L2–5 阶段一轮「6 狼＋2 虫＋1 精英」≈108 金 + 装备卖价 ≈48 金，约 **100 金/分钟**；早期升星成本低，故远快于原「1 星」估计）。
- 所有数值为起始参数，试玩调优后定稿。

## 6.3 安全区与 NPC 通用交互

- **安全区（safe zone）**：只有城镇地图配置局部矩形安全区，覆盖功能性 NPC（货郎 / 铁匠 / 车夫 / 任务官 / 仓库）及城镇回城落点。营地矩形外仍可战斗；其他现有地图全图为危险区，野外车夫、道路出入口不产生免战圈。玩家可自由穿过安全区；怪物不在区内刷新，也不会主动走入追击。区内玩家攻击与怪物攻击均不造成伤害。
- **通用交互**：点击 NPC → 弹出对话框（NPC 自我介绍 + 功能菜单）→ 选功能进入对应面板。所有 NPC 的**商品 / 任务 / 对话文本均以文本可编辑配置**。
- **键盘入口（等价交互）**：靠近 NPC（≤ **2 格**）后按 **`E`** 即可对话 / 开店；鼠标左键点 NPC、右键点 NPC 为等价入口。远处点击会先步行靠近，手动移动可取消待执行交互（M4-2）。
- 与功能 NPC 对话期间，已开启的自动战斗保留开关状态但暂停寻怪、移动、攻击和自动拾取；关闭该 NPC 面板后立即重新决策。普通背包、人物、技能、坐骑等非 NPC 面板仍允许挂机。对话中可按 F 或点头像旁自动战斗图标主动开关自动战斗。

## 6.4 货郎（Peddler）

安全区常驻，负责交易。

- **出售给玩家**：① 药品（不同等级地图的货郎，出售药品等级不同）；② 随机券（当前地图内随机传送）；③ 回城卷（回当前地图所属城镇的安全落点）；④ 复活卷（复活到死亡位置）。
- **卷轴使用口径**：回城卷按当前地图的 `hubId` 返回本区域安全城镇：第一章野外回幸存者营地，第二章野外回沉井镇；已在所属城镇、死亡、城镇不存在／未解锁或世界不可用时不消耗。背包双击与快捷栏共用入口。随机券同样可经这两种入口传送到当前地图内可通行且从当前位置可到达的位置。二者均在校验成功后才消耗 1 张。复活卷仅在死亡选择界面消耗，成功后原地复活，不可拖入快捷栏；烟花仍未接通。
- **收购玩家装备**：玩家可向货郎出售任意装备换取金币。
- **对话框**：自我介绍 + 菜单（购买物品 / 出售物品）。
  - **购买面板**：物品列表，每项含介绍与价格，右侧购买按钮。
  - **出售面板（出售托盘）**：与**背包面板并列**显示（左背包、右货郎），两窗按实际宽度紧挨摆放，仅留小间隙；把背包里的装备**拖拽到出售托盘**（一格一件，先暂存、未结算）。整个托盘网格含格间空隙均可投放，空隙归最近格；玩家放到哪一格，装备就留在该格，不自动压缩排序。占用格拒绝新投放并提示。
    - 点托盘中的装备可取回背包；货郎「一键移入」从 Lv1 即可使用，把背包中同时满足等级与成色阈值的装备批量移入空格（一格一件，阈值与背包一键出售共用）；背包内直接「一键卖出」仍须 Lv15，以引导前期玩家找 NPC 交易。
    - 一键移入不再按已穿戴装备评分判断；手动拖入任意装备仍可用，且应提示潜在高价值装备；
    - 托盘下方为结算金币数与「确认出售」按钮，点确认才真正结算为金币；
    - 关闭面板（`E` / `Esc` / `×`）时，托盘内未确认的装备**自动退回背包**（不静默丢失）；
    - 手动将高于自身穿戴的装备拖入托盘时，点确认需**弹二次确认对话框**。
  - **首版实现说明**（M1）：并列双面板 + 拖拽出售 + 托盘暂存 + 确认结算已实现（工程文档 05）。
    手拖升级件时的**二次确认对话框**、以及对话框式的 NPC 自我介绍 + 功能菜单，随 M4 面板完善一并补齐（首版以托盘结算区的警示行 + 提示文案代替弹窗）。

## 6.5 铁匠（Blacksmith）

安全区常驻，负责装备升星（见 5.6）。对话框：自我介绍 + 菜单（升星装备）→ 十字 5 格升星面板；四个如意格可选填，下方显示基础 / 加成 / 最终成功率、所需金币和升星按钮。点击后按所选如意扣除库存；无论成功失败均消耗金币和已选如意。

## 6.6 车夫（Carter）

安全区常驻，负责地图切换。对话框：自我介绍 + 地图菜单；点击扣金币切换地图。

**可达范围（城镇集群模型）**：地图分**枢纽城镇**与**附属地图**两级；**集群** = 一座城镇 + 从它辐射出的全部附属地图。车夫可选目的地 = **本集群全部地图 ∪ 相邻城镇 − 当前地图**：

| 关系 | 可否一次付费直达 |
|---|---|
| 本镇 ⇄ 本镇各附属（含附属之间互达） | ✅ |
| 本镇 ⇄ 相邻城镇 | ✅ |
| 前往**其他城镇的附属地图** | ❌ 须先到该城镇再**换乘**（2 跳） |

- 「**需中转增加趣味**」保留，但**中转层级由「图」上移为「镇」**（原"每图仅连相邻 1–2 图"的口径已废止，拓扑见 7.8）。
- **同一集群内每张地图的车夫菜单相同**（= 集群 − 当前地图），只是按当前位置标注。
- **到访门控**：目标地图需**已到访**才开放付费直达（教学线路除外）；首次抵达须走**免费步行道路**（见 7.8）。

## 6.7 任务官（Quest Officer）

安全区常驻，负责发布 / 检查任务（详见《08 任务系统》）。主要任务为**打怪数量**（当前地图及附属地图）；满足数量后奖励金币 + 经验。玩家**最多同时接 5 个任务**。

## 6.8 仓库（Warehouse）

安全区常驻，负责背包物品**存储**。

- **存储格**：初始 **40 格**；玩家可**存入 / 取出 / 查看背包中的任何物品**（装备、药品、如意、杂项、任务物品；金币作为独立货币不占背包格）。支持双击 / 拖拽，堆叠物品整堆转移，不会无提示地部分移动。
- 仓库面板有独立「整理」按钮，规则与背包整理相同；只调整仓库内部格位，不影响背包。存取与整理后的物品及容量均需入档。
- **扩容**：玩家可用**金币购买更多存储格**；扩容价格**递增**（几何增长）：
  ```
  expandCost(k) = round( BASE × R^k )，BASE=1000, R=1.6
  第1档(40→50)=1000；第2档(50→60)=1600；第3档=2560；第4档=4096……（初始参数）
  扩容上限可配置（如封顶 200 格）
  ```
- 仓库内物品**不占背包空间**，且**不计入死亡掉落**（死亡惩罚仅作用于背包内物品）。
- 仓库容量与扩容价格配置同样**文本可编辑**。
