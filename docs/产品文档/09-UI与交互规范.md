# 09 UI 与交互规范

本章定义 HUD 布局、快捷栏、四面板、设置、菜单、战斗信息呈现、Toast、加载、对话、拾取、右键、缩放与新手引导。美术为复古像素 / 斜角 2D，允许占位素材；MVP 换装只改数值不改精灵外观。

## 9.1 HUD 布局（文本示意）

```
┌──────────────────────────────────────────────────────────────┐
│ (●)人物名                  ┌────────┐              ⚙(设置)   │
│   ▇▇▇ 血槽                 │ NPC头像│   ╭───╮              │
│   ▇▇ 蓝槽     ●Lv5         │ 名称   │  │地图│ 地图名          │
│                           │ 血/蓝  │  │ ◯ │ 经纬度(col,row) │
│                           └────────┘  ╰───╯              │
│                               任务列表：⚑ 击败 5 只腐化野狼（点击规划路径，可跨图）   │
│                   （世界视图：战斗 / 移动 / 探索）                │
│                                                                │
│                                                                │
│ [技][药][药][药]...[人][包][技][骑]   ← 16格快捷栏(左12+右4)    │
│ ▓▓▓▓▓▓ 经验进度条(悬停显数字) ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓              │
│              │
└──────────────────────────────────────────────────────────────┘
```

1. **左上角 — 玩家状态区**：头像为圆圈；圆圈右侧从上到下为人物名称、血槽、蓝槽；圆圈右下角叠加小圆圈显示等级数字。
2. **头像右侧安全区 — 目标状态区**：显示当前对战怪物或对话 NPC 的头像、名称、血槽、蓝槽；无目标时为空。
3. **右上角 — 小地图区**：圆形；上方显示地图名；中间显示玩家经纬度坐标；边框放设置图标（点击开设置）；点击小地图本体开大弹窗显示大地图，点击大地图可移动到点击位置。
4. **界面下方居中 — 快捷栏（16 格）**：左起 12 格为技能 / 药品快捷格（键 1 2 3 4 5 6 7 8 9 0 - =）；其余 4 格为人物 / 背包 / 技能 / 坐骑图标（各有默认快捷键，可在设置重映射）。可拖放技能 / 药品到 12 格。
   - ⏳ **M4 落地前**（M2.5 临时口径）：先用 `1` = 喝红药、`2` = 喝蓝药（走"按缺口选最小够用档"的挑瓶逻辑），正式快捷栏接管后这两个键位即成为前两格的默认内容。
5. **16 格下方 — 经验进度条**：通栏；默认不显示经验数字，悬停显示当前 / 升级所需。
6. **小地图下方 — 任务列表**：显示已接受任务及完成情况；需击杀怪物名高亮 + 下划线；点击自动规划路径前往（可跨地图）。

## 9.2 面板与弹窗（四面板）

- **人物属性面板**：左侧人物形象 + 14 装备槽位；右侧 12 项属性数值（见 4.2）；装备槽悬停浮动显示属性；右上角关闭按钮。
- **背包面板**：上方格子（每格一件物品）+ 下方金币数；悬停浮动显示物品属性；装备悬停出现**两个**浮动面板（当前装备 + 已穿戴同类型对比）；**双击穿戴 / 使用；点击装备槽位卸下（背包无空位时不可卸下）**；拖拽到地面丢弃。
  - 「使用」的品类分流（M2.5）：**药水**双击即使用，tooltip 显示恢复量与冷却 / 冷却中剩余秒数；装备仍为穿戴；任务物与杂项明确提示不可使用。另可用 `1`（红药）/ `2`（蓝药）快捷使用，见 9.1。
  - **与货郎交易时例外**：本面板**与货郎面板并列**（左背包、右货郎）而不互斥，且背包格开放**拖出**——把装备拖到货郎的出售托盘即完成出售（6.4，见工程文档 05）。
  - 面板互斥规则：除交易会话外，同一时刻只显示一个关闭式面板；交易会话中 `I` / `E` / `Esc` 均结束整场交易。
- **技能面板**：左侧图标 + 名称 + 说明；点击图标可拖到快捷栏空白格（已有则替换）；右上角关闭。
- **坐骑面板**：按 N 或点击快捷栏坐骑入口打开，显示已收藏坐骑的大图、名称与移动速度加成，可选择骑乘或下骑；右上角关闭。未达 20 级可查看收藏，但骑乘按钮禁用并显示等级门槛。未获得坐骑时明确显示获取来源。
- **浮层层级约定**：拖动中的物品**跟随光标浮动**，且**必须绘制在所有面板之上**，不得被任何面板遮挡；同理，提示条（toast）与悬停浮动属性在面板打开时仍应可见。凡"跟随鼠标 / 恒在最上"的元素，其层级要求优先于面板本身。

## 9.3 设置面板字段

- **音频**：音乐音量 / 音效音量 / 屏震开关 / 强光闪烁开关。
- **画面**：UI 缩放(80/100/120/150%) / 文字缩放 / 全屏↔窗口 / 分辨率。
- **游戏**：自动战斗默认关 / 自动拾取默认关 / 喝药血量阈值 / 搜索半径 / 品质过滤。
- **控制**：全快捷键可重映射列表 + 冲突提示。
- **数据**：存档管理（手动存 / 备份 / 删除）。

**M4-6 实施边界（2026-10-12）**：设置由右上角齿轮进入，按当前活动存档槽保存。音乐 / 音效音量分别作用于 Music / SFX 声道；现阶段尚未接入游戏音乐与音效资源，因此音量值可改可存，但需在接入声源后做听感验收。UI 与文字缩放、窗口/全屏、分辨率选择即时生效；改键覆盖移动、战斗、面板和 12 个快捷格，冲突时由玩家确认交换。自动战斗和自动拾取的**运行态默认关闭**保持不变。屏震、强闪与品质过滤只保存配置，相关战斗特效及掉落过滤尚未接线，界面明确标注该限制；不得把它们算作已生效的玩法。

**技能面板当前边界**：展示 `skills.json` 中的名称、说明及解锁等级；只有已接通战斗的基础斩击可拖入快捷栏。未接线的主动技能不可拖入，避免玩家以为可以施放。红/蓝药默认位于快捷格 1/2，普攻默认位于格 3；其余格位为空，后续技能系统接线后开放。人物面板展示 14 装备槽与 4.2 所列 12 项属性，点击已穿戴装备可卸下；背包仍保留穿戴操作。快捷栏末 4 格分别打开人物、背包、技能、坐骑。

## 9.4 主菜单 / 暂停菜单 / 读档界面

- **主菜单**：新游戏 / 继续(若有存档) / 读取存档 / 设置 / 退出。
- **暂停菜单**（Esc）：继续 / 设置 / 保存 / 返回主菜单（停止模拟）。
- **读档界面**：3 张存档卡，显示角色名 / 职业 / 等级 / 地图 / 存档时间；操作 新建 / 读取 / 删除(二次确认)。

## 9.5 战斗信息呈现

- **伤害飘字**：普通 = 白色；暴击 = 黄色加大；格挡 = 蓝色；治疗 = 绿色。
- **血条数值**：默认隐藏，悬停 / Boss 血条显示具体数值。
- **目标选中指示**：选中怪物 / NPC 脚下高亮圈 + 头顶名称条。
- **攻击范围指示**：锁定目标后，地面绘制玩家到目标的连线（虚线），并在目标周围绘制所选攻击方式的攻击范围指示环；超出范围时高亮为"需接近"色，进入范围转为"可攻击"色（与 3.15 超距自动走位联动）。

## 9.6 系统提示 Toast

类型：升级 / 任务完成 / 掉落 / 拾取 / 拾取失败(背包满) / 金币不足 / 升星成功失败 / 地图解锁。屏幕中上短暂淡出(2s)，不阻塞操作；重要(解锁)稍长。

## 9.7 加载界面

启动 / 切图显示加载页：进度条 + 随机世界观提示语；不做无缝加载（单机可接受）。

## 9.8 对话系统推进

点击"继续"逐句推进 NPC 自我介绍；末句展开功能菜单（购买 / 出售 / 升星 / 任务等）；首版无分支选项（预留）。

## 9.9 拾取交互澄清

**主流路径｜怪物掉落（工程文档 10 方案 C）**：
- **生成即入包**：掉落产生的**当帧**即完成入包（金币入账 / 物品入背包），**不依赖玩家是否靠近或逗留** —— 挂机不会丢件。
- **可见性由动画保证**：入包后该物品降级为**纯表现节点**——先原地**停驻 0.2s**（让玩家看清掉了什么），再以 **1.0s 抛物线**追踪玩家当前位置飞入并消失，合计 ≈1.2s；「拾取」提示在**飞行结束**时弹出（使「掉落 → 飞行 → 入包」在时间上成立）。
- **背包满 / 金币满**：**不发生入包**，掉落物留在地面并提示（不静默丢失），此后走下方「未认领」语义。
- **动画开关**：拾取飞行动画默认开（设置项 `dropFlyAnim`）；关闭后入包即消失（无飞行表现），入包时机不变。

**未认领地面物（背包满遗留、未来的玩家丢弃物）**：
- **自动拾取(G 开启)**：靠近地面物品 ≤1.5 格自动拾取（自动战斗亦顺路拾取）。
- **手动也可**：未开 G 时，玩家走到 ≤1.5 格范围自动入包（简化操作），或点击物品拾取；背包满则留地提示。
- **停驻 / 保护期**：生成后 0.2 秒内不触发自动拾取（此时左键点击仍可立即拾取）；地面存在 60s 后淡出。
- 统一结论：**拾取为"靠近自动"而非"必须点击"**，G 仅控制自动战斗时是否**顺路拾取未认领物**（已认领物的飞行动画与 G 无关，照飞）。

## 9.10 鼠标右键功能

- 右键点地面 = 移动指令；右键点怪物 = 选中并攻击；右键点 NPC = 对话；空闲右键 = 取消当前移动 / 攻击指令。
- 左键保持"选中怪物 / UI 交互"。

## 9.11 显示与缩放

- 最小分辨率 1280×800；参考 1440×900；支持窗口自由缩放。
- Retina(2x) 渲染清晰；UI 缩放档位 80/100/120/150%（不影响逻辑坐标）。

## 9.12 新手引导

首屏轻提示：移动(WASD) / 攻击(Space) / 自动(F/G)，由 Q001 长老对话引导；首战(Q002)提示开启自动战斗。不强制教程，提示可关。

## 9.13 目标切换与锁定交互

对应《03》3.15 的战斗机制，本节约操作与可视层：

- **Tab 键（快捷键，可重映射）**：在可视区域敌对目标间循环切换锁定（含普通怪 / 精英 / Boss）。无目标时锁定最近者；已有目标时按距离升序切下一个并循环。
- **锁定高亮**：锁定目标脚下高亮圈 + 头顶名称条（9.5）；HUD 右侧目标状态区（9.1）同步显示其头像 / 名称 / 血蓝。
- **攻击指令作用于锁定目标**：普攻 Space / 左键点目标 / 右键点目标 / 点击技能快捷格，均打向当前锁定目标。
- **超距自动走位**：所选攻击方式范围外时，玩家自动寻路至该攻击范围边界内再攻击（与自动战斗共用移动接口）；范围判定用技能 / 普攻各自范围参数（3.3）。
- **退出锁定**：目标死亡 / 消失 / 切图自动清除；空闲右键取消当前移动 / 攻击指令但保留锁定，再次攻击仍打该目标。
- **与自动战斗互斥**：开启 `F` 自动战斗时，自动决策接管目标，忽略手动锁定。


## 当前试玩交互补充（2026-10-12）

- 无有效战斗目标时，头像右侧目标区整体隐藏；Tab / 点击选中目标或自动战斗选定目标后显示，目标死亡或消失后隐藏。
- Tab 在当前可视存活敌人间循环；左击空地步行，左击怪物自动接近并连续普攻。锁定后按 Space 同样可接近攻击。WASD 或新的空地点击取消追击。
- 手动操作期间显示接管状态；停止操作后显示实际 3 → 2 → 1 秒恢复倒计时。跨地图后继续准确显示 F/G 开关；面板或后台暂停该倒计时。
