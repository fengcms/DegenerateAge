# 09 UI 与交互规范

本章定义 HUD 布局、快捷栏、四面板、设置、菜单、战斗信息呈现、Toast、加载、对话、拾取、右键、缩放与新手引导。美术为复古像素 / 斜角 2D，允许占位素材；MVP 换装只改数值不改精灵外观。

## 9.1 HUD 布局（文本示意）

```
┌──────────────────────────────────────────────────────────────┐
│ (●)人物名                  ┌────────┐              ⚙(设置)   │
│   ▇▇▇ 血槽                 │ NPC头像│   ╭───╮              │
│   ▇▇ 蓝槽     ●Lv5         │ 名称   │  │地图│ 地图名          │
│                           │ 血/蓝  │  │ ◯ │ 经纬度(col,row) │
│                           └────────┘  ╰───╯              │
│                               任务列表：⚑ 击败 5 只腐化野狼（点击规划路径，可跨图）   │
│                   （世界视图：战斗 / 移动 / 探索）                │
│                                                                │
│                                                                │
│ [技][药][药][药]...[人][包][技][骑]   ← 16格快捷栏(左12+右4)    │
│ ▓▓▓▓▓▓ 经验进度条(悬停显数字) ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓              │
│              │
└──────────────────────────────────────────────────────────────┘
```

1. **左上角 — 玩家状态区**：头像为圆圈；圆圈右侧从上到下为人物名称、血槽、蓝槽；圆圈右下角叠加小圆圈显示等级数字。
2. **头像右侧安全区 — 目标状态区**：显示当前对战怪物或对话 NPC 的头像、名称、血槽、蓝槽；无目标时为空。
3. **右上角 — 小地图区**：圆形；上方显示地图名；中间显示玩家经纬度坐标；边框放设置图标（点击开设置）；点击小地图本体开大弹窗显示大地图，点击大地图可移动到点击位置。
4. **界面下方居中 — 快捷栏（16 格）**：左起 12 格为可配置操作格（键 1 2 3 4 5 6 7 8 9 0 - =），可放已接通的技能、药品及已实现使用效果的卷轴；末 4 格为固定的人物 / 背包 / 技能 / 坐骑入口（各有默认快捷键，可在设置重映射）。装备、如意、任务物和未接通的技能不能放入。快捷格之间拖动交换位置；背包或技能面板拖入时替换目标格，源物品仍留在背包；拖到快捷栏外取消，右键清空格子。
   - 拖入药品绑定具体物品模板 ID，不绑定背包格位或物品实例；背包整理、合堆后仍有效。默认红/蓝药格保留按当前缺口自动选档的特殊绑定。数量统计跨背包同模板堆叠；耗尽时置灰但保留绑定，补货后自动恢复。冷却在格上可见。打开背包或技能面板时可拖放，点击快捷格不会误用物品。
   - ⏳ **M4 落地前**（M2.5 临时口径）：先用 `1` = 喝红药、`2` = 喝蓝药（走"按缺口选最小够用档"的挑瓶逻辑），正式快捷栏接管后这两个键位即成为前两格的默认内容。
5. **16 格下方 — 经验进度条**：与 16 格快捷栏整体同宽、底部居中，不随游戏视口拉伸为全屏宽；默认不显示经验数字，悬停显示当前 / 升级所需。
6. **小地图下方 — 任务列表**：每项显示标题与可编辑的一段任务描述，进度可嵌在描述中；进行中可点地图与怪物名规划路径，完成后显示交付文案与可点 NPC 名，点击逐图走近 NPC 并打开对话。链接高亮并加下划线，纯描述文字可自动换行。
   - 主线已领奖而下一主线未接取时，追踪栏顶部显示“主线下一步”及可点击的发布 NPC／地图；与支线并存，接取后自动让位于新任务，章节结束后隐藏。任务官面板也给出同一去向；锁定任务展示具体前置条件，远期任务暂时隐藏。规则见 08 §8.5。

## 9.2 面板与弹窗（四面板）

- **人物属性面板**：左侧以人物全身形象为中心，左右各 7 个图标装备槽，共 14 槽；右侧为 12 项属性数值（见 4.2）。槽内有图标或对应品类的形状标识，悬停显示装备名与属性；右上角关闭按钮。人物面板是唯一的穿戴槽展示位置。
- **背包面板**：展示当前容量的物品格、整理、金币扩容、一键卖出低级装备与筛选设置，不再重复装备槽或人物属性。悬停装备显示自身与已穿戴同类装备的属性对比。药水和已实现效果的卷轴仍可单独双击使用；装备的双击穿戴只在人物与背包两面板同时打开时生效。
  - 背包内直接一键卖出按钮在 Lv15 前置灰；筛选设置始终可打开，条件为“装备等级严格低于 N”且“成色不高于 X”，默认 N=5、X=普通。货郎批量移入从 Lv1 可用并共用筛选；已穿戴、仓库物品不参与。
  - 两面板并开：背包装备可拖到人物面板匹配的槽位穿戴，也可双击自动选槽穿戴；人物面板已穿戴装备可拖到背包空格卸下，也可双击卸下到首个空格。拖放失败（类型不符、等级不足、格子占用、背包满）保留原物并提示原因。仅开其中一个面板时，装备格双击不发生穿脱；单击只选中或显示提示。
  - 自动穿戴按空位→最低品质→最低评分→固定槽序选目标；拖拽采用明确指定槽。降品质弹窗展示目标槽、双方品质与评分，默认焦点在取消，Esc/关闭均取消；确认期间暂停世界并屏蔽其他面板快捷键，结束恢复先前暂停状态。「下次不再提示」仅在确认成功后生效，不写存档，成功读档/新游戏恢复。浮层按默认替换目标显示「更强 ↑」、评分差与①/②槽号，等级不足另行警示。细则见创意 20。
  - 「使用」的品类分流（M2.5）：**药水**双击即使用，tooltip 显示恢复量与冷却 / 冷却中剩余秒数；装备仍为穿戴；任务物与杂项明确提示不可使用。另可用 `1`（红药）/ `2`（蓝药）快捷使用，见 9.1。
  - **与货郎交易时例外**：本面板**与货郎面板并列**（左背包、右货郎）而不互斥，且背包格开放**拖出**——把装备拖到货郎的出售托盘即完成出售（6.4，见工程文档 05）。
  - 面板并存规则（2026-10-13 试玩修订）：背包、人物、技能、坐骑是四个独立窗口，可同时打开；按住标题栏拖动，位置限制在可见画布内，点击窗口会将其置前。四窗没有全屏暗色遮罩，叠开时画面亮度不变；各自关闭按钮只关闭自身，Esc 关闭当前最上层窗口。设置、菜单、存档、NPC 对话等仍按模态流程处理。
  - 四个常驻面板的操作帮助均放在标题栏关闭按钮左侧的问号上；悬停浮层限制宽度、按文字设置缩放并自动分行，底部不重复常驻帮助句。
  - 货郎会话打开时同时打开背包，两窗按内容宽度紧邻展示，仅留少量间隙；关闭货郎只关闭货郎、退回未结算托盘物，背包保持打开并恢复普通可拖动布局。出售托盘格间空隙可投放到最近格，物品留在实际投放格。玩家可随后自行关闭背包。
- **技能面板**：左侧图标 + 名称 + 说明；点击图标可拖到快捷栏空白格（已有则替换）；右上角关闭。
- **坐骑面板与直接骑乘**：按 N 或点击快捷栏坐骑入口打开面板，显示已收藏坐骑的大图、名称与移动速度加成，可选择骑乘或下骑；右上角关闭。按 R 可直接骑乘或下马，优先骑本次会话最近使用的坐骑，否则骑收藏中第一只已解锁坐骑；未收藏或等级不足时提示原因。R 可在设置中重映射。未达 20 级可查看收藏，但骑乘按钮禁用并显示等级门槛。未获得坐骑时明确显示获取来源。
- **浮层层级约定**：拖动中的物品**跟随光标浮动**，且**必须绘制在所有面板之上**，不得被任何面板遮挡；同理，提示条（toast）与悬停浮动属性在面板打开时仍应可见。凡"跟随鼠标 / 恒在最上"的元素，其层级要求优先于面板本身。
- 背包物品和人物面板穿戴装备被拖起后，来源格暂时显示为空槽；物品预览保持格内外观，鼠标停留在开始抓取的相对位置，不额外偏向右下角。放下或取消时来源格立即恢复，实际物品移动仍以成功投放为准。

## 9.3 设置面板字段

- **音频**：音乐音量 / 音效音量 / 屏震开关 / 强光闪烁开关。
- **画面**：界面大小 80/100/125/150/175/200%，地图显示大小 80/100/125/150/175/200%，文字大小 100/110/125/150/175/200%；另有显示适配、全屏↔窗口与窗口大小。
- **游戏**：自动战斗默认关 / 自动拾取默认关 / 喝药血量阈值 / 搜索半径 / 品质过滤。
- **控制**：全快捷键可重映射列表 + 冲突提示。
- **数据**：存档管理（手动存 / 备份 / 删除）。

**M4-6 实施边界（2026-10-12）**：设置由右上角齿轮进入；显示倍率、全屏和窗口大小另存为本机偏好，启动主菜单时就应用，切换角色存档不覆盖。其余设置仍按当前活动存档槽保存。音乐 / 音效音量分别作用于 Music / SFX 声道；现阶段尚未接入游戏音乐与音效资源，因此音量值可改可存，但需在接入声源后做听感验收。UI 与文字缩放、窗口/全屏、分辨率选择即时生效；改键覆盖移动、战斗、面板和 12 个快捷格，冲突时由玩家确认交换。自动战斗和自动拾取的**运行态默认关闭**保持不变。屏震、强闪与品质过滤只保存配置，相关战斗特效及掉落过滤尚未接线，界面明确标注该限制；不得把它们算作已生效的玩法。

**技能面板当前边界**：展示 `skills.json` 中的名称、说明及解锁等级；基础斩击、裂地斩、旋风斩与战意觉醒已接通，达到各自等级后可拖入快捷栏。战意觉醒是无需目标的自身增益，生效期间在角色状态区显示剩余秒数，快捷格仍显示冷却秒数。其余未接线技能不可拖入，避免玩家以为可以施放。红/蓝药默认位于快捷格 1/2，普攻默认位于格 3；其余格位为空。人物面板展示 14 图标装备槽与 4.2 所列 12 项属性；穿脱须与背包面板同时打开。快捷栏末 4 格分别打开人物、背包、技能、坐骑。

**自动药品快捷项恢复（2026-10-13）**：自动红药、自动蓝药是永久可配置的操作，不是背包里的单瓶药品。技能面板始终提供这两项拖放来源；玩家清空、替换或交换快捷格后，可以随时重新拖入任意格。它们与具体药品绑定不同，按背包当前可用药品自动选瓶，背包暂时没药也不丢失配置。

**快捷栏卷轴实施范围**：回城卷从野外返回该地图所属城镇（第一章幸存者营地、第二章沉井镇），随机券在当前地图内传送到可通行且可到达的位置，二者均在成功后才消耗；背包双击与快捷栏共用入口。复活卷只在死亡选择界面使用，不进入快捷栏；烟花仍是未接通的纯装饰模板。快捷栏配置属于每个角色的存档数据，切图及读档不重置；无效配置按存档校验规则拒绝读取。

## 9.4 主菜单 / 暂停菜单 / 读档界面

- **主菜单**：新游戏 / 继续(若有存档) / 读取存档 / 设置 / 退出。
- **暂停菜单**（Esc）：继续 / 设置 / 保存 / 返回主菜单（停止模拟）。
- **读档界面**：3 张存档卡，显示角色名 / 职业 / 等级 / 地图 / 存档时间；操作 新建 / 读取 / 删除(二次确认)。

## 9.5 战斗信息呈现

- **伤害飘字**：普通 = 白色；暴击 = 黄色加大；格挡 = 蓝色；治疗 = 绿色。
- **血条数值**：默认隐藏，悬停 / Boss 血条显示具体数值。
- **目标选中指示**：选中怪物 / NPC 脚下高亮圈 + 头顶名称条。
- **NPC 可接任务标记**：在当前可接任务发布人的头顶名称上方显示单个简洁提示；它与名称一起遵守文字/地图倍率，不能遮挡人物。仅可接任务显示，待交付任务不复用该提示。点击标记等同点击该 NPC，走原有接近与对话流程；具体美术可后续替换，不改变任务判定。
- **攻击范围指示**：锁定目标后，地面绘制玩家到目标的连线（虚线），并在目标周围绘制所选攻击方式的攻击范围指示环；超出范围时高亮为"需接近"色，进入范围转为"可攻击"色（与 3.15 超距自动走位联动）。

## 9.6 系统提示 Toast

类型：升级 / 任务完成 / 掉落 / 拾取 / 拾取失败(背包满) / 金币不足 / 升星成功失败 / 地图解锁。屏幕中上短暂淡出(2s)，不阻塞操作；重要(解锁)稍长。

## 9.7 加载界面

启动 / 切图显示加载页：进度条 + 随机世界观提示语；不做无缝加载（单机可接受）。

## 9.8 对话系统推进

点击"继续"逐句推进 NPC 自我介绍；末句展开功能菜单（购买 / 出售 / 升星 / 任务等）；首版无分支选项（预留）。

## 9.9 拾取交互澄清

**怪物掉落（2026-10-13 试玩修订，替代工程文档 10 的生成即入包口径）**：
- **G 关闭**：金币物品与装备物品均以地面掉落出现，不因生成或玩家靠近自动进背包；玩家左击掉落物才尝试拾取。击杀奖励的经验和模板固定金币仍按战斗结算直接到账，不属于地面掉落。
- **G 开启**：自动战斗可顺路走向未领取掉落物；玩家靠近 ≤1.5 格时自动拾取。原生成即认领的飞行动画只用于 G 开启且成功收取的掉落；不能在 G 关闭时先入包再播放假掉落。
- **背包满 / 金币满**：物品继续留地，收取失败有明确提示。普通掉落按既有 60 秒时限，精英 / Boss 未领取战利品跨图 / 跨档保留。
- **动画开关**：`dropFlyAnim` 只控制成功自动收取后的表现，不改变 G 开关的拾取判定。

**未认领地面物（含背包满遗留和玩家丢弃物）**：G 开启时靠近 ≤1.5 格自动拾取；G 关闭时只能点击拾取，走过物品不收取。生成后 0.2 秒的保护期只限制自动拾取，点击可立即收取。

**任务目标导航（2026-10-13 口径更正）**：怪物名称高亮与下划线应出现在任务面板的击杀目标文字中，人物面板不增加怪物列表。点击任务面板中的怪物名称，关闭任务面板并自动步行到该怪物在目标地图的刷新区域；这不是锁定存活怪物或自动攻击。目标在其他地图时，沿已解锁道路出口逐图前往，到达目标图后读取实际刷新点。当前图小地图下方的任务追踪条可提供相同入口。怪物刷新位置可能随刷新变动；指令应读取当前已生成的刷新点，点位不可用时给出提示，不凭空指定固定坐标。

**任务描述与交付（2026-10-14）**：任务官面板与小地图下方追踪条使用同一可编辑任务描述；完成时切换为交付描述，隐藏旧的击杀目标链接。交付 NPC 链接沿步行出口跨图寻路，走近后打开任务面板。文案标记和权限规则见 8.5。

## 9.10 鼠标右键功能

- 右键点地面 = 移动指令；右键点怪物 = 选中并攻击；右键点 NPC = 对话；空闲右键 = 取消当前移动 / 攻击指令。
- 左键保持"选中怪物 / UI 交互"。

## 9.11 显示与缩放

- 最小分辨率 1280×800；参考 1440×900；支持窗口自由缩放。
- Retina(2x) 渲染清晰；界面、地图、文字各自设定最终显示大小（不影响玩法逻辑坐标）。界面倍率已包含控件内文字的基础变换；文字倍率用于设定最终字形大小，不能与界面倍率再次叠乘。例如界面与文字都设 150%，字形最终仍为基础大小的约 150%。运行中新增的提示、任务行也遵守同一规则。
- 设置等面板的选项卡标题与页内文字使用相同的文字倍率；调整「文字大小」后，选项卡标题立即更新。
- 背包和装备悬浮属性提示的字形大小跟随「文字大小」，其弹出层虽不在 UI 画布下，也不能停留在默认 100%。
- 锁定 Boss 时隐藏普通目标卡，由顶部 Boss 专用血条展示名称与血量；切换到普通怪时恢复普通目标卡。
- 在 4K 屏幕上可独立把界面、地图和文字设为 200%。地图倍率只改变画面中的人物与地形大小及可见范围，不改变攻击距离或怪物数量；三项同为 200% 时文字最终大小仍为 200%，不叠乘。
- 任务、大地图、仓库等关闭式面板在缩小窗口或提高界面倍率后仍应完整留在可见区域；任务列表和仓库格子区域可滚动，仓库双栏随可用宽度减少每行格数，大地图按可用高度收缩。放大或缩小窗口时应即时重排。
- 四个常驻浮窗（背包 / 人物 / 技能 / 坐骑）与货郎、车夫面板同样保证完整留在可见区域：标题行（含关闭键）始终在屏内，标题行以下内容超出可用区时在面板内部滚动查看（2026-10-15 定稿，含界面 200% × 手动显示 150% 的极端倍率组合）。

## 9.13 目标切换与锁定交互

对应《03》3.15 的战斗机制，本节约操作与可视层：

- **Tab 键（快捷键，可重映射）**：在可视区域敌对目标间循环切换锁定（含普通怪 / 精英 / Boss）。无目标时锁定最近者；已有目标时按距离升序切下一个并循环。
- **锁定高亮**：锁定目标脚下高亮圈 + 头顶名称条（9.5）；HUD 右侧目标状态区（9.1）同步显示其头像 / 名称 / 血蓝。
- **攻击指令作用于锁定目标**：普攻 Space / 左键点目标 / 右键点目标 / 点击技能快捷格，均打向当前锁定目标。
- **超距自动走位**：所选攻击方式范围外时，玩家自动寻路至该攻击范围边界内再攻击（与自动战斗共用移动接口）；范围判定用技能 / 普攻各自范围参数（3.3）。
- **退出锁定**：目标死亡 / 消失 / 切图自动清除；空闲右键取消当前移动 / 攻击指令但保留锁定，再次攻击仍打该目标。
- **与自动战斗互斥**：开启 `F` 自动战斗时，自动决策接管目标，忽略手动锁定。


## 当前试玩交互补充（2026-10-12）

- 无有效战斗目标时，头像右侧目标区整体隐藏；Tab / 点击选中目标或自动战斗选定目标后显示，目标死亡或消失后隐藏。
- Tab 在当前可视存活敌人间循环；左击空地步行，左击怪物自动接近并连续普攻。锁定后按 Space 同样可接近攻击。WASD 或新的空地点击取消追击。
- 手动操作期间显示接管状态；停止操作后显示实际 1.5 秒恢复倒计时。跨地图后继续准确显示 F/G 开关；普通界面面板不暂停自动战斗及恢复倒计时，界面仍拦截误点地图的手动指令；功能 NPC 对话期间暂停自动决策并显示对话中暂停，关闭对话立即恢复。F 键及头像旁自动战斗图标在面板打开时仍可开关自动战斗。真正的游戏暂停冻结战斗，窗口失焦仍继续自动战斗。

**玩家头顶名称**：地图中的角色形象上方常显当前人物名称，采用与怪物名称可区分的友方颜色；随人物移动和地图倍率正常渲染，不遮挡头顶其他状态。

**玩家头顶生命条（2026-10-13）**：人物名称下方常显一条友方绿色生命条，随实际 HP／最大 HP 即时更新；死亡显示空条，治疗与复活同步恢复。数值继续由左上角玩家状态区提供，头顶条不重复显示数字。
