# 01 产品定位与愿景

## 1.1 产品定位

- **类型**：2D 等距斜角（isometric）、单机、实时战斗、打怪升级（ARPG / Diablo-like 斜角玩法）。
- **平台**：首发 **macOS**（桌面端，键鼠操作）。远期是否扩展 iOS / Windows / Linux 待发布策略定（移植 iOS 需重做触控与界面尺度）。
- **商业模式**：**买断制优先，可能免费分发**；全产品不含任何内购变现机制。分发渠道（Mac App Store / 独立站 / Steam）待定。
- **一句话定位**：在末法时代的人类失地上，扮演一名能吸收异族灵能的守护者，探索斜角地图、实时战斗、打宝成长，逐步解锁地图与技能、击败章节 Boss、最终关闭异界裂隙。

## 1.2 产品边界（明确不做）

下列功能在首版及可预见版本中均不包含，以避免范围蔓延：

- 联网 / 多人 / 服务器 / 账号系统
- 交易市场 / 公会 / 抽卡 / 氪金内购 / PvP
- 在线挂机收益 / 离线收益计算
- 复杂制造系统（锻造、合成深度玩法）
- 程序自动替玩家购买物品
- 多结局剧情（正式剧情版才纳入）

> 游戏内的"自动打怪"是**单机玩法的一部分**，但进程退出后不继续运行、不累计离线收益。

## 1.3 核心体验目标

产品设计必须让玩家在体验中感知以下 5 点（每条都是验收时的"感受"标准，不仅是功能有无）：

1. **成长感**：几分钟内可观察到等级或装备属性提升，力量变化可感知。
2. **打宝感**：普通怪有小惊喜；精英怪更值得打；Boss 有独特奖励与挑战。
3. **探索感**：进入新地图意味着新敌人、新资源、剧情与阶段目标。
4. **操作自由**：手动操作战斗，或在普通刷怪区开启自动战斗 + 自动拾取。
5. **单机友好**：随时暂停 / 退出、离线游戏、本地保存，不以多人竞争或付费设计数值。

## 1.4 目标用户与设备

- **用户画像**：喜欢斜角 ARPG、打宝刷怪、单机轻度挂机的玩家；偏好 macOS 生态、对联网竞技无强需求。
- **设备基线**：高分辨率 Mac 屏幕；设计参考视区 **1440×900**，支持窗口化调整大小；UI 可缩放，避免窗口变化导致布局溢出。
- **性能基线**：1440×900 普通战斗场景争取稳定 **60 FPS**；约 30 个同屏敌人 + 常规特效下无明显持续卡顿。

## 1.5 内容范围与发布节奏

| 内容 | 可玩 MVP（P2） | 第一章完整版（P3） | 远期完整剧情版（P4–P5） |
|---|---|---|---|
| 地图 | 测试营地 + 试炼野外 | 幸存者营地 + 灰烬之地 + Boss 区域 | 6 章节区域及连接区域 |
| 等级 | 首版内容覆盖 1–10（无限等级，无硬上限） | 同上 | 不限（版本化内容扩展） |
| 职业 | 灵刃战士 | 灵刃战士 | 其他职业待定 |
| 普通 / 精英 / Boss | 1 / 0 / 0 起步 | 3 / 1 / 1 | 每章独立配置 |
| 技能 | 普攻 + 2 主动 | 普攻 + 2 主动 | 逐步扩展至 6 核心技能 |
| 装备槽 | 14 | 14 | 14 |
| 装备模板 | 少量测试模板 | 约 20 个 | 按章节扩展 |
| 自动战斗 / 拾取 | **必须实现** | 完善边界行为 | 优化策略 |
| 剧情 | 暂无复杂过场 | 完整第一章 | 贯通终章与结局 |

> **MVP 定义**：能持续游玩并验证核心循环（打怪 → 掉落 → 成长 → 挑战更强敌人 → 解锁）的版本，**必须能保存进度**。不要求精美素材。

## 1.6 开发排期原则（最小闭环）

产品开发按"**最小闭环逐步推进**"落地，先跑通一个可玩闭环，再逐层叠加：

```
货郎经济闭环  →  任务系统  →  多地图 / 车夫  →  坐骑 / 升星  →  ……（持续内容扩展）
```

该原则是**开发落地顺序**，不是产品范围裁剪——本文档定义的所有功能（任务 / 多图 / 车夫 / 仓库 / 坐骑等）均为产品完整需求，只是在实现时按上述顺序分批交付。
