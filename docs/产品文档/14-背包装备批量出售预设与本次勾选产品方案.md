# 背包装备批量出售：预设＋本次勾选产品方案

本文替换原「装备等级低于 N 且成色不高于 X」的玩家可见配置。已获用户确认，现行规则已同步至 `05-装备与背包系统.md`、`06-经济与NPC系统.md`、`09-UI与交互规范.md`。

## 1. 要解决的问题与边界

当前背包把两个数值筛选项藏在「筛选设置」中，玩家很难预知一键操作最终会处理哪些装备。穿戴等级低、品质低也不等于没有价值：星级、属性组合、空穿戴槽和未达到穿戴等级的高评分装备都可能值得保留。新交互应让日常清包只需选择一个易懂的预设，同时让每次交易的**具体物品、金币和例外**可见、可改。

交互参考：[《暗黑破坏神 IV》官方更新说明](https://news.blizzard.com/en-us/article/24092662/diablo-iv-patch-notes-1-0-1-2)中的废品/收藏标记与批量出售、[《上古卷轴 Online》官方说明](https://help.elderscrollsonline.com/app/answers/detail/a_id/34347/~/what-is-item-locking-in-the-elder-scrolls-online)中的物品锁定，以及[《Last Epoch》开发团队介绍](https://forum.lastepoch.com/t/loot-filter-rules/25125)的等级/稀有度筛选。它们提供设计参考；本方案的三个预设阈值、清单和交易顺序是针对本项目拟定的规则，并非照搬这些游戏。

本轮只影响**背包内装备的批量直卖**与**货郎装备批量移入**。手动拖卖、单件出售、药水/材料/如意的一键移入、装备评分与穿戴、价格公式、仓库、掉落和拾取均不改变。任务物品及非装备不进入装备清单。背包直卖维持 Lv15 解锁；货郎批量移入从 Lv1 开放。装备直卖和货郎托盘结算仍使用同一售价公式。

## 2. 玩家看到的操作

- 背包原「一键卖出低级装备」与「筛选设置」合并为一个「出售装备」入口；Lv15 前入口置灰，并说明可去货郎出售。背包其他按钮维持原位。货郎出售页将「一键移入」改名为「挑选装备」，「一键移入材料」保持独立。
- 点击任一入口，打开同一款**装备待处理清单**。顶部为「谨慎／标准／积极／暴力」四个单选预设，默认「谨慎」；中部按背包格序显示装备图标、名称、穿戴等级、品质、星级、评分提示、售价、勾选框和未入选原因；底部显示「已选 X 件／预计 Y 金币」与取消、确认按钮。默认勾选项由预设计算，玩家可以在本次清单中逐件勾选或取消。关闭清单不改变背包。
- 选择预设会**重新计算默认勾选**，清除本次尚未提交的手动勾选；切换前若已手改勾选，应给出轻量提示。确认按钮在零件选中时置灰。**谨慎／标准／积极**的选择会记入**当前角色存档**，本次勾选不保存；**暴力是一次性动作、不记入存档**（见 §3），关闭清单后预设回落上次保存的预设，下次打开按当时角色/装备状态计算。
- 从背包打开时，确认后直接卖出已勾选装备并显示实际件数与金币。从货郎打开时，确认只把已勾选装备移入空闲出售格，**尚未出售、尚未获得金币**；玩家仍须点击货郎原有的「确认出售」。清单预估金币与货郎最终托盘结算分别明确标为「预计」和「实际」。关闭货郎时未结算物品沿用现有退回规则。
- 清单是普通可移动窗口，不叠加全屏遮罩；背包直卖清单打开期间，已有的世界移动与自动战斗规则不变。发生掉落、整理、升级、换装等变化时，清单提示需要重新核对；确认时若待处理装备或保护状态已变化，不按旧截图成交，而是刷新清单并要求再次确认。

## 3. 四个预设的精确定义

品质顺序为普通、优秀、稀有、史诗、传说。所有预设只默认勾选零星装备；玩家仍可在清单中手选未被锁定的其他装备。

| 预设 | 默认勾选条件 | 典型用途 |
|---|---|---|
| 谨慎（默认） | 穿戴等级比角色低至少 10 级，且品质为普通、星级 0 | 刚开始使用时尽量少误选 |
| 标准 | 装备所属「十级档」早于角色当前档，且品质不高于稀有、星级 0 | 常规清理旧装备 |
| 积极 | 品质不高于稀有、星级 0，**不设等级门槛** | 背包接近满时快速清理 |
| 暴力（2026-10-20 新增） | **背包内所有可售装备**，不设任何品质／等级／星级／评分／旧套判断 | 一次性清空背包；不提示、不二次确认，一次点击即成交 |

**暴力预设的三条边界**（其余预设的规则对它都不适用）：

1. **只作用于背包装备**：身上穿戴、仓库存放、任务物品、药水／如意／卷轴一律不动。
2. **收藏仍然受保护**：收藏是玩家亲手打的「别卖」标记，不属于「价值判断」，因此不随暴力放开。
3. **不记入存档**：它是动作而不是偏好。若落档，下次打开清单就是「整包装备已全选」的默认态，一次手滑即清空背包；同时「暴力」这个取值进入存档还会牵动存档枚举校验（见工程 61 §2.4）。

其余预设「只默认勾选零星装备」「手选保留」「珍贵标签 + 二次确认」的规则对暴力**不适用**——暴力设计上就是「不再问你第二遍」。

「档」按十级带宽划分：`档起点 = floor((穿戴等级 − 1) / 10) × 10 + 1`，角色当前档用同一公式按角色等级计算。装备档起点早于角色当前档起点即视为「旧套」，同档与更高档一律不默认出售；该口径与铁匠合成的档位判定同源。**只有谨慎预设使用「低至少 10 级」这一数字阈值**，标准与积极都用档位表达，避免与「十级一套」模型错配。

上述条件**还须经过共同保护规则**：已标记「收藏／锁定」的装备、不能出售的装备，以及按当前默认替换槽比较后**评分高于已穿戴装备**的装备，均不被任何预设默认勾选。默认替换槽为空（该槽尚未穿戴）时不计入评分保护——否则背包里只要某个槽类还有空位，该类装备就永远无法批量出售。这个判断只服务批量出售保护，不改变玩家看见的评分角标、穿戴资格或手动售卖能力。任何预设都不会默认选中史诗及以上或已升星装备。

**示例**：角色 Lv12 时，「标准」可清理第 1 档（Lv1—10）的普通／优秀／稀有零星装备，同属第 11 档的装备不默认出售。角色 Lv25 时，「积极」可默认勾选背包内全部普通／优秀／稀有零星装备，不论其穿戴等级，但评分高于当前已穿戴同槽装备的仍不会选。

## 4. 本次清单、收藏与风险提示

- 清单列出背包内所有装备，而不只列默认勾选项。未勾选项旁显示一个可理解的原因，例如「等级接近当前角色」「仍属当前或更高档」「稀有装备」「已升星」「评分可提升」「已收藏」。无需让玩家理解底层的 AND 条件。
- 背包装备提供「收藏／取消收藏」操作，格内有明确小标记；装备移动到人物、仓库、地面再拾回后标记仍跟随**该装备实例**。锁定装备在批量清单中可见但不能勾选，须先取消收藏；手动单件出售时也明确拒绝，避免绕过保护。收藏不改变属性、售价、品质、评分及穿戴。
- 对未收藏、但因品质、星级、档位或评分保护而未被预设勾选的装备，玩家仍可**主动手选**。清单用醒目标签标出「珍贵／可提升」；最终确认前再显示一次这些装备的名称和数量。普通默认勾选项无需第二次额外弹窗。
- 已穿戴、仓库中的装备不会出现在清单。手动拖入货郎的旧入口继续可用，但收藏装备须先解锁；手动拖入高价值装备时，货郎最终结算继续展示相同风险提醒，避免两条出售路径保护不一致。
- 预设保护是便利规则，不声称自动判断所有流派、词条和未来配装价值；「收藏」由玩家表达自己真正想长期保留的装备。清单中始终给出逐件审阅机会。

## 5. 货郎容量、金币上限与失败反馈

- 出售托盘现有 24 格，已有手动放入的物品保留原位。本次所选件数**超过剩余空格**时，确认按钮置灰并显示「还剩 X 格，请减少 Y 件」，不默默只移入前 24 件；提交后按背包格顺序依次填入空格。
- 背包直卖在最终确认前重新计算总价；若加上现有金币会超过金币上限，则整批保持原样并提示原因，玩家可缩减勾选后重试。货郎移入阶段不结算金币；最终结算也必须避免「物品已清空但金币因上限被截断」的结果。
- 任一选中装备在确认前被使用、移动、强化、锁定状态改变或不再符合当次人工选择时，整批不成交；清单刷新并提示「背包已变化，请重新确认」。物品空格位置改变但**同一实例、数据与售价均未变**时可以按实例 ID 重定位，避免整理背包造成误售别的装备。
- 首次加载旧存档时，新预设为「谨慎」，旧的等级与品质数字阈值**不自动换算**。玩家首次打开清单即可看见具体勾选结果，确认之前不发生任何出售；旧存档中的装备没有收藏标记时视为未收藏。

## 6. 验收口径

玩家在 Lv15 用「谨慎」打开背包出售，能一眼看到将售出的实例、原因和预计金币；取消勾选能立即更新汇总；关闭不改变背包。换到「积极」会重新计算候选，但不会自动卖出。评分高于已穿戴同槽装备的、已升星、史诗及以上和收藏装备不被默认勾选；某个替换槽为空时，该槽类装备仍可被默认勾选。玩家可以手动选择未锁定的高价值件，但要看见额外风险提示。货郎只暂存、容量不足不部分移入；金币上限或预览失效时不吞物品。Lv15 门槛只限制背包直卖，不限制货郎清单。

## 6. 与「拾取装备自动出售」的关系（2026-10-20 追加）

设置 → 游戏里的「拾取装备时自动出售」**复用本方案的同一档预设**（谨慎 / 标准 / 积极），两处共用一个值：
在设置里改，出售清单跟着变；在清单里改，设置里也跟着变。**暴力不参与**，因为它是一次性主动动作，不是长期偏好。

同一套判据在自动流程里有两处**必须反过来**（详见产品 03 §3.16）：

1. **空槽位不再豁免**。本方案 §3 写的「默认替换槽为空时不计入评分保护」只服务手动批量出售 ——
   清单里玩家看得见每一条、能取消勾选。自动出售没有这一步，若沿用该豁免，某部位捡到的第一件会被当场卖掉，
   玩家将永远穿不上那一件。因此自动出售对空槽装备**一律不卖**。
2. **金币上限不再「照卖只提示」**。手动出售是玩家自己点的，知情；自动出售是「一次授权、长期生效」，
   玩家没点，所以满金币时**不卖**，装备留在背包。
