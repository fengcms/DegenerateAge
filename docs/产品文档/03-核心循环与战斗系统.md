# 03 核心循环与战斗系统

本章定义战斗的核心机制：伤害结算、技能、受击保护、闪避、控制效果、Boss 阶段、等级差，以及自动战斗 / 自动拾取。角色属性与派生公式见《04 角色成长系统》。

## 3.1 战斗总体流程

```
玩家输入 / 自动决策
      │
      ▼
选择目标 → 接近(寻路) → 进入攻击范围
      │
      ▼
结算一次攻击：
  ① 命中判定  攻击者命中 vs 目标闪避(概率Miss)
  ② 基础伤害  max(1, floor(攻×系数 − 防×0.5))
  ③ 暴击判定  criticalChance → 命中则 ×criticalMultiplier
  ④ 约束      不允许负伤害、HP 不低于 0
      │
      ▼
播放反馈：命中/暴击飘字 + 受击硬直 + 无敌帧 + 击退
      │
      ▼
目标 HP≤0 → 死亡结算(经验/掉落/任务，仅一次)
```

攻防双方使用同一套结算公式（敌我对等）。

## 3.2 伤害公式（初始参数）

```
base   = max(1, floor( attacker.attack × skillMultiplier − defender.defense × 0.5 ))
暴击判定：roll < criticalChance  →  damage = floor(base × criticalMultiplier)
否则                             →  damage = base
约束：damage ≥ 1；目标 HP 不低于 0
```

- `skillMultiplier`：技能系数（见 3.4 技能规格表）。
- 防御侧提供线性减伤（`defense × 0.5`）；闪避提供"完全不掉血"的概率（见 3.6）。
- **不破防伤害下限（2026-10-20 定案）**：当 `floor(攻×系数 − 防×0.5) <= 0`（防御项吃掉攻击、未破防）时，**怪物 → 玩家**方向的伤害下限不再取 1 点，而是按玩家最大生命比例结算 `min_hit = clampi(round(maxHP × 0.25%), 10, 60)`（Lv80 约 13、Lv100 约 20–25、HP ≥ 24,000 封顶 60）；**玩家 → 怪物**仍保持 1 点下限，前 60 级"打不动高防 Boss"的手感与既有伤害断言不变；命中判定失败（Miss）仍为 0 伤害。

## 3.3 技能系统规格（灵刃战士）

首版共设计 6 个技能；现均已按等级解锁并接通手动快捷栏与自动战斗。所有数值为**初始参数**，试玩调优。

破甲重击的穿防/破甲与灵刃风暴的三段结算已实现；主动技能冷却跨地图保留，暂停时冻结，读档后重置。

**战意觉醒实施口径**：持续 8 秒的攻击 +20% 与攻击速度 +15% 只作用于实时结算，不改基础属性；攻击速度加成按「基础攻击间隔 ÷ 1.15」计算，仍受最短间隔约束。增益跨图保留，暂停时冻结，读档 / 新游戏、死亡或打坐时清除；重复施放不叠层。自身增益不要求选怪，在安全区也可施放，但不能借此在安全区造成伤害。自动战斗仅在有效目标即将进入攻击流程、增益未激活且资源足够时施放。

- 技能消耗 MP（MP 不足不可放并提示原因）；未解锁 / 冷却中 / 目标无效时不可放。
- 自动战斗技能策略：优先可用范围技（命中 ≥2），否则单体 / 普攻；不绕过冷却。
- 技能定义纳入数据驱动框架（见《10 数据配置与存档技术》），文本可编辑。
- **首版历史口径**是不做技能加点 / 技能树、仅按等级解锁。后续扩展采用下述有限阶升级；不引入技能点或技能树。

### 3.3.1 技能升阶（后续成长扩展）

- 基础斩击保持 1 阶；其余五个主动技能解锁时自动拥有 1 阶，最多升至 5 阶。未达到技能原解锁等级时为 0 阶，不能施放或购买。
- 下一阶同时要求角色等级与金币。目标阶 `r` 的等级门槛为 `unlockLevel + 10 × (r − 1)`；各技能金币价格按 `skillProgression.json` 配置，购买成功永久生效，不需要技能点，不能超阶。升阶不重置当前冷却。
- 攻击技能第 2—5 阶的基础系数倍率分别为 1.03 / 1.06 / 1.09 / 1.12；战意觉醒每阶增加攻击加成 1.5 个百分点、攻速加成 1 个百分点，5 阶分别为 +26% / +19%。范围、段数、破甲、蓝耗、冷却与持续时间不因阶数变化。
- 手动施放与自动战斗读取同一阶数生效值；已经施放的战意觉醒在持续期间保留施放时效果，下一次施放才使用新阶。旧档按角色等级补齐已解锁技能的 1 阶，不能凭旧档自动获得更高阶。
- 上述增量和价格为首版可测试值；上线验收须对比各等级普通怪、精英、Boss 的击杀时间和打金图的清场速度。与 D-19 的技能基础系数决定分开，不静默重调 1 阶系数。

## 3.4 受击反馈与保护机制

采用**受击硬直 + 无敌帧 + 击退**，作为 ARPG 手感底线，防止被多怪围殴连锁控死：

- **受击硬直（hit-stun）**：被命中后短暂无法主动行动，初始 0.2–0.4s（普通怪短、精英 / Boss 长）。
- **无敌帧（i-frame）**：受击后获得短暂无敌，初始 0.5s；无敌帧内不叠加新硬直。
- **击退 / 击倒（knockback）**：部分攻击造成位移（击退）或短暂倒地（击倒）；倒地期间不可行动但享有无敌帧。
- 边界：死亡态、无敌帧内、过场 / 对话中不触发硬直。

## 3.5 命中 / 闪避对抗（概率 Miss）

采用**概率 Miss** 模型，与自动战斗天然兼容：

```
missChance = clamp( defender.dodge / (defender.dodge + DODGE_K), 0, 0.75 )
DODGE_K = 50（初始参数）
```

- 例：闪避 50 → Miss 50%；闪避 150 → Miss 75%（封顶 75%，堆不到 100% 无敌）。
- 怪物侧引入 `accuracy` 字段（默认 0，即不主动降玩家命中）；玩家攻击怪物默认必中（除非怪物有闪避词缀）。
- **口径（M1 校准落定）**：`dodge` 与 `accuracy` 均为**点数**（非 0–1 比例）。例：怪物 `dodge = 6` → Miss 10.7%、`dodge = 8` → Miss 13.8%；装备词条给出的也是点数，与公式一致。
- 自动战斗与手动战斗使用同一结算。

## 3.6 伤害类型

- **首版仅物理伤害**（简化平衡）。
- 预留"灵能 / 裂隙"元素伤害类型与对应抗性字段（`resistType`，怪物 / 装备各预留），供后期版本启用，不增加首版复杂度。

## 3.7 控制效果（CC）与精英 / Boss 技能

**CC 类型清单**（数据可配）：眩晕（stun，无法行动）、减速（slow，移速 / 攻速 −X%）、定身（root，不可移动但可攻击）、击退（knockback，见 3.4）、召唤（summon，Boss 召小怪）。

- **精英"特殊攻击"**：从 CC 池随机取 1 项（如寒霜精英 = 减速、狂暴精英 = 攻速提升），作为打宝差异点。
- **Boss 技能模板**：技能预警（地面提示圈 / 读条）→ 阶段行为（血量阈值触发）→ 效果（范围伤害 / CC / 召唤）。首版每章 Boss 至少 1 个阶段技能。

## 3.8 属性上限（Caps）

- 暴击率 ≤ 75%；暴击伤害倍率 ≤ 5.0×；闪避(Miss) ≤ 75%；攻击间隔(攻速) ≥ 0.2s（下限）；冷却缩减 ≤ 50%。
- 格挡首版**不做**。超限部分在属性结算时截断，不报错。

## 3.9 攻速作用域

攻击间隔影响：**普攻施法间隔**与**技能前摇 / 后摇**；**不影响移动速度**。自动战斗严格遵循攻速与冷却，不绕过。

## 3.10 Buff / Debuff

- 定义：持续（duration）、叠层（首版不叠层）、效果类型（增攻 / 增防 / 增攻速 / 减伤）。
- **战意觉醒**（自增益 Buff）：持续 8s，攻+20%、攻速+15%；可被打坐 / 死亡清除。
- 敌方 Debuff（如破甲重击的"破甲"标记）持续 5s，叠加刷新不叠层。

## 3.11 被动 / 天赋

**首版明确不做**被动技能 / 天赋树（控制范围）；数据预留扩展位。

## 3.12 Boss 阶段行为设计（腐化巨兽范式）

第一章 Boss「腐化巨兽」作为 Boss 设计范式，后续 Boss 参照扩展（与 3.7 的 Boss 技能模板一致）：

```
生命 100%–60%  ── 普通追击 + 爪击（基础攻击）
生命 < 60%     ── 周期性范围践踏，伤害前显示明显地面警示圈（预警）
生命 < 30%     ── 短期狂暴（攻击速度提升）并召唤少量普通怪
被击杀          ── 结算首次通关奖励(firstClearClaimed) → 推进 Q005 → 解锁下一区域入口
```

Boss 可重复挑战，重复击杀不再发放首通奖励。普通怪 / 精英怪无墓碑，击杀后按怪物点刷新时间直接重生；Boss 死亡后生成**墓碑**显示下次刷新倒计时。

## 3.13 等级差机制

```
expMult = clamp( 1 − (playerLv − monsterLv) × 0.04, 0.2, 1.5 )
  （玩家高于怪等级 → 经验衰减；低于 → 微加成）

dmgMult（越级）= 1 + (monsterLv − playerLv) × 0.02，上限 1.3
  （玩家低于怪等级时打该怪伤害略增；怪物打玩家同理）
```

目的：防止高等级回低图无意义刷，也允许适度越级挑战。参数为初始值，试玩校准。

## 3.14 自动战斗与自动拾取

**原则**：自动只调用与玩家相同的移动 / 寻路 / 技能 / 喝药 / 拾取接口；**默认关闭**，玩家主动开启（`F` 自动战斗、`G` 自动拾取）。G 是所有地面掉落物的自动收取总开关；关闭时即使 F 已开启，也不会因击杀、靠近或巡游自动拾取。

**界面与挂机**：背包、人物、技能、坐骑等普通面板打开时，玩家的键鼠手动指令由界面接管，但已经开启的自动战斗继续寻怪、移动、攻击与自动喝药。与功能 NPC 对话（包括货郎交易）期间，自动战斗开关保留但停止寻怪、移动、攻击和自动拾取；关闭 NPC 面板后立即恢复决策。面板打开期间 F 键及头像旁自动战斗图标仍可切换开关。真正暂停游戏、角色死亡或玩家关闭 F 时才停止自动战斗。

**状态机**：`off / searchTarget / roam / pathToTarget / attackTarget / searchLoot / pathToLoot / pickUp / recover / manualOverride / blocked`

**行为（2026-10-12 试玩修订）**：HP ≤ 阈值（初始 35%）喝红药，MP ≤ 同一阈值喝蓝药；两项按自身上限独立判断，并按缺口选"够用的最小档"。同时不足先红后蓝，缺一种药不影响另一种自动使用，红蓝各自独立冷却；**药尽仍继续战斗至死**。自动搜怪覆盖**当前游戏画面可视区域**，按玩家距离优先，排除已死亡、短期黑名单和默认不允许的 Boss；画面内远处怪物也必须主动接近攻击。F/G 同时开启时，先处理附近可拾取物，再处理可见怪物；两者都没有时，沿地图有效区域的巡游点移动，每 0.35 秒重新扫描画面；找到目标立即停止巡游并追击。巡游点到达或受阻后转下一点，循环覆盖整张地图，不能在原地等待刷新。手动接管、游戏暂停、死亡和打坐均停止巡游；面板开启仍继续挂机；窗口失焦仍继续巡游；恢复时重新评估可见目标。**掉落是否自动收取由 G 决定**（见 9.9）；G 关闭时击杀与靠近均不会拾取，G 开启时自动战斗可顺路拾取。

**障碍地图寻路（2026-10-13 试玩修订）**：自动战斗、自动拾取和巡游共用地图的可通行网格与路线。目标格不可走或与玩家不连通时，不得退回穿墙直线移动；应跳过该目标并继续寻找可达怪物或可达巡游点。追击时以路线上的下一节点及玩家实际位移判断推进，绕障暂时远离怪物不算卡住。怪物移动、路线走尽而未进入攻击范围、或玩家偏离路线时重新规划。真正无法推进才短期放弃该目标，避免站在墙边反复撞墙。

**设置项**：自动战斗 `F`、自动拾取 `G`、是否允许 Boss（默认否）、自动喝药阈值（HP / MP 共用，默认 35%）、品质过滤（后续）。旧档中的 `searchRadius` 保留兼容读取，但不再限制搜怪或巡游范围；设置面板移除此项。

**硬性异常规则（必须实现）**：
- 寻路空 / 终点占位 / 连续 3 次不推进 → 目标短期黑名单重搜；
- 目标消失 / 死亡 / 切图 → 停旧指令；
- 手动接管 → 立即取消、松手后 1.5 秒恢复；
- 背包满 → 停拾取该物不循环；
- MP 不足 → 回退普攻；**药不足 / 全在冷却 → 提示「无药可用」，仍继续战斗**（2026-10-12 起不再停战）；
- 死亡 → 自动转 off；游戏暂停或 NPC 对话 → 停决策，普通面板打开仍继续；窗口失焦不改变自动战斗状态与决策；
- Boss 范围技不可被自动跳过。

**首版实现说明（M1 历史记录，2026-10-12；搜怪范围与待机行为已由上方 M4-9 规则取代）**

- **已落地**：自动战斗状态机与寻路、拾取、恢复、手动接管；连续 3 次不推进后改选；松手 1.5 秒后恢复；死亡自动关闭、游戏暂停或 NPC 对话暂停决策，普通面板与窗口失焦继续挂机；背包满时不走向需入包的掉落物；HP / MP 分别低于阈值时自动喝对应药。HUD 显示当前状态（自动中 / 手动接管 / 暂停中）。
- **掉落拾取口径（2026-10-13 试玩修订）**：G 关闭时怪物掉落留地待点击，G 开启时可生成即认领或顺路收取；自动战斗在 G 关闭时绝不替玩家拾取。旧「始终生成即入包」规则作废，详见 9.9。未领取的精英 / Boss 战利品继续持久化。
- **现状说明**：基础斩击、裂地斩和旋风斩已接通；腐化源头使用可通行网格的 A* 四向绕障，开阔地图保持直线移动；16 格快捷栏已接通。历史阶段的临时直线寻路与固定药键规则不再适用。
- **药水使用已接线（M2.5，2026-10-12）**：手动（背包双击 / 键 `1`·`2`）与自动（HP / MP 各自低于阈值）共用 `Consumable.use`；每类药水独立冷却、互不阻塞、无公共 CD（5.11）；满值不扣药不进冷却。方案与执行记录见工程文档 12。

## 3.15 目标选择与锁定（Tab 切换）

手动战斗下的目标选择机制，与自动战斗（3.14）的 `searchTarget` 区分：本机制由玩家主动控制"锁定哪一个敌对目标"后再发动攻击。自动战斗的目标选择仍由 3.14 状态机负责。

**触发与候选集合**
- 玩家按 `Tab` 键，在**当前屏幕可视区域**内的敌对目标之间循环切换锁定目标。
- 候选集合 = 可视区域内所有敌对单位，包含普通怪、精英、**Boss**。
- 无锁定目标时按 Tab → 锁定候选集合中**距离玩家最近**的单位；已有锁定时按 Tab → 按距离升序切换至下一个（循环回到第一个）。
- 可视区域内无敌对目标时按 Tab → 无效果（可选：Toast 提示"附近无目标"）。

**锁定后的攻击交互**
- 锁定目标以"脚下高亮圈 + 头顶名称条"标识（见 9.5），HUD 右侧目标状态区同步显示其头像 / 名称 / 血蓝（见 9.1）。
- 玩家发动攻击的任一入口（普攻键 Space / 左键点目标 / 右键点目标 / 点击技能快捷格）→ 均作用于**当前锁定目标**。
- 若锁定目标**处于所选攻击方式的攻击范围之外** → 玩家自动寻路（A*，与自动战斗共用同一移动接口）走到该攻击方式的攻击范围内，到达后自动展开攻击；范围判定使用技能 / 普攻各自的范围参数（见 3.3）。
- 若已在攻击范围内 → 直接结算一次攻击（流程见 3.1）。

**与自动战斗的关系**
- 手动锁定攻击复用自动战斗状态机中的 `pathToTarget` 与 `attackTarget` 接口（3.14），不另写一套走位逻辑。
- 手动攻击期间若开启 `F` 自动战斗，自动决策接管目标选择，忽略手动锁定。

**退出锁定**
- 目标死亡 / 消失 / 切图 → 锁定自动清除，回到无目标态。
- 空闲右键（9.10）= 取消当前移动 / 攻击指令，但**保留**锁定目标；再次攻击仍作用于该目标。

## 3.16 拾取装备自动出售

**定位**：给高等级玩家（60 级起）一个「清理掉落」的省事手段 —— 捡到装备当场换钱，不必反复开背包清包。它是**可选的个人偏好**，默认关闭，与 3.14 的自动拾取（`G`）互不替代：`G` 决定「捡不捡」，本项决定「捡到之后卖不卖」。

**开关与门槛**
- 位置：设置 → 游戏 → 「拾取装备时自动出售」。
- **60 级才允许勾选**。不足 60 级时勾选框灰显并写明门槛；即使存档被改出「开关为真 + 等级不足」，运行时同样不生效。
- 默认关闭，按角色存档保存（不写入本机偏好）。

**筛选口径**
- 复用背包装备出售面板的**同一档预设**（谨慎 / 标准 / 积极），两处共用一个值：在设置里改，出售面板跟着变，反之亦然。
- **不提供「暴力」**。暴力是玩家当下面板里的主动动作，自动出售是「一次授权、长期生效」，语义不同。
- 谨慎 / 标准 / 积极三档的判据与手动出售**完全一致**（品质上限、等级差、旧套、已升星、评分是否提升）。因此「积极」**不等于全卖**：品质高于稀有的装备（史诗 / 传说）不会被自动出售。

**永不出售的情况**（任一条命中即留在背包）
1. 非装备：药水 / 如意 / 卷轴 / 杂项 / 任务物品 / 金币。
2. 收藏（玩家亲手打的保护标记）。
3. 不可售（任务物品、回收价为 0 的物品）。
4. 比当前该部位更好的装备（评分提升），以及已升星、品质超出预设上限的装备。
5. **该部位当前为空**。手动清单里玩家看得见能不能卖，自动出售没有这一步 —— 若不否决，某部位捡到的第一件会被当场卖掉，玩家将永远穿不上那一件。
6. **金币已达上限**。卖了等于白扔，装备留在背包并提示一次。这与手动出售「满金币照卖只提示」不同：手动是玩家自己点的，知情；自动出售玩家没点。

**反馈**
- 单件成交：提示「自动出售：<名称> +N 金币」，替代原本的「拾取：<名称>」，**不额外增加提示条数**。
- 精英 / Boss 的装备原本就逐件静默，改由批次摘要追加「· 自动出售 N 件 +N 金币」；摘要里的「装备 N 件」仍按掉落总数（玩家要同时知道掉了什么、钱从哪来）。
- 因金币上限而未卖时，提示「金币已达上限，X 未自动出售」（与「背包已满」共用节流，同一时刻只弹一条）。

**边界**
- 只影响**拾取**。商店购买的装备、任务奖励的装备、仓库与已穿戴装备都不经过本逻辑。
- 不改变掉落与拾取的时序：开启飞行动画时，装备仍然落地 → 停驻 → 飞行，只是在认领那一刻直接变现。
- 自动化出售不占背包格，因此开启后「背包满导致装备留地」的情况会显著减少；这不是缺陷。
