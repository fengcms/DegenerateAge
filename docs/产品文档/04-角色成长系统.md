# 04 角色成长系统

本章定义角色创建、人物属性、属性派生公式、经验与升级、无限等级终局模型，以及操控、死亡 / 暂停、生存恢复与死亡惩罚。

## 4.1 角色创建与存档槽

- 首次进入创建角色：名称（2–16 字符）、少量预设外观、职业固定"灵刃战士"、初始等级 1、进入幸存者营地。
- **多独立存档槽，首版 3 个**；能创建 / 读取 / 切换 3 个独立存档，互不影响。

```
┌──────────────────────────────┐
│   创建守护者                  │
│   名称：[__________]          │
│   外观：(○ 选项A ○ 选项B)      │
│   职业：灵刃战士（固定）        │
│   [ 开始游戏 ]                │
└──────────────────────────────┘
```

## 4.2 人物属性（首版核心，共 12 项）

| 属性 | 说明 |
|---|---|
| 血量（HP） | 当前生命值；最大生命值随等级、攻击力、防御力及装备加成变化 |
| 蓝量（MP） | 当前法力值；使用技能消耗法力值；最大法力值随等级与装备加成变化 |
| 攻击力（attack） | 对其他怪物 / 玩家的伤害 |
| 防御力（defense） | 对其他怪物 / 玩家伤害的抵抗 |
| 等级（level） | 当前等级，初始 1 |
| 移动速度（movementSpeed） | 玩家移动速度 |
| 暴击率（criticalChance） | 造成伤害时触发暴击的概率 |
| 暴击伤害倍率（criticalMultiplier） | 触发暴击时伤害乘算系数（如 1.5×） |
| 攻击间隔（攻速） | 普攻施法间隔 / 技能前后摇 |
| 闪避（dodge） | 被命中时完全免伤的概率（见 3.5 概率 Miss） |
| 格挡（block） | 首版不做（保留字段） |
| 冷却缩减（CDR） | 技能冷却缩短比例，上限 50% |

## 4.3 最大生命 / 法力派生公式

采用主流 ARPG「主属性派生次生命池」范式——攻击 / 防御作为成长主属性，间接抬高血量上限，使攻防投入同时提升生存，契合"血量随攻防变化"的设计意图。

```
maxHP = round( ( BASE_HP + level×HP_PER_LV + attack×HP_PER_ATK + defense×HP_PER_DEF )
               × (1 + ΣHPPercent) ) + ΣHPFlat

maxMP = round( ( BASE_MP + level×MP_PER_LV ) × (1 + ΣMPPercent) ) + ΣMPFlat
```

初始参数：

| 常量 | 值 |
|---|---|
| BASE_HP | 50 |
| HP_PER_LV | 8 |
| HP_PER_ATK | 2.0 |
| HP_PER_DEF | 4.0 |
| BASE_MP | 30 |
| MP_PER_LV | 5 |

- `ΣHPPercent / ΣHPFlat`：来自装备的百分比 / 固定加成（见《05 装备与背包系统》）。
- 例：L1（攻 12 / 防 5，无装备）→ `(50 + 8 + 24 + 20) = 102` HP，`(30 + 5) = 35` MP。
- 升级保留当前 HP / MP 百分比。
- **穿脱装备时的当前 HP / MP**：装备只改变上限，当前值**保持绝对值不变**（不按比例缩放、不自动补满）；若上限下降导致当前值超过上限，则收敛到新上限。

## 4.4 经验与升级

- 经验公式：`round(100 × L^1.6)`（多级连升、剩余结转、经验不为负、达到上限停升）。
- 1 级属性初值：攻 12 / 防 5 / 暴击 5% / 暴倍 1.5 / 攻间隔 0.8s；每级：攻 +2 / 防 +1；HP / MP 不按线性固定，由 4.3 派生公式随等级 + 攻 + 防 + 装备成长。
- 所有数值为**初始参数**，须经试玩调优。

## 4.5 无限等级与终局模型

本作**不设满级上限**，等级可无限提升；经验曲线使高等级耗时指数增长，玩家需长期游玩才能升级；通过版本更新补充新地图 / 新装备 / 新 Boss，旧档导入继续游玩。

- **无限等级**：沿用 `round(100 × L^1.6)`，无硬上限。L60→61 ≈ 70k 经验，L100→101 ≈ 200k，天然"越升越慢"。UI / 存档使用 64 位整数防溢出。
- **装备穿戴等级**：当前 1—20 级分两套、每套十类装备且每类只有一个名称；第一套依部位在 Lv1—10 逐级开放，第二套在 Lv11—20 逐级开放。装备实例的 `requiredLevel` 决定显示与穿戴门槛；基础数值与售价倍率按所属套计算。角色低于穿戴要求不得穿戴，怪物等级不直接决定装备要求。详见[现行装备目录](1-20级装备现行目录.md)。
- **版本化内容**：新地图 / 装备 / Boss 经版本更新发布。原三轴模型首次上线时为破坏性存档升级；现行逐级穿戴目录将 schema 11—12 装备实例迁入 schema 13，schema 0—10 仍不兼容。后续版本迁移按当次变更确定。
- **满级后目标（替代传统终局）**：装备词缀深度（刷高阶词条）、Boss 循环（周期性 Boss）、坐骑收集（特定 Boss 掉坐骑）。

## 4.6 操控（macOS 键鼠）

| 键 | 功能 |
|---|---|
| WASD | 屏幕相对八向移动（斜向输入归一化） |
| 鼠标左键 | 选中怪物并手动接近攻击 |
| Space | 普攻 |
| 1 / 2 / 3 | 技能栏 |
| I / C / M | 背包 / 属性 / 地图面板 |
| F / G | 自动战斗 / 自动拾取 |
| X | 打坐 / 起身 |
| Esc | 关闭面板 / 暂停 |

- 自动战斗开启时，手动输入令自动行为暂挂，**连续 3 秒无手动输入后恢复**；界面明显显示"自动中 / 手动接管 / 暂停中"。关闭自动后不得自动恢复。
- 右键功能见《09 UI 与交互规范》。

## 4.7 角色死亡与暂停

- HP 归 0 → 死亡态、取消目标与行动、停自动 → 玩家选择回安全区或消耗复活卷原地复活，恢复满 HP / MP；**不掉等级、不掉已穿戴装备、不扣金币**。背包内装备按 §4.8 随机掉落一件。
- 暂停菜单 → 停止战斗模拟、敌人 AI、刷新计时、掉落过期计时；恢复后继续。游戏窗口失焦仍运行战斗与世界模拟，自动挂机不中断；**进程退出后不累计离线经验 / 金币 / 掉落**。

## 4.8 生存 / 恢复 / 死亡

- **未受击恢复**：玩家存活且游戏未暂停时，每 3 秒结算一次 HP/MP 恢复；普通状态每次按最大值恢复 HP 1%、MP 2%，未满时各至少恢复 1 点，满值不溢出。移动、漫游寻怪、追击和主动攻击均不阻止恢复，也不重置计时；只有实际受到伤害才重置 3 秒计时。窗口失焦后游戏仍运行时计时继续推进。药水与被动恢复共用 HP/MP 变更入口。
- **打坐**：按 `X` 原地坐下，再按一次起身。坐下立即取消当前手动/自动移动与攻击，自动战斗开关保留但决策暂停；仍每 3 秒结算一次，改为每次按最大值恢复 HP 3%、MP 5%，未满时至少恢复 1 点。切换打坐只改变下一次结算量，不重置计时。方向键、地图点击、目标攻击或自动战斗重新开启会起身；怪物造成实际伤害时立即起身并重新开始 3 秒计时。死亡强制起身。打坐是运行态，不写存档；HUD 明示打坐状态。
- **死亡与复活**：HP 归零弹对话框，选择：
  - 「**回安全区复活**」→ 移动到安全区起始位置；
  - 「**原地复活**」→ 消耗**复活卷**，移动到死亡位置。
- **死亡惩罚**：死亡时仅从背包内装备随机掉落一件到地面；已穿戴装备、仓库、任务物、药品和金币不参与。原地复活后可再次拾取。复活选择期间世界暂停，地面物倒计时不推进。
- **地面物品时限**：死亡掉落 / 打怪掉落 / 玩家扔地面 的物品，**均仅保留 1 分钟（60 秒）后自动消失**；切图清当前地图地面掉落；拾取需距离 ≤1.5 格；背包满则留地提示不覆盖。
- 死亡复活对话框、地面物品时限、死亡惩罚随机掉装均属 MVP 核心生存与风险机制。
