# 04 角色成长系统

本章定义角色创建、人物属性、属性派生公式、经验与升级、无限等级终局模型，以及操控、死亡 / 暂停、生存恢复与死亡惩罚。

## 4.1 角色创建与存档槽

- 首次进入创建角色：名称（2–16 字符）、少量预设外观、**职业二选一（武士 / 法师，默认武士）**、初始等级 1、进入幸存者营地。
- **多独立存档槽，首版 3 个**；能创建 / 读取 / 切换 3 个独立存档，互不影响。
- 职业**建档时定下，进游戏后不能切换**（不做转职）；两职业**共用同一套 14 个装备槽**，不设职业专属装备。职业系数与两职业差异见 §4.9。

```
┌──────────────────────────────┐
│   创建守护者                  │
│   名称：[__________]          │
│   外观：(○ 选项A ○ 选项B)      │
│   职业：(● 武士  ○ 法师)       │
│   武士：高血近身，刀刀到肉      │
│   [ 开始游戏 ]                │
└──────────────────────────────┘
```

## 4.2 人物属性（首版核心，共 12 项）

| 属性 | 说明 |
|---|---|
| 血量（HP） | 当前生命值；最大生命值随等级、攻击力、防御力及装备加成变化 |
| 蓝量（MP） | 当前法力值；使用技能消耗法力值；最大法力值随等级与装备加成变化 |
| 攻击力（attack） | 对其他怪物 / 玩家的伤害 |
| 防御力（defense） | 对其他怪物 / 玩家伤害的抵抗 |
| 等级（level） | 当前等级，初始 1 |
| 移动速度（movementSpeed） | 玩家移动速度 |
| 暴击率（criticalChance） | 造成伤害时触发暴击的概率 |
| 暴击伤害倍率（criticalMultiplier） | 触发暴击时伤害乘算系数（如 1.5×） |
| 攻击间隔（攻速） | 普攻施法间隔 / 技能前后摇 |
| 闪避（dodge） | 被命中时完全免伤的概率（见 3.5 概率 Miss） |
| 格挡（block） | 首版不做（保留字段） |
| 冷却缩减（CDR） | 技能冷却缩短比例，上限 50% |

## 4.3 最大生命 / 法力派生公式

采用主流 ARPG「主属性派生次生命池」范式——攻击 / 防御作为成长主属性，间接抬高血量上限，使攻防投入同时提升生存，契合"血量随攻防变化"的设计意图。

```
maxHP = round( ( BASE_HP + level×HP_PER_LV + attack×HP_PER_ATK + defense×HP_PER_DEF )
               × (1 + ΣHPPercent) ) + ΣHPFlat

maxMP = round( ( BASE_MP + level×MP_PER_LV ) × (1 + ΣMPPercent) ) + ΣMPFlat
```

初始参数：

| 常量 | 值 |
|---|---|
| BASE_HP | 50 |
| HP_PER_LV | 8 |
| HP_PER_ATK | 2.0 |
| HP_PER_DEF | 4.0 |
| BASE_MP | 30 |
| MP_PER_LV | 5 |

- `ΣHPPercent / ΣHPFlat`：来自装备的百分比 / 固定加成（见《05 装备与背包系统》）。
- 例：L1（攻 12 / 防 5，无装备）→ `(50 + 8 + 24 + 20) = 102` HP，`(30 + 5) = 35` MP。
- 升级保留当前 HP / MP 百分比。
- **穿脱装备时的当前 HP / MP**：装备只改变上限，当前值**保持绝对值不变**（不按比例缩放、不自动补满）；若上限下降导致当前值超过上限，则收敛到新上限。

## 4.4 经验与升级

- 经验公式：`round(100 × L^1.6)`（多级连升、剩余结转、经验不为负、达到上限停升）。
- 1 级属性初值：攻 12 / 防 5 / 暴击 5% / 暴倍 1.5 / 攻间隔 0.8s；每级：攻 +2 / 防 +1；HP / MP 不按线性固定，由 4.3 派生公式随等级 + 攻 + 防 + 装备成长。
- 所有数值为**初始参数**，须经试玩调优。
- 技能仍按原等级解锁；解锁后可在技能面板用金币将五个主动技能有限升阶，普攻保持 1 阶。升阶等级门槛、上限与生效数值见《03 核心循环与战斗系统》§3.3.1；不采用技能点或无限熟练度。
- **章节节奏锚点**：C3–C6 一章约 **500–700 只普通怪 ≈ 1.5–2 小时**，纯做主线只到 21→42 级（其余靠刷怪），已作为验收锚点冻结在 [13 §2.6](13-满级后循环玩法（循环装备·循环Boss·随身三件套）.md)。该表的数字是实测值，不是可调参数。

## 4.5 无限等级与终局模型

本作**不设满级上限**，等级可无限提升；经验曲线使高等级耗时持续变长（**不是指数**：60 级起在 `L^1.6` 上叠一层线性增速，见 [13 §2.1](13-满级后循环玩法（循环装备·循环Boss·随身三件套）.md)），玩家需长期游玩才能升级；通过版本更新补充新地图 / 新装备 / 新 Boss，旧档导入继续游玩。

- **无限等级**：沿用 `round(100 × L^1.6)`，无硬上限。L60→61 ≈ 70k 经验，L100→101 ≈ 200k，天然"越升越慢"。UI / 存档使用 64 位整数防溢出。
- **装备穿戴等级**：当前 1—20 级分两套、每套十类装备且每类只有一个名称；第一套依部位在 Lv1—10 逐级开放，第二套在 Lv11—20 逐级开放。装备实例的 `requiredLevel` 决定显示与穿戴门槛；基础数值与售价倍率按所属套计算。角色低于穿戴要求不得穿戴，怪物等级不直接决定装备要求。详见[现行装备目录](1-20级装备现行目录.md)。
- **版本化内容**：新地图 / 装备 / Boss 经版本更新发布。原三轴模型首次上线时为破坏性存档升级；现行逐级穿戴目录将 schema 11—12 装备实例迁入 schema 13，schema 0—10 仍不兼容。后续版本迁移按当次变更确定。
- **满级后目标（替代传统终局）**：装备词缀深度（刷高阶词条）、Boss 循环（周期性 Boss）、坐骑收集（特定 Boss 掉坐骑）。

## 4.7 角色死亡与暂停

- HP 归 0 → 死亡态、取消目标与行动、停自动 → 玩家选择回安全区或消耗复活卷原地复活，恢复满 HP / MP；**不掉等级、不掉已穿戴装备、不扣金币**。背包内装备按 §4.8 随机掉落一件。
- 暂停菜单 → 停止战斗模拟、敌人 AI、刷新计时、掉落过期计时；恢复后继续。游戏窗口失焦仍运行战斗与世界模拟，自动挂机不中断；**进程退出后不累计离线经验 / 金币 / 掉落**。

## 4.8 生存 / 恢复 / 死亡

- **未受击恢复**：玩家存活且游戏未暂停时，每 3 秒结算一次 HP/MP 恢复；普通状态每次按最大值恢复 HP 1%、MP 2%，未满时各至少恢复 1 点，满值不溢出。移动、漫游寻怪、追击和主动攻击均不阻止恢复，也不重置计时；只有实际受到伤害才重置 3 秒计时。窗口失焦后游戏仍运行时计时继续推进。药水与被动恢复共用 HP/MP 变更入口。
- **打坐**：按 `X` 原地坐下，再按一次起身。坐下立即取消当前手动/自动移动与攻击，自动战斗开关保留但决策暂停；仍每 3 秒结算一次，改为每次按最大值恢复 HP 3%、MP 5%，未满时至少恢复 1 点。切换打坐只改变下一次结算量，不重置计时。方向键、地图点击、目标攻击或自动战斗重新开启会起身；怪物造成实际伤害时立即起身并重新开始 3 秒计时。死亡强制起身。打坐是运行态，不写存档；HUD 明示打坐状态。
- **死亡与复活**：HP 归零弹对话框，选择：
  - 「**回安全区复活**」→ 免费返回当前地图所属集群 `hubId` 指向的已解锁安全城镇，并在城镇默认落点满血满蓝复活；与回城卷使用同一目的地规则。若已在该城镇，则仅移动到默认落点；目的地配置无效或未解锁时保持死亡选择，不回退到幸存者营地。
  - 「**原地复活**」→ 消耗**复活卷**，移动到死亡位置。
- **死亡惩罚**：死亡时仅从背包内装备随机掉落一件到地面；已穿戴装备、仓库、任务物、药品和金币不参与。原地复活后可再次拾取。复活选择期间世界暂停，地面物倒计时不推进。
- **地面物品时限**：死亡掉落 / 打怪掉落 / 玩家扔地面 的物品，**均仅保留 1 分钟（60 秒）后自动消失**；切图清当前地图地面掉落；拾取需距离 ≤1.5 格；背包满则留地提示不覆盖。
- 死亡复活对话框、地面物品时限、死亡惩罚随机掉装均属 MVP 核心生存与风险机制。

## 4.9 职业（工程 98 新增）

两职业共用等级、经验、装备三轴、套装、耐久与技能阶位规则；职业差异集中在四条乘数、攻击射程，以及法师专属的法力成长与法术费用口径。

| 项 | 武士 | 法师 | 说明 |
|---|---|---|---|
| 生命系数 `hpMult` | 1.00 | **0.64** | 血池按比例缩小；这是法师「脆」的**唯一**来源 |
| 法力系数 `mpMult` | 1.00 | **2.00** | 武士沿用原公式；法师旧蓝池作成长下限，固定法力词条仍享 2 倍收益 |
| 攻击系数 `atkMult` | 1.00 | **1.08** | 略高，用来抵消少打一半的普攻次数 |
| 防御系数 `defMult` | 1.00 | **1.00** | 🔴 **两职业防御完全相同**（见下） |
| 攻击射程（格） | 1（近战） | **6（远程）** | 普攻、贴怪、自动战斗寻敌全部走同一个射程入口；6 格 = 屏幕高约 48%，是默认缩放下「正好不打出屏幕」的距离 |
| 普攻技能 | 斩击（单体近战） | 火球术（单体远程） | 火球有飞行弹道，但**伤害在按键那一刻结算**，飞行只是表现 |
| 主动技能 | 裂地斩 / 旋风斩 / 战意觉醒 / 破甲重击 / 裂魂风暴 | 雷电术 / 火焰喷发 / 魔法盾 / 冰咆哮 / 陨石术 | 技能按 `class` 归属，技能面板只列本职业 6 条 |
| 主色 | 原色 | 冷蓝（`86c8ff`） | 只影响角色贴图的 `modulate`，不影响任何数值 |

**为什么防御不降**：伤害是差值公式 `攻×系数 − 防×0.5`，**防御打九折就等于承伤 +39%**，是阶跃式的、不可控的。所以「脆」这件事**只由生命系数线性承担** —— 想调强弱改 `hpMult`，永远不要动 `defMult`。

**法师蓝池成长（工程 103）**：让法师在常规同级配装下呈现“红少蓝多”，目标法力/生命比为 **1.1—1.4**，全生命偏科配装允许偏离。法师以 `max(旧基础蓝×2, 1.20×战斗档次核心)` 作为法力底数；战斗档次核心由等级、**不含套装的基础攻防和装备固定攻防**按原生命派生权重计算，再乘法师生命系数 0.64。法力百分比词条作用于新底数，固定法力词条保持原有 2 倍收益，套装加成只乘最外层。直接生命词条不送法力。武士蓝量逐位不变；旧法师存档首次读取时按旧蓝池比例结转当前蓝量，此后不重复结转。具体公式与验收见 `docs/工程文档/103-法师生命法力成长与资源玩法调整方案.md`。

**法力与蓝耗（工程 103）**：法师攻击法术的配置系数为 **1.2%—2.6%**，实际费用由统一入口按 `系数 × (0.55×新法力上限 + 0.45×旧公式法力上限)` 取整；容量越大费用仍上涨，但不会完全抵消蓝池带来的额外施法次数。魔法盾开盾仍按**新法力上限的 6%** 付费，受击转蓝仍为每 1 点伤害扣 1 点法力；火球普攻不耗蓝。武士技能保持固定点数。技能详情显示系数、实时点数及折算说明，不能误称攻击法术费用是“最大法力的固定百分比”。

**技能节奏（工程 98 §13）**：除魔法盾（CD 10 秒）外，法师所有攻击技能的冷却都压到**攻击间隔级** —— 雷电术 **0.6 秒**（≈1 个攻击间隔，实际瓶颈变成攻击间隔本身）、冰咆哮 2.8 秒、火焰喷发 3.2 秒、陨石术 3.8 秒。**法师的输出方式是技能轮转，不是砍普攻**（普攻只在蓝不够时兜底），这是「不能硬扛、靠爆发换安全」定位的落点。
🔴 这条改动**必然**伴随系数下调（单次伤害降到初版的 0.57—0.60 倍）：技能施放本来就占用攻击槽位，CD 一短普攻就被挤掉，伤害若不同步降，法师 DPS 会达到武士的 2—3 倍。**改 CD 必须同时改系数，这是数学对价，不是可选优化。**

**法师挂机施法站位（工程 102）**：通常保持 6 格普攻射程；单怪优先雷电术，冷却或缺蓝时由火球术填槽。多怪时优先施放当前位置确实能命中至少两只的范围技；即使当前追击目标在远处，身边形成可命中的敌群时也先完成一次群攻，再继续追原目标。自中心圆形群攻按身边实际命中集合释放，扇形群攻选择射程内的有效朝向目标，远处锁定目标不应让一次本可命中的群攻施放失败。若陨石术暂不可用，而火焰喷发或冰咆哮已经就绪，且前方直线路段可通行、靠近后能命中至少两只，才短距离进位施法。进位失败则保持远程攻击，不因此拉黑原目标；低蓝保盾时不为范围技贴近。范围技能不为凑轮换对单怪空放，自动拾取与药水、魔法盾的既有优先级不变。

**魔法盾（法师专有主动 buff）**：持续 30 秒、基础 CD 10 秒，开启时扣一次蓝；CD 结束后可在盾仍有效时重施，把剩余时间刷新为 30 秒并按当前技能阶覆盖效果，不叠层、不累加时长。自动战斗在剩余不超过 5 秒时补盾；法力不足或角色无法施法仍可能断盾。期间受到的伤害按 **35%** 转由法力承担（1 点伤害换 1 点蓝，5 阶升到 47%）。**蓝被打空后转嫁立即失效**，掉血恢复常态 —— 这是法师「续航换生存」的核心风险。世界画面中魔法盾以包围人物的竖向椭圆护罩呈现，站立与骑乘分别适配外观尺寸；只有 Buff 有效且法力大于零时显示，断蓝熄灭、回蓝且 Buff 仍有效时恢复，死亡或 Buff 结束时消失。该外观不改变碰撞与伤害判定。

**冰咆哮减速**：命中后目标移速下降 35%、持续 3 秒；**对 Boss 生效但时长减半（1.5 秒）**，防止百首禁域那种 100 席场景被无限减速刷。

**平衡基线（160 级满紫 12 星实测，工程 98 §11.3）**：法师打同一只 Boss 的耗时约为武士的 **×0.92**、开盾时承伤生存力约为武士的 **×0.99**、**断盾时约为 ×0.64**。也就是说：**盾在线两者持平，盾一断法师明显更脆** —— 这是设计意图，不是数值失衡，不要「为了平衡」把 `hpMult` 调回去。
