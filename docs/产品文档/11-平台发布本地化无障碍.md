# 11 平台发布本地化无障碍

本章定义平台策略、发布 / Demo、本地化、成就、手柄、崩溃反馈与三项无障碍规范。音频规范并入 11.7。

## 11.1 本地化

- 首版 **中文**。P0 界面骨架与 P1 按钮、提示、错误文案统一由 `data/localization.json` 提供；物品名、任务正文、怪物名等 P2 数据文案仍以各自 `data/*.json` 为来源（见 10.2）。
- 文案 key 按界面或系统分组；缺失 key 会报警并回退显示 key。提交前运行 `tools/check_localization.py` 校验引用与 UI 脚本。正式增加第二语言前，还需复核按语言变化的文本宽度与语序。
- 字体方案支持中文渲染；国际版(英 / 日)待发布策略定，文案已外置故成本低。

## 11.2 成就系统

首版 **不做平台成就**；预留自建成就框架（首杀 / 章节 Boss / 等级里程碑 / 坐骑收集），上 Steam / MAS 时对接平台成就。

## 11.3 手柄支持

首版 **仅键鼠**（macOS 首发）。输入已抽象（4.6），后期可加手柄映射，不阻塞首版。

## 11.4 Demo / 试玩版

与商业模式耦合（买断制优先，可能免费分发）：建议「免费试玩第一章 + 付费解锁后续」或「限时免费 demo」。最终方案随商业模式分发渠道定。

## 11.5 崩溃报告 / 反馈

单机可后置；上线前加本地崩溃日志 + 设置内"反馈"入口（邮件 / 表单）。

## 11.6 无障碍规范

- **色盲模式（S44）**：背包与快捷栏药水除颜色外增加形状文字标识：红药为「十」，蓝药为「滴」；设置内可切换黄/青色盲友好配色，图标与文字标识始终保留。
- **文字大小 / 字体缩放（S45）**：文字缩放独立于 UI 缩放（9.3），档位 90/100/110/120%，保证最小可阅读。
- **键位重映射完整性（S46）**：全快捷键可改（9.3 控制项）；改键冲突实时提示并要求换键；提供恢复默认按钮。

## 11.7 音频与可访问性

- 最少音效：命中 / 受伤 / 死亡 / 拾取 / 升级 / 装备 / Boss 警示。
- 设置：音乐 / 音效音量分离、UI 缩放；声音不成为唯一提示。屏震、强光闪烁目前没有实际效果，正式效果上线时再开放对应开关，旧存档字段继续兼容。
- 基础音效 + 音量设置属 MVP。当前使用项目内原创合成的可替换占位素材：命中、受伤、死亡、拾取、升级、装备、Boss 警示和循环环境音乐。素材由 `tools/generate_placeholder_audio.py` 生成，无外部许可依赖。
