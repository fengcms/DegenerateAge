# 05 装备与背包系统

本章定义装备槽位、属性与词条、等级梯度、文本可编辑配置、杂项物品、装备经济、升星、品质与实例、背包，以及"属性更高"评分算法与药水数值。

## 5.1 装备分类与槽位（14 位）

```
防御向： [头盔][护甲][鞋子][盾牌][护腕][护腕][护膝][护膝]
攻击向： [武器][手镯][手镯][戒指][戒指][项链]

槽位数：头盔1 护甲1 鞋子1 盾牌1 护腕2 护膝2 手镯2 戒指2 武器1 项链1  =  14 位
```

- 武器与盾牌可同时装备；每类装备（含双槽类）可分别穿戴；装备即更新派生属性，不改基础值；卸下需背包有空位。
- 术语：原 GDD「服装」→ 本文件「护甲」，原「护肘」→「护腕」。

## 5.2 装备属性与词条

- 首轮固定属性为攻击、防御、生命、法力；随机百分比属性只开放生命和法力。攻击/防御百分比及其他战斗属性须等执行链实现后再开放掉落。
- **等级、品质、星级三轴独立**：当前两套各十种型号，穿戴要求依部位逐级分配为 Lv1—10 / Lv11—20，合计二十种；同一型号可生成五品质、0—12 星。`requiredLevel` 控制显示与穿戴门槛；所属套起点 1/11 控制基底与价值倍率，怪物等级与装备门槛分开。
- 品质只提高基础属性并决定词条总数；词条生成后永久固定。星级放大该件装备的基础与词条数值，不改变档位、品质或词条种类。

现行名称、两档基础值与任务奖励见[1—20 级装备现行目录](1-20级装备现行目录.md)。不再为任务、区域改装或首领传说设独立装备型号；来源只控制档位、品质与掉落数量。

## 5.3 装备配置（文本可编辑）

装备数据以**文本可编辑**格式存储（JSON，依最终引擎而定）；开发期可直接编辑文本文件中的装备属性，**不硬编码在代码里**。所有装备（及下文杂项物品）的字段由数据配置驱动（见《10 数据配置与存档技术》）。

## 5.4 可扩展杂项物品

除装备 / 药水外，支持「杂项物品」类别，属性可编辑、可后续扩展。例如「烟花」点击后播放动画（`useType=playAnimation`）。物品类型与效果由数据配置驱动，方便后续自行添加更多物品。

## 5.5 装备经济（出售 NPC）

每件装备有其**金币价格**；玩家可出售给 NPC 获取金币（见 6.4 货郎）。装备售价是金币的回收通道，与怪物掉落金币共同构成经济循环。

## 5.6 装备升星（核心金币消耗）

- 装备可**升星**以增加属性，最多 **12 星**。
- 由**铁匠**执行：中心放装备、四周最多放 4 枚如意（铁 / 玉 / 金 / 钻石如意 +5 / +10 / +15 / +20 个成功率百分点，仅 Boss 掉落）。如意可不放，也可在不同格放同类；选中的每枚均需占用背包中一枚库存。最终概率为 `min(100%, 基础成功率 + 各如意加成之和)`。升星前完整检查装备实例、金币和所有如意数量，不足时不扣任何资源；正式结算后无论成败均扣金币及已放如意，失败不降星。未放如意时保持原升星规则。
- 升星面板提供“**如意如意**”按钮，一键替换四格如意预选，**不直接升星或消耗材料**。优先从背包现有库存凑到 100%，达标组合先尽量少用钻石、再少用金、再少用玉如意；其后比较超过 100% 的溢出量及总枚数。因此 90% 时优先选两枚铁，而不是一枚玉。若四格内凑不到 100%，按单枚加成从高到低选最多四枚，不足四枚就只用现有数量。无可用如意、未选可升星装备或装备已满星时按钮置灰；基础率已是 100% 时点击清空误选如意。玩家仍可逐格手动改动。**背包中的如意减少后，面板自动保留库存允许的前几格预选并清空超额格；全部耗尽时四格变空，仍可不放如意继续升星。**最终扣除始终以结算时的背包库存为准。
- 升星是金币的**主要消耗途径**，迫使玩家刷怪获取金币。
- 装备详情显示未乘品质基底、品质基础增量、词条原值与升星增量；固定和百分比词条均展示升星增加值。实际战斗、评分和升级预览共用同一结算入口。

**升星成功率（初始参数）**：

| 0→1 | 100% | | 6→7 | 40% |
| 1→2 | 90% | | 7→8 | 30% |
| 2→3 | 80% | | 8→9 | 20% |
| 3→4 | 70% | | 9→10 | 10% |

## 5.7 品质与实例

品质枚举：`common / uncommon / rare / epic / legendary`（普通 / 优秀 / 稀有 / 史诗 / 传说）。
颜色上是：白色，蓝色，绿色，黄色，紫色。

- **模板 ID 与实例 ID 分离**：同模板可不同词条；生成后实例属性永久保存，不每次重随。
- 传说是所有正式型号均可获得的最高品质，不能强制绑定特定武器或专属池；不因传说品质自动获得未实现的独特被动。
- 首版品质基础倍率/随机词条总数：普通 `1.0/0`、优秀 `1.2/1`、稀有 `1.5/2`、史诗 `1.9/3`、传说 `2.4/4`。百分比计入总数，同属性不重复。

## 5.8 背包

- **初始 40 格**，可用金币按仓库同类递增价格扩容，每次 +10 格，最多 400 格（具体参数见 6.8）；扩容次数随角色存档，旧档默认 0 次；装备不可堆叠、药品 / 材料堆叠 99；已穿戴不占背包。
- 支持查看 / 比较 / 穿戴 / 卸下 / 用药 / 拖到地面丢弃 / **自动整理**。背包面板有独立「整理」按钮。
- 穿戴槽只在人物面板展示。人物与背包面板同时打开时，背包装备可拖到同类穿戴槽，穿戴装备可拖到背包空格；双方装备格可双击快速穿戴 / 卸下。只打开一侧时，装备格双击无效；药水、卷轴的背包双击使用不受此限制。
- 双击自动穿戴先选同类空槽；全满时选择最低品质，同品质选最低评分，完全相同按固定槽序。拖放尊重指定槽。候选品质低于实际目标时，两种入口均须确认；勾选「下次不再提示」且更换成功后仅本次游玩省略提醒，新游戏、成功读档或重开恢复。确认时暂时暂停世界，取消不交换物品。详见创意 20。
- 悬停背包装备时，浮层显示背包装备及所有对应穿戴槽的完整属性：单槽类两张卡，戒指、护腕、护膝、手镯等双槽类三张卡，宽度不足时分行。未装备槽显示「未穿着」。展示评分、默认替换目标与差值；评分提高且当前可穿戴时标注绿色「更强 ↑」，评分提高但等级不足时标注灰色「评分更高，需 LvX 才可穿戴 ↑」。默认目标为空槽时明确标出「默认目标空槽」，不声称胜过另一槽的已穿装备。双槽标为①/②。
- 背包中按默认替换槽计算后评分严格提高的装备，在格子右上角常驻向上箭头：当前可穿戴为绿色，等级不足为灰色；空槽装备后得到正评分也算提高。灰箭头仅表示达到等级后可提高评分，不允许提前穿戴。非装备、无有效槽、同分或降分均不显示。穿戴、升级、整理及背包变化时即时刷新。箭头与浮层使用同一评分和默认槽口径，不参与低级装备出售筛选。
- 并列属性浮层按内容紧凑决定高度，不拉伸至窗口底部；标题和属性文字跟随设置中的「文字大小」倍率（含显示适配系数）。
- 背包操作帮助放在标题栏关闭按钮左侧的问号图标上，悬停查看；面板底部不再常驻帮助文案。
- 背包中的任意物品都可手动拖到另一格：目标为空格则移动，目标已有物品则交换；不合并堆叠、不重随装备属性。整理按钮仍执行自动排序。
- 拖动物品时，跟随鼠标的预览沿用原格子的尺寸、底色、边框、图标或文字及数量角标，不切换为另一种形状。
- 人物面板已穿戴槽显示该装备实例对应模板的实际物品图标，不再按槽类型画通用图形；素材尚未交付时，以装备名称缩写暂代，后续放入模板指定图标路径即可自动生效。
- **星级角标（2026-10-20 新增）**：凡装备格（背包、人物穿戴槽、仓库、商店货架、合成材料格）在**左上角**显示星级徽标，让玩家一眼分辨「这件有没有升过星」。0 星不显示（否则满背包都是标记，反而成噪音）；1—5 星 `★N` 亮蓝、6—8 星 `★N` 亮绿、9—11 星 `★N` 亮金、12 星为 ☀️（彩色 emoji 太阳，字号比星号大 2px）。星级色取同色系**提亮版**，与品质框的蓝 / 绿 / 金拉开明度差，避免「金角标 + 绿边框」被误读成金装。字符一律用 `★`（U+2605，可染色的字形）而**不是** `⭐`（U+2B50，彩色 emoji 无法染色）。
- 为给星级角标腾位，原左上角的**收藏标记**改为 `◆` 移到右上角（升级箭头 ↑ 的左侧，字号 10px）。收藏与星级同格并存、互不遮挡；宽度实测：`★11`@11px = 24px、`◆`@10px = 8px、`↑` 字符 13px 右对齐，三者在 52px 格内 `[2,26] / [26,36] / [37,50]` 互不重叠；46px 的仓库 / 商店格把星级再缩 2px 以维持同样的间隙。星级角标不拦截鼠标与拖放。
- 未穿戴槽显示灰色边框及槽位类别文字（如「武器」「盾牌」「戒指」），不显示装备图标。
- 整理规则：只处理当前容器，按**装备 → 药品 → 如意 → 杂项 → 任务物品**排列，同类按物品模板 ID 排列；同模板装备再按品质、星级由高到低排列。空格移到末尾。可堆叠物品仅在除数量外的实例数据完全相同时合并，单堆不超过模板上限；装备不合并，原有属性 / 词条 / 实例 ID 不变。
- 背包「出售装备」在 Lv15 解锁；点击后按角色保存的「谨慎／标准／积极」预设生成本次待售清单，逐件显示并允许取消或增加勾选，确认后才整批卖出。谨慎（默认）：穿戴要求比角色低至少 10 级、普通、0 星；标准：装备所属十级档早于角色当前档（档起点 = floor((穿戴等级 − 1) / 10) × 10 + 1）、不高于稀有、0 星；积极：**不设等级门槛**、不高于稀有、0 星。收藏装备、不可售装备和**评分高于已穿戴同槽装备**的装备均不会被预设自动选中；默认替换槽为空时不计入该评分保护。未锁定的预设外装备可由玩家手选，经额外风险确认后出售。收藏装备须先解锁，单件出售也不可绕过。预设随角色存档，本次勾选不存档；交易前重新核对实例、价格、装备状态和金币上限。只处理背包装备，不触碰穿戴、仓库、任务物或货郎托盘。**暴力预设（2026-10-20 新增）**：背包内所有可售装备一次售出，不提示、不二次确认，且**不记入存档**；收藏装备与任务物品仍不卖。详见产品方案 14。
- 向货郎**一键出售**见 6.4。
- **药水 / 材料也可回收（2026-10-17 修订）**：除装备外，药水、杂项材料与如意同样可拖入货郎托盘换取金币，非装备按基础价**六折**、**整叠一次卖完**结算（见 06 §6.2 / §6.4）。任务物品不可出售。「出售装备」与货郎「挑选装备」**始终只列装备**，不会把药水当低价值装备卖掉；清理药水请用货郎出售页的「一键移入药品」（2026-10-20 起只搬药水，卷轴与如意需单独拖入）。

## 5.9 「属性更高」判定算法（评分）

用于替换提示"新装备评分更高"；一键出售按预设的档位／等级与品质筛选，另对**评分高于已穿戴同槽装备**的装备加保护（5.8）。

```
score = w_atk×有效攻击 + w_def×有效防御 + w_hp×有效生命 + w_mp×有效法力
        + Σ(有效百分比×100×对应权重)

权重初稿：攻 1.0 / 防 1.0 / HP 0.3 / MP 0.3（按数值量纲归一，试玩调优）
```

## 5.10 随机词条池与值域

- **首轮可生成词条池**：固定攻击、防御、生命、法力；百分比生命、法力。其他属性须完成战斗效果、显示和上限规则后再开放。
- **品质词条数**：普通 0、优秀 1、稀有 2、史诗 3、传说 4；每个属性键同件不重复。百分比词条计入总数，稀有及以上可出现且每件最多一条；若合法池不足，配置必须报错。
- **首轮词条值域**：固定值按装备档位配置并抽取；百分比为 2%—8%，稀有/史诗/传说各以 50% 概率尝试一条。后续以试玩调整配置。

## 5.11 药水数值

MVP 药品：分级红蓝药水（小 / 中 / 大），**每类独立冷却、互不阻塞、无全局公共冷却**，恢复量不超过最大 HP。

| 药水 | 恢复量(红HP / 蓝MP) | 冷却(s) | 价格 | 堆叠 |
|---|---|---|---|---|
| 小红 / 小蓝 | 80 | 8 | 20 | 99 |
| 中红 / 中蓝 | 220 | 12 | 60 | 99 |
| 大红 / 大蓝 | 500 | 20 | 150 | 99 |

**使用交互（M2.5 落地，2026-10-12）**

- **手动**：背包面板**双击**药水即使用；快捷键 `1` 喝红 / `2` 喝蓝（键位与 9.1 快捷栏一致，M4 由正式快捷栏接管）。装备双击穿戴须同时打开人物面板，避免单独查看背包时误穿戴。
- **自动**：自动战斗中 HP ≤ 阈值（3.14，默认 35%）时自动喝药，**按缺口选"够用的最小档"** —— 缺口 60 → 用回 80 的小药，避免中药 220 溢出浪费；无一档够用时取恢复量最大者。红蓝各按其自身缺口独立判定（用户 2026-10-12 拍板红蓝一并开）。
- **满值不浪费**：当前 HP / MP 已达上限时**不扣药、不进冷却**，只给出明确提示。
- **药尽仍继续战斗**：药水耗尽或全部处于冷却时不再停寻怪（与 3.14 同步变更）。
- **冷却为运行态**：不写入存档（与自动战斗开关同类，见 10.3）；重启 / 读档后清零。
- **实现**：`scripts/systems/consumable.gd`（`Consumable`，手动与自动共用唯一入口）；方案与执行记录见工程文档 12。

## 5.12 升星与品质 / 词条关系

- 升星对**该件装备全部数值贡献**生效：`S=1+star×0.1`，固定属性 `S×(档位基底×品质倍率+固定词条)`，百分比属性 `S×百分比词条`。不放大玩家基础属性、其他装备或技能；汇总后统一取整。
- 品质决定基础倍率和词条数量；升星不解锁 / 新增词条，不改变品质或穿戴档。
- 升星后售价按经济模型公式含 `star×0.08` 加成（见《06 经济与 NPC 系统》）。

## 5.13 铁匠合成与保星升级

- 金色指 `epic`、紫色指 `legendary`。四件金装可合成一件**输入最低十级档**的随机类型紫装；四件**同档**紫装可指定目标类型，合成该档的一件紫装；“四紫升紫”则消耗 **2—4 件同档**紫装，生成**高一档、随机类型**的一件紫装，例如 61—70 档升为 71—80 档。三种四合一产物都是全新 0 星实例，词条重新随机；合成不额外收费。四金材料允许任意星级，四紫定向与四紫升紫允许 0—11 星，**12 星紫装不可投入**。已升星材料消耗前需明确提示星级消失；四紫升紫的最高可用输入档是 9971—9980，再高时在预览阶段拒绝。
- **四紫升紫用件数换成功率**：4 件 100%、3 件 75%、2 件 50%，产物档位与件数无关（都是材料档 +1，仍是全新 0 星随机部位）。**掷骰失败会消耗投入的全部材料且不生成产物。** 这不是打折——三档的**期望材料消耗都精确等于 4 件**（`n ÷ (n/4) ≡ 4`），件数少只是**方差更大**（消耗件数标准差 0 / 2.00 / 2.83）；2 件档有 10% 的概率要烧到 6.6 件才成一次。因此预览必须同时显示成功率与「失败将消耗投入的全部材料」，且 2—3 件时首次点击只出警告、第二次才结算。四金与四紫定向**不开放**这个阶梯：品质跃迁与「可指定部位」本身是额外价值，打折会把高价值兑换变成赌博。
- 保星升级消耗低档 12 星紫装、**任意更高十级档**（不是只能高一档）的同类型 0 星紫装，金币按**跨档数**收取：跨 1 档 = `Σ Upgrade.cost(0…11)` = **128,747** 为基准价，每多跨 1 档多扣 1 份基准价（跨 2 档 257,494、跨 3 档 386,241，依此类推）。产物是目标档同类型的全新 **12 星紫装**，词条重新随机；两件材料原词条均不继承，不满意可重铸。51 档武器可配 61 / 71 / 81 档武器，不可配 61 档戒指；同档与降档仍然拒绝。目标档最高到 9981 套（9981—9990 级），再高会造出超过实例等级上限 9999 的产物，规则层在预览阶段直接拒绝并说明原因。
- **产物穿戴等级高于玩家当前等级时照样合成**（材料是玩家自己的，规则不替他判断值不值）；确定部位的产物预览提示准确需求等级，四紫升紫因部位随机，预览提示目标档等级范围及“可能暂时无法穿戴”，产出后显示准确需求等级。
- 四项操作均由铁匠提供，材料默认取背包；收藏件一律不可投入。**保星第一格（旧 12★）可以直接从人物面板把身上正穿着的那件拖进来**，确认后该穿戴槽清空、角色当场变弱，因此首次确认必须额外写明「该部位将空出」。四金、两种四紫与保星第二格仍只收背包件（第二格要的是 0★ 新料，从身上拖等于「先脱下来再当肥料」，收益不对等）。确认时重新核对实例、等级档、星级与金币，**这类校验失败不消耗资源**；唯一的例外是四紫升紫掷骰失败——它按设计就吃掉投入的材料（见上一条）。详见工程文档《铁匠装备合成与保星升级开发计划》《68-四紫升紫可行性与实施方案》及《75-四紫升紫随机放入档位与材料数量调整方案》。
- 四种服务均与背包并排（窄窗口改上下排列），从背包拖入材料格；**会话中可同时打开人物面板**（按 C 不会关掉合成工作台），人物面板是普通浮窗、可拖标题栏挪开，窄屏下玩家自行摆放。材料在确认前只被预选，仍留在原背包格并显示“已选”，关闭或撤下不扣物。四金、四紫定向、四紫升紫各有“随机放入”：仅从未收藏、0 星装备中**取最低合格档**（四紫升紫该档 ≥2 件即可，四金与四紫定向需 ≥4 件），无放回抽到该档能凑出的件数并替换当前预选——**低档料先当肥料，背包里留着的高档紫装不会被「省事」按钮吃掉**；四紫升紫不选择已到最高档、无法再升级的装备。随机放入不会立即合成。保星只提供两个指定用途格，不提供随机放入。拖入、随机放入均不改变上文手动四金混档和结算规则。

## 5.14 套装加成（品质套 + 星级套）

**目的**：给「收集整套同色装备」和「全面发展星级」一个可见的长期目标，让玩家愿意在 14 个槽位上平均投入，而不是只堆武器。

**判定基数**：14 个槽位（5.1 的十部位）**全部穿满**才成立。空 1 槽即不成套，两档都不生效。

**两个维度独立判定、结果相加**（不是相乘）：

| 维度 | 判定 | 档位 |
|---|---|---|
| 品质套 | 14 件中**最低品质** | 优秀（蓝）2% / 稀有（绿）5% / 史诗（金）10% / 传说（紫）20% |
| 星级套 | 14 件中**最低星级** | 全 +6 星 3% / +8 星 5% / +10 星 10% / +12 星 20% |

- 加法叠加：**全紫 + 全 12 星 = 20% + 20% = 40%**（乘法会得 44%，不采用）。
- 白装 `common` **不给品质加成**（0%）。它是过渡品，也是战斗节奏的基线口径。
- 混搭示例：13 件紫 + 1 件蓝 ⇒ 按蓝档 **2%**；13 件 12 星 + 1 件 6 星 ⇒ 按 6 星档 **3%**。

**「全部属性」的确切清单**：

- 放大：攻击、防御、生命上限、法力上限、暴击率、暴击伤害、闪避、格挡、冷却缩减、移动速度。
- **反向**：攻击间隔**除以** (1+加成)——乘 (1−加成) 会让攻速实涨 66.7%，与「属性 +40%」不符。
- **不重复计算**：`hpPercent` / `mpPercent` 词条不单独放大，它们的收益已经包含在生命 / 法力上限的放大里。
- 战斗百分比属性放大后仍受各自上限截断（暴击率 75%、暴伤 5.0×、冷却缩减 50%、闪避 / 格挡 100%）。

**口径与展示**：

- 加成为**派生值，不落档**。读档后由已穿戴装备重新计算，存档结构与 schema 不变。
- 「生命上限 +40%」是**一次性放大**：生命公式内部用不含套装的基础攻防，套装只在最外层乘一次（等价于玩家在人物面板看到四项主属性各为原值的 1.4 倍）。
- 人物面板必须同时显示**当前档位**与**距下一档还差几件**，否则玩家无法判断「差一件」的距离 —— 这是本机制诱导收集的关键，不是装饰。
- 未成套时显示「套装  未成套（n/14）· 穿满 14 个槽位后生效」。

**与升星 / 品质的关系**：套装加成是在「品质倍率 × 星级倍率」之上的第三个乘数。全紫 12 星的单件数值已是基底的 5.28 倍，叠加套装后为 7.39 倍。该量级为产品有意设计（终局收集目标），不视为数值缺陷；怪物侧的相应对冲另行评估。

## 5.15 装备耐久度与修理

**实例字段**：每件装备带 `durability`（0—上限，当前 800）。旧档缺失该字段视为满耐久，零迁移。

**损耗**：每次击杀结算时，已穿戴 14 件按怪物档次各自扣点——普通怪 1 点、精英 4 点、Boss 12 点。分档的目的是让升级、循环、刷金三种玩法的修理周期都落在 1.5—2.5 小时（约一章 / 一次挂机小节）。若统一 1 点/杀，循环图 30 Boss/h 只耗 30 点/h，修理在后期直接消失——而后期恰是金币最需要出口的时候。

**失效语义**：耐久归零时该件**自身属性失效**（攻击/防御/生命/法力/词条全部不计入），**套装加成照常**——套装按槽位计数，破损件仍穿戴仍算数。属性展示与生效分离：tooltip 照常列出属性（灰显 + 红字「已损坏，属性未生效」），玩家能看见修好后拿回什么。

**修理**：铁匠新增「一键修理」，只修**身上** 14 件（背包破损件可能是留卖/留合成的料）。费用按缺失比例收取，修满全身约等于一次重铸的费用（61 级后恒成立）。随身商店提供 1.5 倍价格的应急修理——铁匠仍是回城最优解，但挂机玩家不至于眼睁睁看着装备归零。金币不足时一件不修。

**预警**：耐久跌破 20% 与归零时各提示一次 toast（每件每档一辈子一次，修理后复位），避免 14 件同时破损时刷屏。

**与其他系统的关系**：
- **自动出售 / 一键出售排除破损件**——破损 ≠ 垃圾，修好还是好装备；`score()` 归零会让破损件失去「属性更高」保护，必须单独拦截。
- 升星 / 重铸 / 保星可正常操作破损件（耐久与星级正交）；合成产物恒满耐久。
- 死亡**不扣**全身耐久（与挂机断装螺旋风险叠加，本期不做）。

## 5.16 重铸精炼（紫装的新出口）

重铸面板在词条锁定之外新增**精炼材料区**：最多投入 4 件背包里的紫装，把本次重铸**未锁定词条**的数值下限抬高。这是紫装在「四紫定向 / 四紫升档」之外的持续出口——不需要同档凑件，任意档位、零散件数都能投入（方案见工程文档 86）。

- **可投材料**：背包中 `legendary` 品质的装备，不得收藏、不得与目标件为同一实例；金装、蓝绿白、药水杂项一律拒收。人物身上正穿的件不能投入（需先脱下进背包）。
- **折算有效件数**：同档 1、高 1 档及以上 2、低 1 档 0.5、低 2 档及以下 0.25；**12 星额外 +1**。折算后相加，**封顶 4**，超出部分不累计。
- **收益**：本次未锁定词条的下界抬到 `min(60%, 15% × 有效件数)` 分位——1 件 15%、2 件 30%、3 件 45%、4 件 60%。词条类型池、条数、锁定条目原值均不变；锁定词条不吃这个下限。
- **金币**：**不变**，仍按 `Reforge.cost(等级, 锁定条数)` 收取。精炼既不额外收费也不打折，锁词条加价照旧。
- **扣除时机**：材料与金币在确认重铸时**同批扣除**，先掷词条再扣；任何校验失败（材料不合格、金币不足）一件材料都不扣。预览、撤下材料、关闭面板均不扣。
- **面板提示**：材料区实时显示「精炼 N 件（有效 X）· 未锁定词条下限 Y%」；不投材料时提示「不投入材料则按原区间随机」。
- **会话并开**：打开重铸面板时自动打开背包（宽屏左背包、右重铸）；关闭重铸保留背包，在背包侧按 I / Esc 退出整场会话。规则见工程文档 87。
- **随机放入**：精炼区标题行提供「随机放入紫装」，自动从背包取未收藏、0 星、目标同档或更低档的紫装替换当前 4 格，同档优先、低档兜底；只改预选、不扣物品。没有候选时保留原预选并提示原因。
- **与存档**：材料只是本次面板的选择，**不落档**；读档后精炼区为空。
- 死亡**不扣**全身耐久（与挂机断装螺旋风险叠加，本期不做）。
