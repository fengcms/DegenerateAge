# 05 装备与背包系统

本章定义装备槽位、属性与词条、等级梯度、文本可编辑配置、杂项物品、装备经济、升星、品质与实例、背包，以及"属性更高"评分算法与药水数值。

## 5.1 装备分类与槽位（14 位）

```
防御向： [头盔][护甲][鞋子][盾牌][护腕][护腕][护膝][护膝]
攻击向： [武器][手镯][手镯][戒指][戒指][项链]

槽位数：头盔1 护甲1 鞋子1 盾牌1 护腕2 护膝2 手镯2 戒指2 武器1 项链1  =  14 位
```

- 武器与盾牌可同时装备；每类装备（含双槽类）可分别穿戴；装备即更新派生属性，不改基础值；卸下需背包有空位。
- 术语：原 GDD「服装」→ 本文件「护甲」，原「护肘」→「护腕」。

## 5.2 装备属性与词条

- 除固定数值加成外，可有**百分比加成**属性：增加血量 / 蓝量 / 攻击力 / 防御力（按比例提升对应属性）。
- **百分比属性不出现在普通装备上**；装备阶位越高，出现百分比属性的概率越高。
- 每一件**高阶**装备随机出现不同属性加成（非固定，随机词条）。
- **装备等级梯度（每 10 级一套）**：装备按等级分段（1–10 / 11–20 / 21–30 …），每分段配一套适配模板；分段越高，基础数值越高、出现百分比属性 / 随机词条概率越高。
- **装备等级需求（穿戴门槛）**：每件装备有穿戴等级门槛（如 1–10 段需 Lv≥1、11–20 段需 Lv≥11），低于门槛不可穿戴；与"每 10 级一套"梯度配套。

## 5.3 装备配置（文本可编辑）

装备数据以**文本可编辑**格式存储（JSON，依最终引擎而定）；开发期可直接编辑文本文件中的装备属性，**不硬编码在代码里**。所有装备（及下文杂项物品）的字段由数据配置驱动（见《10 数据配置与存档技术》）。

## 5.4 可扩展杂项物品

除装备 / 药水外，支持「杂项物品」类别，属性可编辑、可后续扩展。例如「烟花」点击后播放动画（`useType=playAnimation`）。物品类型与效果由数据配置驱动，方便后续自行添加更多物品。

## 5.5 装备经济（出售 NPC）

每件装备有其**金币价格**；玩家可出售给 NPC 获取金币（见 6.4 货郎）。装备售价是金币的回收通道，与怪物掉落金币共同构成经济循环。

## 5.6 装备升星（核心金币消耗）

- 装备可**升星**以增加属性，最多 **12 星**。
- 由**铁匠**执行：中心放装备、四周放如意（铁 / 玉 / 金 / 钻石如意 +5%~20%，仅 Boss 掉落）；成功率见下表；无论成败均扣金币与如意。
- 升星是金币的**主要消耗途径**，迫使玩家刷怪获取金币。

## 5.7 品质与实例

品质枚举：`common / uncommon / rare / epic / legendary`（普通 / 优秀 / 稀有 / 史诗 / 传说）。
颜色上是：白色，蓝色，绿色，黄色，紫色。

- **模板 ID 与实例 ID 分离**：同模板可不同词条；生成后实例属性永久保存，不每次重随。
- 传说装备通过**独特被动**而非词条数量堆叠体现强度（见 5.11）。

## 5.8 背包

- **40 格**（待定）；装备不可堆叠、药品 / 材料堆叠 99；已穿戴不占背包。
- 支持查看 / 比较 / 穿戴 / 卸下 / 用药 / 拖到地面丢弃 / **自动整理**。
- 向货郎**一键出售**见 6.4。

## 5.9 「属性更高」判定算法（评分）

用于一键出售排除"评分 ≥ 已穿戴同槽位"的装备，以及替换提示"新装备评分更高"。

```
score = w_atk×atk + w_def×def + w_hp×hp + w_mp×mp
        + Σ(pct×100×对应权重) + starBonus

权重初稿：攻 1.0 / 防 1.0 / HP 0.3 / MP 0.3（按数值量纲归一，试玩调优）
```

## 5.10 随机词条池与值域

- **词条池**：攻击力 / 防御力 / 最大 HP / 最大 MP / 暴击率 / 暴击伤害 / 攻击间隔(攻速) / 闪避 / 格挡 / 冷却缩减 / 移动速度。
- **各品质随机词条数**：普 0 / 优 1 / 稀 1–2 / 史 2–3 / 传 = 独特被动（传说不随机词条，依独特被动效果区分）。
- **值域（每条，初始参数，随 Tier 缩放）**：固定值词条 = 基础 ×(0.8~1.2 随机)；百分比词条 = 2%~8%（仅稀 / 史出现，传说靠独特被动不产随机百分比）。
- 百分比词条仅高阶装备（稀 / 史）出现，普通 / 优秀不出现。

## 5.11 药水数值

MVP 药品：分级红蓝药水（小 / 中 / 大），**每类独立冷却、互不阻塞、无全局公共冷却**，恢复量不超过最大 HP。

| 药水 | 恢复量(红HP / 蓝MP) | 冷却(s) | 价格 | 堆叠 |
|---|---|---|---|---|
| 小红 / 小蓝 | 80 | 8 | 20 | 99 |
| 中红 / 中蓝 | 220 | 12 | 60 | 99 |
| 大红 / 大蓝 | 500 | 20 | 150 | 99 |

## 5.12 升星与品质 / 词条关系

- 升星**仅加固定属性**（每星 +基础值 ×starMult，starMult 初始 0.1），**不解锁 / 新增词条**。
- 品质决定词条数量与值域（5.10）；升星在品质基础上叠数值，不改变词条结构。
- 升星后售价按经济模型公式含 `star×0.08` 加成（见《06 经济与 NPC 系统》）。
