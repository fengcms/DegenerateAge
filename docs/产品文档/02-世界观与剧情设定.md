# 02 世界观与剧情设定

## 2.1 纪元背景

纪元 3172，灵气衰竭的末法时代。古代灵脉的过度开发导致世界屏障损坏，紫色异界裂隙开启，异族大举入侵，人类文明退守至最后几处幸存营地。玩家扮演一名在废墟中苏醒的年轻守护者，天生能够吸收异族消散时逸出的灵能，并将其转化为自身成长的力量——这正是"打怪升级"在世界观层面的解释。守护者的使命是夺回家园、查明裂隙真相、击败异族统帅。

## 2.2 主角

- 身份：废墟中苏醒的年轻守护者。
- 核心能力：吸收异族消散灵能转化为经验（成长来源）。
- 使命：夺回家园、查明裂隙、击败异族统帅。

## 2.3 章节结构

游戏规划 **6 章 + 序章**，每章拥有独立的 Boss 与区域主题。首版聚焦 **序章 + 第一章**。

```
序章：苏醒与试炼
  └─ 第一章：幸存者营地 / 灰烬之地 / 腐化源头（Boss：腐化巨兽）
       └─ 第二章及以后（版本化内容扩展，旧档可导入继续）
```

每章独立 Boss；章节之间通过车夫中转与区域解锁串联（详见《07 地图关卡与怪物》）。

## 2.4 首版聚焦内容

首版（第一章完整版 P3）覆盖：

- **地图**：幸存者营地（安全区）→ 试炼野外 → 灰烬之地 → 腐化源头（Boss 区）。
- **怪物**：腐化野狼（近战）/ 裂壳虫（高防）/ 灰烬游魂（远程）+ 精英裂爪狼王 + Boss 腐化巨兽。
- **任务**：主线 5 连（Q001–Q005）+ 任务官发布的支线打怪任务。
- **系统**：战斗 / 装备 / 经济 / NPC / 坐骑（达 20 级后）/ 升星（后期闭环）等完整产品需求。

## 2.5 第一章主线任务链（Q001–Q005）

任务状态枚举：`locked / available / active / completed / rewarded`。同一次击杀只记一次，奖励不重复领取；主线任务不可放弃（随章节推进锁定）。

| 任务 | 目标 | 奖励 |
|---|---|---|
| **Q001 守护者苏醒** | 与长老交谈 | 基础武器 / 药品 / 操作引导 |
| **Q002 初战试炼** | 击败 5 只腐化野狼 | 经验 + 金币；开启自动战斗提示 |
| **Q003 荒野遗物** | 拾取 3 个灵能碎片 | 初级护甲 + 经验 |
| **Q004 精英踪迹** | 击败裂爪狼王（精英） | 装备奖励 + Boss 线索 |
| **Q005 腐化源头** | 击败腐化巨兽（Boss） | 第一章完成 / 第二章入口解锁 + 经验 + 金币 |

```
Q001 苏醒 ──→ Q002 初战 ──→ Q003 遗物 ──→ Q004 精英 ──→ Q005 源头
  (引导)      (5野狼)       (3碎片)      (狼王)       (巨兽→解锁第二章)
```

## 2.6 剧情呈现方式

- 首版无复杂过场动画；剧情通过 **NPC 对话 + 任务文本 + 区域氛围** 推进。
- 对话系统为线性逐句推进（点击"继续"），末句展开功能菜单；首版无分支选项（数据结构预留）。
- 世界观提示语在加载界面随机展示，强化沉浸。
