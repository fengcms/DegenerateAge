# 07 地图关卡与怪物

本章定义等距坐标与瓦片、移动 / 寻路 / 渲染、地图加载释放、战争迷雾、怪物模板与派生、怪物清单与掉落绑定、精英词缀、地图清单与车夫拓扑、怪物状态机。Boss 阶段行为见《03 核心循环与战斗系统》3.12。

## 7.1 等距坐标与瓦片

- 2D 等距瓦片地图，地表瓦片 **64×32** 逻辑尺寸。
- 分层储存：地面 / 装饰 / 遮挡 / 碰撞 / 交互 / 出生 / 刷新 / 导航。
- 等距坐标转换：

```
screenX = (col − row) × tileW / 2
screenY = −(col + row) × tileH / 2
```

逻辑坐标统一世界 / 网格，绘制在渲染层转换。

```
等距瓦片俯视示意（菱形）：
        /\
       /  \   ← 单块 64×32 瓦片
      /    \
      \    /
       \  /
        \/
```

## 7.2 移动 / 寻路 / 渲染

- 八向移动归一化、世界速度一致；脚底碰撞体；**禁止 corner cutting**（斜穿两阻挡格角）。
- 寻路：静态通行网格 + 节流（不得每帧为全部怪算路）；动态障碍需更新图。
- 遮挡：动态高物体按脚底 Y / 深度排序；相机平滑跟随，防露边界。

## 7.3 地图加载与释放

- 地图加载：读静态定义、建实体、定出生 / 刷新；离开释放旧场景实体与计时器 / AI 引用，持久化任务 / Boss 信息。
- 入口有解锁条件并提示失败原因。

## 7.4 探索揭示 / 战争迷雾

> M3-3 已实现：按 4×4 格区块持久化，玩家周围 8 格半径揭示；M / 小地图打开大地图，点击当前地图位置步行前往。任务标记可在未探索区域显示，但不会揭示其周围地形。任务面板的击杀目标可沿已解锁道路跨图导航至实际刷新区域（见 08 §8.5）。

- 小地图 / 大地图随玩家探索**逐步揭示**（fog of war）：已探索区域常显、未探索暗显。
- 任务目标点 / Boss 点在接取任务后于大地图**标记揭示**，便于"点击移动 / 跨图寻路"。
- 道路出口与车夫使用不同图标；小地图只显示当前画面内的道路和车夫，大地图从进入地图起显示所有道路出口及其目的地名称（不揭示周围地形），锁定道路带锁提示。

## 7.5 怪物模板字段与派生

定义 `MonsterTemplate`（数据驱动，见《10 数据配置与存档技术》）：

`id, name, tier, level(基准等级), hpBase(基准等级下的HP), mpBase(默认0), attack, defense, attackInterval(s), attackRange(近战/远程+射程), moveSpeed, accuracy(默认0, 点数), dodge(默认0, 点数), resistType(预留), xpReward, goldReward, dropTableId, kind(普通/精英/Boss), specialAttack(CC类型), bossSkill(Boss阶段技能模板), spawnWeight(怪物点内密度)`

> `goldReward` 语义（M1 校准落定）：**仅当怪物未配 `dropTableId` 时的回退值**；一旦绑定掉落表，金币由表中 `coin` 条目产出，模板 `goldReward` 仅供文档对照、不参与结算（见《10》10.2）。

**怪物 HP / MP 派生公式（仅随刷新等级缩放，初始参数）**：

```
monsterMaxHP = max(1, round( hpBase × (1 + M_HP_PER_LV × (spawnLevel − templateLevel)) ))
               M_HP_PER_LV = 0.12（每高 1 级约 +12%）

monsterMaxMP = max(0, round( mpBase × (1 + M_MP_PER_LV × (spawnLevel − templateLevel)) ))
               M_MP_PER_LV = 0.10；mpBase 默认 0（首版怪物仅物理攻击）
```

- 设计要点：怪物 HP **只随刷新等级线性缩放，不耦合攻击 / 防御**——防御已通过伤害公式独立提供减伤（3.2），避免双重叠算坦度。
- `spawnLevel` 受区域等级梯度（7.9）/ 等级差（3.13）影响，可 ≠ `templateLevel`；低等级区复用高基准怪时自然下降。
- 例：裂壳虫 `hpBase=140 @ L3`，刷在 L7 → `140×(1+0.12×4)=196`；刷在 L9 → `140×(1+0.12×6)≈241`。

## 7.7 精英词缀池

随机取 1–2 条（数据可配）：

```
狂暴(攻+30%, 攻速+20%) / 寒霜(攻击附带减速20% 2s) / 坚硬(防御+50%)
迅捷(移速+30%) / 召唤(死亡召2只小怪) / 吸血(造成伤害5%回血)
```

首版做词缀，不做"传奇词缀"深度系统。

M3-4 已落地于 `affixes.json`：每次精英出生随机获得不重复的 1–2 条，名称前缀和金边区分。攻速 +20% 对应攻击间隔 ÷1.2；减速重复命中刷新 2 秒、不乘算叠加，死亡清除。吸血按实际扣血量计算（无敌、未命中无收益），小数累计且不超过满血。死亡召唤两只同等级普通野狼，无独立刷新点，随地图释放。

## 7.8 地图清单与车夫拓扑

**两级拓扑（城镇集群）**：**枢纽城镇** = 具备车夫与完整功能 NPC 的安全区；**附属地图** = 从某城镇辐射出的野外 / 关卡图；**集群** = 一座城镇 + 其全部附属。

```
第一章 · 集群「幸存者营地」
┌──────────────────────────────────────────┐
│ 幸存者营地 (枢纽 · 安全区 · L1)             │
│    ├─ 试炼野外   (附属 · L1–5)             │
│    ├─ 灰烬之地   (附属 · L5–9)             │
│    └─ 腐化源头   (附属 · L10 Boss区)       │
└──────────────────────────────────────────┘
镇间连线：暂无（第二章解锁后连第二章城镇）
免费步行道路：营地 ↔ 野外 ↔ 灰烬 ↔ 源头（相邻图之间）
```

- **车夫可达**：本集群全部地图（城镇 ⇄ 各附属、附属之间**互达**）+ **相邻城镇**；前往其他城镇的附属地图须**先到该镇换乘**。（中转趣味由「图级」上移为「镇级」，取代原"每图仅连相邻 1–2 图"。）
- **免费步行道路**：相邻地图之间沿地图边界的道路出口**免费**往返；靠近可按 E，也可左击出口，远处点击会自动走近并在进入交互范围后通行；未解锁与受阻时明确提示；车夫是**到访后的付费捷径**，金币不足时始终保留步行返程。
- **区域等级梯度**：地图 `tierRange` 约束推荐进入等级；低于推荐仍可进但风险高（配合 3.13 等级差）。

> 口径变更记录（2026-10-12）：车夫拓扑由「每图仅连相邻 1–2 图，需中转」改为**城镇集群模型**（本镇集群内全连通 + 仅连相邻城镇枢纽）。第一章四图同属一个集群，到访后可从营地直达灰烬之地、腐化源头；未到访前仍须步行探索（营地→试炼野外免费教学线例外）。

## 7.9 怪物状态机

```
spawn → idle/patrol → aggro → chase → attack → (return) → dead → respawn
                                  ↑___________________|

dead：结算一次（经验/掉落/任务），不重复
普通/精英：按怪物点刷新时间直接重生
Boss：生成墓碑显示刷新倒计时，倒计时结束重生
超出追击边界 → return（返回）
```

- 三类怪物：普通（密集稳定收益）/ 精英（高血量外观标识 + 特殊攻击 + 优奖）/ Boss（独立血条 + 技能预警 + 阶段行为 + 首通奖）。
- 怪物刷新：地图设**怪物点**，被击杀后按该点配置的刷新时间自动重生。
- Boss 墓碑：Boss 死亡后生成墓碑显示下次刷新倒计时；普通 / 精英无墓碑。
