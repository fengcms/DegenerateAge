# 附录A 术语表

| 术语 | 含义 |
|---|---|
| 护甲 | 原 GDD「服装」；防御向装备槽（1 槽） |
| 护腕 | 原 GDD「护肘」；防御向，2 槽 |
| 如意 | 升星概率道具（铁 / 玉 / 金 / 钻石），仅 Boss 掉落 |
| 灵能 / 裂隙 | 世界观核心（异界裂隙）；预留元素伤害类型 |
| 附属地图 | 某安全区车夫可达的相邻地图集合 |
| 安全区 | 地图内聚集 NPC + 复活锚点 + 回城落点 |
| 怪物点 | 地图上配置刷怪位置，含 resp 时间 |
| 阶位 Tier | 装备 / 等级分段 `floor((L−1)/10)+1` |
| 精英 / 词缀 | 强化怪，随机 1–2 条词缀 |
| Boss 墓碑 | Boss 死亡后显示刷新倒计时的标记 |
| 自动战斗 / 打坐 | 自动刷怪 / 加速回血蓝 |
| 升星 | 铁匠处消耗金币 + 如意提升装备属性，最多 12 星 |
| 经验曲线 | `round(100 × L^1.6)`，无满级上限 |
| 概率 Miss | 闪避对抗模型：`clamp(dodge/(dodge+50),0,0.75)` |
| 硬直 / 无敌帧 | 受击短暂停顿 / 受击后短暂无敌（防围殴控死） |
| 掉落表 | `dropTables.json`，按品质权重生成装备实例 |
| 数据驱动 | 装备 / 怪物 / 任务等全部 JSON 文本可编辑，不硬编码 |
| 模板 / 实例 | 配置模板 ID 与运行时实例 ID 分离，同模板可不同词条 |
| 最小闭环 | 开发落地顺序：货郎经济 → 任务 → 多图 → 坐骑 / 升星 |
