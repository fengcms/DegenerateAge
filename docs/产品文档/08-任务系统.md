# 08 任务系统

本章定义任务生命周期、主线与支线、附属地图定义、放弃 / 重接规则、任务官，以及任务奖励数值。主线任务链内容见《02 世界观与剧情设定》2.5。

## 8.1 任务生命周期

```
locked → available → active → completed → rewarded
                            ↘ abandoned（放弃后可重接，重接后计数清零重做）
```

- `locked`：前置未完成，不可接取；
- `available`：已解锁，可接取；
- `active`：进行中；
- `completed`：目标达成，待领奖；
- `rewarded`：奖励已发放（同击杀只记一次，奖励不重复领）；
- `abandoned`：主动放弃，立即可重接同一任务。

## 8.2 主线 vs 支线

- **主线**：Q001–Q005（见 2.5），线性、推进章节解锁；主线任务**不可放弃**。
- **支线**：任务官发布，以"当前地图及附属地图打怪数量"为主；可轮换。

## 8.3 「附属地图」定义

某安全区地图 M 的"附属地图" = M 的车夫可达相邻地图集合（见 7.8 拓扑）。

```
附属地图(M) = M ∪ carterLinks(M)
```

任务官"当前地图及附属地图"即 `M ∪ carterLinks(M)`，限定任务目标的击杀 / 收集发生在该范围内。

## 8.4 放弃 / 重接

- 进行中任务可放弃（已杀 / 已收集计数清零，怪物点不受影响）；放弃后立即可重接同一任务。
- 同时接取上限 **5 个**；主线任务不可放弃（随章节推进锁定）。

## 8.5 任务官（Quest Officer）

- 安全区常驻，发布 / 检查任务；主要任务为打怪数量（当前地图及附属地图）；满足数量后奖励金币 + 经验。
- 对话框：自我介绍 + 任务列表——
  - 未接受：后方「接受任务」按钮；
  - 已接受未完成：后方「完成」按钮（禁用）；
  - 已完成：后方「已完成」按钮，点击发放金币 + 经验奖励。

## 8.6 任务奖励数值（初始参数）

| 任务 | 击杀 / 收集 | 金币 | 经验 |
|---|---|---|---|
| Q001 守护者苏醒 | 对话引导 | 50 | 0 |
| Q002 初战试炼 | 5 野狼 | 100 | 150 |
| Q003 荒野遗物 | 3 碎片 | 0 | 200 + 护甲 |
| Q004 精英踪迹 | 1 狼王 | 200 | 400 + 装备 |
| Q005 腐化源头 | 1 巨兽 | 500 | 1000 + 解锁 |

支线任务奖励由数据配置驱动，按"击杀数量 × 单位奖励"生成，与主线保持同一数值框架。

## 8.7 补充口径（M2 实现确认）

> 以下为 8.1–8.6 在 M2 落地时确认的边界口径，用于消除歧义；实现细节见工程文档 11。

- **状态与存档（对应 8.1）**：`locked` / `available` 属**推导态**（由 `prev` 前置链决定），不作为玩家数据存档；
  存档只记录玩家实际产生过的状态（`active` / `completed` / `rewarded` / `abandoned`）。
- **单图期的目标范围（对应 8.3）**：第一章开发期只有「幸存者营地」一张图，Q002–Q005 的击杀 / 收集范围
  暂时限定在营地；接入多图后恢复为 `M ∪ carterLinks(M)`。
- **Q001 的「交谈」目标**：与长老交谈**在接取任务的那一刻即视为完成**（避免"同一句话听两遍"的绕路），
  任务列表随即显示可领奖；奖励仍由玩家点击领取。
- **支线示例**：为验证 8.2 / 8.4 的放弃与重接机制，M2 附两条固定支线（清剿巢穴 / 补充药剂）；
  **自动轮换生成**仍留待后续（M4/M5）。
- **同时接取上限（对应 8.4）**：上限 5 只统计 `active`（进行中）；`completed` 待领奖的任务不占名额。
