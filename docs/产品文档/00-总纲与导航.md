# 《末法纪元：最后的守护者》产品文档（基线 v1.0）

## 文档目的

本文档集是《末法纪元：最后的守护者》的产品需求基线，是后续技术选型、工程实现与验收的**唯一权威来源**。所有设计决策均已最终确定，开发团队可直接据此开展工作。

本文档集整合并取代了此前的设计草案（`docs/产品需求梳理.md` 及 `docs/history/` 归档稿），所有开放性议题均已收敛为确定结论，不再保留讨论过程。

## 文档约定

- **文本图**：关键系统、布局、流程以 ASCII 文本图表达，便于在任意编辑器中阅读与评审。
- **初始参数**：文中所有数值表标注的"初始参数"为设计起始值，将在试玩校准阶段依据"击杀耗时 / 升级耗时 / 掉落统计"三项度量调优后定稿；调优只改变数值大小，不改变系统结构与机制。
- **术语**：统一见《附录A-术语表》。
- **技术栈已定**：采用 **Godot 4**（GDScript 起步，必要时切 C#）作为游戏引擎（R3 决策，2026-10-11）。产品需求机制与引擎解耦，第 10 章配置 Schema 与机制在 Godot 4 下直接落地；选型依据与工程准备见《12-技术栈选型与工程准备》。

## 游戏概述

**一句话定位**：在末法时代的人类失地上，扮演一名能吸收异族灵能的守护者，探索斜角地图、实时战斗、打宝成长，逐步解锁地图与技能、击败章节 Boss、最终关闭异界裂隙。

**一段话描述**：本作是一款 **2D 等距斜角（isometric）、单机、实时战斗、打怪升级（ARPG / Diablo-like）** 游戏。首发平台为 **macOS**（桌面端，键鼠操作）。商业模式为**买断制优先、可能免费分发**，全产品**无联网、无账号、无抽卡、无氪金内购、无 PvP、无交易市场**。玩家在斜角地图上探索、与怪物实时战斗、拾取经验与掉落、升级并穿戴更好装备，挑战精英与 Boss，解锁下一区域，循环成长。

## 核心循环（总览图）

```
        ┌─────────────────────────────────────────────┐
        │                  探索地图                     │
        │   （新地图 = 新敌人 / 新资源 / 剧情 / 阶段目标）  │
        └───────────────────┬─────────────────────────┘
                            │ 发现怪物 / 接取任务目标
                            ▼
                   ┌───────────────┐
                   │   战斗         │ ← 手动 / 自动 (F + G)
                   │  (实时 ARPG)   │
                   └───────┬───────┘
                           │ 击杀
           ┌───────────────┴────────────────┐
           ▼                                 ▼
     ┌─────────────┐                  ┌──────────────┐
     │  掉落        │                  │  任务进度      │
     │ XP/装/药/金  │                  │ (击杀/收集)    │
     └──────┬──────┘                  └──────┬───────┘
            ▼                                  │
     ┌─────────────┐                           │
     │ 拾取 / 使用   │                           │
     │ 换装 / 嗑药   │                           │
     └──────┬──────┘                           │
            ▼                                   │
     ┌─────────────┐                            │
     │  升级 / 成长  │←──────────────────────────┘
     └──────┬──────┘
            │ 变强 → 挑战精英 / Boss
            ▼
     ┌──────────────────┐
     │  解锁下一区域       │ → 回到「探索地图」（更大世界）
     └──────────────────┘

经济侧：金币 ──买药 / 支付升星费──→ 货郎 / 铁匠 ；Boss ──掉落──→ 如意；装备 ──卖货郎──→ 金币
出行侧：车夫跨图 / 随机券 / 回城卷 / 复活卷
```

每个循环节点都具备明确反馈：命中 / 受伤动画、浮动伤害值、经验提示、物品掉落、装备对比、升级特效、Boss 奖励及地图解锁提示。
