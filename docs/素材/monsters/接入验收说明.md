# 四只怪物八向动画接入验收

接入日期：2026 年 10 月 14 日。裂爪狼王、灰烬怨灵、裂壳虫卫、腐化巨兽已使用正式 PNG 动作图集替代旧的程序造型，原有普通狼、普通裂壳虫、灰烬游魂和木桩继续使用既有美术。

[游戏实机截图](接入验收/游戏实机.png) · [验证结果](接入验收/验证结果.json) · [原始八向动作交付说明](八向动作交付说明.md)。截图使用主游戏场景和 HUD，将四只怪物集中放在试炼野外进行审阅。

## 实际接入行为

- 静止与移动分别播放待机、行走图集；根据屏幕运动向量选择八个方向。
- 普通攻击沿用即时伤害结算，动画从命中姿态开始播放收势；动画不会再次触发伤害。
- 受击播放独立的短受击动作。Boss 践踏预警及狂暴咆哮期间保持对应动作，受击不打断关键表现。
- 践踏蓄势直接读取 Boss 的真实预警剩余时间；预警结束才切到落地姿态，原有警示圈和伤害判定保持一致。脱离警示圈仍可躲避。
- 进入第三阶段播放狂暴召唤动作；若此时正在践踏，会在践踏恢复后播放咆哮。攻速变化和召狼仍由原 Boss 行为负责。
- 死亡立即结算经验、掉落、首通、任务与刷新计时，完整播放 0.7 秒死亡动作后，再用 0.35 秒淡出移除。死亡怪物关闭碰撞，不参与战斗，也不会在播放尸体动作时阻挡角色。
- 保留精英身份标记、名称、血条和 Boss 选中圈，按新贴图高度移动头顶信息；鼠标点击范围覆盖新贴图画布。
- 存活时的碰撞形状、怪物属性、AI、攻击射程、掉落概率和任务流程没有因贴图而调整。

## 正式资源与重建

正式图集和动画配置位于 assets/sprites/monsters/四个怪物 ID 目录，包含 22 张图集。scripts/entities/monster_actor_art.gd 控制动作，scripts/entities/monster_animation_library.gd 是生成的纹理注册表；静态 preload 引用确保导出的游戏包含全部纹理，不依赖 docs 下的制作素材。

从源素材重建使用 tools/build_monster_animation_assets.mjs。此工具复制已有 PNG 图集，生成运行配置与纹理注册表，不调用图片生成服务。

## 测试结果

MonsterAnimationTest、BossReviewTest、SkillCombatTest 和 ChapterOneAcceptance 通过。专用动画测试覆盖八向移动、停止、攻击无额外伤害、受击、头顶点击、践踏预警与落地、狂暴咆哮、完整死亡到实体移除；同时使用有图形窗口的主游戏场景验证了实际渲染。

ChapterOneArtTest 与 ArtSampleTest 仍有原有失败，分别是木桩血条位置断言与主角缩放断言。在未包含本次改动的已提交快照上重跑，得到同样的失败。未改动这两个既有断言或对应美术。

测试运行在随机命名的独立 Godot 项目与 user 目录，审阅场景关闭自动存档，不使用玩家已有存档。

重跑完整独立快照验收使用 tools/run_monster_animation_acceptance.py，添加 --capture 参数会同时生成游戏实机截图。该工具从最新提交取稳定代码，仅叠加本次怪物资源、控制器和测试，隔离其他尚未提交的界面修改。
