# 幸存者营地 A/B 样板源图

八张 PNG 为本任务通过 OpenAI ImageGen 制作的 A/B 局部试作原图：铁匠铺、货郎摊、长老树、夯土地纹各两张。`western_rocks_b.png` 是后续为 B 方案精修生成的整体岩带源图。独立物件保留真实透明背景，地纹用于可重复的透明局部底图；它们只用于 `tools/build_camp_style_sample.py`，尚不是正式营地定稿。

使用条件：项目内美术试作。生成日期：2026-10-16。派生运行资源见 `assets/maps/camp_style_sample/`，裁切、尺寸、图层和坐标以生成器及相邻清单为准。A/B 为同场景的视觉与分辨率对照，不能单独拿一张全图贴到正式营地。
