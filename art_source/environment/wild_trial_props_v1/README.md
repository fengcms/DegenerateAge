# 试炼荒野岩脊和残车源稿

本项目使用内置 imagegen 生成两张独立透明源稿。输入参考为项目原有岩脊和残车，只取画幅方向、相机角度和占地关系，完整提示见各自的 `_prompt.txt`。

`tools/art_pipeline/build_wild_trial_props.gd` 读取本目录 PNG，裁掉透明边并缩放至原有运行画幅，输出到 `assets/tiles/chapter1_v2/wild_trial/`。在独立 Godot 项目中用 `--script <构建脚本绝对路径> -- <仓库绝对路径>` 运行。原始 alpha 在缩放中保留。

| 物件 | 运行图片 | 画幅 | 脚底锚点 |
|---|---|---|---|
| 岩脊 | moss_ridge_modular.png | 188×182 | (94, 178) |
| 残车 | broken_cart_modular.png | 180×177 | (90, 173) |

地图保持原有纹理过滤、实例比例和世界 Y 排序。17 处岩脊共用一张纹理，残车共一处。两图理论 RGBA8 总量 264,304 字节，与被替换的同画幅纹理一致。地图退出时释放本图纹理引用。地图运行清单和碰撞多边形保持原样。
