# 模块化营地写实首批源稿

2026-11-17。用户已认可style_pilot_20261117的风格。本批使用内置image_gen生成独立材质和物件，没有生成或加载整张地图。

prompts.json记录首批提示词：soil/road为俯视平光低对比周期材质；wall/tree/shelter为正交斜俯视透明单体。参考图只用于风格。源图不直接进入样板运行依赖，Godot构建脚本负责投影、缩放和图集打包。

wall.png是过长候选，缩到单格后墙体高度不足，保留用于追溯；wall_short.png是定向修订稿。修订要求：同种旧灰石，两块石料长度、四层石高，实际约0.8米长、1米高、0.3米厚，近方形轮廓，沿左下至右上斜率-0.5，干净接头，无柱、地板和投影，透明背景。只有短墙进入运行资源。

树与棚屋暂为整体单体，不把外轮廓等同为精确碰撞；棚屋阻挡调整为4×4格用于本阶段测试，屋檐和入口精修另验。不得因图片好看就标记为完整地图接入。
