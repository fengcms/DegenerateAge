# 营地补给物件 V1

内置image_gen生成原创旧木箱与木桶，提示词见prompt.json。source.png为1536×1024素材页，两件物体独立分离；它不是地图背景。build.json记录各自裁切区域、输出宽度和源图地面接触区中心。

运行素材位于assets/environment/camp_modular_v1：木箱60×51、pivot(30,34)，木桶44×51、pivot(22,44)。从同一源稿分别裁切缩放，不改变现有64×32地砖规格；源图不进入运行项目。锚点由生成manifest统一提供给样板，不能一律取图片底边。木桶显示底座小于一个格子，导航保留一格储物占地（约10px侧向安全余量）；并不声称逐像素碰撞。

两套layouts.json使用不同摆放，木箱替换旧占位图；旧正式素材不覆盖。每套新增一个木桶的单格静态障碍，按同一布局生成导航与碰撞，B可检查。物件无开箱、拾取或其他游戏逻辑。
