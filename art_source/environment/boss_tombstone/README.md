# Boss 死亡墓碑样图说明

本轮仅供确认造型，不接入游戏。主图为 `tombstone_64.png`；同屏、六倍和倒计时状态预览分别在 `docs/素材设计/样板/Boss墓碑样图/` 的 `preview_at_scale.png`、`preview_x6.png`、`preview_states.png`。

## 造型与像素规格

- 直立的冷灰紫石碑：折角拱顶、左右短护柱、矮基座。左右破损略不对称，中心保留整块平整、无字的碑面，未来可另加名字或编号。
- 画布 **64×64 RGBA**，实像素包围盒约 **50×53**（`x=7…56, y=10…62`）；脚底锚点建议 **(32,62)**，底部两行用不透明深色像素做接地阴影。碑体不作等距菱形压扁。
- 颜色严格收敛为七色：`#272633`、`#343442`、`#4a485a`、`#605d70`、`#777486`、`#9692a0`、`#b6b1bb`；另有全透明像素。所有 alpha 仅为 0 或 255，没有羽化边。源图没有橙色、金色或文字。
- 用内置 imagegen 生成造型参考，再按比例等比缩小、最近邻取样、硬阈值透明和固定调色板量化成 64×64；没有横向或纵向单独拉伸。六倍图也只用最近邻放大，不增添绘画细节。

## 比例、文字和状态

`preview_at_scale.png` 以世界像素 **1:1** 合成当前游戏的 Boss、墓碑与玩家：Boss 用 `boss_corrupted_beast/idle_atlas.png` 第一帧，帧格 192×192、显示倍率 1；玩家用 `look_06_idle_atlas.png` 第一帧，资源帧格 64×80、当前 `ART_SCALE=1.5`，因此按 **96×120** 显示；墓碑按 64×64、倍率 1。三者脚底对齐。任务书中的玩家 128×80 与当前图集实际尺寸不同，预览按当前运行资源与代码倍率制作。中性暗地面仅供对比，不伪装成某张正式地图截图。

金色 `#f2cc71` 的 `Boss 刷新 MM:SS` 只在预览图中模拟代码实时文字，置于碑体上方并居中；`tombstone_64.png` 完全不含这些字。`preview_states.png` 的 10:00 与 00:10 **只改倒计时文本，石碑像素完全相同**；本轮不另加发光、变色或复活动效。

以实像素包围盒比较，Boss 第一帧约 102×108、玩家在当前倍率下约 27×72、墓碑约 50×53。墓碑明显矮于 Boss，也比玩家略矮，碑面在 1:1 图里仍可辨认，因此判断 **64×64 足够**。不制作 96×96 备选：那会让碑体高度接近当前 Boss 可见体量，并增加像素占用与遮挡，不利于地标和战斗主体分层。

需要用户确认的是：这版折角拱顶加双护柱的造型、64×64 与 Boss/玩家的相对比例、以及倒计时置于碑体上方的观感。确认前不接入游戏。
