# Boss 死亡墓碑素材说明

`tombstone_64.png` 是源稿；相同像素的运行图位于 `assets/sprites/environment/boss_tombstone.png`，由 `scripts/entities/boss_tombstone.gd` 绘制。`docs/素材设计/样板/Boss墓碑样图/` 保存同屏、六倍和倒计时状态预览。

## 造型与规格

- 冷灰紫石碑保持直立，但绕竖轴转向：碑面、右侧厚度和斜向底座构成游戏 45 度视角。碑面留白，无固定刻字。
- 画布为 **64×64 RGBA**，实像素范围约 `x=10…53, y=6…62`，脚底锚点 **(32,62)**，底部深色像素作为接地阴影。运行时将纹理绘制在节点局部坐标 `(-32,-62)`，使碑脚落在刷新点位置。
- 七色像素调色板为 `#272633`、`#343442`、`#4a485a`、`#605d70`、`#777486`、`#9692a0`、`#b6b1bb`，另有透明像素。Alpha 只有 0 或 255，无矢量描边、羽化、橙色或金色。
- 用 imagegen 根据已确认的正面样图生成斜向造型参考；再等比缩至 56×56，以最近邻取样、硬阈值透明和固定调色板量化，并放在 64×64 画布内。六倍预览仅做最近邻放大。

## 游戏接入与预览

刷新点仍负责墓碑创建、定位和销毁；墓碑只绘制共享纹理及实时倒计时。纹理采用最近邻过滤，倒计时继续由代码以 `#f2cc71` 绘制在碑顶上方，秒数变化时才重绘。没有改变 Boss 刷新时间、碰撞和存档数据。

`preview_at_scale.png` 以世界像素 **1:1** 合成当前游戏的 Boss、墓碑与玩家：Boss 取 `boss_corrupted_beast/idle_atlas.png` 第一帧，帧格 192×192、倍率 1；玩家取 `look_06_idle_atlas.png` 第一帧，帧格 64×80、当前 `ART_SCALE=1.5`，因此按 96×120 显示；墓碑按 64×64、倍率 1。三者脚底对齐。预览中的暗地面只供比例对比，并非正式地图截图。

`preview_states.png` 的 10:00 与 00:10 只改变模拟倒计时文字，墓碑像素完全相同。素材在 1:1 下比 Boss 明显矮，碑面仍可辨认；**64×64 足够**，无须放大运行纹理。
