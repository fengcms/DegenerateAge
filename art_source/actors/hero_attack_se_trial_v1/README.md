# 主角右前挥剑四阶段试装

candidate.png由内置image_gen参考右前站姿生成，四阶段分别为抬剑蓄力、向前下劈、低位收势和复位。首稿边缘alpha检查失败，不进入运行；通过背景提取生成candidate_alpha_v2.png后通过。完整生成和提取提示词见prompt.json、alpha_prompt.json。

build.json为唯一打包事实源：2048×768源页，四列512×768，统一0.13缩放、源锚点(275,735)，运行帧112×128与共用锚点(56,112)。源稿不逐帧吸附脚底，剑尖保留，四边逐像素alpha须小于0.05。

阶段时长0.18/0.09/0.15/0.18秒，总计0.60秒。visualContactFrame=1仅表示视觉下劈参考，未连接伤害或正式角色事件。隔离营地T键原地展示，移动取消、H关闭取消、切图释放，播放中重复触发不重置。还缺其他方向攻击、受击与死亡，衣物和站走比例需持续精修。
