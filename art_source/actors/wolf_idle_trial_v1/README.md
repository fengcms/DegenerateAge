# 腐化狼四帧警戒待机试装

内置image_gen以原腐化狼源稿生成，完整提示词见prompt.json。candidate.png为1536×1024、2×2布局；review.json用于固定锚点审片，build.json用于运行打包。源格768×512、倍率0.16、源锚点(384,460)，输出128×96帧格、(64,80)落点的一列四帧图集。

三帧每秒，头颈轻抬、露齿再回落；没有移动、攻击或伤害事件。四足仍有数像素级漂移，轮廓相较原图稍高，仅隔离样板试装。未逐帧重缩放、吸附足尖或用代码形变造帧。透明角与棋盘底审查通过，不能据少量透明点宣称全图alpha完美。J可恢复原静态图；正式怪物外观不变。
