# 初始主角腐化之翼

内置imagegen生成。参考已验收主角身份和旧腐化之翼概念，不沿用旧Q版比例。idle_source_v2.png为修正朝向后的四列两行八向待机，walk_source.png为四列四行的两拍移动：前两行第一拍，后两行第二拍。方向s/sw/w/nw/n/ne/e/se，不镜像。第一版待机重复朝向，未接入并移出项目；原输出仍保留于生成工具默认目录。

运行单帧128×128，脚锚(64,112)，主体高96像素。待机一帧、移动两帧，是简化步态而非完整飞行周期。使用build_turntables.gd和turntables.json复建。运行播放按各坐骑声明帧数，旧look_06四帧骑乘不变；速度、收藏与骑乘等级规则不变。上下骑乘保持原即时切换，没有虚构未制作的上下马中间帧。

完整生成与修正提示见三个prompt.txt。源稿与运行资产分离，透明度经编译检查。主角攻击、受击、死亡沿用原非骑乘状态表现规则。
