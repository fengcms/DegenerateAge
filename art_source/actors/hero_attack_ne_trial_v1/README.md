# 主角右后挥剑四阶段试装

内置 image_gen 参考项目原创右后站姿生成 candidate.png，完整提示词见 prompt.json。背面右上视角、右手持剑、左手空，四阶段为抬剑、前劈、低位收势、复位，不镜像。仅供隔离样板，未接正式战斗。

build.json 按实际 1254×1254 源稿登记 627×627 两行两列，统一缩放 0.15、源锚点 (315,610)。运行帧 112×128、锚点 (56,112)，纵排 112×512，共 224 KiB RGBA8。阶段时长沿用右前 0.18/0.09/0.15/0.18 秒，总计 0.60 秒。

透明预览中的红色大片主要位于低 alpha 区域。只读逐像素统计源稿红色条件 r>0.7、g<0.3、b<0.3 的 3149 个像素，最高 alpha 为 0.015686；运行图集同条件 39 个像素，其中 2 个 alpha 高于 0.05，最高 0.14902。实际场景未见预览中的大片红色，仍保留轻微低 alpha 彩边精修项。尝试重提透明未改善，短围巾版改变服装设计，均未采用；没有用这些变体覆盖候选稿。

4 键播放右后挥剑，T 保持右前；结束回各自站姿，移动或 H 取消，受击/倒地沿现有优先级打断。重建：`python3 tools/modular_camp/launch.py --build-assets`。
