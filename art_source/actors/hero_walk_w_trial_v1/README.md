# 左侧站走试装

内置image_gen参考八视角工具的w骨架与同角色身份图生成，完整提示词在prompt.json和idle_prompt.json。candidate.png因近侧左手出现多余短刃、左腰误带右腰包而拒绝；candidate_fixed_v2.png定向修正，近侧左手空、腰包移出近侧，只有远侧右手持剑。

源行走2048×768、四列512×768，统一缩放0.135、源锚点(260,715)；独立站姿1024×1536、缩放0.065，源锚点按脚底统一标定（见../hero_walk_pilot_v3/build.json的extraIdleSources）。运行帧112×128，共用(56,112)锚点。没有镜像其他方向或逐帧吸附脚底。

仅供隔离营地。动作仍是四帧简化试装，步幅、衣物跳变与俯视角一致性需精修；接入方向不代表最终美术认证，也不代表其他攻击状态已齐全。
