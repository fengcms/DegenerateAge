## 制作描述

原创东方末法幻想二维等距ARPG局部样板；固定正交斜俯视，2:1地面轴，无地平线与景深。左上旧木灰石棚屋、瓦屋顶与暖灯，右上古树与残石墙，中央夯土道路、自然碎草碎石路缘。主角成年男性约七头身，黑发、沙色围巾、旧铁灰石甲、原创断环标志、右手实用长剑；腐化灰狼有厚重肩背与少量紫裂纹；低伏铜甲节肢虫有分节甲壳与少量紫色寄生组织。统一左上柔光、接触阴影；炭灰、泥土、灰绿、旧铜为主。预渲染精灵写实材质，无Q版、动漫脸、塑料感、低多边形块面、粗黑边、像素方块、霓虹、UI、文字或现有游戏资产。请求人物约115像素高、狼110像素长、虫100像素长，保留清楚通行空地。

## 目视检查与限制

- 营地、人物、两类怪物均出现；布、铁、木、石材质与光向基本统一；土路没有旧样板连续硬色带。
- 实际输出未遵循要求的对象像素尺寸，主角约三百像素高；视角也需要在工程中以投影校准物进一步校准。因此只验收风格与造型，不能验收运行比例。
- 未生成独立透明精灵、八向连续动作或可平铺地砖；不能把本图直接替代有碰撞和遮挡的正式地图。
