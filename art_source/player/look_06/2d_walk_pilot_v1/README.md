# look_06 二维行走首轮小样

2026-10-25。以已确认角色与八向站立母版为身份参考，使用内置 image_gen 生成并修正 `sw` 单方向静态和行走候选。本目录为审稿样片，**动作未通过验收，不属于可接入素材**。不生成其他方向或怪物。

## 查看顺序

1. `static_comparison.png`：原画、静态候选、现有与候选的 4 倍像素对照。
2. `walk_comparison.gif`：左为现有行走，右为候选，均 10 FPS；另列原尺寸和玩家 1.5 倍尺寸。
3. `walk_contact_sheet.png`：候选八帧逐帧板。
4. [评审记录](../../../../docs/素材设计/look_06二维行走小样首轮评审-2026-10-25.md)：问题与下一步判断。

## 文件与来源

| 文件 | 用途 |
|---|---|
| `static_sw_source.png` | 选定的静态生成原图，保留原始 RGBA |

| `static_sw_64x80.png` | 静态候选的运行尺寸审稿帧 |
| `walk_sw_review_strip.png` | 64×640 的单方向审稿条，时间从上到下；不是正式八向图集 |
| `walk_comparison_still.png` | 动图首帧静态备份 |
| `metrics.json` | 固定尺度、排版注册点、alpha 门槛与帧格检查结果 |
| `prompts.json` | 本轮七次内置 image_gen 调用的完整提示词；淘汰图没有入库 |

没有引入第三方角色素材。静态源图以 `idle_8dir_master.png` 第二列裁片为编辑参考；行走源图经过整表修正及反侧承重姿势参考迭代。生成调用无法保证逐像素复现，下面的审稿构建可以从保存的两张原图确定性重建。

## 重建与边界

在仓库根目录，用装有 Pillow 的 Python 执行：

```bash
python3 tools/player_2d/build_look_06_walk_review.py
```

工具输出仅覆盖本目录审稿文件。行走全序列采用同一缩放系数 `48/440`；两排分别使用固定源注册点 `(198,480)`、`(198,448)` 修正生成图的排版偏移，不逐帧缩放或按包围盒重新定位。源注册点不是经验证的脚掌接地点。输出按既有构建器使用 alpha ≥153 的实像素门槛，原图透明度不变。

帧格 64×80、参考锚点 `(32,64)`，8 帧、10 FPS。八帧像素不同、没有触及帧格边缘，只说明文件检查通过；腿部交替、动作连续性与身份一致性仍不合格。本轮未做实地图移动验收，也未改 `assets/`、角色登记或战斗逻辑。
