# 折光观测偶八方向试玩稿

使用内置 `image_gen` 参考 `concept.png` 和已生成的方向图，分别制作南、西南、西、西北、北、东北、东七张透明单体；东南向沿用原运行图第一格。造型锁定巨型银白观测镜、深绿缠藤、灰白石腿、悬挂小镜、破红布与苍绿菌。西南和东北方向曾出现暗色背景，最终版本以干净方向图为参考重新生成。逐方向检查朝向与透明边缘，未用镜像代替反侧。

`directional_preview.json` 记录七张源图及 112×112 帧、脚底 y=88 的构建参数。执行 `godot --headless --path . --script tools/build_monster_directional_preview.gd -- --id=c4_elite03` 可重建运行图集。可在第四章 `c4_map02`「失声哨林」目视检查转向、镜体识别、受击与死亡变色。东南向沿用旧图，体量略小于新方向，是试玩稿限制；正式五状态逐帧动画仍待制作。
