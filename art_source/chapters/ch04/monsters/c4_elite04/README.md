# 白孢母体八方向试玩稿

使用内置 `image_gen` 参考 `concept.png` 制作南、西南、西、西北、北、东北、东七张透明单体；东南向沿用原运行图第一格。造型锁定白红多层菌冠、蜂窝状白腹、深绿缠藤、石包巨臂、白色孢球和破红旗。西北方向两次生成带暗色背景，最终改为无参考图重画，并逐方向检查透明边缘与朝向；该方向菌冠与石臂细节和其他方向有轻微差异，作为试玩稿限制保留。

`directional_preview.json` 记录七张源图及 112×112 帧、脚底 y=88 的构建参数。执行 `godot --headless --path . --script tools/build_monster_directional_preview.gd -- --id=c4_elite04` 可重建运行图集。可在第四章 `c4_map03` 目视检查转向、菌冠识别、受击与死亡变色。东南向旧图体量略小；正式五状态逐帧动画仍待制作。
