# 物品运行图标

本目录的 16 张 48×48 透明 PNG 来自 `docs/素材/icons/items/` 的同名交付图；仅复制 48 像素运行版本，96/256 像素审阅图保留在素材目录。图标由 `SampleArt` 按稳定物品 ID 预载，背包、仓库、快捷栏和地面掉落共用；地面绘制缩至 32×32，使用最近邻过滤。金币只在地面显示图标，不进入背包。

已有的 `*_ground.png` 是早期样板的 32 像素地面图。正式药水与灵能碎片现使用同名 48 像素图；旧地面文件留作历史素材，不再由 `SampleArt` 引用。`weapon_starter_ground.png` 继续供初始武器使用。

美术来源、提示词与生成方式见 `docs/素材/README.md` 及 `docs/素材/sources/generation_manifest.json`；运行图无需独立授权变更。新增物品时先确认数据 ID，再提供同名 48 像素图并更新 `SampleArt` 与图标集成测试。
