# 营地模块化写实首批运行素材

来源为 `art_source/environment/camp_modular_v1`，内置image_gen原创生成。构建入口 `python3 tools/modular_camp/launch.py --build-assets`。正式地图尚未引用；隔离样板通过launch.py复制本目录。

- terrain_atlas.png：1024×1536，RGBA8理论6MiB，不含导入压缩和mipmap；16列为4×4材质相位，48行为基础地面与47种道路连接。每格64×32。不能随机打乱相位，否则材质共边不连续。
- 每格由同一256×256周期母版映射到等距地面。母版对向8px边带共同收口，运行不加载源稿或整幅地图。此过程只做技术投影/接缝处理，没有从概念图切地图。
- tree.png、shelter.png、wall.png为独立透明物件；实际尺寸及临时底部中心锚点见manifest.json。墙使用wall_short源稿，长墙候选未接入。
- 图集使用nearest过滤防止紧排图集串色；物件按现有精灵过滤显示。后续如切换图集线性过滤，需要增加挤出边和UV内缩。
- 当前只含一个墙轴方向，缺另一轴、转角/端帽、树冠分层、屋檐分层、草土族和贴花，不能称完整营地素材包。

## 第二批：草土过渡与双轴墙

- grass_atlas.png：同为1024×1536，共16相位×48行。首行为备用土底，其余为47种草土覆盖。两张图集理论RGBA8合计12MiB，不含物件、导入压缩、mipmap及驱动内存。
- 草土使用较宽的共边渐变，道路仍保持原有较窄渐变；两套规则均测试连接边alpha连续。草层独立合批，顺序为土底→草→路，实例数据禁止草格覆盖道路格。
- wall_other.png为另一轴向真实生成稿，wall_corner.png为一个前向L角，均为58×56。没有镜像现有贴图，仍沿原脚底世界Y排序与单格占地。当前角件不能替代其他三个朝向，端帽亦未完成。
- 更新范围只限隔离样板；不表示正式地图接入。第一批说明中的“一个轴向/缺草土族”属于历史状态，已由本批扩展。

## 第三批：地面贴花

decals_atlas.png为256×64，两个128×64槽分别为roots和gravel，主体限制96×48以内并留透明间隔。RGBA8理论64KiB。仅作为静态地面细节，无碰撞和独立更新节点。每布局12实例，合为一个网格，位于道路上方、所有角色物件下方。源稿及提示词见源目录prompts_decals.json。

树/棚屋本批没有修改图片；隔离样板通过高度蒙版shader实现上部局部淡出，不等价于已经交付精确分离的树冠、树干、屋顶和屋檐素材。

## 第四批：轮廓保护蒙版

新增tree_reveal_mask.png（452×230）、shelter_reveal_mask.png（392×200），尺寸与对应物件一致。白色为可淡出区域，黑色为保护区域。来源为tools/modular_camp/occlusion_regions.json人工多边形，由同一构建工具生成；无需重新生成或改变原画。主干、根部、墙体、门柱保持不透明；冠层、屋顶与棚布仅在遮住角色时局部淡出。替代上一批高度蒙版近似，仍不是分层美术包。

两张RGBA8蒙版理论显存合计729440字节（约0.70MiB，不含导入和驱动开销），shader增加一次蒙版采样。运行端缓存蒙版图像替代旧原图alpha缓存，切换布局释放旧物件及其材质/图像引用。未测量完整游戏GPU帧耗，不承诺大地图性能。

## 独立补给物件

crate.png为60×51，barrel.png为44×51，各自地面锚点由manifest.json记录；源稿、提示词和构建参数位于art_source/environment/camp_supplies_v1。理论RGBA8合计20,400字节，原稿不加载。仅模块化样板引用，正式旧木箱不覆盖。木箱使用地面接触中心(30,34)，木桶(22,44)，不能按最低像素统一落地；样板保持一格静态存放区，木桶视觉较窄有保守余量。

2026-11-19：正式营地通过 CampModularArt 使用地面、草地图集，复用棚屋/树木及遮挡掩码。模块不携带NPC或战斗逻辑；原整体碰撞轮廓由正式布局负责。正式使用的图集和导入设置随仓库提交。
