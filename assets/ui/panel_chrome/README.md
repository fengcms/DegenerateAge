# 统一面板按钮素材

这组 SVG 是可伸缩操作按钮和标题圆钮的运行素材，不包含按钮文案。颜色、渐变、上沿高光与环形按钮的层级依据用户确认的 `docs/素材设计/样板/统一面板UI-v1/01-背包与人物浮窗.svg` 制作；各交互状态沿用同一视觉结构。执行 `python3 tools/generate_panel_chrome_assets.py` 可重新生成。操作按钮由 `PanelChrome` 以九宫格方式拉伸，标题按钮保持正方形。

Godot 的对应 `.svg.import` 将 `svg/scale` 设为 2.0，使 200% 界面倍率仍有足够的源像素；切片端部不参与横向拉伸。修改尺寸或路径后需重新导入并检查 80% 至 200% 的实际显示。
