# 幸存者营地 B 第二版运行素材

运行入口为 `manifest.json`。用 `python3 tools/build_camp_style_full_b_v2.py` 重建，依赖 ImageMagick 和标准库。地面由 1024×1024 原生像素裁片镜像为 2048×2048 循环纹理；道路是 1672×941 的真透明零散铺石层，不再使用大面积模糊笔刷。围栏在源图去除低 alpha 噪点后使用最近邻缩小与模块拼接，只保留训练场四段。每个保留障碍仍是一张整体图和一个对应碰撞多边形。

布局唯一事实源为 `data/map_art/camp_whitebox_v2.json`：7 个整体实体、4 段训练场围栏。地图尺寸、NPC 与出入口不在此清单里重新定义。房屋、树和摊位复用已认可的 B 素材；马车及中央灯仅改运行尺寸与前后分层，源图不拉伸成不符原始宽高比的形状。
