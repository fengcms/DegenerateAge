# 幸存者营地正式美术 v1

本目录是正常游戏使用的矩形营地运行素材：一张 `1672×941` WebP 环境底图、六张从同一底图提取的带透明边整体实体前景，以及定位清单 `manifest.json`。前景按实体接地位置排序，用来在角色走到建筑或树冠后方时遮挡角色；纹理本身不决定通行，碰撞与寻路继续来自 `data/map_art/camp_whitebox_v1.json`。

源稿是 `art_source/environment/camp_final_v1/clean_plate.png`。它以已确认的 `docs/游戏创意/第一章地图视觉设计稿/幸存者营地-v1.png` 为参考，使用内置 imagegen 两次定向编辑：先移除所有静态人物和三只概念木桩，同时保留建筑、道路、围栏、东门与训练场开口；再清理镇灵灯左下方残留人物。运行文件由 `python3 tools/build_camp_final_art.py` 使用 ImageMagick 重建，WebP 质量 93，前景从同一 WebP 解码图抠取，以减少遮罩边缘的色差。不要手工修改生成图片或定位清单。

这些图像属于同一张原画的分层表现；六个前景分别为铁匠棚、仓库、货郎摊、镇灵灯、长老树和马车。训练木桩由游戏中的怪物实体绘制，不烘焙在环境图里。该底图约 640 KiB，六张透明前景合计约 960 KiB；解码、纹理上传与实际窗口帧成本以实机测试为准。
